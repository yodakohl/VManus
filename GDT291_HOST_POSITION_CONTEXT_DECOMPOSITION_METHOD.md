# GDT291 — host-position omitted-context decomposition

## Question

GDT289 and GDT290 show that the GDT286 exact `host × field-position`
increment is not captured by one universal transition or by 2/4/8 opaque host
classes.  Before calling it lexicalized or high-capacity, test whether GDT286
omitted known record and non-wrapper compiler coordinates that account for the
interaction.

This is a formal renderer decomposition.  It does not assign any function or
meaning to a host, wrapper, right family, closure, or record position.

## Frozen population and holdout

Use the same eight f84-free 8,448-event panels as GDT286--290.  Predict the
frozen wrapper class with one complete physical folio held out.  No earlier or
later target-page wrapper outcome enters any model.

## Frozen hierarchical models

Every layer uses Dirichlet-1/2 global smoothing and a fixed 11-event prior from
the immediately preceding layer.

1. `SHAPE_CONTEXT`: section, Currier, hand, register, within-field position,
   host length, first host character, last host character.
2. `RECORD_CONTEXT`: add record-ordinal bucket `1/2/3-4/5+`, field-ordinal
   bucket `1/2/3-4/5+`, physical line group position
   `ONLY/FIRST/MIDDLE/LAST`, line close, paragraph close, and frozen known-label
   renderer.
3. `NONWRAPPER_COMPILER`: add local frame, inner-D, right family, DY closure,
   and B3.  The q flag is forbidden because it is exactly the target class
   `wrapper=q`.
4. `EXACT_HOST_RICH`: exact opaque PAGE_HOST identity, shrunk to the full
   non-wrapper compiler context.
5. `EXACT_HOST_X_POSITION_RICH`: exact host and within-field position, shrunk
   to `EXACT_HOST_RICH`.

For direct comparison, also compute `EXACT_HOST_SHAPE` and
`EXACT_HOST_X_POSITION_SHAPE` from the same target-history-free
`SHAPE_CONTEXT`.  This is a clean GDT286-style anchor, not an exact numerical
reproduction of GDT286, whose predictor used earlier target-page wrappers.

Report held bits, top-1, per-folio and per-panel increments.  For Voynich also
repeat the complete chain with whole section and whole hand held out, plus
fixed prior-mass sensitivities 5 and 22.

## Frozen interpretation rule

Let `A` be the target-history-free shape-anchor host×position increment and
`R` the rich-context host×position increment.

- `HOST_POSITION_EFFECT_REVERSED_BY_RICH_CONTEXT` if `A > 0` and `R <= 0`;
- `HOST_POSITION_EFFECT_REDUCED_BUT_REMAINS` if `A > 0` and `0 < R < A`;
- `HOST_POSITION_EFFECT_PERSISTS_OR_STRENGTHENS_RICH_CONTEXT` if `A > 0` and
  `R >= A`;
- `NO_POSITIVE_TARGET_HISTORY_FREE_HOST_POSITION_ANCHOR` otherwise.

This is a nested held-out mechanism decomposition, not a new significance
test.  Controls calibrate direction and magnitude; no post-hoc p-value is
attached.

## Claim ceiling and seal

At most this localizes the wrapper interaction to known record/compiler
context or residual exact-host cells.  It cannot establish lexical class,
morphology, grammar function, abbreviation, sound, language, meaning,
plaintext, or translation.  Only the published f84-free native event inventory
is read.  No f84 row may be opened, parsed, retained, joined, or scored.
