## What a replacement model must actually reuse

The live guide permits connected hypothetical readings and unresolved
alternatives. No confirmed anchor or independently established meaning is a
prerequisite to propose them. A shared conventional code for pitches, actions
or objects is legitimate. The problem is allowing an assignment or missing
clause separately for each token or passage, then calling fluent rendering
evidence for the chosen semantic domain.

The retained word-structure facts constrain how such a proposal should be
written. GDT607 distinguishes five output-bearing formal roles; frequent
elements are not licensed empty separators. GDT608 finds directed component
backoff, but atomic whole-form identities outperform that rule on all 23 held
folios. In particular, the shared visible `o` is not a single stable stem role,
and the closure behaviour of `dy` does not simply inherit the head behaviour
of `d`. GDT282/286/318's retained position and entry-context qualification must
also remain. A code may use reusable ordered parts, compound-specific forms
and an explicitly finite contextual realization rule. None of those facts
selects a semantic name for a part, licenses unrestricted allomorphs or makes
the 98 learned BPE units an alphabet.

GDT611 supplies the strongest immediate countercase: exact shared frames can
remain unchanged under different material, disease or operation names. Its
17 defaults and four families did not pass their fixed gates. GDT397 gives
the broader identical-observation witness: anonymous structure and denotation
are different claims. These do not forbid a conditional whole reading. They
require the report to distinguish a model's concrete assertions from the
observations that actually constrain those assertions.

Variable length is useful, but it does not solve this problem. GDT903 already
constructs a large common reversible action compatible with all 413 fixed
lines; renaming its states as substances or notes would add no consequence.
A new grammar must constrain a whole interpretation through a small shared
inventory and fixed composition, not merely supply more states or phrases.
Nor should its syntax be chosen because it avoids GDT969's INPUT/HIGH failures.
Any defensible code can fail before its later semantics is evaluated. GDT969
remains closed without changing widths, step counts or consumed groups.

## Strongest next acquisition: the complete Reading Rota event matrix

This is a source acquisition proposal, not a selected Voynich model. The
producer's [source dossier](WHOLE_CONTENT_WITHOUT_FIXED_LENGTH_SUPPLY.md)
records its native inspection of Harley 978 f.11v and the original-image hash

The raw IDEA142 counterpoint URLs did not yield their full texts in the

The concrete provisional content hypothesis is a complete instruction to
perform interacting parts: introduce a written melody and two pes parts,
start a singer with the pes, bring in subsequent copies at the specified
cross, preserve the different pes rest phases, and repeat as directed.
The source permits two to four rota singers in addition to the pes singers;
it is not a fixed two-voice calculation or a fixed-duration performance.
The finite semantic object is the written parts plus rules. A hypothetical
target may state such an object in variable syntax without copying the lyric
or the Latin prose. That declared content scope must precede any target fit.

Acquire one complete table from the existing source image, with every written
note and rest in the rota and both pes parts. Each row needs its part and
source location, order, staff position, clef/accidental dependence, note or
rest type, duration interpretation, and the entry/repeat markers. Preserve
all unresolved mensural readings explicitly. Do not regularize them to make
a modern performance convenient. This is the one missing acquisition;
additional musical exemplars, outside contacts and Voynich images are not
needed for it.

The smallest source check uses that table to reconstruct the simultaneous
event lattice for each source-permitted number of singers. Since repetition
is open, use the complete written initialization and the resulting common
period where a duration interpretation supplies one; do not invent a fixed
performed ending. Compare the prescribed entry and two pes rest phases with
moving the entry to a different written marker, exchanging the two rest
phases, and reversing a written part. Keep the written pitch/duration inventory
fixed in these rivals. Record exactly which sounding intervals, rests or
source-prescribed alignments change, including rivals that remain equivalent.
Do not impose a modern rule that every simultaneous interval must be consonant.

This check has a specific failure mode. If one observes only that a melody is
copied after a delay, any invented melody satisfies the canon relation by
construction. An arbitrary permutation of pitch labels preserves copy
equality. A recovered REPEAT or WAIT name would then be GDT397 again. Complete
pitch and duration relations can break arbitrary pitch permutations and
distinguish different entries, while global transposition and common time
rescaling can remain genuine symmetries. Those alternatives should be retained,
not eliminated with guessed absolute note or tempo names.

A small, fixed global pitch/duration/operation code could therefore produce a
whole conditional reading without prior target note anchors. Its repeated
parts and syntax would have real dependencies. It would still have to specify
the finite writing inventory, all permitted constructions and their complete
realization before any target fit. The current dossier has not supplied that
contract, and this review does not invent an opcode/number serialization for
it. A source check cannot be reported as evidence that Voynich paragraphs are
musical parts.

**Decision changed by the acquisition:** if the complete source table retains

draft. If ambiguities leave all nominated rivals indistinguishable, or the

not automatically authorize a decoder, select target paragraphs, or relax a
failed model. Budget the source transcription and its independent check at

or another source. No new data admission is needed.
