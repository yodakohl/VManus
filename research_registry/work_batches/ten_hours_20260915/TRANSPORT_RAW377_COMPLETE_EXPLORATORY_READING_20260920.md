## Common grammar and references

An invented finite controlled reading grammar for this exposed paragraph, not a deciphered historical grammar or a cipher writer.

Distinct lexical constants keep one identity for the entire paragraph. The typed Cargo inventory is obtained from all explicit Cargo names in this whole paragraph, including later names; this prospective whole-record scope is an assumption. This inventory is not picked from a safe-path solution. Introduction order used by FIRST is only first occurrences already read, deduplicated by literal whole name. Statements may explain constraints after actions, but no action uses a later name to resolve FIRST.

1. Initial := INIT CARGOS COLOC Agent HOME. This declares the Cargo set and Agent at L, establishing their union as the GoalSubject.

2. Goal := GOAL BankName WITHOUT_HARM HARM. It registers the BankName R as GoalBank and requests that GoalSubject arrive unharmed. It does not move anyone.

3. SafetyRule := UNSAFE PAIRS FORBIDDEN WHEN WITHOUT_AGENT Agent. Pair co-location is forbidden exactly when that Agent is at the other bank.

4. Capacity := AT_MOST_ONE BESIDES Agent EXAMPLE Cargo. This declares capacity for the unique Vehicle named in the paragraph and introduces the example Cargo without moving it.

5. Trip := WITH_TRIP Entity TripCore | TripCore. WITH_TRIP binds Vehicle as instrument or Cargo as load according to the fixed lexical type; it cannot create either. A conflicting duplicate argument makes the construction undefined.

6. TripCore := TAKE_OUT CargoRef | CONVEY_OUT NEXT CargoRef | FERRY CargoRef | RETURN_EXCLUDING CargoRef | RETURN ALONE | RETURN with an inherited WITH_TRIP Cargo | FINALLY OUTWARD TRAVEL_TOGETHER Agent CargoRef.

7. OUT operations go to R, RETURN operations to L, FERRY to the bank opposite the current bank. Every complete TripCore denotes exactly one prescribed voyage by the same Agent M and Vehicle B. Non-local cargo cannot be loaded. Cargo capacity is at most one. No silent boat or cargo movements are supplied.

8. RETURN_EXCLUDING X allows only locally available zero-or-one loads not containing X. It does not silently mean empty in every possible context, and does not choose using safety. If more than one load survives local availability/exclusion/capacity, the reading remains ambiguous. In S07 only G is local, so the sole allowed load is empty.

9. THEN is a discourse sequencer applicable to a Trip or Assertion. It is not the W91 proof operator; the type of the following head determines whether any movement occurs.

10. PairAssertion := CargoRef PAIRED_WITH UNATTENDED CargoRef WOULD_BE UNSAFE. Its two argument positions are preserved. The absent Agent is the unique M; this is a conditional property of a pair, not a current-world absence assertion.

11. FrameCopy := LIKEWISE OTHER_CARGO. It copies the most recent complete PairAssertion in textual order, replacing argument1 only and retaining argument2, absence condition, modal force and predicate. It cannot copy a trip or an incomplete fragment.

12. FIRST_CARGO selects the first distinct previously written Cargo name. OTHER_CARGO selects the unique member of the previously named Cargo inventory after removing both arguments of the copied PairAssertion. Zero or multiple eligible members makes OTHER undefined; no choice by safety or wished-for continuation.

13. Stay := LEAVE THERE. Subject is the Cargo of the immediately preceding actual Trip, never the nearest untyped noun. It requires that exact Cargo to remain at GoalBank through the next Trip unless explicitly carried. If that previous trip had no cargo, this construction is undefined.

14. Result := JOINING_RESULT REST_CARGO COLOC CargoRef. Subject is the Agent+Cargo travellers of the immediately preceding actual Trip. REST_CARGO is the already named Cargo set minus that previous load. It asserts resultant co-location, not a new journey.

15. Conclusion := THUS ALL UNHARMED THERE ATTENDED_BY Agent. ALL quantifies the paragraph Cargo set. THERE always refers to GoalBank R. This is a whole-result claim, not another instruction.

The rules are given explicitly rather than installed as a decoder. They supply a particular typed parse; no exhaustive or unique surface parse is claimed. Each listed lexical head has a declared arity and mode. No production chooses an object because that choice is safe.
