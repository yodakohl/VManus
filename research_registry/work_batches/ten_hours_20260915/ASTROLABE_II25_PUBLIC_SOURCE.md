## Operations and quantities

| branch | source conditions | operation | explicit quantities/result |
|---|---|---|---|
| Equinoctial noon | Sun at Aries/Libra heads; noon; equinoctial line | subtract solar altitude from 90° | 90 - 38 = 52° latitude; Oxford is stated to be certain minutes less |
| North declination | Sun in another zodiac degree; declination north of equinoctial | subtract north declination from noon altitude | approximately 56° - 18° = 38° plus odd minutes; this is the Aries/Libra/equinoctial height |
| North then complement | same north branch | subtract equinoctial height from 90° | line 53's later complement rule supplies the regional pool distance/latitude relation; no new numeric result is printed for this example |
| South declination | declination south of equinoctial | add declination to noon altitude, then subtract equinoctial height from 90° | result is the distance of the regional pole from the equinoctial; no worked south numbers are supplied |
| Fixed star alternative | a known fixed star; highest altitude and lowest elongation from equinoctial | use the manner already stated | no numerical operands are supplied in this branch |

The first numeric example is an independently checkable arithmetic relation:
the operands 90 and 38, the subtraction direction, the 52 result, the
Aries/Libra condition, the Oxford qualification, and the verification invitation
all belong to one complete source unit. The north branch gives a second
approximate subtraction with 56 and 18. The south branch is an inverse-sign
operation followed by the same 90-degree complement, but it is not a numerical
worked example. The fixed-star branch is a procedural alternative without
explicit numbers.

## Conditional structure versus chronology

The section is a decision tree, not evidence that one observation was executed
through every branch. Than if introduces the equinoctial case; Now yf so be
introduces the north-declination alternative; Also if introduces the
south-declination alternative; Or elles, if introduces the fixed-star
alternative. A future model must not convert the textual order into a mandatory
90 -> north -> south -> star time sequence.

## Nonliteral candidate consequence

A small compositional content hypothesis can represent a writer's calculation as
typed roles:

SETUP(condition) -> OPERATOR(sign, reference) -> INPUT(operand) -> RESULT ->
QUALIFICATION -> VERIFY

The coupled prediction is stronger than direct string equality:

1. the operator and operand order must reproduce the stated result (90 - 38 =
   52, and approximately 56 - 18 = 38);
2. the setup condition must select the sign/operation (north subtracts, south
   adds);
3. the result must scope over the qualification/verification closure;
4. alternative branches must remain conditional and may not be collapsed into a
   chronological sequence.

This is source-role scaffolding only. It does not propose target word meanings,
a literal-character sum, or a fixed phase label.
