## Primary finite passage

The Ulrich Harsch electronic witness of Vinidarius’ *Excerpta* (Apicius,
*Porcellum oxyzomum*, XXIV) gives a short continuous chain:

> `dum bullire coeperit, saepius agitabis, ut spissum fiat. si aliquid minus iuris facere coeperit, tunc adicies heminam I aquae.`

Primary source: https://www.hs-augsburg.de/~harsch/Chronologia/Lspost04/Apicius/api_exc2.html,
XXIV, `PORCELLVM OXYZOMVM`, lines 176–177 in the web text. The full finite
semantic chain is: mix the sauce ingredients; put the pork into it; when boiling
starts, stir repeatedly so the sauce thickens; **if** too little sauce begins to
form, add one hemina of water; finish boiling; serve. The exception changes the
input inventory, and the following completion/serving clause records the result.
This is an actual conditional operation, not a list inferred from ingredient
counts. A related Vinidarius source chain also uses a timed branch (`cum
mediaverit coctura, tolles`) and moisture removal before binding and thickening
(*Pisces scorpiones rapulatos*, VII), but XXIV is the cleaner primary case.

## Whole hypothetical reading and rival

**Conditional correction model A.** Read the four lines as one record: an
initial material/state entry; one or more measured additions; a bounded
correction when the developing result is insufficient; then a closure/result
record. The repeated amount-like positions in f53v.4–5 are arguments to the
same evolving record, while the final `... choldam` is a result/state report.
All content values remain `[INPUT]`, `[MEASURE]`, `[STATE]`, `[CORRECTION]`,
and `[RESULT]`; no token is translated.

**Static inventory model B.** The same lines are independent entries listing
materials, qualities and measures. Repeated amount-like forms need not respond
to a prior deficit, and the final line is another peer record rather than an
outcome.

A predicts an observable second-stage consequence: where a written condition
or exception marker occurs, it should be followed by a compensating amount or
state change and then a completion/result position; matched records without the
condition should lack that compensating step. B predicts no condition-specific
addition and no systematic result carry. The smallest discriminating observation
is one already admitted complete passage with an independently bound condition,
compensating argument and subsequent output; repeated `daiin` or `chol` alone
cannot supply it.

## Limits and recommendation

This source analogy is useful because it demands a real multistep asymmetric
content pattern: operation -> evolving result -> exception -> compensating input
-> completion. It currently has **no target binding**: f53v has no independently
readable conditional marker, output, or author-visible correction relation, and
ZL/IT diverge in the amount run. The strongest likely failure is therefore
relabeling a static quantity/state list as a recipe correction loop. W85 also
records that a continuous recipe reading remains unconfirmed. Keep this as a
source-grounded whole hypothesis only; do not add a raw idea or import the
Apicius words as Voynich glosses.
