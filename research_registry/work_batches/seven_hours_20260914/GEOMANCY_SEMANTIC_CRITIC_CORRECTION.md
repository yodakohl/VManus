# Correction to `GEOMANCY_SEMANTIC_NEXT_DISCRIMINATOR.md`

The original audit incorrectly stated that the 16 IT2a survivors represent
the possible omitted figure. The actual `ALL_SURVIVING_CALCULATIONS.tsv.gz`
rows show that all 16 IT2a charts omit the same source value, `0`, whose fixed
Turner dictionary name is **Populus**. The 16 survivors differ in the mother
assignment while preserving that omission.

This correction does not change the audit's main conclusion: the result is a
formal compatibility set with no repeated target form or independently fixed
semantic relation. It does remove the claim that the omitted figure itself
contributes 16 semantic alternatives.
