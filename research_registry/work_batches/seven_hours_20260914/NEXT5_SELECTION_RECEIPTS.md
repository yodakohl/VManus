with the Wellcome MS 542 IIIF links recorded there.

**Admitted target.** GDT768/GDT625 bind the complete surfaces f17r.5

`kooiin shor chetchy ... cthy ...`, and f29v.4
`ysho otshy okaiin cthy oltchy s shot sho okaiin`.

**Two readings.** A: these are parallel material/part/state fields in an
inventory record. B: they are an ordered process in which a reusable operator
lies between an input and a changed state, followed by a separate closure or
output. **Smallest executable difference:** across two already bound complete
lines, a frozen whole must recur in that input-to-state operator slot and a

TARGET BINDING MISSING; do not select**. Nearest rival is a whole-phrase or

the source distinction transfers only as an expectation; no independent
Voynich operation/output anchors exist. Predecessors: GDT625, GDT768,
IDEA000293.

controls. No target query is authorized here, and first-group headword status
is an assumption. Verdict: **PROMISING ASYMMETRIC SOURCE CASE, NO CURRENT
TARGET DIFFERENCE**. Failure: a two-edge star is exchangeable or target
boundaries are editorially imposed. Predecessors: IDEA000115 card,
GDT341/GDT342 (record-local graphs, not this source-named network).

**Source and concrete chain.** GDT214 describes Met 55.121.11: one water

**Admitted target.** q13 supplies repeated graphical units and nearby labels;
GDT187 reports 57/215 label groups reused anywhere in same-page prose and 22

**Two readings.** A: same whole recurs across independently owned visual units

stage/state coding nor a recovered label owner; the page-reuse result is the
wrong bridge. Verdict: **NO CURRENT TARGET DIFFERENCE**. Failure: stage and
owner labels would be inferred from the same drawing. Predecessors: GDT214,
GDT187, IDEA000039.
