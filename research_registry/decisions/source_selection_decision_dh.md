# DH bounded source-review navigation decision

DG identified two concrete preparation hazards: dictionary-shaped evidence is
ignored by list-only interval collectors, and `scope_comparison_open` is omitted
by a filter that only recognizes `scope_open`. The thirteen DE receipts refer to
different sibling source IDs, not exact duplicates. Containment must not suppress
an unreviewed proposition; the Pass347 interruption-marker clause demonstrates why.

The unknown is whether one small reusable receipt lookup can expose existing
source work and open questions without inferring semantic coverage. A correct
lookup changes which source preparation can be reused and which comparison stays
open. A tool that merely hides contained spans would make the workflow worse.

Smallest adequate change: normalize evidence dictionaries/lists, expose exact-ID,
containing-span and partial-overlap receipts separately, preserve explicit open
statuses and unknowns, and return bounded navigation records. No automatic skip,
full-coverage, novelty, scientific status or reopening decision. Reuse existing
registry metadata access and enabled review paths; do not create a new source
registry, modify legacy tools, import private supplements, or open event data.

Budget25minutes including implementation, targeted regression checks, independent
review and publication. Tests should cover the actual object/list and open-status
regressions plus the non-equivalence of interval containment and claim coverage.
Stop scope expansion if a persistent index or broad migration seems necessary.
