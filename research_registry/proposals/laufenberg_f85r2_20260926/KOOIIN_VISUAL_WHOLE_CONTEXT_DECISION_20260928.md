The shared narrow visual description is **emphasized horizontal, subdivided
underground material**. This is a defensible descriptive refinement of GDT623's
rootstock observation, not an independently acquired lexical meaning. The
three axes are not the same shape, and other rootstock-rich pages lack these
heads (GDT768). The public f29v description prompted reinspection; it does
not create a new counterexample or validate the word.

trial without a newly owned referent or a different predeclared whole-reading
consequence. The generic-head and other opaque-class alternatives remain.

investigator and prior project exposure. Confirmed translated words: zero.
