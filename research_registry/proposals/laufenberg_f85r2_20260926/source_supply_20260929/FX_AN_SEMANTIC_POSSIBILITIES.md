# FX: finite aN semantic possibilities and actual remaining rivals

The existing evidence constrains **particular argument requirements**, but does not select an aN meaning. A generic reference, determined nominal, or finite quantifier/determiner class is a reasonable first C0 to author; state assertion remains an equally live semantic rival. An obligatory performed-result reading has an additional event/producer debt. This is an order for exploratory work by unpaid commitments, **not** a frequency-derived word class or meaning probability.

This audit uses only the frozen complete FW discovery packet and its existing aggregate whole-form priors, plus bounded claim-bearing primaries. No new query, statistic, image, decoder, application body, admission, arbitrary plant name or registry change was made. The shared aN construction is finite: `d+aN=daN` (`daiin`), `qok+aN=qokaN` (`qokaiin`), `ok+aN=okaN` (`okaiin`). N is the frozen collapse of visible iin. Neither N nor the left parts are sounds or translated morphemes.

## Three finite competing classes and the left residual duties

| Class | Exact shared operation a C0 would have to pay | d / qok / ok left payload duty | What it does not provide for free |
|---|---|---|---|
| Assertion / result | State assertion binds `PropertySpec(P)` to written x as `StateRecord(P,x)`; a performed result instead binds an actual `Event(e,x)` and its output o. | Each left payload needs a declared sort and content. If one is Event and another PropertySpec, the same operation needs separately paid finite adapters or must reject one. | Actual event, success, output identity, property-to-event conversion, or a patient supplied by ambient context. |
| Referential identifier | Produce `Ref(x)` from a written reference specification and context, preserving that individual's identity at a later consumer. | d, qok and ok must specify distinct, priced paths/selection rules or exact residual restrictions. No universal prefix reference meaning. | A preceding group is not automatically antecedent x; repeated form is not coreference; a same-kind object is not the same individual. |
| Determined nominal | Select or introduce `Entity(x:P)` from a PropertySpec and a priced determination/uniqueness policy. | Each left residual needs a nominal/property payload and a finite distinction from the other two. d cannot be merely an obligatory following-head article under the tested scope. | Existence/uniqueness criteria, property inheritance to a newly created part, performed event, or selection of which written individual. |

Quantification adds a fourth concrete alternative within determination, without supplying a new glossary. **Each** needs a written set S and predicate P and distributes P over its members. **All** must specify collective P(S) versus distributive ∀x∈S P(x); those are different consequences. **Of these** requires a demonstrative set antecedent S and a member/subset selection T⊆S, without asserting that every member is affected. A definite nominal instead selects x under a uniqueness/context rule. None entails a performed event merely by selecting or quantifying.

A paragraph-initial daiin does not bar set introduction, a self-contained quantified nominal, a new nominal participant, or a state snapshot with actually supplied arguments. It does bar an exceptionless *paragraph-local mandatory preceding anaphor* under the IT flags. An each/all determiner obligatorily requiring a separate following head also faces the registered right-host contradictions. Bare/pronominal quantifiers or a different explicit scope are different models, with their own set/reference debt; they are not retrospective rescues. d/qok/ok must supply finite paid domain/scope distinctions, not a universal literal shared-o interpretation.

A fixed designation **Winter** must keep the season as its denotation; a true proper name must keep the named individual. Their broad recurrence would need actual content or reference ownership, rather than a new locally guessed identity at each use. The daiin counts do not refute frequent seasonal discussion or a salient recurring entity. Generic each/all/of-these can range over different written sets while keeping its operation constant, which gives it explanatory scope, but the sets still need to be written and bound. This is a logical difference from invariant naming, not a frequency-selected gloss.

A reference identifier and determined nominal can yield the same argument object in these contexts, until a written consumer distinguishes prior identity from new introduction/selection. State assertion differs by committing P(x), rather than merely providing a description or argument x. A performed result adds still more: an actual event and its owned output. Calling all three “binding” without an actual difference would only rename formal roles.

One may hypothesize that a left whole residual supplies an assertion in one child and an identifier in another; GDT608 permits residual information. But then aN has not yet been shown to do the claimed shared semantic work. An unlimited residual that already donates the desired final result makes the family irrelevant. Finite adapters, their types and the retained whole information must be explicit before any test.

## An explicit scope assertion can constrain meaning without a later consumer

The existing source-reviewed [IDEA000594 supply](FX_FALLBACK_SUPPLY.md) gives a different concrete falsifier template. Complete Steele paragraph96 retains one quicksilver x as a watery/earthly mixture, then as matter of metals, and consequently as a simple element **relative to those metals**. Its full owned-source duties and edition limitations are in [OWNED_REFERENCE_REUSE_C.md](../OWNED_REFERENCE_REUSE_C.md): an edited English anthology excerpt of historical natural philosophy, not a proven early Latin exemplar, direct-copy source, or modern chemical efficacy claim.

`Mixed(x) + MatterOf(x,C=Metals) → ElementRelative(x,C=Metals)` preserves both x and the written comparison class. Interpreting simple as absolute constituent-free simplicity conflicts with the mixed-composition claim; interpreting it relative to its products does not require purification. Binding the class to watery/earthly constituents instead of metals, changing the subject, or inserting a treatment changes the assertion. These are actual source reference/predicate-scope consequences, **without an invented downstream consumer**.

The source separately states joint quicksilver+brimstone matter of all *melting* metal and singular quicksilver matter of *all* metal. Quantification and class restriction must preserve both subject and restrictor. An each/all/of-these guess cannot erase that distinction. A finite aN C0 could attempt a shared scoped assertion over explicitly written x/P/C, with residual restrictions; no FW glyph has thereby become MIXED, METALS, SIMPLE or ALL. The complete FW unit currently supplies no independently bound version of that class hierarchy.

One focal source case also allows an independent qualified whole-name or a constant-on-one-class function. Consequently this source-owned logical contrast permits a concrete C0 falsifier, but does not alone identify a reusable aN scope operation. It is a possible alternative to a consumer test, not new selection or an alchemical translation of f83v.
