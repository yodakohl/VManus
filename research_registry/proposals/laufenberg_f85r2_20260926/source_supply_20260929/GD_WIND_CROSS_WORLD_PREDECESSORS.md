## Smallest potentially new falsifier

Unknown that would change a research decision: can the **released and frozen**
wind shared-part denotation, with unchanged typed arguments, owner/reference,
time and generic/actual status, participate in a complete medical reading where
written downstream uses distinguish its output from a genuinely different rival?
This is not the already-positive question of whether flexible dictionaries can
fit another paragraph.

The smallest adequate unit would be one complete already-exposed medical
paragraph with a documented structurally licensed exact aN-family recurrence,
plus the complete wind unit from which the operation was frozen. GDT1028 supplies
a concrete existing49-group whole medical benchmark with persistent food,
changed waters/new event and a desire-versus-actuality separation. **This report
does not establish that benchmark contains the required supported recurrence**;
its eligibility cannot be inferred from its Galenic subject or similar spelling.
Use it only if the already-owned evidence establishes the exact form and supported
decomposition. Otherwise this particular minimum is unavailable, rather than a
reason to search new leaves or attach the operation to another convenient word.

Predeclare the full medical unit, every inherited shared exact form, supported
decomposition, fixed operation, allowed typed inputs and the rival's distinct
observable obligation before authoring. Price new whole assignments separately;
do not permit them to bypass the shared contribution or invent an ambient owner,
time reset, identity cast, default or vacuous condition. The same operation must
be non-null and actually consumed; an unused instruction, renamed predicate or
OriginalOnly consumer stipulated solely to select a winner does not count.
Generic conditions and desires must not be promoted to actual events. A static
explicit two-time description that makes the same predictions remains equivalent.

Possible decisions:

* Contradiction at a fully bound written consumer closes that **frozen universal
  shared denotation**; it does not erase the local wind C0 account or all aN meanings.
* Complete unchanged reuse with a source-faithful distinguishing consequence
  retains a cross-domain C0 hypothesis and narrows the rival under the declared
  assumptions; it confirms no lexeme and supplies no independent holdout.
* Missing constructor/operand/reference, missing recurrence eligibility or two
  equally complete rivals yields PARTIAL/NO_CAPACITY/AMBIGUOUS as appropriate.
  It does not authorize lexicon repairs or another world-state variable.

Proposed ceiling if separately selected:45 minutes including prerequisite review,
whole-unit authoring, validation and publication; at the ceiling report the actual
barrier rather than expand infrastructure. This note authorizes no execution.
If there is no frozen nontrivial shared operation or no written distinguishing
consumer, both outcomes leave the same meaning decision unchanged: do not build
another decoder or run another fixture census.

### The commitments that would differ

Predicate restriction must state its actual semantic commitment before use:
for a specified domain D, predicate P and selection rule, the returned referent
x lies in D and satisfies P at the declared time/condition. If it merely returns
a kind or a description containing P, that does not assert an actual instance
or event. If it creates a new portion y from x, P(x) does not entail P(y).
An intention that P should hold is not evidence that P actually holds.

Arbitrary description reference only requires a relation to a description or
discourse anchor. A broad such family can emulate predicate restriction, so
the families are not mutually exclusive. A successful restricted nominal
cannot eliminate arbitrary reference generally. A **frozen rival** can differ
if its written selection rule picks an already introduced object that fails P.
Type labels alone cannot select material, event or proposition meanings:
`about an event`, an event itself, and a statement about an event require
different consumers. A complete extensional static description remains a fair
rival to a dynamic program with the same consequences.

### One small consequence worth paying for, conditionally

The sharpest modest commitment is **predicate satisfaction by the selected
owner**, with no automatic transfer to a newly formed object. In one complete
already-owned medical unit, require two already-written same-type candidate
owners, a written/source-faithful predicate that distinguishes them at the
operation's time, and a later written use of the returned owner. Reuse the
released wind operation and arguments unchanged. A fixed restriction account
must select a satisfying owner; a precommitted anchor/current-owner rival must
select the other owner if its policy says so. A medically described property
of the parent versus a newly formed portion, or actual retention versus a
retention intention, can supply the **conceptual** contrast. Neither concept
identifies an eligible Voynich form or a source-bound owner by itself.

Required capacities before any selection: supported exact aN-family decomposition;
the frozen wind signature actually entails satisfaction rather than merely
description reference; explicit operands and their type; independently justified
within-source P and not-P/unknown-P contrast; written owner/time/condition;
an actual output consumer; and enough already-paid context to interpret the
whole chosen unit without30+ new aliases. A missing truth value is UNKNOWN,
not false. Generic/quoted/desire scope cannot be silently recast as actuality.
No inherited owner label, assumed medical sense, invented witness or default
may supply the distinguishing endpoint. All exact assigned recurrences and
alternate-reader barriers remain obligations.

This audit identifies **no specific eligible medical unit** meeting that entire
capacity set: GDT1123 is incomplete and GDT1028's aN recurrence was not established
in the preceding review. This is a bounded prerequisite statement, not an absence
claim or an invitation to repeat a global audit. Root can assess already-paid
candidate material after final C release; if the capacities are missing, stop.

Research decision changed by an actual bound counterexample: reject the specific
universal aN satisfaction/owner commitment while retaining local wind C0.
Complete unchanged reuse with distinct consequences retains a narrower
cross-domain C0 and excludes only the frozen contrary policy, without confirming
a lexeme. Identical consequences yield AMBIGUOUS; missing truth/owner/type or
whole-context coverage yields PARTIAL/NO_CAPACITY. If both proposed outcomes
leave the same decision unchanged, there is no implementation justified here.
