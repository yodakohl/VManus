# R771: same class versus the same previously described object

**A backward identity reading adds a genuine constraint, but no observed
constraint currently selects it.** In the complete f75v.43–49 construction,
the final object would have to carry both the earlier and later descriptions.
The earlier Class reading permits different objects with those descriptions.
It also permits the same object: different variable names never establish
physical inequality.

This is a bounded explanatory comparison, not a new decoder or a new native
experiment. The complete original source and all six readings remain in
[R771_WITNESS_READING](R771_WITNESS_READING_20261016.json). Every frame and every
body term not explicitly joined below is unchanged. All unknown predicates,
annotations, local existential terms, repetition and phase differences remain.
The [comparison plan](R771_REFERENCE_PLAN_20261016.json) pins the dependencies.

## What an ordinary reader would need to keep track of

The original proposed constructions have these roles, still unconfirmed:

| Written site | Existing conditional contribution | Reference consequence |
|---|---|---|
| .45 `qokar olchedy` | Some object satisfies AP and the following description F. | An existential introduction; it does not identify a unique individual. |
| .46 `tol olchedy` | Every AP object has the following description U. | A universally bound variable, not a newly introduced individual to remember. |
| IT .47 `qokar olshedy` | Some AQ object has description V, including later P. | An additional existential introduction, also AP-qualified by its completed description. |
| ZL/RF .47 `qotar olshedy` | QOTAR remains unknown inside U. | No new existential object at this site. |
| .48 `qokar otar` | Some OTAR object has the final description T. | The current final object; not asserted to be new or distinct. |
| IT/ZL .49 `olchedy` | The final object also satisfies AP. | This is the sole additional identity site being compared. |
| RF .49 `olche@152;y` | One opaque predicate of the final object. | No licensed AP contribution or OLCHEDY reference. |

AP abbreviates the inherited conjunction A and P; OTAR abbreviates the
unassigned predicate N_otar. None of these symbols names a substance, person,
operation or translated word. A backward reading is about discourse identity,
not automatically a physical production or material transfer.

The source writes a universal occurrence between the initial and final
existential descriptions. Consequently, “take the last OLCHEDY” is not a
well-typed way of retrieving a previously described individual. It would pick
the .46 universal restriction. The distinct proposal “reuse the existential
introduced by the last exact QOKAR OLCHEDY” picks .45. That distinction must be
stated before claiming that an ordinary repetition supplies the antecedent.

## Complete comparison with one explicit antecedent

For IT or ZL, let F be the complete body of FRAME2 after .45 QOKAR OLCHEDY.
Let T be the complete final body's terms except its final OLCHEDY, retaining
each reader and phase exactly. Let R be the conjunction of every other full
frame, unchanged. The original entire reading can then be written:

```text
CLASS = R AND EXISTS x [AP(x) AND F(x)]
          AND EXISTS y [OTAR(y) AND T(y) AND AP(y)]
```

The exact-introduction reference rival is:

```text
REF45 = R AND EXISTS x EXISTS y
          [AP(x) AND F(x) AND OTAR(y) AND T(y) AND AP(y) AND y=x]
```

Equivalently, one object z must satisfy AP, F, OTAR and T together. This is a
new common-witness condition. It is not obtained by writing the same letter
under two separately closed existential quantifiers. The old model explicitly
closes top-level scopes and forbids escaping variables; the rival therefore
pays for access across those scopes, either through this explicit joint
quantification or a newly specified discourse-reference mechanism.

F contains all 17 written predicates at .45G004–.46G008, including the two
QOKEEY and two QOKEDY occurrences. In IT/ZL its first contribution is N_qor;
the final description includes N_dal, N_por, N_shey and N_okain. REF45 requires
one object to satisfy both descriptions; it does not translate any of them.
RF has the same early source sites but literal annotated predicates in F;
its final annotated form does not authorize REF45 here.

PRE-IT's final `chedy qol` is a local existential BP clause; it does not assert
B of the final object. POST-IT predicates P and B of that object directly.
The equality comparison does not erase this distinction or replace ZL's
opaque QOLSHEOL with IT's QOL SHEOL.

The distinction has content even without choosing meanings. As a purely
logical counterexample, take two objects a,b, all primitive classes universal,
N_qor true only of a and N_otar true only of b, and all other opaque predicates
universal. The original complete IT/ZL readings can hold, while REF45 fails.
This is a manual countermodel to entailment, not an assertion that QOR and
OTAR are actually disjoint and not a new native truth score. Conversely, a
shared witness can satisfy both readings. No logical argument here decides
which situation the manuscript describes.

## The alternative antecedent is not a harmless choice

“Last explicitly OLCHEDY-restricted existential” and “last completed
existential whose object satisfies AP” differ in IT. The second rule can pick
the .47 AQ object: its restriction gives A,Q and its later CHEDY gives P.
Local existential terms and the assumed initial object introduce further
accessibility questions; they are not silently admitted as global named
referents. A rule that publishes the current final object before resolving
its own OLCHEDY can even turn the identity into a self-reference.

The source and original grammar supply no published witness store, selection
policy, global uniqueness or ordering among real individuals. We therefore
record these as competing requirements rather than choose the most convenient
antecedent. No generic USE, recipe/batch/result vocabulary or hidden cast is
added. IDEA842's broader raw proposal is not thereby selected; IDEA895's
previous USE(b)/USE(c1) construction remains an already executed, unresolved
different account.

## Prior evidence and limits of exclusion

[Exact-form profiles](R771_REFERENCE_PROFILES_20261016.json) were retrieved
before this comparison. Standalone OLCHEDY has ZL34/IT35/RF21 occurrences on
22/22/16 admitted page selectors, mostly Currier B, with 8/8/6 line-final
occurrences. It is not confined to the chosen paragraph. Those counts do not
establish a demonstrative, a noun or a backward-reference operation. Embedded
strings and alternate readers are not pooled. QOKAR, TOL and OTAR profiles
likewise remain descriptions, not lexical assignments. The existing WE009
composition evidence supports neither an arbitrary OL prefix meaning nor a
free inventory of confirmed whole-word values.

GDT947 did **not** test OLCHEDY. It rejected a fixed same-paragraph exact naked
core obligation for OLSHEDY/OLSHEY, with three other diagnostic pairs. That
failure neither establishes nor refutes this local whole-form reference.
GDT1113 shows why intervening written material cannot be skipped to obtain a
desired antecedent. GDT1039 shows how publication/consumption choices can make
an apparent comparison tautological. Both warnings are directly relevant to
the extra access and selection obligations above. Their old results remain.

**Decision:** retain REF45 as an explicit stronger conditional account, with
an unbound identity contribution and no preference over CLASS. No whole-form
translation, reference mechanism, reader or phase has been selected. The
comparison has now been worked out; repeating this missing-identity audit or
building a free referent resolver would not improve it. Before broader model
work, check already known concrete operator counterexamples against the exact
R771 grammar, retaining the successful GDT1386 paragraph result in its scope.

## Already known counterexample prevents global export

`qotchy daiin daiin` at G003–G005. The unchanged R771 rule consumes QOTCHY and
the first DAIIN together; the second DAIIN is necessarily an orphan. POST/PRE
make no difference there. This does not need another corpus experiment.
GDT1047 additionally supplies two IT paragraph-initial DAIIN countercases;
their source-boundary uncertainty is not transferred to ZL.

The same unchanged grammar cannot be promoted to a general manuscript system.
Adding an identity bridge does nothing to repair this separate operator issue.
