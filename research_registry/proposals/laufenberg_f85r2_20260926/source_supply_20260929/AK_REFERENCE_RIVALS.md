A shared TO_B term would fit both-aliquot goals but would conflict with the
second destination in sequential return **if** it scopes over both events.
The actual earlier qokar does not by itself determine that scope. Conversely,
a later FROM_A term selects a returned location only **if** it is a current
location check on that same P and no intervening operation changes location.
Those are GDT985-style additions, not automatic semantics of FROM_A.

This is why an event simulator alone cannot settle the reading: changing
argument identity, assertion force or scope can change its result while the
same R word value remains. AL's whole account should choose a concrete
structure and expose its choices; unexplained neighbouring groups are not
implicitly allowed to repair its obligations, nor assumed inert to force a
contradiction. Existing .45 and .46 repetitions must both be retained.
