# Official digital-witness follow-up: Vat. lat. 2383

This is a bounded supplement to the earlier `GALEN_LATIN_NATIVE_B.md`; that report remains unchanged.

## Catalogue verification

The official [DigiVatLib viewer](https://digi.vatlib.it/view/MSS_Vat.lat.2383) led through its ordinary “READ MORE” and “BROWSE” links to the Vatican's catalogue detail for internal item 227509. That item record identifies Biblioteca Apostolica Vaticana, Vat. lat. 2383; date range 1301–1400; locus 1r–21r; *De facultatibus naturalibus*; and summary “Lib. I-III; interpretatio latina Burgundionis Pisani.” This directly identifies all three books in the selected witness and removes the earlier work-extent uncertainty for this manuscript.

## Native-text access result

The ordinary viewer displays “Manuscript - Vat.lat.2383” but the extracted page exposes only generic image controls and an input for a manifest URI, not a linked manifest or folio/canvas selector. Following the catalogue's normal BROWSE link returned to that same viewer. One standard IIIF manifest lookup at `https://digi.vatlib.it/iiif/MSS_Vat.lat.2383/manifest.json` was inaccessible through the browser tool. This was the single permitted manifest lookup; I stopped rather than guessing other endpoints or using an access workaround.

No verified page image or canvas was obtained or viewed, so there is no native visual reading, Latin transcription, image hash, or certainty claim about the fasting liver-vein/body wording. The catalogue establishes that books I–III belong to this witness; it does not independently establish the exact wording, sequence, or local chapter boundaries of the III.13 argument. This is a bounded interface/access gap, not evidence that the passage is absent. It has no bearing on Voynich language or target interpretation.
