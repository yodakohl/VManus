The new analytical law is deliberately restricted:

```
INHIBITS(q, loss, case)
DEPLETES(loss, resource, case)
SUPPORTS(resource, operation, case, guard)
    => positive PATH through that loss and resource, under guard

INHIBITS(q, motion, case)
SUPPORTS(motion, operation, case, guard)
    => negative PATH through that motion, under guard
```

These are **proposed local influence rules**. They require compatible backgrounds and a locally monotone interpretation, an added modeling assumption. They are not a universal calculus licensed by any occurrence of “because.” Every repeated argument must retain its denotation. Resource preservation is not total spatial immobility, and conditional support is not achieved success. A missing edge means no derivation, not a negative physiological fact.

The two paths may contribute opposite signs to the same operation only after owner, operation, time and conditions are explicitly joined. Opposed path contributions do not contradict one another and cannot be added into an overall sign without further assumptions. A genuinely contradictory outcome claim would require opposed **net** comparisons of the same aspect against the same baseline under the same conditions. None is supplied here.

The most important serious rival is a phased account: conservation first, later action after conditions change. The source does not force simultaneous action, so this rival remains possible. A second rival locates goal-relative usefulness in one predicate and mediation elsewhere. A third expresses the same events with temporal order. An event sequence can be causally dependent; matching physical outcomes does not decide where the text places causal meaning. Thus no experiment of “because changes outcomes, then does not” is proposed.

The smallest useful written result would be two **complete** cases sharing one inhibition construction while exposing different owned intermediates. The expulsion branch must retain the separately stated qualification and additional mechanism in the card; those cannot be hidden inside an omnibus preservation word. A fixed descendant fails if an intermediate silently changes owner, if an explicit guard disappears, or if a path contribution becomes unconditional success. If the only achievable fit assigns helpful/harmful labels, retain the source graph without selecting an executor.
