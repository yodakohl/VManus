# Schermar comparator decision note

2026-09-26. Pre-inspection source-selection note for a bounded catalogue/image check; not a Voynich interpretation.

## Question and decision

Unknown: whether the former Ulm Schermar Ms. Med. 8 supplies one documented text-image program in which the quartered circle with season-opening saints, outer winged figures, an annular inscription, and the cloud-emerging half-figures around a four-element earth/planetary sphere are relationally connected—or whether these are separate layouts inside a multi-part bound collection. This changes only the quality of this source as a comparator for outer forms, quadrant figures, circular writing, and cloud bands; neither outcome identifies a target figure or proves what any target text means.

## Fixed source and evidence rules

The selected witness is exactly **ehem. Ulm, Schermar-Bibliothek, Ms. Med. 8 (now private ownership)**, KdiH 11.4.44. The source locations fixed in advance from its catalogue are 49v and 58v. The reported catalogued layout features to test are: 49v quartered roundel, four season-opening saints, four outer winged evangelist symbols and frame inscriptions; 58v earth divided into four element quarters, a surrounding planetary sphere with inscriptions, and two half-figures emerging from clouds that hold it. Catalogue-derived prose is limited to 200 words; interpretation will be marked separately.

Search only for public institutional or library scans that unambiguously identify this exact manuscript and folios. Inspect at most those two whole-page surfaces; no crops, alteration, OCR, other manuscripts, or Voynich material. If no exact, attributable scans can be found within the bounded search, stop at the primary catalogue and report access as unavailable here, not as proof the images do not exist.

## Contrast to preserve

Evidence for a continuous relationship between both folios or a repeated programmatic connection would make this a useful historical comparator for several features at once. Separate text units, distinct page layouts, or visual features with no evidence of connection would leave only component-level analogies. A pointing/winged or feather-like outline by itself will not count as an evangelist or wind identification. The fact that the codex is a composite collection will be kept distinct from unit-level links.

Time budget: up to 25 minutes including route/predecessor check, exact catalog review, scan search/inspection if available, report, and receipts. No hypothesis values, target roles, or semantic claims are selected.
