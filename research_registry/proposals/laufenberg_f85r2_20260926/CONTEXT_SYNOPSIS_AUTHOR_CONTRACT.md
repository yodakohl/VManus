## Semantic types and interfaces

These are disjoint sorts unless an explicit function below relates them:

- `Kind`: a generic evaluated thing/kind, not a physical token, patient, action episode or proposition. The source does not name its subclass.
- `KindDesc = Kind -> Bool`: a range restriction, distinct from a bound Kind and from a reference.
- `HealthClass = {SICK, HEALTHY}`; `TimeSituation` is a separate sort whose values require later written provision; neither is an individual person.
- `Context = Health(HealthClass) | AtTime(TimeSituation)`. This tagged sum is an explicit new modeling choice. It is not a coercion from any word to a context. No mixed health/time pair is licensed by the first pair description below.
- `PairDesc = Context -> Context -> Bool`, describing an ordered pair before binding; it is not itself either context.
- `KindRef` and `ContextRef` are lexical reference instructions. They are not Kind or Context values. An environment must bind their referents; an unbound reference is a gap, never an invitation to supply the desired argument.
- `Outcome = {GOOD, HARM}`. They are distinct positive evaluations, not Boolean complements. HARM does not mean merely NOT GOOD.
- `Atom` is an unmodalized proposition about an explicit Kind, Context and Outcome. `Prop` includes atoms, conjunction, quantification and modality.
- `BinderHead` and `ModalHead` are syntactic heads, not values silently applied by ordinary adjacency. Their scope rules are written below.

The semantic kernel is a ternary relation `Eval(k,c,o)`. Its intended content is that generic input k has the named favorable or harmful health response in context c. A Health context qualifies a generic response for a recipient class; it neither quantifies over every individual in that class nor identifies a particular patient. An AtTime context qualifies a generic response for the specified temporal situation; it contains no silent recipient identity. This deliberately modest contextual relation does not explain a cause, intervention, successful treatment or transition.

`ApplyEval(rC,rK,o; env) = Eval(resolveKind(rK,env), resolveContext(rC,env), o)`.

Resolution is partial: a reference succeeds only under an overt matching binder.
