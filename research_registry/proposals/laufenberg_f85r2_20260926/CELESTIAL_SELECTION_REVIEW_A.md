## The strongest source-compatible rival

The serious rival keeps the same referents, station arguments, scopes, traveller,
conditions and source assertions. It uses direct contextual relations:

```text
NIGHT_REPORT(e, frame, scope, phase)
VISIBILITY_REPORT(star_or_class, frame, scope, visibility)
```

It may also share a written frame-binding phrase or ordinary references. It need
not invent one unrelated predicate per source sentence or forget identity.

Where VIEW is immediately consumed by a reporting function, its wrapper can be
eliminated:

```text
REPORT(VIEW(x,f,c), value)  <->  REPORT_DIRECT(x,f,c,value)
```

Frame replacement can likewise be represented as replacement of the frame
argument while preserving x and c. These notations can express exactly the same
constraints with the same non-frame meanings. Counting source truths, or checking
that a constructed record retains its own fields, does not prefer VIEW. A common
frame record is useful notation; it is not yet evidence for a manuscript word.

The weak rival of one observer-free, unique global label is not the main test.
Without the additional stage bridge it is especially unsafe to reject that
rival from the eclipse alone. A fixed-station changing-world narrative can also
describe changing appearances, but must explicitly accommodate the source's
traveller and station changes to cover this selected unit.

## What a written constructor would really constrain

The proposed reusable contribution is **shared written argument binding**, not
the name VIEW. A future candidate should actually write a construction taking
a referent, station frame and compatible observation scope, then reuse the same
construction with an Event input and a Star/class input. Its form values and
argument order must remain fixed. The two report channels remain separately
typed; no word changes from night phase to visibility merely because a paragraph
changes.

Plural claims require explicit quantification over Stars, or a separately declared
collective type and its reporting law. A StarClass is not silently cast to the
card's singular Star type. Neither choice requires identifying one named star.

An explicit repeated reference or derived-term use must carry an earlier
referent into a later report/reframing expression. Reframing must change only
the designated station argument; it cannot introduce a new eclipse, change the
star/class, replace the observer with the star, or silently change the scope.
The eclipse observers and northern traveller are not automatically the same
people or physical stations. The same constructor may take genuinely different
frame arguments without identifying those frames.

If all such bindings can be flattened into equally explicit contextual clauses,
retain that equivalence. It does not defeat an exploratory content reading.
But if the target supplies no repeated written argument construction at all,
do not report the source's shared variables as a compositional target result.
Conversely, a fixed construction that forces an Event into a Star-only report,
loses a reference, or silently changes a cyclic visibility claim into an
instantaneous observation has a concrete type/content failure.

The source requires more than the two proposed report channels:

- C1/C6 need rising/setting precedence and a counterfactual scope; approximate
  night-phase labels do not automatically encode that ordering.
- C4's farther-south comparison cannot be reduced to two identical HAS_SETTING
  flags. Its qualitative comparison needs written content, without inventing
  a numerical astronomical model.
- C8 concerns Earth and perceived shape. Earth is outside the card's
  Event-or-Star sort, so this needs an explicit additional entity/perception
  clause rather than an unannounced widening of VIEW.
- Quantifiers, conditional travel, both rejected flatness consequences and the
  attributed curvature explanation remain part of the synopsis.

These may be factored into reusable ordinary constructions, but their values,
scope and costs must be visible. A single whole form meaning an entire source
sentence would not discharge the obligation.
