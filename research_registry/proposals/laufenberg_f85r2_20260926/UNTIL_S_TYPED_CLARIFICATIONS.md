# Clarifications to the typed IDEA550 descendant

This is an append-only clarification following root review. It does not change `UNTIL_S_TYPED_GRAMMAR.md`, `UNTIL_S_TYPED_MODEL_CHECK.md`, any frozen IDEA550 files, the 24 whole-form values, or the receipts for those files. The following refinements are not to be retroactively described as contents of the earlier packet.

## 1. Four content assertions, not three

The model-check document's phrase “three explicit conjuncts” is an error. The typed proposal contains four content-bearing propositions after the S.12 frame:

1. S.13: x adheres/remains attached at r.
2. S.14: the presentation event p for x at r is earlier than the adhesion onset.
3. S.15: under the newly stipulated generic scope, a continued departure condition for x away from r prevents the adhesion and assimilation outcomes.
4. S.16–17: the attractive faculty draws x toward r under the second temporal guard.

S.12 contributes the written x/r introductions and the first fronted guard; it is not another asserted proposition. S.13’s `chy` is retained as a written coordination marker, but the proposed clause grouping does not erase any of the four propositions. The physical lines remain unchanged and are not counted as sentence boundaries.

## 2. Exact UNTIL/AFTER contrast

For clarity, write `B(e) = end(e)`, where the endpoint operation and point-event convention are unchanged between rivals. Let `G_U(e)` and `G_A(e)` be alternative readings of the two written `chey` tokens, with the *same* attachments:

- S.12 `chey sorain` scopes forward to the S.13 adherence state H. Under UNTIL, H holds before B(c) and ceases exactly at B(c). Under AFTER, H starts strictly after B(c).
- S.16 `chey orar oldar ain` scopes to the attraction event a. Under UNTIL, a occurs before B(p) and ceases exactly at B(p). Under AFTER, a starts strictly after B(p).

The AFTER comparison replaces every temporal equation derived from `chey` in the UNTIL case. It does **not** retain either “ceases at B(c)” or “ceases at B(p)” as an independent constraint. It holds constant only the written group order, participant binders, forward-scope attachments, `oldar` completion operation, event-identity assumptions, locative condition, and all non-`chey` values/rules. The rival replaces the guard semantics as a whole; it does not silently preserve an UNTIL endpoint equation. No other production in the grammar imposes either cessation boundary.

## 3. Non-vacuous generic-departure counterworld and event reference

The `nourishment cycle κ` of the earlier grammar must be read as a *cycle/attempt schema indexed to the written participants x and r*, not as an assumption that assimilation has already succeeded. A successful actual instance is represented in the UNTIL witness; a counterfactual instance can fail. Participants x and r remain rigid across the two compared situations, while event tokens need not exist in each situation.

A non-vacuous possible two-situation witness for the generic departure construction is:

| Situation | Same introduced participants | Event and outcome status |
|---|---|---|
| `w₀` actual UNTIL case | x and r from the written S.12 introductions | p occurs; h₀ and H occur; c occurs as assimilation completion; no d occurs. |
| `w₁` departure alternative | The same x and r | p may occur first. A sustained departure d of x away from r then occurs. No h₀/H token occurs for this attempted cycle, and no c token/completion occurs. |

Thus the generic is not made true only by an empty domain or by absence of the participants: it has a specified possible departure and failed outcomes. The written `.15` construction is assigned the conditional: for each eligible attempted cycle of these same participants, if the sustained departure d occurs, it blocks the H and c outcome roles in that situation. Whether that conditional is genuinely the text's modality remains an authoring assumption; no generic marker is supplied by a new word.

An event reference and an event occurrence are kept distinct. In `w₀`, the written event descriptions resolve to actual tokens `p⁰`, `h₀⁰`, and `c⁰`. In `w₁`, the corresponding presentation/adhesion/completion *roles* can be evaluated, but the prevented h₀ and c outcomes have no event tokens. The counterfactual does not contain absent events as though they were actual objects. The cross-situation role/counterpart relation that lets `.15` refer to the same outcome roles is an additional intensional assumption. `sorain` is accordingly treated as an outcome-slot description whose actual completion token exists in `w₀` but not `w₁`; that possible-world reading was not explicit in the prior grammar document.

These two-situation examples demonstrate only one coherent interpretation of the written `am` content under the generic-scope choice. They are not observed Voynich events, dates, or timings. The `nourishment cycle` label does not guarantee success: the counterfactual attempted cycle is specifically unsuccessful.

## 4. Causal PREVENTS remains a primitive and a cost

The earlier typed grammar gives `am` two typed outcomes, `Prevents(d,h₀)` and `Prevents(d,c)`, but it does not fully define the causal relation. The implication “if d, then not H and not C” is not, by itself, a causal definition: another condition could block the outcomes, and d could be irrelevant.

One possible additional definition is a matched counterfactual criterion: holding the same x/r, cycle attempt, and background fixed, `PREVENTS(d,o)` holds only if (a) the no-d counterpart produces outcome o and (b) the d counterpart lacks o because the intervention introducing d changes that outcome. The two-situation witness above can instantiate that criterion for both H and c. But this criterion itself requires a counterpart relation, a permitted intervention, background invariance, and causal attribution; it is not supplied by the current word assignment or the frozen source alone.

For the present descendant, therefore, `PREVENTS` remains an explicitly typed **primitive causal relation** within the already fixed `am` sense, with its two outcome slots and same-cycle links counted as costs. The generic conditional illustrates a possible model; it does not reduce `PREVENTS` to material implication or settle its full truth conditions. This is an honest residual semantic incompleteness. The draft does not receive a formal consistency/causal PASS from this clarification.
