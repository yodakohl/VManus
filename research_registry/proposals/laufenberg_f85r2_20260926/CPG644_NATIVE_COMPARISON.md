# Further physician comparator: Heidelberg Cpg644, 100v

2026-09-26. This is one native source comparison, not a census of30pictures.
KdiH87.6.2 dates the manuscript to1450–1470 and places it in southern Germany,
possibly Franconia. It identifies a30-picture Harnschau sequence at94r–108v,
with different urine descriptions below repeated physicians. Those are
catalogue claims; root personally inspected only the catalogue reproduction
of100v (Abb107), which was selected by the catalogue editors, not selected
from30images after a similarity search.

The primary digitization landing page returned an Access Denied page through
the web tool. The freely available catalogue reproduction was fetched instead.
Its311x450resolution permits a gesture comparison but limits transcription.
Exact source URL, size and hash are in `CPG644_COMPARISON_RECEIPT.json`.

## Native observation

A robed, capped physician is shown as a half-figure facing right. One forearm
is raised in front of the torso, with an open supporting hand under a rounded
flask. The flask has a tapering neck and visible top rim; colored contents
occupy the lower body. The face is oriented toward the lifted vessel, which
is above mouth level and does not contact the mouth. Fingers are schematic,
yet the base-supporting gesture is legible. Blue clothing is distinct from
the flask contents. No circle, sun, season figures, plume set, staff or beads
is present on this source leaf.

The first caption words are readable approximately as `Ist der harn rot vnd
lauter vnd dick so ist der mensch siech ...`. The following anatomical/diagnostic
phrase is not transcribed confidently at this resolution. This supports an
if-observation/then-diagnostic-meaning caption, while the exact condition is
not claimed. The image's physician/urine interpretation is therefore not
inferred merely from a generic drinking glass.

## Relation to the retained f85r2 observations

GDT1043 describes the east figure's raised bulb/neck object and face orientation
as flask-inspection-compatible, with uncertainty about the grip. This source
provides an actual late-medieval half-figure, raised flask, supporting hand and
inspection pose. It strengthens that specific class comparison; it does not
resolve the target grip, identify its object contents, or prove an occupation.
No new target image was opened here. The absence of the other panel features
prevents promoting this single resemblance to a whole-program or copied-source
match. Its possible Franconian origin also gives no exclusive Upper-Rhine
provenance argument.

A nearby medical text can describe a diagnostic relation rather than merely
name the drawn object. Therefore the catalogue's short source caption cannot
justify assigning a neighboring Voynich group directly to URINE, PHYSICIAN,
RED or any disease. This is a source-level content alternative for a later
complete reading, not a changed Voynich dictionary or a semantic test.
