## Two useful next discriminators

1. **Locate and compare the complete inscriptions.** Verify exact whole forms,
   boundaries and the written continuation under each reader. If the writing is
   circular, an opening requires a physical start cue or independently fixed
   reading origin. Choosing the common word as origin supports only a shared
   adjacent subsequence. If other groups also differ, retain all differences
   instead of calling this a one-variable minimal pair. A genuinely repeated
   frame would constrain a construction without naming its variable.
2. **Make any eventual semantic trial pay the outside-context obligations.**
   A body-name, property or reference proposal must keep the same `okaiin`
   value in the already documented standalone label, two-word inscription,
   repeated prose and astral context. Separate a failure of a strict grammatical
   contract from a merely unexplained contextual use. The present profile can
   reject an exclusively line-initial `okeo` claim; it cannot select a Sun/Moon,
   quality or genitive gloss. No new unregistered census is proposed here.
