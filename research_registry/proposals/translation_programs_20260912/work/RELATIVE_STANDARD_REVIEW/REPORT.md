## Exact conditional consequences

Let a be the value of the currently assumed subject on one shared unspecified axis, and b one fixed comparison standard. The following are analytic consequences, not new Voynich meanings:

| Proposed three readings | Consequence |
|---|---|
| a < b; a > b; a < b | First two statements incompatible |
| a > b; a < b; a > b | Same incompatibility after reversing axis |
| a <= b; a >= b; a <= b | Exactly a = b; third statement redundant |
| a >= b; a <= b; a >= b | Exactly a = b; no orientation identified |

Proof: a < b and b < a imply a < a by transitivity. The weak opposing inequalities imply a = b by antisymmetry. This uses an ordered scalar axis and fixed subject, standard and time; it is not a claim about every possible relation. The three visible forms are not silently assigned different referents.

Changing the standard between occurrences can make strict inequalities satisfiable: a=1, b1=2, b2=0, b3=2 is one example. It introduces two distinct standard values and a return to the first, none identified between the adjacent forms. Changing time could also make alternating comparisons possible, just as P11's temporal reading already did. Neither is a new solution unless a fixed written rule selects that change throughout the declared reading scope. An adjective-modified comparison or nested expression is another possible analysis, but would change the predicate/argument contract rather than validate the proposed unchanged one.
