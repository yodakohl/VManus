## Two precise reference failures, rather than a vague missing-input list

**Historical role is not typed recency.** Consider two supplied discourse histories with the same current P, G and W but former owners A and B respectively. After accession, a representation retaining only the same active action/argument has the same input in both cases. A deterministic function of that current-only input cannot return A in one history and B in the other. This is a conditional interface argument, not an executed manuscript test or a universal claim about GDT564. A written or retained owner-history argument would distinguish them, but adding it changes the interface. Creating one exceptional type per desired historical owner would be a hidden answer lookup.

Likewise, the GDT1016 permutation restriction cannot be bypassed by a unary anonymous wrapper: exchanging A/B while fixing its input must fix its output. An explicit relation/history argument could remove that obstruction, because it would change under the same exchange. GDT1016 already states that explicitly written arguments would constitute a different hypothesis; this is not a new discovery or a rescue of its failed 72 checks.

**Open OTHER is not a unique residual member.** Transport OTHER_CARGO works only after removing two named cargo arguments from its closed inventory and obtaining one candidate. Justinian's `sive ... sive alius` does not name such an inventory, promise a unique other person, or say that the other thief is O or W. With two eligible other persons the transport operation is undefined, although J06 remains intelligible; with no previously named eligible other person it is also undefined. Replacing it with a bound variable constrained by T≠M is a defensible new semantic operation, not an application of the inherited one.

There is also a source-coverage trap: the logical disjunction T=M or T≠M is exhaustive, so an optimizer could erase it while preserving many truth conditions. That would erase the explicit maker-role introduction and same/other statement required by J06. A lossless source-account writer must retain the branch/scoping expression, even if a theorem prover considers it redundant. No branch is to be encoded by a free whole-sentence alias.

## Where a definite writing prediction is still absent

A true small writer would have to fix, before target selection, at least: how written components introduce and recall typed arguments; how pre-accession role bindings persist; how role/history arguments are spelled; how equal/different alternatives and general assertions open and close; which components may share a word; and whether any explicitly delimited context changes a component's realization. These choices must jointly emit a stream or a finite enumerable set, not merely an English account after reading the target.

The strongest available source constraints are shared P/G identities across relations, shared CONDICTION across specific and general assertions, distinct VINDICATION/THEFT_ACTION values, and the two identity branches. But “same semantic value” alone does not say that its surface repeats. A no-allomorphy concatenation convention would force repeated substrings; a contextual realization convention might not. Choosing between those conventions now solely to obtain a count-compatible target would repeat the weakness of the closed record-code routes. No already declared component in the inspected full readings identifies which realization is required here.

This is the decisive stop: **the current proposal can be formalized, but the inspected inherited mechanisms do not yet make one concrete, source-complete manuscript writing prediction.** Neither an absent target fit nor a contradictory source interpretation has been established. No candidate paragraph should be opened on the authority of this note.
