# f22r: two named *moris/mûrier* source pictures inspected

29 September 2026. This is an exploratory, target-exposed follow-up to the six-witness catalogue-level capacity screen in `F22R_SOURCE_ONLY_SCREEN_20260929.md`. A web search yielded two **entry-specific folio locators**, a changed input from that earlier screen. The question was whether either independently named pre-1500 illustration actually shows the two unlike upper forms fixed for f22r: three dark blue cup/bell terminals and many red/pale bead-bearing axes on one plant. This visual prerequisite was checked before any source-prose-to-Voynich alignment. No new Voynich page or transcription was admitted.
