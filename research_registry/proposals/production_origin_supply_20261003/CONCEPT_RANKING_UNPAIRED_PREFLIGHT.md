## Smallest finite model

1. Per side fit on at most **32,000 exact whitespace-group occurrences**, keeping complete records. Written side takes complete records in inherited source order, stopping before the next record exceeds the cap. Reference takes other-books complete records round-robin, preserving each book's source order, with the same stop rule. Do not skip an overflowing record to seek a favorable later one. Keep case/Unicode/punctuation/marker intact before anonymization. This is a fixed small-corpus working budget, not a measurement of every Voynich transcription's word count.
2. Select128 most frequent written types with at least20 occurrences; reference candidates are the most frequent types with at least20 occurrences, capped at256 and requiring at least128. Variable reference cardinality is input-only and predeclared. Missing capacity is NO_CAPACITY, not a smaller repaired vocabulary. Each side has separate randomized opaque IDs with separate seeds; no shared alphabetical ordering, lexical hash or spelling-derived initialization. The fitter receives no strings, marker indicators or subword features.
3. Count signed offsets−5…−1,+1…+5 within complete records. Context columns are each side's own top1,024 types plus RARE, tagged by all ten signed offsets. Count all center types before selecting rows. For count matrix `C`, use `PPMI[i,j]=max(0,log(C[i,j]*sum(C)/(row_sum[i]*column_sum[j])))`, with zero-count cells zero. Cosine distance is `1-dot(x,y)/(norm(x)*norm(y))`; divide each matrix by its mean over all ordered off-diagonal cells. All-zero selected profiles or zero mean distance stop capacity. This uses every group's context, not only ingredient spans, and claims no long-range grammar. No neural model, pretrained vectors, morphology or cross-space coordinate registration.
4. Normalize `p` by the sum of the128 selected written counts and `q` by the sum of the selected reference candidate counts, independently; both sum to one. Minimize the row-constrained objective below; only row mass is compulsory, so aliases/unequal inventories are allowed:

   `GW(Dw,De,G) + KL(column_mass(G) || q) + .01*KL(G || p*q), G>=0, row_mass(G)=p`.

   `GW` is the sum of `(Dw[i,k]-De[j,l])^2 * G[i,j]*G[k,l]`. Here `KL(x||y)=sum(x*log(x/y))` for equal unit-total nonnegative arrays, with zero terms zero: both displayed KL terms have **positive** signs. This is a **proposed marginal-relaxed modification**, not a replication of2018's balanced GW. Parameterize `G=diag(p)*row_softmax(Z)`. Use float64, three fixed independent seeds0/1/2,200 full-batch Adam steps at.05, betas(.9,.999),epsilon1e-8,no weight decay/clipping, initial `Z=log(q)+Normal(0,.1)`; choose lowest objective evaluated after step200, exact ties seed order. No early stopping or tuning; nonfinite results are computational failures. Publish all three outcomes; nonconvex search is not exhaustive. Each row's normalized coupling supplies a complete ranking, descending mass with exact ties by opaque ID, not calibrated semantic probabilities.
5. F's pair cost is absolute `log(p_i)-log(q_j)`. B's pair cost is squared Euclidean distance between16 quantiles at `k/15,k=0..15` of each word's off-diagonal within-space distance row, using linear interpolation of the sorted row. Scale each pair-cost matrix by its mean over all cells; an all-zero matrix stays zero. Both minimize `sum(cost*G)` **plus the same two KL terms**, with the identical row constraints, optimizer, starts and ranking tie rules. Neither is forced to be bijective or have exact reference column mass. B checks whether GW's joint matching adds anything beyond a cheap contextual fingerprint; matching mass regularization avoids giving GW an unmatched frequency constraint.

## Scoring, countercases and decision

Lock all rankings before gold. Score **whole-book** sites whose blinded marked span exactly equals its containing group and has one marker. Source types outside the128-node fit inventory remain UNSUPPORTED in full coverage accounting; no label-based selection. Primary is equal mean across selected marked types of occurrence-level exact gold inclusion in top5, then equal mean of four books. Publish top1/MRR, full rankings, mixtures, collisions, all OOV/multiword truths as errors, selected/unselected coverage and outside-fit-record results. A type-global ranking does not disambiguate individual ambiguous occurrences. Report its oracle top5 ceiling only after locking; never use it to filter.

Require at least ten selected marked types and200 eligible marked whole-book occurrences per book, using only blinded support. The primary denominator contains **observable marked forms only**, never all128 mostly unchanged nodes. All selected wholeforms/whole-book coverage remain secondary. Failing this is NO_CAPACITY. Do not import1160's gold-derived two-expansion support rule. These capacity conditions were amended following independent/root design review before any extraction or counts.

Use19 fixed null worlds per fold: independently permute all tokens of each fit panel globally into the original record-length slots. This preserves each side's type marginals and reset capacities while destroying local and record/topic alignment. Rebuild geometry and refit all three GW starts and B; F is unchanged. **Wholeword-ID permutation is not a null**, because geometry is invariant to renaming. Score null mappings against original held truths. This constructed comparison is not a population p-value or complete search correction.

Proposed promotion rule: GW mean top5 coverage>=.50, mean gain>=.10 over the stronger F/B mean, strictly above both in at least3/4 books, and `(1 + null gains >= observed gain)/20 <= .10`. These are proposed operational cutoffs, not user requirements or calibrated meaning confidence; freeze them before any extraction outcome/fit. Publish all results even if an earlier condition fails.

**Success changes the next action:** register one exploratory frequent-wholeform ranking on already admitted native inputs under a stated stable-type/context hypothesis. Use frozen source hypotheses and finite inventories, retain native alternatives and complete context, report all rankings/UNKNOWNs; no source language is selected by this control. Candidate lists may prioritize a later complete C0 account, not become accepted dictionary entries. No automatic decoder or reserve access. **Failure/unstable or null-equivalent gain:** stop this geometry/ranker at this corpus budget. **Capacity failure:** retain missing capacity, without weakening thresholds or treating it as a semantic negative. A positive cannot prove that Voynich uses this writing representation.
