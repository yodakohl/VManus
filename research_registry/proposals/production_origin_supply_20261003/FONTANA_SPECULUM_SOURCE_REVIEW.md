## Operation in the quoted text

Concentric wheels turn independently. All share radial divisions; each wheel
contains an entire alphabet, one letter per division. To retain a word, the
operator aligns its first letter on the first wheel, second on the second, and
so on, along one radius. Thus the selected radius reads across wheels; going
around a wheel presents alternatives for one character position. The figure
shows concentric segmented bands with signs and a central Speculum label,
inside a handled circular object. Its visible layout is compatible with the
quoted operation. A flat drawing does not demonstrate a built working machine.

The source explicitly distinguishes character position from selectable character.
It does not state that rotation preserves the remembered word. Independently
turning a selected wheel generally changes the displayed character. Coordinated
rotation with a correspondingly moved readout direction could preserve a radial
sequence geometrically, but that is an inference, not an additional author-given
operation in this complete passage. No secret address, second decoding alphabet,
character-to-word expansion or Voynich syntax follows.

## Relation to the other source leads

The Serpens description also selects letters at fixed sites, using separate
small wheels. It is not the same physical geometry as Speculum. The symbolic
mirror in the virtue/science lists (IDEA000904) is a third use: a depicted carrier
can represent a named concept. The shared modern word mirror does not establish
that these passages all describe one mechanism or meaning. The distinction is
useful when authoring a historical hypothesis, but is not target evidence.

## Decision

Retain the exact historical distinction between circulating alternatives and
reading a selected sequence. Do not launch a Voynich rotor or compare alphabet
shapes. The source passage supplies no already-owned Voynich readout direction,
letter-position correspondence, or equivalent content observed under a changed
setting. Consequently it does not presently choose a target interpretation.
