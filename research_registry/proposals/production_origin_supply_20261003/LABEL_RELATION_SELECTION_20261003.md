## Two possible discriminants considered, neither selected

### 1. Stable referent under a change of depicted anatomical extent

An account that preserves the same kind while expressing a basal part differs from an account that merely names the depicted object only if the written material separately identifies the invariant kind and the varying part. The existing two-sided anatomy observations do not themselves do that. Renaming a latent KIND variable as BASAL-KIND gives the same ownership edges and can fit the same rare labels.

A concrete discriminator would be an independently owned crossed contrast: the same kind in two extents and a second kind in those same extents, with a written construction that reuses its kind argument and changes the same part argument. This is **not a newly discovered route**: IDEA000669's reviewed reopening condition already demands the corresponding complete written argument/consumer, and GDT1128 already closes the unchanged literal bridge and one-identical-unit shortcuts. Running a free graph optimizer on the current pairs would introduce a chosen factorization rather than distinguish it. No new extraction or model was started.

### 2. Label value reused as a prose reference versus a portable property/count

A locally singular label plus its exact prose recurrence does not by itself imply coreference. An independently fixed consumer relation that selects that labelled object would distinguish a local reference account from a freely portable class/property value. The current best owned example, `otor`, has no such prose pointer. Counting the star rays would supply a chosen numeral interpretation rather than the required written consequence.

The existing `words profile otor` was retrieved before considering this route: ZL3b33 occurrences on29/179 selectors, IT2a38 on32, RF1b29 on25. ZL contains17 Herbal,8 S,4 B,2 P,2 T occurrences;31 are prose and2 local. Positions are6 starts/26 middle/1 end; no adjacent repeat, one locus with two occurrences. Profiles keep whole form separate from embedded strings and readers separate. GDT1072 already makes the cross-register constraint and retains the f68r1 RF boundary difference. This review therefore does not assign a star name, number, or broad function to `otor`, and does not rerun frequency/ray screening.
