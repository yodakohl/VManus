## Strongest candidate considered: selecting an earlier eligible object

GDT1137 already does more than attach English labels to a pattern. Its common
constructor computes two types from directed components; a later written
selector retrieves a computed object, and subsequent written expressions
consume its material and operation fields. This uses actual positive
composition knowledge while retaining whole-form costs. Literal pictured
object labels are unnecessary for that proposed reference mechanism.

The alternatives are precise:

- H1: select the earliest object matching the written restriction.
- H2: select the latest object matching that same restriction.

The observable needed is **a later expression whose fixed realization differs
according to the selected object's properties**. Suppose two objects both
match restriction R but differ in another feature F. A subsequent expression
that asserts or spells out F must then differ under H1 and H2. Identifying
the material as powder, metal or a particular plant is unnecessary. Anonymous
feature identity is enough if the writer independently fixes how it is
expressed. This is an actual route from reference semantics to a written
consequence, not merely an internal program trace.

## Why the actual strongest case does not provide that test

In1137, the two generated types have different material/operation restrictions.
The later SOL+CHEDY restriction admits **only the first**. Earliest-compatible
and latest-compatible therefore return the same object. The rejected
latest-product-only rival ignores the written restriction; rejecting it
cannot establish an EARLIER meaning. The following material assertion is
partly redundant with that restriction. Changing a field inside the program
and causing an assertion to fail proves that the code uses the field, not
that the manuscript selects the English interpretation.

The method explicitly allows nominal types before production and scopes the
construction to one complete IT account. Turning all repeated similar words
elsewhere into earlier products would change that scope and manufacture the
multiple-eligible-object condition. No such extension is recommended here.

IDEA895 supplies a different conditional endpoint, USE(b) versus USE(c1), but

forms**, argument arities, or reference identities under two readings. Those
are legitimate discriminators even when no noun is translated. The minimum
is not “obtain an independent plant name”; it is “fix the common realization
law so both hypotheses cannot spell the same consequence by construction.”
No fixed writer with that unequal consequence is supplied by1137 or895.
Their semantic relabeling symmetries remain real.
