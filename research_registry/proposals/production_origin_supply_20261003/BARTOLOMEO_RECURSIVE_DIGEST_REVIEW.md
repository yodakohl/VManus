Unlike a generic claim that a word “summarizes” a passage, this proposed law
constrains literal material already written at several levels. Formalize its
necessary relation as

    parent = p1 p2 ... pn,
    each pi a nonempty prefix of the corresponding ordered child ci.

The source's actual syllable rule would be stronger than this existential
prefix relation. It must be collated rather than replaced by flexible cuts
chosen separately to fit each node. Distinguish a failed exact source
syllable rule from success of its weaker necessary prefix condition.

## Useful correction: the necessary relation is not restricted to bijections

For any fixed **non-erasing concatenative code** E, including variable-length
character codewords, E(parent)=E(p1)...E(pn), and each E(pi) remains a prefix
of E(ci). Thus the existential relation survives such a code. It need not
be injective for that necessary implication, although collisions weaken its
discriminating power. A one-to-one letter renaming is only a special case.

What does not transfer unchanged is a fixed number of visible characters
per syllable. Context-dependent allography, resegmentation, erasure, or a
non-concatenative writer also needs its own contract. No EVA letter is named
as a Latin letter, and no learned Voynich unit is declared a syllable.

## A real future falsifier, not a free hidden-tree model

The smallest useful target packet would contain one written parent, its
independently ordered children, and a written grandparent with all its
children. Freeze every node and edge before inspecting prefix compatibility.
Then require the **same source-derived clipping law at every edge**, all
children included and ordered, no inserted filler. One unambiguous required
node that cannot be reconstructed contradicts this fixed architecture.
Shared first-child prefix inheritance through successive levels is an
additional necessary consequence, not another fitted parameter.

A successful necessary-relation test would favor recursive written cue
construction over unrelated free labels only if the entire search and short
prefix opportunities are controlled. It would not recover a plant name or
prove the exact historical source. Known directed composition makes this
worth considering; whole-form/context residuals mean that importing a plain
prefix writer is still a substantive hypothesis.

No already-owned target packet nominated in the inspected primaries supplies
this multi-level textual tree. That is a bounded capacity statement, not a
claim that the manuscript contains no such organization. Existing labels,
paragraph starts and graphical panels must not be connected after seeing a
convenient fit. Mere membership in one illustration supplies no ordered
parent/child equation.

If only the final digest was written, every unseen child can be invented to
start with its required fragment. Many original name lists then have exactly
the same digest. Even a known tree shape does not restore the discarded
suffixes or full propositions. The learned referent catalogue is essential
for inversion; word-frequency fitting cannot recover the lost information
uniquely. A digest-only target therefore supplies no unequal endpoint for
this test.

**Recommendation:** finish the already selected source collation to determine
the actual clipping convention and exceptions, and retain the resulting law.
Do not build a decoder, arbitrary hidden hierarchy, or global acronym scan.
Only a separately nominated existing parent/child packet would justify a
target contract. Source-law verification is a historical mechanism finding;
it is not yet a manuscript interpretation or a translated word.
