# GDT146 — coarse visual confound audit

This exposed post-hoc audit asks whether the GDT140 five-pair assignment is
already recoverable from the twelve coarse, pre-existing GDT137 human visual
feature flags.  It uses the same 120 one-to-one assignments and three fixed
visual similarities: positive-feature Jaccard, twelve-bit agreement, and exact
coarse illustration profile.  No image or transcription source is opened.

Use `COARSE_VISUAL_PROFILE_DOES_NOT_EXPLAIN_RELATION_ASSIGNMENT` when none of
the three similarities has inclusive p at most .05.  This rules out only the
recorded coarse feature profile as an explanation; it does not make the human
relation statements objective or establish content, identity, or meaning.
