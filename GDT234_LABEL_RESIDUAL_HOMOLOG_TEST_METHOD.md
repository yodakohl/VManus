# GDT234 — label-prefix residual homolog test

Apply the unchanged GDT233 strict prefix set to every GDT231 same-visual-unit
pair.  Compare normalized family edit similarity before and after removing the
longest selected prefix from each member.  Empty residuals are retained in the
full diagnostic; the strict sensitivity requires both members to lose a
prefix and both residuals to remain nonempty.

This is a post-hoc mechanism decomposition on an exposed atlas.  Improvement
would nominate the residual as a better content candidate; degradation means
the visible homolog similarity was carried mainly by the register prefix.
No new source table, image, or f84 row is opened.
