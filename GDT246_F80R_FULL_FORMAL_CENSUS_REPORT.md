This is exact whole-group reuse, not substring resemblance. Four of eight
strict labels participate and the same three forms account for five prose

crosses P1 and P3.

The most economical interpretation is a reusable graphical/prose code
interface: some complete forms used as labels can also occupy an internal
prose-group position. It weakens models in which every label is an isolated
object name or a purely graphical prefix shell. It does not decide whether the
reused form is a content identifier, a construction, a conventional caption
formula, or a common nonsemantic code unit.

## Translation consequence

content model must allow some opaque group identities to pass unchanged
between graphical labels and paragraph prose, underneath or alongside the
partial label renderer. It still supplies no referent dictionary.
