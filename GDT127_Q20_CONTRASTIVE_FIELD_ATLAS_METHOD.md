# GDT127 — Q20 contrastive field-template atlas

## Purpose

Extract repeated HPR2 field skeletons from the 170 clean Q20 records and find
cross-folio cases in which one aligned PAGE_HOST changes while the surrounding
compiler template is fixed. These are internal contrastive slots and candidate
future codebook entries, not linguistic words or semantic roles.

## Extraction

- Parse all source groups exactly as in GDT114.
- Split each physical line after every DY-closed group; retain the final
  non-DY field separately.
- A compiler skeleton records, for every group, WRAPPER, O/OT frame,
  RIGHT_FAMILY, inner-D, DY, and B3 while removing PAGE_HOST identity.
- ZL3b is the primary atlas. IT2a and RF1b are stability views of one
  manuscript.
- An atlas template needs at least four primary occurrences, two physical
  folios, and two distinct host fillings. Every template and every qualifying
  one-slot pair remains exported.

## Matched nulls

The primary diagnostic counts cross-folio multi-group field pairs with the
same exact skeleton and either zero or one differing host position. In 4,096
worlds, permute host identities among groups while retaining page, exact
compiler cell, and host-length bucket. A stricter sensitivity also retains the
host final character, which is already known to license renderer state.

The null tests enrichment of reusable one-slot formulas beyond page-local host
frequency and compiler licensing. Failure does not erase the observed formulas;
it prevents treating their abundance as unusual.
