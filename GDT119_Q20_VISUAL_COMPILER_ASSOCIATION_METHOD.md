# GDT119 — Q20 star morphology versus record compiler

Status: `YOLO_ARCHIVED_TARGET_HYPOTHESIS_GENERATION`

The earlier SME001/SME003 route built a provenance-bound, source-independent
star morphology panel but failed its target-free confirmation calibration and
therefore never joined visual targets to text features.  GDT119 does **not**
rewrite that failure.  In exploratory YOLO mode it joins those already acquired
human observations to the record compiler discovered independently in
GDT114–GDT117.

Use the 156-row complete-page binding on seven physical folios.  Test three
binary visual axes from the human Stolfi source table:

- `RAYS_8_VS_7` (other ray counts missing for this contrast);
- `TAIL_2_VS_1` (missing/other tail values excluded);
- `COLOR_RED_VS_YEL` (white/unknown excluded).

Color is an explicitly confounded sensitivity because it is usually
alternating by ordinal.  No color meaning is inferred.

Hold out one physical folio.  A fixed logistic-ridge nuisance sees ordinal
parity, normalized ordinal, page record count, page side, OPEN/BODY lengths and
record line count.  Compare five formal additions: OPEN wrapper, OPEN compiler,
BODY compiler, combined OPEN+BODY compiler, and combined raw record character
trigrams in 32 fixed SHA bins.  All 15 axis×representation variants are
retained.  Within each held page, 4,096 worlds permute complete formal record
profiles while preserving labels, page, ordinal nuisance, record counts and
the feature multiset.  Report local and max-15 p-values.

ZL3b is primary; IT2a/RF1b are alternate-reading sensitivities.  The visual
observations are human annotations, not new AI image calls.  f84r is absent and
receives no query or prediction.  No star meaning, record meaning, role, word,
morpheme, POS, sound, language, plaintext, translation, or recipe is assigned.
