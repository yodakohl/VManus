# GDT005 duplicate audit

The proposed matched physical-cut test is **not already answered**, but its
scope must remain narrow.

| Prior route | What it tested | Why GDT005 is not a rerun |
|---|---|---|
| IGR001/IGR002 | neutral whole-unit shapes behind recurrent transcription disagreements | did not inspect proposed module cuts or compare them with pseudo-cuts |
| UNPARSED_SURFACE / source-separator impact | alternate-reading split/fused spaces and source-safe boundaries | used manual transcription boundaries, not native within-group physical separation |
| GDT002 morphology | free/bound counts, formal split/join analogies, minimal pairs | did not compare native target cuts with matched ordinary groups |
| GDT003 paradigms | fourth-cell prediction against string baselines | formal prediction only; no image measurement |
| GDT004 module-shape atlas | nine successful completion groups | target-only physical pass; no matched ordinary-cut control |

The untested question is therefore: **does a proposed analytic cut have a
coarse visible separator more often than a mechanically matched pseudo-cut in
an ordinary source group on the same line?** GDT005 answers only that question.
It does not repeat IGR's grapheme-shape classification and does not reopen a
failed language or morphology model.
