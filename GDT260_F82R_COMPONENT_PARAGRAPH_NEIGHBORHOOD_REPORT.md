## Why this may matter

This is the first corrected-q13 case in which a human-attached graphical label
selects a narrow member-code neighborhood concentrated in the physically
following paragraph. A useful provisional generator is:

```text
attached graphical tuple = renderer/component code
following paragraph opening = locally related code variants
```

That is compatible with a component-indexed paragraph, a local topic/address
family, or a page-local register template. It is not yet a decoded component
name.
