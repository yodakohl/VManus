# f67v2 / Rosettes native visual scaffold check

Date: 2026-08-11

This is a bounded manuscript-internal visual comparison prompted by a public
2026 observation that f67v2 and the Rosettes foldout may share a rotated
layout. The comparison was prescreened before image review because it proposes
an author-visible relation between two Voynich pages rather than an imported
historical label or decoder claim.

Only the official Yale images carry evidential weight. The public comparison
fixed the component questions; its interpretation is not assumed true.

## Fixed visual questions

1. Does each diagram have one central position, four principal-axis
   positions, and four corner positions?
2. Are the node classes and complete connection graph the same?
3. Do distinctive Sun-like, T-in-O-like, connected-dot, and fanning motifs
   establish one unique 0/90/180/270-degree alignment?
4. Does the alignment give a one-to-one source-native text-slot map?
5. Does the evidence establish copying or shared content rather than a common
   visual vocabulary?

## Decision rule

A coarse 1/4/4 occupancy pattern is retained as a scaffold candidate. A
cross-page slot map requires the same node classes and edge graph plus a
unique rotation fixed by nonrepeating landmarks. Repeated decorative motifs,
different node contents, or unequal text registers cannot fix a transfer.

## Exclusions and ceiling

No OCR, automated transcription, CLIP, embedding, image-similarity score,
batch recognition, automatic glyph reading, or decoder claim is used. The
observations are machine-authored native visual inspection, not literal human
annotation.

A pass may establish only a manuscript-internal coarse layout analogy. It
cannot prove that one page copies, keys, or explains the other and supplies no
object identity, direction, place, map, word, sound, language, cipher,
plaintext, meaning, or translation.
