# Hypothesis registry

`ACTIVE_HYPOTHESES.tsv` is the compact authoritative registry of post-reset
hypotheses, including completed, stopped, and registered work. Detailed
preregistration files are retained only where they are primary evidence for a
live claim; deleted closed-route preregistrations are represented by their
complete registry rows and the active experiment ledger.

A new row must specify independent evidence, a prediction that competing
system classes do not share, a falsifier, and held data before scoring. Image
resemblance, proximity, a new neural model, spelling similarity, historical
plausibility, and an uncorrected subset association are not independent
semantic evidence.
