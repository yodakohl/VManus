## Transfer gate

Transfer to f67v2 requires all of:

- exact source-to-target unit cardinality and topology;
- explicit ownership of one target text locus by each target figure/group;
- a one-to-one source-name/target-locus map; and
- a common start and orientation.

Four source names and four target corner groups are insufficient when the
source's individual placements are unstated, the target groups contain three
or four faces, and the target has several competing text registers.

source-family comparator and a precise qualified-human review task.  No
