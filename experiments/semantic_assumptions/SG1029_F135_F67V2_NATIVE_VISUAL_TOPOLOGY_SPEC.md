## Bounded visual questions

1. Does the source show exactly twelve busts as four repeating sectors of
   three?
2. Is one crowned bust present at each principal axis, with two smaller busts
   between consecutive crowned busts?
3. Do the four human-published cardinal names occupy four distinct axial
   positions aligned to those crowned busts?
4. Does f67v2 show the same twelve-unit annulus, crown hierarchy, and 4x3
   cardinal ownership?
5. If not, which f67v2 register is the closest visible fourfold analogue, and
   does a source-to-target start/orientation actually survive?

## Decision rule

Source-internal topology may be strengthened from a collective four-name
register to a positional map only when all four names occupy distinct axes and
each axis meets one crowned bust. A Voynich transfer requires the same unit
cardinality, ownership relation, and independently fixed orientation. Mere
wind-rose genre, fourfold layout, or shared number twelve is insufficient.
