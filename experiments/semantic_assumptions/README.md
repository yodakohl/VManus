# Fresh-start investigation

This is the only active experiment directory after the 2026-08-06 reset.
It intentionally contains no inherited semantic hypothesis, image cache,
historical-source candidate, or English word assignment.

- `grammar/` records the confirmed structural baseline and its frozen evidence.
- `CLOSED_ROUTE_FAMILIES.tsv` prevents accidental repetition of failed routes.
- `hypotheses/` admits only predeclared, falsifiable new ideas.
- `tests/` builds/verifies the curated archive and active evidence pointers.
- `results/` contains only post-reset reports.

The complete old bulk directory is no longer retained. A curated subset of
primary evidence remains at
`../../archive_pre_reset_2026-08-06/semantic_assumptions/`. Read only a report
named by the active evidence index. The active ledger and closed-route table
are authoritative for removed negative-route history.
