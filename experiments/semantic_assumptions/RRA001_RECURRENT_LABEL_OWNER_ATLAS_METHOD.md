# RRA001 recurrent-label owner atlas method

Status: **PREREGISTERED BEFORE SIXTEEN NEW TARGET-SPECIFIC OWNERSHIP JUDGMENTS**.

Build the complete panel from editorial kind-`L` loci which have one source
group, the same literal surface of length at least two in ZL3b/IT2a/RF1b, and
at least two physical folios. Require an existing human annotation at every
occurrence and retain a type only when every occurrence shares at least one of
the coarse tags `PLANT`, `FIGURE`, `WATER_OR_APPARATUS`, or `STAR_OR_SKY`.
Freeze all qualifying types and every occurrence. Images, parser roles, object
description prose, glosses, and individual favorable examples do not select
the panel.

For each locus judge ownership of the frozen shared coarse class, not merely
ownership by any nearby object:

- `SINGULAR_COMMON_CLASS_OWNED`: the inscription is securely localized; one
  object of the shared class occupies a unique local slot; an enclosure,
  partition, leader, reserved column, or unambiguous local stack assigns it;
  no equal competitor exists; and the assignment does not depend on editorial
  wording or transcription order.
- `OTHER_CLASS_OR_SLOT_ASSOCIATED`: a local slot or a different object class
  is visibly assigned, but the shared class is not singularly owned.
- `PROXIMITY_OR_GROUP_ONLY`: only nearness or plural/group association is
  visible.
- `LOCALIZATION_UNRESOLVED`.

Carry forward the published RFO001 outcomes for the three `otoly` loci. Carry
forward the published `darol` conclusion that f75v.21 and f82r.35 are
unattached proximity/group labels for the common `WATER_OR_APPARATUS` class.
The other sixteen target-specific ownership outcomes are sealed despite prior
full-canvas exposure for unrelated layout questions.

A surface type passes only if every occurrence is
`SINGULAR_COMMON_CLASS_OWNED`. The atlas is descriptive acquisition evidence,
not a confirmatory semantic test, because human tags define the candidate
classes. Even a passing type would be only a repeated label in visibly owned
same-class positions; it would not name the class or establish a word, POS,
sound, language, cipher, plaintext, meaning, or translation.
