# `cho/che` masked scope universe

## Purpose

Freeze the complete source-native event geometry needed to calibrate the
paragraph-scope test without storing the binary `o/e` value at the selected
`ch/sh+o/e` site.

This is a data-separation artifact, not a result. It extends the already
validated capacity panel from eligible queries to every strict single-site
event, so synthetic outcomes can be attached without reopening manuscript
outcomes.

## Construction

Reconstruct the same 4,024-line, 709-paragraph ZL editorial scaffold and the
same strict single-site event rule as the capacity audit. For every retained
event, replace only the selected site's `o/e` with `X`, discard the unmasked
projection, and store its source ID, physical identity, page/panel/folio,
section and Currier metadata, paragraph, line and group coordinates, masked
template, and whether it belonged to the already frozen primary query panel.

The event table must contain exactly 9,983 ZL, 10,124 IT, and 10,053 RF rows.
It must reproduce all 1,503 primary queries and the 350 common physical query
keys exactly. Its schema may contain no target-value, raw-surface, state,
score, effect, p-value, or English-gloss field.

## Claim ceiling

Passing establishes only a masked geometric universe suitable for synthetic
calibration. It does not establish paragraph scope, authorial paragraphs,
sound, wordhood, language, cipher operation, meaning, plaintext, or
translation.
