# Special-circle plain-legend native-visual screen

Date: 2026-08-12

Status: `BOUNDED_DESCRIPTIVE_ANCHOR_SCREEN`

This screen asks one narrow question of every official Yale canvas covering
f67 through f73: does a circle contain a clearly readable, multi-character
plain-alphabet or numeral legend in the main diagram hand, with an
author-visible relation to a Voynich register?

The screen is deliberately not OCR. Each official 2000-pixel-wide IIIF
rendering is inspected directly. The cached public folio catalogue fixes which
physical panels each canvas contains. The public page annotations independently
identify the French month names as extraneous writing in a different hand.

The following do not qualify as an anchor:

- folio, quire, or navigation marks;
- isolated Latin-shaped marks without a readable sequence;
- the already-audited unresolved ending around the f68r2 lower face;
- the later-hand French month names, because they label whole zodiac pages and
  do not equate any Voynich group with the readable name;
- a nearby string without a leader, bracket, equality sign, interlinear
  alignment, or repeated paired value.

No Voynich string is transcribed, no formal feature is constructed, and no
association is scored. The native visual judgments are machine-authored,
source-bound observations, not inherited human annotations.

A stop establishes no letter value, number, month word, sign name, sound,
language, cipher, plaintext, meaning, or translation.
