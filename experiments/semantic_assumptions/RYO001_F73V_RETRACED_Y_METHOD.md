## Source-only selection

unique row whose comment says that a retraced glyph **may have been** a
different named glyph. The selected row is `f73v.32` (`f73v.S2.9`), an inner

## Allowed outcomes

1. `TWO_STATE_O_BASE_RETRACED_AS_Y_VISIBLE`
2. `CURRENT_Y_LIKE_GLYPH_ONLY`
3. `UNRESOLVED_SOURCE_IMAGE`

Outcome 1 requires all five gates:

- the Grove-9 inner-band label and initial glyph are unambiguously localized;
- a closed o-like base remains independently traceable beneath or beside the
  current y-like form;
- the y-defining added stroke is bounded authorial ink, not a star line,
  nymph contour, stain, bleedthrough, wash, or compression;
- an overlap, ink boundary, interruption, or other physical feature supports
  the added stroke being a later intervention rather than one continuous
  original glyph;
- the source supports the o-like/y-like description without relying on a
  linguistic or phonetic value.

If only one current y-like form is visible, choose outcome 2. If the target or
chronology cannot be resolved, choose outcome 3.

## Access and claim ceiling

Use direct native inspection of official source pixels and source-native IIIF
regions/rotation only. No enhancement, OCR, CLIP, embedding, automated image
recognition, or batch feature extraction is permitted.

A positive result would establish only one physical source-transcription
glyph modification from an o-like base to a y-like current form. It would not
establish correction intent, character equivalence, sound, morphology, word,
language, cipher, plaintext, meaning, or translation.
