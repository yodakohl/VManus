# Public MSI translation-anchor worth screen

Date: 2026-08-12

## Purpose

Use the public 2014 Lazarus Project multispectral release as new primary image
data, but inspect only the folios with the greatest prior chance of exposing a
translation anchor.  This is a worth screen, not a decoder test and not a
validation of somebody else's translation claim.

## Source and fixed subset

- Release description and credit instructions:
  `https://manuscriptroadtrip.wordpress.com/2024/09/08/multispectral-imaging-and-the-voynich-manuscript/`
- Public data folder:
  `https://drive.google.com/drive/folders/1mNQGKQDSCR4M_c2M2JrsU5soghvYwMig`
- Credit: The Lazarus Project and the Chester F. Carlson Center for Imaging
  Science at RIT; manuscript witness Beinecke MS 408.

The bounded subset contains seven folios:

- f8r, f47r, and f102v1: processed-image triage where no prior anchor was
  registered;
- f17r and f116v: the two already registered mixed-script marginal contexts;
- f70v1 and f71r: the available MSI witnesses within the special-circle block.

Every inspected JPEG is identified by its public Google Drive file ID and
SHA-256 in `msi_translation_anchor_worth_screen_observations.tsv`.  Crops and
display rotations, when used, are deterministic views of the same source and
are not additional evidence.

## Frozen questions

For each folio record:

1. Does MSI reveal a distinct text layer that was not already visible in the
   ordinary-light witness?
2. Does it expose an equality/gloss device, interlinear pairing, explicit
   owned plain-script legend, or recoverable before/after correction?
3. Is the extra visibility better explained as contrast enhancement,
   show-through/offset, pigment response, or existing marginal writing?

An anchor passes only when a newly exposed distinct text layer also contains
at least one of: an explicit equivalence, a readable owned plain legend, or a
recoverable correction pair.  Improved legibility alone is not a translation
relation.

## Method and ceiling

The observations are source-bound native AI visual inspection and are recorded
as machine-authored, not human annotation.  No OCR, automated transcription,
CLIP, embedding, batch recognition, image-similarity score, proposed reading,
language fit, or decoder output is used.

A stop means only that this seven-folio public processed-MSI subset supplies no
new translation anchor.  It does not rule out a future spectral image of an
unscanned folio, a specialist diplomatic reading, or an independently readable
authorial gloss.  No glyph, sound, word, language, cipher, plaintext, meaning,
or translation follows.
