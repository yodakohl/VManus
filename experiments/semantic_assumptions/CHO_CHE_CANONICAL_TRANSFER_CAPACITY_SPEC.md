# `cho/che` canonical latent-form transfer capacity

Test capacity for the branch authorized by the independently validated broad
co-switch nonconfirmation.  Among the same eight opposite-state physical
leaves, retain source-native groups with one clean ASCII fragment and exactly
one `ch/sh` immediately followed by `o/e` site.  Store identity, fixed
metadata, page-side state, group length/position, and `ch` versus `sh` site
prefix, but store neither the `o/e` realization, raw surface, nor the
canonicalized template.

Capacity requires all three readings, all eight leaves, both 5/3 state
orientations, at least 2,000 rows total, at least eight rows on every
reading/leaf/side, exact within-leaf metadata overlap, a 256-state leaf orbit,
zero target templates/realizations/scores, and independent reconstruction.

A pass authorizes only a preregistered synthetic transfer/equivalence
preflight.  The future test must compare held-leaf cross-state raw versus
canonical type transfer, include complexity-matched random type-pair merges,
side/domain/one-leaf controls, and establish power for a meaningful
raw-to-canonical improvement before opening templates.  A pass can establish
only that `o/e`-opposed forms behave usefully as a formal latent-form collapse;
it cannot establish sound, wordhood, language, cipher, meaning, plaintext, or
translation.
