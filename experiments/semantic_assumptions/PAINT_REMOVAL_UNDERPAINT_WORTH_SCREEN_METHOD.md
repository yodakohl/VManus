# Processed paint-removal under-paint worth screen

Date: 2026-08-12

## Purpose and provenance

Test the two strongest surviving Voynich-script/paint near-misses against the
public full-manuscript image set published by `oshfdk` in December 2024. The
public voynich.nu gallery describes the processing as removing paint while
leaving writing and line drawings, and links the image set. The exact gallery
page, image index, Yale IIIF manifest, processed JPEG URLs, byte hashes, image
dimensions, canvas IDs, and prior source-bound result hashes are frozen in
`paint_removal_underpaint_worth_screen_observations.tsv`.

The processed-image number is bound to the official Yale canvas order: Yale
manifest item 4 is f2r and maps to `image.005.jpg`; item 175 is f99v and maps
to `image.176.jpg`. This establishes page identity only.

## Question and stop rule

Inspect only:

- f2r.15, the already transcribed three-group note at the bottom-right leaf;
- f99v.45, the disputed tiny trace on the west tuber of plant `[3,4]`.

Ask whether the processed witness supplies a **new stable character sequence,
new writing layer, physical ink/paint order, or explicit text/image
equivalence** beyond the already published ordinary-light checks. Stop if it
does not.

The paint-removal image is an algorithmic display transform, not
multispectral or physical layer imaging. Suppressed colour, enhanced contrast,
or apparent survival of a mark cannot by itself establish that ink lies below
paint, prove glyph identity, or recover a pre-paint state.

This is direct source-bound native AI visual inspection recorded as
machine-authored, not human annotation. It uses no OCR, automated
transcription, glyph classifier, CLIP, embedding, image-similarity score,
plant identification, decoder, proposed reading, or language fit.

The result can close only these two processed-image witnesses. It supplies no
character value, colour gloss, word, sound, language, cipher, plaintext,
meaning, or translation.
