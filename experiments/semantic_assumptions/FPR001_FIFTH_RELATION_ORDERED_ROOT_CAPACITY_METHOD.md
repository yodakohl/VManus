Status before execution: **TARGET PAGE UNSCORED**.

## Question and novelty

Can the newly owned fifth repeated-plant relation support a one-shot held-page
test using the already exposed five-root pharmaceutical label, while its paired
Herbal page `f37v` remains unopened for formal content?

This is a versioned successor enabled by new relation `JSP2025_05`. It does not

## Fixed target-free capacity projection

Use `pre_grounding_locus_atlas.tsv` for target metadata only. It must identify
f37v as Herbal, Currier A, hand 1, with all three alternate readings present.

Stream `pre_grounding_interlinear.tsv`. Test `page == f37v` before indexing any
surface, root-sequence, or formal-interlinear field, and exclude those rows.
Retain background rows only when section is H, Currier is A, hand is 1, and
grammar scope is `CONFIRMED_PROSE`. Treat ZL3b/IT2a/RF1b as alternate readings,
not replications.

For each background word and reading calculate:

- whether each of the four adjacent query-root pairs occurs within that word;
- the longest common subsequence (LCS) length between the five-root query and
  that word's ordered root tuple.

No background page identity or matching word is serialized. Capacity records
only page counts, edge page-support counts, nonzero-page counts, and LCS count
histograms.

## Gates

Proceed only if all hold:

1. exactly 94 non-target H/A/hand-1 pages exist in every reading;
2. every one of the four query edges occurs on at least two background pages
   in every reading;
3. at least 20 background pages per reading contain at least one query edge;
4. the page score can vary in every reading;
5. the inclusive rank floor over target plus background is `1/95 <= .02`;
6. no f37v root, surface, formal interlinear, match, score, or rank is indexed,
   retained, or computed.

The `.02` ceiling is frozen because the exact valid orbit has 95 pages. It must
not later be reported as `.01` or enlarged with mismatched registers.

## Consequence and ceiling

within-word ordered-root score, followed by a separately frozen one-shot f37v
rank if calibration succeeds. A final target pass could establish only that
the newly owned repeated drawing pair shares an unusually strong anonymous
formal composition. It cannot name the plant, root, leaf, flower, label,
word, sound, language, cipher, plaintext, meaning, or translation.
