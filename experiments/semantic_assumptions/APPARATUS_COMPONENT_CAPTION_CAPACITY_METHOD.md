# Apparatus-component caption capacity method

This is an exploratory worth screen, not a target experiment. It uses only the
current human exact-locus annotation table and source-bound direct inspection
of the corresponding official Yale canvases. Voynich strings and formal
features remain unopened.

Select rows whose human tags contain both `WATER_OR_APPARATUS` and `LABEL`,
whose certainty is `UNHEDGED`, and whose local or unit relation includes
`REL_EXPLICIT_ATTACHMENT`. Apply fixed human-comment keyword families:
`tube|pipe|channel`, `tub|barrel|container`, `pool|pond`, and
`stream|outflow|inflow|waterfall`. A component family is worth a later text
test only if at least three physical folios contain a label that can be assigned
to one component under a deliberately generous source-bound visual grade.
Between/near multiple objects, junction labels, figure labels merely located
inside a vessel, and labels spanning two component kinds are not singular.

The inspection is machine-authored and source-bound, not human annotation.
It may record only ownership/topology; it may not OCR, transcribe, embed,
similarity-score, or interpret the labels. Failure stops before any text or
formal feature association.
