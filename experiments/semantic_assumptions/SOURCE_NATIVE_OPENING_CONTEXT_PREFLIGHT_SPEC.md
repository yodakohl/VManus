# `NONE` versus `DA` structural-context preflight

Status: **FROZEN_TARGET_FREE_SYNTHETIC_CALIBRATION**

The preflight uses only the masked 1,207 movable rows in 197 exact
remainder–folio quota strata (59 folios / 44 represented remainders). Every
assignment preserves the exact `DA` count inside every stratum.

Two fixed label-blind feature systems are scored separately:

1. `POSITION`: one-hot `FIRST/LAST/MIDDLE/SINGLE`, centered inside each quota
   stratum and divided by population RMS, dropping zero-RMS columns.
2. `NEIGHBOR`: one-hot left and right external family/edge categories, centered
   inside each quota stratum, linearly residualized by `np.linalg.lstsq` with
   `rcond=None` against centered locus-role and exact-group-count one-hots,
   divided by population RMS, and zero-RMS columns dropped.

For feature matrix `X`, assignment label `y`, quota probability `p_s`, and
folio `f`, define `c_f = mean_{rows in f} X_i (y_i-p_s)`. The statistic is the
equal-folio mean dot product across all ordered distinct folio pairs. Its folio
contribution is `c_f dot mean_{g != f}(c_g)`. The exact upper tail uses 1,024
assignments in calibration and 8,192 in the target-size checks, with assignment
zero observed and all remaining assignments generated by frozen SplitMix64
quota-preserving ranks.

A feature system passes only if p<=.01, z against the population null SD >=3,
at least 35/59 folio contributions are positive, maximum absolute contribution
fraction <=.25, every one-folio deletion statistic is positive, and the
separate Currier-A and Currier-B equal-folio statistics are each >=.01.

Synthetic worlds are frozen as 64 `NULL` worlds 0–63 and eight each of
`POSITION` 100–107, `NEIGHBOR` 200–207, `ONE_FOLIO` 300–307,
`FOLIO_RANDOM` 400–407, and `ONE_BASE` 500–507, using planting strength .82.
The preflight passes only if:

- both systems have 0/64 null passes;
- `POSITION` passes 8/8 position plants and `NEIGHBOR` passes 0/8;
- `NEIGHBOR` passes 8/8 neighbor plants and `POSITION` passes 0/8;
- both systems pass 0/8 for every concentrated/random adversary; and
- all six representative decisions remain the same at 8,192 assignments.

No real row operation label may be reconstructed, read, joined, or scored.
GPU execution is an acceleration only; outputs must be independently
reconstructable on CPU. A pass authorizes one separately frozen held target.
It cannot establish detachment, wordhood, prefix function, syntax, sound,
language, cipher operation, meaning, plaintext, or translation.
