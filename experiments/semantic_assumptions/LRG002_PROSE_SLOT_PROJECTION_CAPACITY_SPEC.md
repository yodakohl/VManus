# LRG002 prose-slot projection capacity

Status: `REGISTERED_SCORE_BLIND_CAPACITY`

LRG001 confirms a transferable aggregate profile separating manual label groups
from exact-page/exact-length B/P prose controls. LRG002 asks a different
question: when that already fixed profile is applied out of parity to prose,
does relative label likeness occupy a repeatable position inside the corrected
drawing-reset segments?

Before any profile is reconstructed, freeze every confirmed-prose group in
sections B/P from the validated drawing-reset atlas. Keep the complete B/P
universe for page-by-symbol-count rank normalization. The primary position
universe is every segment containing at least three groups, so every unit has
one FIRST, one LAST, and at least one CORE group. Preserve exact group ID,
segment ID, page, physical folio, section, symbol count, segment index/count,
position, and folio parity. No family sequence, LRG001 feature weight, score, or
rank may enter capacity selection.

Capacity passes only at 5,824 normalization rows in 742 segments and 5,769
primary rows in 705 segments, on 34 pages and 16 physical folios, with both B/P
sections and both parities represented. Each primary segment must contain
exactly one FIRST and LAST and all remaining groups must be CORE.

Passing capacity authorizes target-blind synthetic calibration of a
within-page-by-length rank projection and within-segment rotation test. It does
not authorize opening the manuscript position association. Neither capacity nor
a later positional association establishes a word, name, identifier, noun,
part of speech, meaning, plaintext, or translation.
