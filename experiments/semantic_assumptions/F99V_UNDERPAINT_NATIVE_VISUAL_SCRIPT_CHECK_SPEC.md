# f99v under-paint native visual script check

Date: 2026-08-11

This is a bounded source check of the only local near-miss to the `COL001`
colour-note capacity stop. It uses the user-authorized source-bound native
visual method. It is not OCR, a transcription replacement, or a lexical
search.

## Selection and sources

The target was fixed before image inspection by the existing human exact-locus
annotation at `f99v.45`. That source describes apparent tiny letters on the
west tuber of plant `[3,4]`, under reddish paint, and explicitly asks whether
they are real. The three current manual readings omit the locus.

## Fixed questions

1. Is a localized dark trace visible within the reddish-painted west tuber in
   both ordinary-light witnesses?
2. Is it visibly deliberate writing rather than pigment variation, abrasion,
   parchment texture, or another mark?
3. Can its character count and segmentation be recovered consistently?
4. Can it be classified independently as Voynich-style or plain-alphabet
   writing?
5. Does it supply the missing second authenticated Voynich-script under-paint
   record needed to reopen `COL001`?

## Decision rule

The colour-note route reopens only if the trace is visibly deliberate writing
and has a stable script classification. A vague mark, a prompt-dependent
reading, or an unresolved `p`/`r`/Voynich alternative is insufficient.

## Exclusions and ceiling

No OCR, automated transcription, multispectral inference, CLIP, embedding,
image-similarity score, automated glyph classifier, enhancement-derived
reading, or external decoder claim is used. The observations are
machine-authored native visual inspection, not literal human annotation.

A stop at ordinary-light resolution does not rule out a future qualified
multispectral or palaeographic reading. It establishes no character, word,
colour name, pigment instruction, sound, language, cipher, plaintext,
meaning, or translation.
