# ZBV001 — source-bound zodiac barrel-state capacity

Date: 2026-08-11

Status: `CAPACITY_ONLY_NO_TEXT_FEATURE_ACCESS`

## Purpose

Test whether the user-authorized source-bound native visual method repairs the
public zodiac catalogue's missing BARREL-ABSENT state without opening a
Voynich label string, and whether the repaired panel contains an
unconfounded author-visible contrast suitable for a later formal-label test.

This is a capacity audit, not a BARREL-word test. Native visual observations
are machine-authored direct inspections, not literal human annotation.

## Inputs

Use the validated 300-record Stolfi/Grove zodiac catalogue, its current-locus
crosswalk, and only the structural metadata of the all-reading consensus table.
Bind the official Yale manifest and the full official f73r/f73v canvases.

The public catalogue's explicit `vert. barrel` and `hor. barrel` records are
BARREL_PRESENT. Its explicit `no barrel` records are BARREL_ABSENT. Missing
mentions remain UNKNOWN except on f73r and f73v, where direct inspection of the
complete official pages is permitted to assign a page-uniform state only if:

1. the 30 catalogue records correspond to exactly 10 inner, 16 outer, and four
   outside-circle figures on each page;
2. all 30 visible figures can be counted on the official page; and
3. no visible figure is enclosed by or stands in a barrel/tub outline.

No glyph, label surface, OCR, CLIP output, embedding, object identity, sex, or
plant name may enter the observation.

## Strict formal-source capacity

A state record is strict only if its crosswalk row is primary-eligible, has a
current locus, and all consensus groups at that locus are `kind=L`,
`grammar_scope=DIAGNOSTIC_NONPROSE`, `strict_zero_alternative=1`, correctly
indexed, and on the catalogue page. Do not read family or member identities.

An eventual BARREL association test is authorized only if both states span at
least two physical folios and at least one strict page-by-ring stratum contains
both states. Ring is the public human `inner`, `outer`, or `not in circle`
description. A mixed page with state perfectly determined by ring fails this
gate; it cannot distinguish a barrel marker from a ring/register marker.

## Ceiling

Passing the visual state count but failing within-page/ring mobility is a
capacity stop before Voynich feature access. It supplies no BARREL, INNER,
OUTER, person, star, zodiac, word, stem, sound, language, cipher, plaintext,
meaning, or translation.
