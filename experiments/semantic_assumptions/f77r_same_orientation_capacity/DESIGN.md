# F77r same-orientation source-capacity audit

## Purpose

The provisional f77r transition bridge can only be independently tested on a
second construction with the same information orientation: short labels in
successive parts of one connected apparatus, with both active and inactive
boundaries visible independently of the strings. The broader circular
boundary/sector transfer already failed, so generic circles, stars, pools,
figures, nearby labels, and outputs without inactive controls are ineligible.

This is a source-capacity audit, not a Voynich-string test. It reads no
transcription surface, parsed root, grammar field, OCR, image feature, or
automated visual output.

## Existing human-annotation universe

Group the complete exact-locus annotation atlas by its human-defined page and
unit. A broad near-match enters the review table when:

1. it has at least five exact annotated loci;
2. the human unit description calls them labels; and
3. at least one row carries the human-derived `WATER_OR_APPARATUS` tag.

This intentionally over-includes labels near figures, pools, paths, or
illustrations. It prevents a narrow keyword search from hiding a near-match.
The legacy exact-locus page ID `f85v2` has no literal page-atlas row because
its current loci belong to the compound `fRos` foldout. It remains in the
broad table with page-level output evidence explicitly unavailable; it is not
silently dropped or assigned to a different catalogue page.

The strict same-orientation gate then requires all of the following literal
source evidence:

1. every slot comment places its label **between** successive apparatus
   boundaries;
2. the comments enumerate one contiguous set of internal side branches and
   the slot count equals boundary count plus one; and
3. the independent page description states that a positive number smaller
   than the total internal-boundary count emits/ejects material.

The target unit `f77r/V1` is reconstructed as a positive control and then
excluded. A second eligible unit is required before any new Voynich string may
be opened or scored.

## Interpretation ceiling

Zero second units means only that the current provenance-clean public human
annotation layer cannot confirm the bridge. It does not prove that no drawing
could be annotated that way, close the f77r topology, license new manual
ownership labels, or establish any quality, element, object, word, plaintext,
language, or translation.
