# Public slot-grammar overlap audit

This descriptive source audit compares the frozen six-edge source-native
family atlas with the public Voynich word-paradigm literature. It is not a new
manuscript target or a statistical confirmation test.

Public sources:

- Rene Zandbergen, “Voynich MS - Analysis - Word paradigms,” especially the
  published Zattera slot alphabet and Stolfi summary:
  <https://www.voynich.nu/a3_para.html>
- Jorge Stolfi, “A Grammar for Voynichese Words”:
  <https://www.ic.unicamp.br/~stolfi/voynich/00-EXPORT/00-06-07-word-grammar/>
- Patrick Feaster, “Rightward and Downward in the Voynich Manuscript,” for the
  previously published `qo...` versus otherwise identical `o...` line-position
  contrast:
  <https://griffonagedotcom.wordpress.com/2021/08/18/rightward-and-downward-in-the-voynich-manuscript/>

The Zattera table is encoded exactly as the ordered optional EVA chunks:

`[q/s/d] [o/y] [l/r] [t/k/p/f] [ch/sh] [cth/ckh/cph/cfh]
[e/ee/eee] [s/d] [o/a] [i/ii/iii] [d/l/r/m/n] [y]`.

Using the frozen STA-to-basic-EVA table, a family pair is called
`PUBLIC_SLOT_COMPATIBLE` if at least one concatenation of a left-family member
and a right-family member is generated by this optional ordered slot table.
This is deliberately an existence test, not a claim that the STA family
boundary equals a public slot boundary. For example, STA `K2=ee` plus `J1=e`
forms public one-slot `eee`.

The audit must report compatibility separately for favored, disfavored, and
unresolved atlas labels. A favored edge being compatible proves no novelty;
a compatible disfavored edge shows that permissive grammatical legality is not
the same as held-folio frequency preference.

Claim ceiling: the audit may reclassify novelty and relate formal structures
to public transliteration models. It supplies no physical glyph identity,
sound, wordhood, morpheme, language, cipher, meaning, plaintext, or
translation.
