## Admission and stop rule

A recoverable correction pair requires all of:

1. a stable earlier character or sequence;
2. a stable later character or sequence;
3. a visible physical relation fixing their order as before and after;
4. separation from an original compound/variant glyph, pen accident, damage,
   texture, or display-processing artefact.

Stop if no candidate meets all four. A darker, crossed, plumed, or crowded
glyph is not by itself an ordered correction pair. The paint-removal witness
is an algorithmic display transform, not physical-layer imaging.

This is direct source-bound native AI visual inspection recorded as
machine-authored, not human annotation. It uses no OCR, automated
transcription, glyph classifier, CLIP, embedding, similarity score, decoder,
proposed reading, or language fit.

A pass could establish only a formal manuscript-internal edit relation. A stop
supplies no character sound, word, language, cipher, plaintext, meaning, or
translation.
