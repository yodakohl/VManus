# GDT408 method

## Question

When each of the 26 admitted pages is removed in turn, how much of its surface,
recipe, package, atom, local-label, and scope-factor inventory can be taught
from the other 25 pages without retuning?

## Inputs

Only GDT407's 4,576 running events, 693 local groups, 5,051 attachments, and
26-page inventory, plus GDT405's pre-existing portable/local atom classes.

## Method

For each held page, build training inventories from every other page. Classify
each running event as exact-surface, exact-recipe, adjacent-package,
known-atom composition, or failure. Test local groups separately because local
copying is part of the frozen architecture. Replay every attachment first as
an exact seven-axis factor signature and then as a composition of independently
attested factor values.

## Decision rule and claim ceiling

A running page passes if no portable atom or parser factor value is private to
that page. A local sign may remain page-private because GDT405 already classed
it as local before this test. Local-only pages pass without opening prose
scope. The result tests portability of the creative formal system; it does not
confirm any German word value.
