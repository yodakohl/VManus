## Why the finite proof can decide the cases

Every code must fit inside one word. At an atom's first occurrence there are
therefore only finitely many possible prefixes of the unconsumed part of that
word. Every later occurrence is fixed. The enumeration covers those choices
completely, subject only to necessary frequency, length, seam and prefix-code
conditions. It finishes only when source and target both finish exactly.

One useful derived consequence is that any word starting with a known code must
start with that atom: neither a shorter nor a longer competing code could coexist
with it in a prefix-free dictionary. Thus a source atom occurring k times cannot
have a value that starts more than k target words. This constraint was stated
and frozen before target fitting; it changes no986writing assumption. Exhausting
all permitted branches is a contradiction, not a low score or failed restart.
