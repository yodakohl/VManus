# GDT792 method

## Question

Can complete-whole physical host behavior on the 27 non-deep released pages
predict the uses of `otedy`, `okal`, `otchdy`, and `olaiin` on f77r, f82r, and
f83r, and does that transfer justify a concrete replaceable working gloss?

## Inputs

- the GDT791 30-page occurrence spine and line-owner atlas;
- the exact GDT581 event/statement and local-card ledgers, used only for the
  explicitly parser-coupled diagnostic channel;
- GDT790 panel records, local label owners, and existing exact string edges;
- the GDT515 source-owner layer for f72r Ring D versus Ring E;
- the GDT734 dictionary and cell register, used only to distinguish an actual
  predecessor cell from a new 30-page overlay position;
- a guarded projection of section, language, hand, paragraph flags, token count,
  and EVA-clean text for the same 35 selectors.
- a second guarded projection of the ZL3b/IT2a/RF1b line crosswalk, used only
  to report exact-token reading stability rather than independent support.

The guarded query checks selectors before materialising rows and rejects f84
and f84r.  No raw mixed TSV is loaded directly.

## Method

1. Replay all 5,866 GDT791 occurrences against the 1,007 guarded source lines.
2. Build a 58-row occurrence atlas for the four targets: 48 running events and
   ten local cards.  Physical line role, paragraph flags, scope, register,
   topology, deep-page holdout status, neighboring complete wholes, panel,
   record, and component are independent fields. Source paragraph flags are
   retained as source-flag runs, not promoted to visible diagram paragraphs.
   Alternate-reader stability uses an all-maximum exact-token line LCS and is
   marked `SAME_MANUSCRIPT_READING_DIAGNOSTIC`. Statement position, parser
   recipe, and alias behavior remain visibly marked `PARSER_COUPLED`.
3. Learn a simple majority physical-line role from the 27 outside pages and
   apply the fixed 60% transfer rule to the held running occurrences.
4. Test local-label membership, singleton status, and topology novelty without
   borrowing a gloss from the image owner.
5. Compare each target with declared controls, two deterministic sensitivity
   decks, and every complete form having 3–25 running occurrences. Report the
   deck overlap and keep the all-30 ranking separate from a training-only
   ranking; neither deck is an independent confirmation.
6. Materialize the two newly recognized f72r exact-whole Ring-D-label to
   Ring-E-prose reuse observations and run them through the GDT388 relation
   intake. They remain acquisition-only, not score-ready relation proof, and
   transcription order is not treated as reference direction.
7. Evaluate the preregistered `okal` trigger exactly as written. A raw trigger
   pass is not sufficient if its contributing all-30 rank leaks held labels,
   its edges have zero semantic credit, or the observations do not distinguish
   address, class and addressed-member candidates. In that case emit only a
   20-position structural overlay and keep all semantic glosses unselected.
   Separate the fifteen positions present in the GDT734 cell cache from the
   five new overlay positions.

## Decision rule and claim ceiling

The full preregistered trigger is frozen in `PREREGISTRATION.md`; it is reported
even when semantic adequacy withholds the proposed consequence. Physical
evidence can license a structural exact-whole role. Parser-created statement
closure, visual proximity, string reuse and component recipes cannot establish
a lexeme. No component export, unseen-page transfer, object identity,
substance, number, language, sound, or plaintext is permitted.
