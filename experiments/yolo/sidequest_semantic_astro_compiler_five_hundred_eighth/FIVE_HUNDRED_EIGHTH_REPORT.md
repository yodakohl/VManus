# Pass 508 — Astro als eigener Werkstatt-Compiler

Die drei Astro-Seiten werden nicht durch die nasse Prosa-Grammatik gelesen.
Sie benutzen eine eigene kleine Schleife:

1. lokalen Namensraum wählen;
2. sichtbaren Ort adressieren;
3. dessen Gruppenfolge als zusammengehörige Etikette kopieren;
4. den lokalen Eintrag lesen oder eintragen;
5. vor dem nächsten Ort vollständig zurücksetzen.

Diese `LOCATE → READ → RECORD → RESET`-Schleife deckt 142 Loci und 395
sichtbare Gruppen. Dreizehn bildgetreue Namensräume ersetzen vierzehn ältere,
zu grobe Astro-Besitzerklassen.

## Konkrete Arbeitslesung

- **f67r2:** zwei getrennte Himmels-Auswahlräder mit lokalen Sektoren, Feldern,
  Bändern und einer ungeklärten Seitenlegende;
- **f68r1:** ein Mehrpaneel-Sternstationsatlas mit mehreren Zentren und 28
  einzeln adressierten, ungeordneten Sternorten;
- **f69v:** drei getrennte Himmels-Bedingungsräder; nur das linke besitzt ein
  lokales 28-Plätze-Inventar.

Ein Schreiber muss dabei keinen absoluten Start und keine Drehrichtung kennen.
Er kopiert das sichtbare lokale Etikett an seinen Bildort. Es gibt keinen
f68→f69-Schlüssel und keine Übertragung der Prosa-Primitiven in Planetennamen,
Monate oder Tierkreiszeichen.

Das gemeinsame Prinzip aller zehn Seiten ist damit nicht ein gemeinsamer
Wortschatz, sondern ein gemeinsamer Werkstattprozess: **Bildort wählen, lokalen
Karten- oder Etikettenwert aus dem Exemplar holen, regelhaft schreiben, am
nächsten Besitzer neu ansetzen.**

Als Nächstes wird das gesamte 124-Einträge-Handbuch auf echte Lehrzeit
komprimiert: Welche Regeln muss jeder Schreiber auswendig können, welche Karten
werden als kleines Kernset gelernt, und was darf einfach aus dem
Seitenexemplar kopiert werden?
