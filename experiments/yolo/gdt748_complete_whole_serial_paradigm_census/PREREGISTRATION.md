# GDT748 exploratory declaration

GDT748 is an iterative sidequest experiment, not a blinded confirmation. The
unconditioned serial rule was run first; its known-card leave-one-out failure
motivated the complete-whole form bridge. This chronology is part of the
result and the weak unconditioned layer remains published.

The final packaged pass is fixed to:

1. all cached length-three/four written windows on the inherited 179-page
   allow-list;
2. exactly one non-W2/W3 target and at least two distinct known whole cards;
3. quality/stage intersection only;
4. leave-one-out calibration on fully known windows;
5. complete-surface edit distance ≤2 as the only bridge;
6. one collapsed evidence unit per physical target position;
7. recurrent consensus requiring two positions and 60 percent bridge weight;
8. literal identities, components, phonetics and unseen forms receiving zero
   credit.

Expected outcomes are an unconditioned serial failure, a more useful
form-bridged exploratory class, explicit GDT747 candidate adjudications, and a
finite set of replaceable whole-role leads. No outcome confirms a lexeme.
