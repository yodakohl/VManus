## Token definition before any profile result
Primary units are editorial WHITESPACE groups from each sentence's exact '# text = '
comment, split using Unicode whitespace. Preserve every other character, including
case, accents, punctuation and one-character strings. No normalization or POS filter.
If a sentence has no text comment, reconstruct its declared surface from CoNLL-U:
use a range-ID FORM once for a multiword token and skip its covered integer rows;
ignore decimal empty-node IDs because they have no written surface; keep every other
integer FORM. Insert a space unless that selected surface row has SpaceAfter=No.
Then split that reconstructed string by whitespace. This source-format fallback is
fixed BEFORE counting; flag/count every fallback sentence in the sample. It is not
claimed to restore original medieval spaces. FORM/MISC and text-comment disagreement
will be reported for sampled sentences, not silently fixed or used to drop sentences.
Require unique sent_id within each file and10columns on token rows; malformed input
stops that source rather than deleting inconvenient words.

Secondary declared sensitivity: exact FORM for every integer-ID row, including
punctuation and expanded components; skip range IDs and decimal empty nodes. Keep
case/Unicode/unigram words unchanged. This is SYNTACTIC-TOKEN projection, not a
replacement primary definition. Neither one-letter-word removal nor003normalization
is reintroduced. Both projections retain their own first8000units in train-file
sentence order. No author/chapter reranking, random split or count-dependent sampling.
