# Sidequest Pass 866: Herbal-to-Biological process pairing

The four Herbal pages now supply four concrete preparation archetypes, and the
six Biological records supply six application archetypes. A compact 4x6 workshop
matrix combines process fit with already observed exact-card overlap. All four
Herbal archetypes win at least one Biological record.

The resulting chain is useful but deliberately one level above product identity:
an application can request an aqueous base, expressed extract, measured warm batch
or ingredient-rich passage preparation without telling us which plant product it is.
The current ten pages therefore support preparation-type -> application-type pairing,
not an exact Herbal-page -> Biological-station key.
