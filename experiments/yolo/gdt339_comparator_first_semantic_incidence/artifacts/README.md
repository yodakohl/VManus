# GDT339 artifacts

The `gdt339_comparator_*` tables, result and validation plus
`gdt339_invariant_freeze.json` form the public comparator-first checkpoint.
They contain opaque IDs, model summaries and anonymous coefficients, but no
exported comparator lexical forms and no Voynich target outcome. Later
`gdt339_voynich_*` artifacts apply this exact freeze diagnostically.
