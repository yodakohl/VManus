# GDT761 — state-pair outer carrier bridge

Status: PARTIAL

GDT761 verfolgt `cheor/sheor/cheo/sheo` über 151 reader-exakte Vorkommen auf
80 Cache-Seiten. Nach der vereinigten GDT754/GDT737/GDT738-Quarantäne bleiben
224 direkte Kanten zu 173 Nachbaroberflächen.

`chor` ist der einzige Nicht-Mengen-Kandidat mit direktem Kontakt zu allen vier
Zielen: fünf Kanten auf fünf Seiten. Das stärkt seine Rolle als gemeinsamer
Pflanzenteilträger; „Blüten-/Samenstand“ bleibt eine C1-Arbeitsidentität. Fünf
exakte Spans erhalten konditionale konkrete Lesungen. Zwei `shor sheor`-Spans
bleiben separat als Basis-/Feuchtform-Rivale.

Kein Lösungsmittel wird identifiziert. `ckhy` ist der beste kleine
rollenübergreifende Feuchtmedium-Kandidat; `sheo pcheey` ist ein auffällig
wiederholter Komplementspan, nachdem die alte Pulverglosse entfernt wurde.

Reproduktion:

    python3 experiments/yolo/gdt761_state_pair_outer_carrier_bridge/src/run.py
    python3 experiments/yolo/gdt761_state_pair_outer_carrier_bridge/src/validate.py

Der Primärbericht ist `REPORT.md`.
