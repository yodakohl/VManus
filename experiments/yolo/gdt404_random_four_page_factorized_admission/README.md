# GDT404 – zufällige Vierseitenaufnahme

Vier zuvor nicht verwendete physische Seiten wurden einmalig zufällig gezogen
und vollständig mit der festen 46-Zeichen-Tafel sowie dem GDT402-Scope-Parser
gelesen.

Ergebnis: **formale Aufnahme bestanden, 49 neue Mikroformen bleiben Amber**.
Alle 688 Ereignisse, 88 Aussagen und 677 Fokusbindungen sind in den Artefakten
enthalten. Keine neue Wurzel, kein elfter Handlungskopf, kein neunter Selector,
kein Besitzer-/Aussagegrenzsprung und kein Vorgriff über mehr als eine Karte war
nötig.

Ausführen:

```bash
python3 experiments/yolo/gdt404_random_four_page_factorized_admission/src/run.py
python3 experiments/yolo/gdt404_random_four_page_factorized_admission/src/validate.py
```

Die vollständige lesbare Kernausgabe steht in
`FOUR_RANDOM_PAGES_READABLE_CORE_EDITION.md`; der kompakte Befund in
`REPORT.md`.
