# GDT638 — konkrete Ganzformen einzeln aufnehmen

Status: `PASS_13_EXACT_COMPOUNDS_PROMOTED__14_NEW_COMPLETE_LINES__2_HELD`

GDT638 prüft fünfzehn konkrete Ein-Loch-Komposita aus GDT637 nacheinander an
allen 396 Vorkommen ihrer vollständigen Oberflächen. Dreizehn kurze Werte
werden in V15 aufgenommen; `keechy` und `chokshy` bleiben wegen ungeklärter
Feldfolge beziehungsweise einer ungetrennten Trocken/Feucht-Kollision offen.

Das Wörterbuch wächst von 259 auf 272 Zeilen. Vollständig gedeckte
Mehrwortzeilen wachsen von 16 auf 30, davon 20 dreileser-exakt und scope-sauber.
Vierzehn neue Zeilen besitzen neben der tokenweisen Lesung eine kurze
geglättete Arbeitslesung.

Ausführen:

```bash
python3 experiments/yolo/gdt638_sequential_compound_promotion/src/run.py
python3 experiments/yolo/gdt638_sequential_compound_promotion/src/validate.py
```

Der vollständige Befund steht in `REPORT.md`.
