# Lehrlingsblatt der Zehn-Seiten-Werkstatt

## Die Schreibidee

Ein Schreiber lernt nicht 173 lange Übersetzungen. Er lernt 29 kurze Bausteine, fünf Feldarten und 22 unteilbare Ganzkarten. Beim Schreiben wird zuerst der Bild- oder Stationsbesitzer still gesetzt, dann Quelle, Menge und Ziel, danach Handlung und Grad; eine lizenzierte Endkarte schließt die Zelle.

## Die wichtigsten Bausteine

| Zeichenfamilie | Werkstattwert | Einfache Leseregel |
|---|---|---|
| `OK` | EINSETZEN | den folgenden Posten in den laufenden Gang setzen |
| `OL` | WEITER | beim bestehenden Gang bleiben |
| `OT` | FOLGE | zum nächsten Posten oder Schritt wechseln |
| `AR` | QUELLE | von dort nehmen |
| `AL` | ZIEL | dorthin bringen |
| `L` | AB | aus dem aktiven Posten herausführen |
| `P` | ZU | in einen Empfänger hineinführen |
| `AIN` | PORTION | eine abgegrenzte Teilmenge |
| `AIIN` | SOLLMASS | das vorgeschriebene Maß |
| `IIN` | STUFE | eine vorgeschriebene Arbeitsstufe |
| `E / EE / EEE` | KURZ / LANG / VOLL | Dauer oder Ausführungsgrad |
| `Y` | DIES | der aktuell gemeinte Posten |
| `DY` | SCHLUSS | nur als gelernte Endkarte schließen |
| `OR` | ANSATZ | der bereitete Arbeitsansatz |
| `HO` | ZUTAT | ein weiterer Materialposten |
| `CHEO` | AUSZUG | ein gewonnener Auszug |
| `AIR` | LAUFFLÜSSIGKEIT | Flüssigkeit in einem Lauf |
| `CHED / CHD` | ÜBERFÜHREN | von einer Station in die nächste bringen |
| `CTH` | BEREIT | als vorbereitet kennzeichnen |
| `SHED` | ABSETZEN | stehen und sich absetzen lassen |
| `CHK` | WÄRMEN | erwärmen oder warm halten |
| `CKH / CKHE` | DURCHLASS / SEIHEN | durch eine Passage bzw. Trennung führen |
| `SOLK` | SAMMELN | an einer Auffangstelle halten |
| `LSH` | WASCHEN | Wasch- oder Spülgang |
| `TY` | TEIL | Materialteil oder Rest |

## Die fünf Feldarten

- `CH`: Grundansatz eröffnen.
- `D`: aktiven Posten mitnehmen oder wiederaufnehmen.
- `O`: laufenden Ansatz fortsetzen.
- `Q`: einen konkreten Teilschritt aktivieren.
- `S`: Zustand, Ergebnis oder Nebenast eintragen.

Diese Hüllen bestimmen den Schreibmodus; sie müssen nicht jeweils ein gesprochenes Wort sein.

## Die 22 Ganzkarten

`Zusatz`, `Zubereitungsgefäß`, `kalt stellen; Schluss`, `kurz bearbeiten`, `Einlage`, `Haltetransfer; Schluss`, `Wurzel`, `Vollwaschung; Schluss`, `auftragen; Schluss`, `abkühlen; Schluss`, `Kurzteil`, `Stängel`, `Auffanggefäß`, `Klarlauf`, `Kurzabzug; Schluss`, `auswringen`, `Frischwasser zugeben; Schluss`, `vom vorigen`, `teilen`, `nachseihen`, `Aufnahmegefäß`, `befestigen; Schluss`.

Diese Karten werden wie Nomenklatorzeichen aus dem Musterbuch gelernt. Ihre Oberfläche darf handabhängig variieren, ihr Kartenwert nicht.

## Fünf Rücklesebeispiele

1. `qokaiin` → `OK + AIIN` → **bemessen**.
2. `qokeedy` → `OK + EE + DY` → **lange einwirken; Schluss**.
3. `lchedal` → `L + CHED + AL` → **Zielabführung**.
4. `otchor` → `OT + OR` → **Folgeansatz**.
5. `solkeey` → `SOLK + EE + Y` → **Langsammlung**.

Die vollständigen 29 Komponenten, alle 22 Ganzkarten und der komplette 173-Karten-Index stehen in den begleitenden TSVs. Das Blatt ist eine konkrete Schreib- und Lesehypothese für die zehn Seiten, kein behaupteter Klartextschlüssel.
