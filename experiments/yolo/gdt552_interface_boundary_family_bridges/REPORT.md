# GDT552 — fünf verschiedene Brücken schließen die letzte Restliste

Status: `PASS_FIVE_BOUNDED_INTERFACE_BRIDGES__ZERO_SUPPORT_RESTS`

## Ergebnis

Keines der fünf Restpaare kommt im alten 26-Seiten-Deck direkt innerhalb einer
Karte vor. Das bleibt ausdrücklich sichtbar. Trotzdem besitzt jede bereits
beobachtete Zielkarte eine konkrete, begrenzte Ordnungsbrücke:

- 76 alte benachbarte Karten tragen vier der fünf Paare genau an ihrer
  Satzkartengrenze;
- elf alte Karten tragen vier Paare mit genau einem sichtbaren Atom dazwischen;
- zehn weitere Nichtziel-Vorkommen auf den aktuellen vier Seiten wiederholen
  zwei Mechanismen;
- `chap` behält zusätzlich seine bereits publizierte `cha+p`-Stammregel.

Alle fünf endlichen Zielgates bestehen. Die aktive 23-Karten-
Verbesserungswarteschlange aus GDT548 ist damit leer.

## Die fünf Mechaniken

### `aiicthy = AIIN+CH+T+Y`

Das alte Deck enthält 70 gleiche Satzkartengrenzen `AIIN|CH` auf 20 Seiten.
Entscheidend ist ein exakter Zielpfad auf f11r:

```text
daiin = AIIN  |  cthy = CH+T+Y
```

Damit stehen genau die beiden Rezeptteile von `aii|cthy` bereits in der
richtigen Reihenfolge unmittelbar nebeneinander. Acht aktuelle Nichtziel-
Kartengrenzen verstärken denselben Übergang.

### `chap = CH+A_ADDR+P`

Hier gibt es keine alte Kartengrenze `A_ADDR|P`. Dafür stehen zwei alte
Binnenkarten `A_ADDR+LOCAL_CHAR_I+P` und die unabhängig eingefrorene
GDT526-Regel bereit:

```text
cha = CH+A_ADDR  +  p→P   (Suffixkanal 2/2, Zielrang 1)
```

Das ist eine Stamm-plus-Kürzel-Brücke, nicht die Behauptung eines freien
`A_ADDR>P`-Gesetzes.

### `ofaram = O+LOCAL_CHAR_F+AR+AM_ADDR`

Vier alte benachbarte Karten reproduzieren die sichtbare Naht `...ar|am...`;
eine davon ist sogar das isolierte Paar `ar|am`. Zusätzlich steht
`AR+O+AM_ADDR` in der alten Karte `darom`.

### `rotaiin = R+OT+AIIN`

Eine alte Satzkartengrenze endet sichtbar auf `r` und beginnt rechts mit `ot`.
Die alte Binnenkarte `roloty=R+OL+OT+Y` bewahrt dieselbe gerichtete Folge mit
einem sichtbaren `OL` dazwischen.

### `shso = SH+S+O`

Eine alte Grenze `sh|s` reproduziert den Zielanfang. Sieben alte
`SH+X+S`-Ketten liefern die Ordnung innerhalb einer Karte; fünf davon sind die
bereits unabhängig publizierten GDT444-Fokusketten. Zwei weitere aktuelle
Nichtzielkarten tragen `SH+O/E+S`.

## Was „leer“ bedeutet

Alle fünf sichtbaren Routen, Rezepte und vollständigen neutralen sowie
kontextuellen Arbeitslesungen bleiben bytegleich. Die nun leere Restliste sagt:
Für jede der 145 zugelassenen Prosakarten ist die bisher benannte
Strukturstützung konkret dokumentiert. Sie sagt nicht, dass das Manuskript
übersetzt ist oder dass ein fehlendes altes Direktpaar nun beliebig produktiv
wäre.

Alle 32 unabhängigen Prüfungen bestehen. Keine Seite, Oberfläche, Zerlegung,
Rezeptfolge, Stamm­bedeutung oder Arbeitslesung wurde geändert.

## Nächster Griff

Jetzt sollte nicht noch eine Hilfsbrücke gesucht werden. Sinnvoll ist eine
einzige konsolidierte 145-Karten-Ausgabe mit Null Resten, die pro Karte die
sichtbare Route, Rezeptfolge, Steckplatzregel, vollständige Bedeutung und die
jeweils stärkste konkrete Provenienz aus GDT541–GDT552 nennt. Danach können die
Arbeitsübersetzungen als zusammenhängende Aussagen auf innere Widersprüche und
wiederkehrende Satzschablonen geprüft werden.
