# GDT809 artifacts

The official builder produces two complementary layers.

- GDT809_*: 35-head census, exact relation and ED1 comparison, external
  record compatibility, contextual candidate ranks, gate coverage and
  exploratory dictionary. RESULT.json contains the formal summary.
- JOINT_*: four complete paragraphs, token-aligned rival readings, a shared
  16-entry hypothetical dictionary, repeated-pattern and boundary audits,
  and a reader-facing German document.
- SOURCE_LOCK.tsv, REGISTERED_VALIDATION.json, VALIDATION.json and
  JOINT_VALIDATION.json record reproducibility and independent checks.

Neither table is a decoded vocabulary. Prior glosses, structural relations,
historical analogy and unknown identities remain separately labelled.
