# GDT360 source audit

GDT360 reuses existing repository evidence and acquires no new description.

The exact-locus human atlas contains one row per current locus derived from the
same Stolfi source file. Its local comments, unit descriptions, relation tags,
and object tags are different representations of one source assertion, not
replications. The legacy label atlas and current-locus crosswalk descend from
the same Stolfi archive and likewise add mapping provenance, not another human
witness.

The GDT002 CONTACT/GAP rows are AI direct visual observations; BFE, zodiac
facing, barrel, clothing, star-tail, and ray/ownership rows preserve their own
published provenance. Repeated review, derived TSVs, and alternate
transcriptions do not multiply the number of manuscript observations.

ZL3b, IT2a, and RF1b are alternate readings of one object. Main formal features
use their family consensus. Reading disagreement is retained through strict
and alternative-site fields; it is not counted as replication.

The GDT327 interlinear covers confirmed formal events rather than the entire
label atlas. Its exact coverage is reported rather than backfilled with legacy
parser semantics. The wider label analysis therefore uses the independently
validated source-native family consensus, not unavailable roots, semantic
roles, or translations.

No source was searched or selected because its Voynich strings looked
promising. No catalogue or external-source search is performed. All `f84*`
rows are rejected on their raw selector field before any remaining field is
parsed.
