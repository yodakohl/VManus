# GDT360 artifacts

- `gdt360_annotation_inventory.tsv`: provenance-deduplicated existing visual
  cases and coverage states.
- `gdt360_visual_formal_join.tsv`: scored case rows joined to source-native
  family consensus and any already available GDT327 tuple sequence.
- `gdt360_candidate_atlas.tsv`: top ranked single-predicate candidates per
  visual endpoint.
- `gdt360_joint_worlds.tsv`: postselected multi-channel worlds using the same
  formal predicate.
- `gdt360_capacity_gaps.tsv`: channel capacity, topology mobility, and exact
  tuple coverage.
- `gdt360_counterexamples.tsv`: explicit confounds and failed transfer facts.
- `gdt360_result.json`: compact result, method settings, hashes, and seal
  assertions.
- `gdt360_validation.json`: nonimporting reconstruction and integrity checks.
