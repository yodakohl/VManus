# Ausgewählte Wärme-, Zeit- und Reihenfolgefassung

## Kurzurteil

Die vier Rollen konvergieren auf ein deutlich einfacheres Werkstattsystem:

```text
FOLGE/FORTSETZUNG + PROZESS + STUFE + POSTEN/SCHLUSS
```

Die ausgewählte Fassung übernimmt R3 als technisches Gerüst und korrigiert
23 Wörterbuchwerte mit den kürzeren Lösungen aus R1, R2 und R4. Sie umfasst
weiterhin **173 Karten, 381 Ereignisse, 116 Aussagen und elf Records**.

Das Ergebnis ist keine Entzifferung. Es ist momentan unsere beste kreative,
von einem Lehrling ausführbare Arbeitstheorie für die zehn festen Seiten.

## Das kleine produktive Wörterbuch

| Baustein | gewählte Bedeutung | unmittelbare Vorhersage |
|---|---|---|
| `AIIN` | SOLLMASS | mit `OK`: auf Sollmaß einstellen; mit `OT`: Folgemaß |
| `IIN` | ZIELSTUFE | mit `K`: weiche Zielstufe; mit `DA`: zweite Öffnungsstufe |
| `OK` | ANSETZEN / IN ARBEIT SETZEN | ruft einen Prozess am aktuellen Posten auf |
| `E` | STUFE I | meist kurz oder mild |
| `EE` | STUFE II | meist länger oder anhaltend |
| `EEE` | STUFE III | meist vollständig |
| `CHK` | WÄRMEN | `CHK+E`: kurz wärmen; `CHK+EE`: länger wärmen |
| `SHED` | ABSETZEN | `SHED+EE`: länger absetzen; `SHED+AL`: Absetzstelle |
| `CTH` | BEREIT | `CTH+E+Y`: kurz bereithalten |
| `SOLK` | AUFFANGEN | kurz/länger auffangen, optional mit Schluss |
| `OT` | FOLGE | Folgeansatz, Folgemaß, Folgeposten, Folgestelle |
| `OL` | FORTSETZUNG | Fortsetzungsansatz, weitere Portion, fortsetzen |
| `OK+OK` | ERNEUT | denselben Arbeitsaufruf wiederholen |
| `Y` | AKTUELLER POSTEN | trägt den gegenwärtigen Gegenstand; heißt nicht selbst „offen“ |
| gelernte Endkonstruktion | SCHLUSS | sichtbares nacktes `dy` ist ausdrücklich kein globaler Schluss |

`AIN=PORTION`, `AL=STELLE`, `AR=QUELLE/AUSLASS` und `OR=ANSATZ` werden aus den
vorigen Runden unverändert mitgeführt. Die vollständige Liste steht in
`THERMAL_TEMPORAL_COMPONENTS.tsv`.

## Warum das jetzt kompositionell besser ist

Die Bedeutung eines neuen Kartenkompositums kann erstmals mit einer kleinen
Regel geraten werden, ohne sofort einen ganzen Satz zu erfinden:

```text
OT + OR       FOLGE + ANSATZ       = FOLGEANSATZ
OL + OR       FORTSETZUNG + ANSATZ = FORTSETZUNGSANSATZ
OT + AIIN     FOLGE + SOLLMASS     = FOLGEMASS
OL + AIN      FORTSETZUNG + PORTION= WEITERE PORTION
CHK + E + Y   WÄRMEN + STUFE I     = KURZ WÄRMEN, Posten bleibt aktiv
CHK + EE + DY WÄRMEN + STUFE II    = LÄNGER WÄRMEN; SCHLUSS
OK + OK + Y   wiederholter OK-Ruf  = ERNEUT ANSETZEN
```

Die Regel ist absichtlich beschränkt. `ROL`, `LOL`, `QOTCHOL`, `OLTCHY` und
ähnliche Karten werden nicht wegen eines sichtbaren `OL` oder `OT` zerlegt.
Sie sind gelernte Ganzkarten. Ebenso blockieren `CTHOOR`, `CTHAIIN`,
`QOTEDAIIN`, `CHODAIIN`, `OTYTCHOL`, `TSHOL` und `CHCKHY` eine rücksichtslose
Substring-Grammatik.

## Gelerntes Wärme- und Zeitdeck

| ganze Karte | kurzer Default |
|---|---|
| `SCHOAL` | WEINSUD |
| `QOTCHOL`, `OLTCHY` | ANWÄRMEN |
| `ROL` | NOCH WARM |
| `LOL` | WARM |
| `QEKY` | ROH |
| `SHECTHY` | TEMPERIERT |
| `TCHODY` | ABKÜHLEN; SCHLUSS |
| `CHARY`, `RAL` | ABKÜHLEN |
| `ODY` | KÜHL; SCHLUSS |
| `SHFYDAIIN` | STANDZEIT |
| `CHCKHAL` | DAUER |
| `CHLDAIIN` | ABSETZSTAND |
| `CHEALROR` | KLARPUNKT |

Diese Werte sind kurz genug für ein echtes Werkstattdeck. Insbesondere heißt
`SHFYDAIIN` nicht mehr als einzelnes „Wort“ *für die vorgeschriebene Zeit
stehen lassen*, und `CHEALROR` nicht *bis der Strom klar abläuft*. Das Feld
liefert das Verb und den Gegenstand; die Karte liefert nur STANDZEIT oder
KLARPUNKT.

## Die stärkste echte Korrektur

Die exakte Karte `OLDY` kommt zweimal vor. Vorher hieß sie auf f55v sinngemäß
FORTSETZEN/SCHLUSS, wurde auf f83r aber zu der frei erfundenen ganzen
Wärmeanweisung „den Badezusatz sanft erwärmen und den Schritt beenden“.

Jetzt gilt an beiden Stellen invariant:

```text
OLDY = FORTSETZEN; SCHLUSS
```

Wärme wird nur noch von den CHK-Reihen oder den gelernten Thermalkarten
getragen. Das entfernt eine attraktive, aber widersprüchliche Übersetzung.

Das ist keine perfekte deutsche Prosa, aber eine konsistente Registerfolge,
die ein Lehrling mit Bild und Masterexemplar ausführen könnte.

## Vier Rollen, eine Auswahl

- R1 lieferte die verständlichste Lehrregel und entdeckte die `OLDY`-
  Inkonsistenz.
- R2 lieferte die historisch plausibelsten Prozessnomen und entschied
  `SHED=ABSETZEN`.
- R3 lieferte die vollständigste technische Grammatik, alle Schlusskarten und
  die wichtige Sperre gegen `dy=Schluss`.
- R4 zwang die Glossen zurück auf kleine Atome und trennte `OT`, `OL` und
  verdoppeltes `OK` besonders sauber.

Darum ist die Auswahl kein Mehrheitsvotum pro Wort, sondern
**R3-Struktur + R2-Prozesspräzision + R1/R4-Glossenkompression**. Die exakten
Abweichungen aller vier Fassungen stehen in
`SELECTED_THERMAL_TEMPORAL_PARADIGM.tsv`.

## Historischer Vergleich

Zeitnahe Rezept- und Werkstatthandschriften stützen den Mechanismus, nicht die
einzelnen Voynich-Zuordnungen: Handlungen, Maße, Wartezeiten, Wärmegrade,
beobachtbare Endpunkte und gelernte Fachkürzel treten nebeneinander auf. Gute
Vergleichsobjekte sind das
[Manoscritto Bolognese](https://bub.unibo.it/it/allegati/manoscritto-bolognese-traduzione/%40%40download/file/manoscrittobolognese-traduzione.pdf),
die [Medieval Welsh Medical Texts](https://www.ncbi.nlm.nih.gov/books/NBK558238/),
[Othmer MS 1](https://openn.library.upenn.edu/Data/0025/html/OthmerMS1.html),
[Wellcome MS.140](https://wellcomecollection.org/works/actgjagb) und
[Wellcome MS.5262](https://wellcomecollection.org/works/nuckbt25).

Das historische Analogon ist eine Mischung aus produktiven Fachkürzeln und
gelernten Ganzwörtern beziehungsweise Ganzzeichen. Keines dieser Manuskripte
liefert einen direkten Schlüssel zum Voynich-Text.

## Was noch nicht funktioniert

- Die Stufen I/II/III sind geordnet, aber nicht als Minuten, Temperaturgrade
  oder exakte Intensitäten kalibriert.
- `ABSETZEN` schlägt `RUHEN` technisch, kann in einzelnen Körperanwendungen
  aber zu eng sein.
- `ROL=NOCH WARM`, `LOL=WARM`, `QEKY=ROH` und `CHEALROR=KLARPUNKT` sind
  kreative Ganzkartenwerte mit je sehr wenig direkter Wiederholung.
- Das System identifiziert keine Pflanze, Krankheit, Körperstelle oder
  Sprache.
- Viele seltene Karten bleiben gelernter Wortschatz; die Grammatik sagt nur,
  wie der wiederkehrende Kern mit ihnen verbunden wird.
