# Method

## Fixed target and sources

The target is the thirteen reader-exact complete-form `ychor` occurrences
enumerated by GDT755. No new page or image is introduced. The builder reloads
the inherited allowed-page context through the existing guarded loader and
keeps f84/f84r inaccessible.

Three dated comparators add an expression missing from GDT755: late-fourteenth-
to-early-fifteenth-century recipe sequences in which `Item` opens an additional
remedy, including the directly transcribed forms `Item ... take` and
`Item ... stampe`. `Recipe/Accipe`, `Item take`, and a topic-heading reading
remain explicit rivals.

## Body geometry

For every target line the complete `ychor` token is removed before inspecting
the body. Reader-variant body tokens and all 172 GDT754 source-composed forms
contribute no independent axes. Four broad features are then recorded from the
remaining complete-whole cards: content, amount/level, process, and
quality/stage. A recipe triad requires content + amount/level + process in the
same line body.

Each target receives up to twenty nearby controls with:

- the same section, Currier language and hand;
- paragraph-continuation status;
- line length within one token;
- an exact line-initial whole other than `ychor`.

Nearest corpus-order controls are selected deterministically. This yields 247
matched rows representing 236 distinct lines. The same body feature extractor
also ranks every exact initial surface with at least five initial lines.

## Complete candidate layer

The 71 post-`ychor` token positions contain 53 written wholes. Each has one
short German working candidate and two rivals in
`src/YCHOR_BODY_CANDIDATE_PRIORS.tsv`. GDT755 values take precedence for its
top-24 wholes. Six formerly unread wholes receive explicit context candidates
instead of question marks. C0 literal nouns are deliberately aggressive test
values; none is selected from an EVA initial or substring.

The reader prints three complete-form alternatives for `ychor`: `ferner`,
`nimm`, and `ferner, nimm`. Every remaining token is rendered, so differences
between the alternatives can be judged on whole lines without generic
work-item prose.

## Claim boundary

The comparison ranks replaceable complete-form candidates. It does not recover
Latin spelling, a sound, a character value, a component meaning, a confirmed
content word, or plaintext syntax.
