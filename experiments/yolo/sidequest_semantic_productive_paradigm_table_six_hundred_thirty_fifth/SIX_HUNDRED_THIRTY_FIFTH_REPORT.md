# Sidequest Pass 635: the productive apprentice paradigm table

## Result

Six compact paradigms account for 20 attested compositional cells, 22 exact
cards, and 70 occurrences. In each paradigm a single visible component changes
one short dimension: grade, endpoint, or quantity.

This is closer to the target historical architecture than the earlier
sentence-sized dictionary. The learner memorizes roots and a small table, then
constructs the card value.

## The six paradigms

### 1. `OK × E/EE/EEE × Y/DY`

| Form | Reading |
|---|---|
| `okey / qokey` | set briefly; item remains active |
| `okeey / qokeey` | set for longer; item remains active |
| `qokedy` | set briefly; close |
| `qokeedy` | set for longer; close |
| `qokeeedy` | set fully; close |

This is the strongest productive grid. `OK` supplies ANSETZEN, vowel grade
supplies duration/completion, and `Y / DY` separates an active item from a
licensed close.

### 2. `SH × E/EE × Y/DY`

| Form | Reading |
|---|---|
| `tshey` | hold briefly; active |
| `cheey / shey / sheey` | hold longer; active |
| `dshedy` | hold briefly; close |
| `sheedy` | hold longer; close |

Two exact long-open cards occupy the same semantic cell. They are renderer or
learned-card alternatives, not two new meanings.

### 3. `SOLK × E/EE × Y/DY`

Attested: short collecting active, long collecting active, and long collecting
closed. The short closed cell is absent.

### 4. `CHK × E/EE × Y/DY`

Attested: short heating active, long heating active, and long heating closed.
Two exact cards share the long-open cell. The short closed cell is absent.

### 5. `OT × E/EE × Y/DY`

Attested: next/then-long active, then-short closed, and then-long closed. The
then-short active cell is absent.

### 6. `OK × AIN/AIIN`

| Form | Reading |
|---|---|
| `okain / qokain` | set a portion |
| `okaiin / qokaiin` | set the prescribed amount |

This is a quantity opposition, not a grade opposition.

## Why this is better than the old dictionary style

`qokeeedy` no longer receives the complex indivisible gloss “apply until the
full result is achieved and then finish.” It receives four short contributions:

```text
OK      ANSETZEN
EEE     VOLL
DY      SCHLIESSEN
```

Likewise `shey` is not “until the liquid runs clear.” It is simply:

```text
SH      HALTEN
EE      LANG
Y       AKTUELLER POSTEN BLEIBT AKTIV
```

Local liquid, body, vessel, or herbal content comes from the picture owner and
the surrounding whole cards.
