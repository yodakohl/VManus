# Method

## Inputs

- GDT416's exact component recipes and imperative clauses;
- GDT421's complete ordered-pair inventory;
- GDT407's preserved R-topology attachment field.

No new page, image, or transcription is used.

## Reduction

1. Select all recipes containing at least three action roots.
2. Test every adjacent action pair against GDT421.
3. For a missing pair, allow only four already present mechanisms:
   positional R topology, repeated-action scope, a visible slot boundary, or a
   break between peer action packages already licensed by the multi-action
   sentence template.
4. Require every occurrence and every gap to receive one explicit reduction.

The peer break does not invent a meaning: each side retains its existing
single-head or pair card. It merely says that two peer packages share a
surface card without becoming a new fused action.
