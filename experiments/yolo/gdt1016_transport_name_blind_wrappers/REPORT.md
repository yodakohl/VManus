## Die tatsächliche Konsequenz

Die Hypothese verlangt eine allgemeine Operation F, die keine der drei willkürlich
benannten Frachten auswählen kann. Wenn eine Umbenennung den Eingabewert
unverändert lässt, muss sie auch F(Eingabe) unverändert lassen. Das ist eine
zusätzliche Bedeutungsannahme, keine Folgerung aus bloßer Umbenennbarkeit eines
vollständigen Wörterbuchs.

den vollständigen Stopp zu begründen. Die72 Tabellenzeilen zeigen jeweils ein
