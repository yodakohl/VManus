# Selected translation revisions

This compact sheet shows how the newly completed components alter the current
ten-page working translation. The full, mechanically consistent edition is in
`SELECTED_116_COMPONENT_COMPLETE_STATEMENTS.tsv`.

## Referential `Y/CHY`

Old working assumption:

```text
Y = open/active state
```

Selected revision:

```text
Y   = this; the currently intended work item
CHY = wrapped realization of the same reference card
```

Thus `oky`, `qokchy`, `okey`, `okeey`, and bare `chdy|chedy` now retain the
same referent while varying operation or contact grade. Openness is a structural
consequence of missing closure, not the meaning of `Y`.

## Repetition and target order

```text
qokokchy = den laufenden Posten erneut in Arbeit nehmen
qokaly   = den laufenden Posten an der Zielstelle einsetzen
```

The first selects repetition over the earlier vague “again or strongly”. The
second assigns one stable contribution to each visible component:
`OK=in Arbeit setzen`, `AL=Zielstelle`, `Y=dies/aktueller Posten`.

## Receiver direction

```text
pchedy  = in den Empfänger einführen; Schluss
pchedal = Einfüllstelle
```

This is the bounded counterpart of `L+CHED = ab-/ausführen`. It is not yet a
global free-standing meaning for `P`.

## Graded learned families

```text
cheky    kurz oder mild erwärmen
cheeky   länger warm halten

cheedy   kurz oder gewöhnlich ruhen lassen; Schluss
sheedy   länger ruhen oder nachwirken lassen; Schluss

solkey   Sammelstelle kurz öffnen oder aktiv halten
solkeey  Sammelstelle länger offen halten
solkeedy an der Sammelstelle stehen oder absetzen lassen; Schluss
```

These are learned family readings. They are not licenses to translate every
visible `sh`, `chk`, or `solk` substring the same way.
