# Source-only preflight development

Before any new target match, the first plain backreference implementation passed
5,100 small exhaustive cases but hit its one-second limit on a known complete
source positive. It was not adequate for selection. Two necessary remaining-text
bounds were then added: enough characters for remaining nonempty forms, and no
more remaining words than forms. No source or target model changed, and no
manuscript pattern result informed this preflight revision. The final fixture
receipt, if PASS, includes all small cases and all24whole-source controls. The
superseded incomplete fixture attempt is not a manuscript contradiction.
