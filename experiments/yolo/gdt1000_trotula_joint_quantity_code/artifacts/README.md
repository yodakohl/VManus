# Reproduction artifacts

CANDIDATES.tsv: every paragraph, recipe and writer prediction and observed status.
PARAGRAPH_CASES.json: complete raw groups, provenance and quantity options.
PAIR_DECISIONS.tsv.gz: every different-leaf ordered pair, indexed into the above.
JOINT_CASES.json: all numerically compatible joint cases, including unknowns.
READINGS.md: every full joint code witness with complete word/part reading.
RESULT.json: bounded decisions, actual counts and independent-capacity limits.
VALIDATION.json and INDEPENDENT_SOLVER_REPLAY.json: separate census/word checks.
Preflight artifacts check software only. PUBLIC_REGISTRATION.json and
EXECUTION_RECEIPT.json record public freeze and actual execution times.
