# GDT385 artifacts

`gdt385_pre_score_freeze.json` and its validation bind the public design.
`gdt385_route_scores.tsv` and `gdt385_collection_folds.tsv` contain compact
held-collection results. `gdt385_predictions.tsv.gz` retains all anonymous
comparator predictions for independent rescoring. `gdt385_null_worlds.tsv`
contains the shared max-four null. The result and validation JSON files bind
the complete reproducible chain.
