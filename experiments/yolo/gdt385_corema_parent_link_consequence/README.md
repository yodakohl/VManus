# GDT385 — CoReMA parent-link consequence calibration

Comparator-only calibration of a genuinely editor-supplied relational
consequence.  The experiment asks whether a role recovered from the frozen
Voynichified observation layer improves prediction of an opaque element's
backward editor parent link under whole-collection holdout.

The experiment has no Voynich stage unless the complete comparator gate
passes.  It never reads any Voynich source or f84 material.
