# Method

Preregistered exact membership test on all old179selectors, internal definite
prose groups only. Each22unit token is counted separately per reader; compare
its distinct inventory with13. The validator uses an independent whole-string
regex and list reconstruction. No frequency threshold, optimizer or decoder.

A second predeclared diagnostic checks literal conflict with the nine excluded
synthetic roots, without confusing this with global-renaming impossibility.
The complete proof, scope, dependencies and outcomes are in PREREGISTRATION.md
and src/SPEC.json.
