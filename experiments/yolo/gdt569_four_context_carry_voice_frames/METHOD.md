# GDT569 method

## Question

Can the remaining difference between locally written and context-carried action
and argument slots be reduced to four explicit reading modes, then rendered
naturally throughout the complete GDT568 edition without changing a root?

## Inputs

- GDT568's complete 5,122-event and 793-statement action-voice editions;
- GDT566's ordered 30-page profile;
- GDT565's 1,656 state-card replay;
- GDT567's nineteen owner-voice argument cells;
- GDT562's complete 693-row inherited-action provenance;
- the GDT416 and GDT539 context metadata and owner-bound control clauses.

No new page or transcription source is opened.

## Method

1. For every state card, read independently whether its effective action and
   effective argument are written locally or carried by context. Their two
   binary states define four modes: neither carried, argument only, action
   only, or both.
2. Retain the nineteen GDT567 register×argument forms. When an argument is
   carried, change only its German article: `den` becomes `denselben`, `die`
   becomes `dieselbe`, and `die beiden` becomes `dieselben beiden`. Apply the
   form once per concise action unit, retaining GDT565's `zweimal` compression.
3. For every carried action, retain the GDT562 source root, source event and
   distance. Add one of three scope frames according to the existing outer
   sentence shape: `Weiter im laufenden Gang`, `Danach im laufenden Gang`, or
   bare `Im laufenden Gang`.
4. Leave the 214 locally explicit state clauses and all 3,466 nonstate clauses
   byte-identical. Reassemble all 5,122 events, 793 statements and 30 admitted
   pages in their original order.
5. Keep the owner-bound clauses as controls. Require every one of the 1,208
   argument-carry events to have an old `[wie zuvor]` marker and every one of
   the 693 action-carry events to have an old running/continuation/closure
   witness.

## Decision rule and claim ceiling

Pass only if the four modes exhaust all 1,656 state cards with counts
214/749/234/459, all 693 action sources replay byte-exactly, all nineteen
argument cells are used, every carry has its control witness, all nonstate text
is unchanged and deterministic regeneration is exact. The result may expose
context state in the German working edition. It adds no written atom, Voynich
root value, historical lexeme, plaintext, language, surface, recipe, event,
statement or page.
