# Hundertsiebenundachtzigste Runde: Hand B aendert 40 Formen, nicht den Text

Der komplette 73-Token-Miniabschnitt wurde durch eine zweite Schreiberhand gerendert. Wo eine Karte
mehrere bereits registrierte Oberflaechen hat, nimmt Hand B die naechste Form ihrer Lehrliste. Wo nur
eine Form existiert, bleibt sie stehen.

Das Ergebnis veraendert vierzig Token aus 23 verschiedenen Karten; 33 Token bleiben sichtbar gleich.
Keine neue Form wurde erzeugt. Jede Hand-B-Oberflaeche ist im 173-Karten-Woerterbuch registriert und
ordnet sich eindeutig derselben Karten-ID zu. Deshalb stimmen alle 73 Kartenwerte, alle achtzehn
Feldgrenzen, alle Slotrollen und alle Schlusspositionen exakt mit Hand A ueberein.

Beispiele:

- `dchol` wird `schol`, bleibt aber *vom vorigen*;
- `aiin` wird `chaiin`, bleibt *Sollmass*;
- `chedy` wird `chdy`, bleibt *ueberfuehren*;
- `qoky` wird `choky`, bleibt *einsetzen*;
- `chor` wird `or`, bleibt *Ansatz*.

Damit ist die Mehrschreiberidee nun praktisch ausfuehrbar: Ein Lehrling kopiert keine Buchstabenfolge,
sondern waehlt einen erlaubten Renderer fuer dieselbe gelernte Karte. Ein Leser normalisiert die
Oberflaeche zuerst und liest erst danach Slot und Kartenwert.

Als naechstes sollte eine dritte Hand **nicht** einfach die naechste Listenform waehlen, sondern die
beobachteten Positionsgewohnheiten aus den zehn Seiten benutzen: bestimmte Renderer am Feldanfang,
andere medial oder feldfinal. Dann zeigt sich, ob die gleiche Kartenfolge auch wie ein plausibel
positionell geschriebenes Werkstattmanuskript aussieht.
