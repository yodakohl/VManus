# Pass 469 — die Grammatik schreibt vorwärts

Auf den zehn Seiten stehen 487 verschiedene sichtbare Oberflächen. Sie
realisieren 399 Komponentenfolgen:

- 349 Folgen besitzen genau eine Oberfläche;
- 50 Folgen besitzen mehrere Schreiberallographen;
- eine kanonische, häufigste Form pro Folge trifft 606 von 776 sichtbaren
  Gruppen exakt;
- für alle 776 Gruppen erzeugt sie eine tatsächlich belegte Form derselben
  Komponentenfolge.

Die 170 nicht exakt getroffenen Fälle sind keine Bedeutungsfehler. Sie zerfallen
in 27 einfache q-Präfixformen, 66 Eintritts-/Voranstellungsallographen, 29
Ein-Zeichen-Allographen und 48 komplexere gelernte Allographen. Ein Lehrling
kann daher zuerst immer die kanonische Form schreiben und anschließend die
lokale Hand-/Registerform einsetzen.

Das ist der erste echte Vorhersagegewinn der Arbeitstheorie: Aus einer
Bedeutungskomposition folgt nicht nur eine deutsche Paraphrase, sondern eine
zulässige Voynich-Oberfläche. Offen ist nur noch, welche der zulässigen
Allographen ein bestimmter Schreiber an einer bestimmten Stelle bevorzugt.
