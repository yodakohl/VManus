# GDT585 — learned name compound atlas

Status: `PASS_80_CLASS_CORE_TYPES__109_OWNER_CONTENT_SLOTS__89_NAME_LABELS__18_CANONICAL_GROUPS_PLUS_1_VISUAL_CONTEXT_PAIR`

GDT585 ersetzt die rein vorläufige Namenpalette der 80 gelernten
GDT582-`content_class × raw_name_core`-Typen durch eine bild- und
ownerkonditionierte Arbeitstheorie. Alle 107 festen GDT581-Namensslots und die
zwei getrennten `LOCAL_X`-Inhalte bleiben belegt. Die alten GDT582-Hausaliase
verschwinden nicht: Sie stehen bei jeder geänderten Karte als sichtbare Rivalen
neben dem neuen Primärwert.

Der wichtigste Umbau betrifft die pharmazeutischen Seiten. Die 38
Arznei-/Zutatenslots verteilen sich sichtbar auf 29 Slots an Pflanzenfragmenten,
sieben Slots an sechs Gefäßlabels und zwei Slots eines Grenzlabels. GDT585 liest deshalb zuerst
eine Wurzel, ein Blatt, einen Blütenstand, eine Mutterpflanze, einen Vorrat oder
eine Bildgrenze und erst danach einen möglichen Einzelstoff. `d=Wasser`,
`y=Wein`, `s=Salz` oder `cheo=Essig` bleiben als alte Rivalen erhalten, werden
aber nicht länger gegen das sichtbare Objekt zur Primärlesung gemacht.

Auch die Sternringkarten werden einfacher: Die zehn wiederkehrenden kurzen
Kerne decken 27 Occurrences als wiederkehrende Ring- oder Kalenderwerte; die
33 einmaligen, im Mittel deutlich längeren Kerne bleiben gelernte Figuren- oder
Sternwerte. Ihre Position kommt aus Panel, Ring und Locus, nicht aus einer in
den Kern hineinerfundenen laufenden Nummer.

Neben den 89 einzelnen Namenslabels gibt der Pass 19 zusammengesetzte oder
gruppierte Lesungen aus: siebzehn Mehrnamenslabels, die beiden Blütenlabels an
der einen f17r-Pflanze und das optische Zeilengrenzpaar `dchos/yor` auf f89r.
Die GDT474/GDT476-Lesung bleibt jeweils grammatische Primärspur. Die kreative
Kompositionslesung steht in einem eigenen Feld daneben; produktive technische
Hüllen bleiben von den gelernten Namen getrennt.

Ausführen:

```bash
python3 experiments/yolo/gdt585_learned_name_compound_atlas/src/run.py
python3 experiments/yolo/gdt585_learned_name_compound_atlas/src/validate.py
```

Das Verfahren steht in [METHOD.md](METHOD.md), das Ergebnis in
[REPORT.md](REPORT.md). Die vollständigen Typ-, Slot-, Label-, Gruppen- und
Rivalenkanäle liegen unter `artifacts/`.

Alle deutschen Werte sind eine aggressive, ersetzbare Arbeitsübersetzung. Sie
sind weder wiedergewonnener Klartext noch bestätigte Voynich-Wörter.
