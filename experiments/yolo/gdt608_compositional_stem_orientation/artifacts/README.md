# GDT608 artifacts

- `RESULT.json`: compact model, null, folio, depth, and W diagnostics.
- `merge_tree.tsv`: all 64 direct merges and their tree leaves.
- `unit_profiles.tsv`: train/held profiles for all 98 units.
- `merge_composition_scores.tsv`, `model_feature_scores.tsv`: complete model
  scores by merge and feature.
- `stable_stem_role_summary.tsv`, `stem_family_roles.tsv`,
  `stem_family_children.tsv`: stable and rejected side families.
- `nominated_pairs.tsv`, `nominated_pair_verdicts.tsv`: the six concrete
  compound tests.
- `lomo_predictions.tsv`, `lomo_coefficients.tsv`: leave-one-merge-out model.
- `mobile_null_scores.tsv`, `matched_frequency_controls.tsv`,
  `held_folio_model_scores.tsv`: controls and folio transfer.
- `compositional_counterexamples.tsv`, `w_composition_diagnostic.tsv`,
  `tree_depth_summary.tsv`: limits and architecture diagnostics.
- `ARTIFACT_MANIFEST.json`, `VALIDATION.json`: hash binding and 95-check
  validation.
