# GDT796 artifacts

- `GDT796_OUTER10_400_TRANSFORM_RANKINGS.tsv`: all 400 f71/f72 dihedral
  transform pairs for eight source/member/family/prefix/residual views.
- `GDT796_OUTER10_NULL_SUMMARIES.tsv`: inclusive-missing and fixed-mask null
  calibrations for every view.
- `GDT796_OUTER10_SPLIT_HALF_RANKS.tsv`: both odd/even train-test directions;
  this is the main warning against turning F9 into a reusable key.
- `GDT796_OUTER10_BOUNDARY_POSITION_CONTRIBUTIONS.tsv`: ten position-level
  contributions to the boundary-family F9/R0 result.
- `GDT796_174_VISUAL_STATE_ATLAS.tsv`: exact-locus guarded visible-state
  records for barrel, clothing and facing.
- `GDT796_VISUAL_TRANSFER_SUMMARY.tsv` and
  `GDT796_VISUAL_RECURRENT_FAMILY_CENSUS.tsv`: local, held-page and
  held-physical-folio transfer, baselines, nulls and counterexamples.
- `GDT796_3_VISUAL_STATUS_CARDS.tsv`: three deliberately retained visible
  rivals below the GDT796 selection gate; none is a free word value or active
  renderer card.
- `GDT796_240_FACIES_GLOBAL_TRANSFORMS.tsv`: two historical matrices, two
  Taurus half-page phases and all sixty shared orientation/offset transforms.
- `GDT796_4_FACIES_SELECTED_MODEL_SUMMARY.tsv`,
  `GDT796_FACIES_LEAVE_ONE_FAMILY_OUT.tsv`,
  `GDT796_24_FACIES_LEAVE_ONE_SIGN_OUT.tsv` and
  `GDT796_HISTORICAL_FAMILY_STATUS_CENSUS.tsv`: target-masked selections and
  transfer diagnostics.
- `GDT796_AQABAC_FACIES_RIVAL.tsv`: nominal and independently selected values
  for every AQABAC occurrence.
- `GDT796_CANDIDATE_ADJUDICATION.tsv`: explicit retained/rejected readings,
  confidence, evidence, counterevidence and zero export licences.
- `RESULT.json` and `VALIDATION.json`: machine result and independent replay
  validation.
