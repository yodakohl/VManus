# Zehn Nicht-Handlungen: kurze Kontrastkarte

Der Rahmen bleibt gleich; das ausgetauschte Kürzel ändert Argument, Relation oder Reihenfolge.

- **Y = POSTEN** — der aktive, weiterverwendbare Arbeitsposten. Nicht automatisch WERT.
- **AIIN = WERT** — ein vorgeschriebener oder eingetragener Wert. Nicht automatisch MASS.
- **AIN = ANTEIL** — ein abgegrenzter Anteil innerhalb des Besitzers. Nicht automatisch PORTION.
- **OR = EINHEIT** — eine begrenzte Arbeits- oder Eintragseinheit. Nicht automatisch ZUBEREITUNG.
- **AL = ZIELORT** — die Adresse, an der der folgende Gang ankommt oder gilt. Nicht automatisch STELLE.
- **AR = AUSGANG** — die Adresse, von der der aktuelle Gang ausgeht. Nicht automatisch QUELLE.
- **L = VERBINDUNG** — eine Verbindung, die einen folgenden Gang oder Posten trägt. Nicht automatisch MIT.
- **AIR = BAHN** — die Bahn, auf der ein Posten oder Gang geführt wird. Nicht automatisch WASSER.
- **OL = FORTSETZEN** — den bereits aktiven Gang oder Bezug fortsetzen. Nicht automatisch VORIGES.
- **OT = DANACH** — einen nächsten gleichrangigen Gang danach eröffnen. Nicht automatisch NÄCHSTES.

## Drei Lehrsätze

- POSTEN wird weitergereicht; WERT füllt eine Einstellung; ANTEIL begrenzt; EINHEIT bündelt.
- ZIELORT nimmt auf; AUSGANG gibt her; VERBINDUNG schließt an; BAHN trägt den Verlauf.
- FORTSETZEN bleibt im Gang; DANACH eröffnet den nächsten Gang.
