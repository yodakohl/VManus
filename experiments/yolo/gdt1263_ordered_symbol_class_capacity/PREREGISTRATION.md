## Exact constraints and certificates
For every consecutive unit pair a,b INSIDE each included whole group impose
rank(a)<=rank(b). Never add interword/interline edges. Weak inequalities permit
unlimited equal-rank shapes. Reversing one global order gives the equivalent
nonincreasing contract; arbitrary bijective unit renaming changes nothing.
Directed paths impose weak inequalities and cycles force equality. Thus each
strongly connected component must be a single class. Conversely the component
DAG admits a topological ordering, giving exactly its number of distinct classes.
Therefore the maximum possible number of ordered active classes equals the SCC
count. A count1excludes nontrivial fixed classes; it does not exclude flexible
stages where the same symbol may occur in several stages or normal morphology.
