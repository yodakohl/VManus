# GDT447 — Katalog-Nachbaratlas

Alle 1.563 exakten Schlüssel werden durch Atomlöschung, Nachbartausch und
begrenzten Austausch innerhalb derselben portablen Kernklasse verändert. Die
Ausgabe trennt weiterhin exakte Zielidentität von unabhängiger
Faktorausführung.

```bash
python3 experiments/yolo/gdt447_catalog_near_neighbor_identity_atlas/src/run.py
python3 experiments/yolo/gdt447_catalog_near_neighbor_identity_atlas/src/validate.py
```
