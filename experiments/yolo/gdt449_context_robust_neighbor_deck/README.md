# GDT449 — Kontextrobustes Nachbardeck

GDT449 verdichtet die 61.878 GDT448-Proben auf 25.576 gerichtete
Nachbarkanten und 18.381 verschiedene Zielrezepte. Eine günstige Einzelstelle
wird dabei niemals als allgemeine Erlaubnis behandelt.

```bash
python3 experiments/yolo/gdt449_context_robust_neighbor_deck/src/run.py
python3 experiments/yolo/gdt449_context_robust_neighbor_deck/src/validate.py
```
