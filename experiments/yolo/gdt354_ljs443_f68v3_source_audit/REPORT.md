# GDT354 report: LJS 443 / f68v3 source audit

## Result

**`PROVISIONAL_EIGHT_BAND_SYSTEM_HOMOLOGUE_NO_SLOT_TRANSFER`**

The official Penn facsimile confirms a repeated eight-curved-compartment
diagram family on three adjacent LJS 443 surfaces. Penn dates the Armenian
calendar/astronomy compilation to after 1416. The already published human
Voynich annotation independently describes eight inward-spiralling written
bands on f68v3.

This is a useful external system-family lead. It shows that f68v3's broad
eight-band spiral architecture has a close chronological comparator in a real
calendar/astronomy manuscript, rather than requiring an anachronistic galaxy
interpretation.

## Why it is not yet a grounding endpoint

The source audit did not find a scholarly, folio-specific key giving all eight
compartment values, a fixed start, or a reading direction. The visible repeated
crescent/circular marks make a lunar hypothesis plausible, but that hypothesis
is not equivalent to an ordered phase key. The target is one physical folio and
has no independently phased transfer page.

Accordingly:

- external identity/date/provenance: **PASS**;
- eight-compartment external family: **PASS**;
- lunar interpretation: **PROVISIONAL_SECONDARY**;
- readable external slot values: **FAIL**;
- fixed external start/order: **FAIL**;
- fixed target phase: **FAIL**;
- independent target-folio transfer: **FAIL**;
- Voynich formal scoring authorized: **NO**.

No Voynich transcription, tuple, PAGE_HOST, or string was read or scored. No
f84 row or image was accessed.

## Next acquisition

Obtain a scholarly transcription/edition or qualified catalogue description
of the exact LJS 443 diagram series that identifies each compartment and its
authorial order. Even then, a target-side start/direction and an independent
homologous Voynich folio would be required before testing text alignment.

## Claim ceiling

This result licenses only a provisional eight-curved-band calendar/astronomy
diagram-family homologue. It does not establish a lunar phase table, Armenian
connection, source copying, compartment semantics, language, plaintext, or
translation.
