# GDT354 method: LJS 443 / f68v3 source audit

Date: 2026-08-19

Status: `SOURCE_FIRST_POSTHOC_ACQUISITION_AUDIT`

## Question

Does University of Pennsylvania LJS 443 provide a provenance-clean,
period-appropriate external homologue for the already human-described eight
curved writing bands on Voynich f68v3, and does it fix enough slot semantics and
order to authorize a later text comparison?

## Evidence boundary

The external facsimiles were inspected directly at native resolution. New
claims from that inspection are marked `AI_DIRECT_EXTERNAL_VISUAL_OBSERVATION`.
The Voynich target image was not opened. Its topology is taken only from the
existing human page annotation and is marked `EXISTING_HUMAN_ANNOTATION`.

The audit distinguishes:

- visible geometry;
- repository or library catalogue statements;
- secondary iconographic interpretations; and
- hypotheses.

No OCR, image similarity, object detection, automated captioning, or Voynich
transcription is used. f84 is forbidden.

## Fixed endpoint gates

An external witness is sufficient for later slot scoring only if all of these
are available:

1. source identity, date, and diagram provenance;
2. the same cardinality and comparable topology;
3. externally readable compartment values;
4. a fixed authorial start and order;
5. singular target correspondence; and
6. an independent target folio for transfer.

The first two gates can establish an iconographic/system-family homologue. All
six are required before any Voynich text or tuple is exposed to this endpoint.

## Reproducibility

The source manifest records exact official URLs, folio mappings, remote byte
hashes for the three inspected web JPEGs and the OPenn TEI hash. Images are not
copied into the repository. The validator independently rebuilds the selected
f68v3 human-source row through a guarded reader, checks the fixed source and
observation inventory, gate logic, hashes, and f84 exclusion. It does not claim
an independent second visual review of the external facsimiles.

## Claim ceiling

At most this experiment can establish a provisional eight-curved-band
calendar/astronomy diagram-family homologue. It cannot identify the target as a
lunar phase table; assign phases, compartment values, start, direction, words,
language, plaintext, origin, or translation.
