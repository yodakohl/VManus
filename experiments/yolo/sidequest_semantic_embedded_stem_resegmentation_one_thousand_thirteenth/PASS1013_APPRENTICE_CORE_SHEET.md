OK  SETZEN       CH  NEHMEN       SH  HALTEN       K   GEBEN
S   WÄHLEN       T   EINSTELLEN   CHD UMSETZEN     P   EINSETZEN

BEZUG / FOLGE / TOPOLOGIE

## Eingeschobener C_H-Rahmen

```text
C<T>H  = CH + T        NEHMEN + EINSTELLEN
C<K>H  = CH + K        NEHMEN + GEBEN
C<P>H  = CH + P        NEHMEN + EINSETZEN
C<F>H  = CH + F_LOCAL  NEHMEN + NEBENADRESSE
```

## Häufige lineare Verkettungen

```text
CHEO  = CH + E + O     NEHMEN + GRAD I + AUSFÜHRUNG
CHK   = CH + K         NEHMEN + GEBEN
SHED  = SH + E         HALTEN + GRAD I
LSH   = L + SH         VERBINDUNG + HALTEN
SOLK  = OL + K         FORTSETZEN + GEBEN
LD    = L + D_ADDR     VERBINDUNG + TEILADRESSE
```

`BEREIT`, `DURCHLASS`, `AUSZUG`, `WÄRMEN`, `UMLEITEN`, `ABSETZEN`,
`AUFFANGEN`, `SPÜLEN`, `TRENNEN` und `BEFESTIGEN` sind keine selbständigen
portablen Stammwerte mehr. Sie dürfen nur als lokale Ausführung einer
Kernsumme erscheinen.

## Leseregel

1. Bildbesitzer oder Diagrammplatz bestimmen.
2. Längste bekannte graphische Karte erkennen.
3. Karte in die obigen Kerne zerlegen.
4. Kernsumme unverändert lesen.
5. Erst danach den konkreten Stoff oder Handgriff aus Bild/Exemplar ergänzen.

Wenn die Kernsumme nicht passt, wird die ganze Karte als lokale Ausnahme
gelernt. Kein Kern wird nachträglich umgedeutet.
