source. The condition does not assert that its outcome actually occurred.

## Channel and exact predictions

One nonempty finite string over the fixed alphabet acdefghiklmnopqrstxy for each
of the 32 source units, globally injective and prefix-free. One WHOLE source word
must equal one WHOLE target group. No nulls, title/entry-glyph removal, joined
groups, normalized dots, new inflections, local code values or atomic root codes.
This is a proposed writing channel, not an identified Voynich alphabet.
The unchanged GDT900 solve_words/extend_word enumerate its exact word equations.

The shortest reference word has two source units; a one-character target word
therefore cannot fit this channel. A fruit head has at least five. The previously
published GDT905 tar-/ol-initial dictionary witnesses do not satisfy this head
model. Their failures are anticipated; no special heading exception follows.

For every source/target pair, register the entire generated source and require:
equal word count; each target word at least as long as its source unit sequence;
identical whole-word equality patterns; equivalent ordered whole-word prefix
relations; and raw common prefix/suffix lengths at least as long as the common
source-unit prefix/suffix. These are necessary consequences, not similarity
scores. Save every applicable contradiction, with positions and observed values.
When word counts differ, the word-count contradiction closes that case and
positional word comparisons are inapplicable. Nonliteral target words remain
UNKNOWN_SOURCE; literal characters outside the fixed alphabet contradict the
channel. No string is repaired.

two seconds per case, eight processes, a total600-second exact-search ceiling,
and at most16 valid observed keys per case. Every observed key must admit a full
32-unit injective prefix-free completion. If the occupied code trie is complete
while source units are missing, reject that observed key. Otherwise a free trie
branch gives a deterministic arbitrary completion for unused units.

A complete exhausted search with no key is UNSAT_EXACT. A time/global/witness
limit preserves incomplete enumeration, including when valid witnesses exist.
Report every encountered valid witness, without choosing the most fluent one.
