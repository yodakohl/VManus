## Exact assumptions and lemma
Let C be a fixed set of distinct nonempty working-unit strings; concatenation
of ANY finite list of C entries is uniquely decodable. Each complete retained
whole group belongs to C*. No prefix/suffix freedom or finite cardinality cap is
assumed. Whole-group/source-word correspondence and the22working units are paid
assumptions. No code spans a space, deletes symbols, overlaps strokes or changes
by context. The code need not represent letters; values stay unassigned.

If x,xy,yz,z belong to C*, with y nonempty, then y belongs to C*: both[x][yz]
and[xy][z] yield xyz. Free uniqueness makes their code-entry lists identical.
The list has cuts after x and after xy; their intervening entries concatenate to y.
Thus a one-unit y must itself be an entry. Derived strings need not be manuscript
words. One-sided cancellation alone is invalid for generalUD: {a,ab} is a countercase.
