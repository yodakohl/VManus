# Pass 482 — die Ellipsenmatrix

Nicht jede kurze Zelle muss Quelle, Menge, Lauf und Ziel neu ausschreiben. Für
alle 116 Prosaaussagen wird deshalb jeder nur tatsächlich benötigte Slot als
eine von sechs Arten geführt: EXPLICIT, OWNER_VISIBLE, WHOLE_CARD,
RECORD_INHERITED, LOCAL_EXEMPLAR oder NOT_REQUIRED.

Die Regel ist werkstatttauglich. Ein sichtbarer Besitzerwechsel setzt Quelle
und Bio-Ziel neu. Innerhalb desselben Records darf der laufende Bestand, das
zuletzt gesetzte Maß, der Lauf oder das Ziel weitergetragen werden. Ein
gezeichnetes Becken-/Leitungssystem liefert den Lauf; ARBEITSFACH kann einen
Empfänger liefern. Nur wenn weder Karte, Bild noch Record einen benötigten Slot
liefert, bleibt er lokaler Exemplarstoff.

Die Ausgabe schreibt jede Aussage zweimal zugleich: als originale kurze
Handlungsfolge und als vollständige Quelle–Menge–Lauf–Ziel-Ergänzung mit
sichtbarer Herkunft jedes ergänzten Slots. Damit wird Ellipse zu einer
positiven Schreibregel statt zu einer Einladung, beliebige Wörter einzusetzen.

Acht Aussagen schreiben alle von ihnen benötigten Slots aus. Dreiundfünfzig
werden aus dem laufenden Record vervollständigt, elf aus Bild oder Ganzkarte;
23 benötigen für ihre Handlung gar keinen Richtungs-/Mengenslot. Nur 21
Aussagen brauchen noch mindestens einen lokalen Exemplarwert. Der größte Teil
der Kürze ist damit geregeltes Weglassen, nicht fehlende Werkstattstruktur.

Als nächstes sollte die Matrix auf ihre knappsten echten Formularsätze
reduziert werden: gleiche Slotversorgung + gleiche Phasenkette ergibt eine
Formularklasse. Daraus kann ein Lehrling zunächst die häufigsten Klassen lernen
und nur die verbleibenden seltenen Klassen aus dem Masterexemplar kopieren.
