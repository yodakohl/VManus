# GDT584 method

## Question

Can the 591 statements affected by GDT583 be made grammatically coherent by
composing all written packets at their exact complete GDT581 governor, and do
whole-statement collocations identify a small set of occurrence readings that
should be narrowed without reopening the broad dictionary?

## Inputs

- The fixed GDT582 complete slot ledger, event, statement, local-card and
  twenty-passage editions.
- GDT583's 1,921 occurrence assignments, 1,623 affected events, 158 affected
  local cards, 591 affected statements and twenty fixed passages.
- No new page, image, transcription, segmentation, atom, root or owner.
- `f84` and `f84r` are explicitly forbidden.

## Method

### 1. Three independent reading passes

The same frozen material was inspected through three different lenses:

1. A direction/process pass read all 25 warm/cool/dry occurrences, all 51
   grade-hosted T occurrences and all 13 form-hosted T occurrences.
2. A material-practice pass read all 145 steep/soak/grind/strain/sieve/separate
   fine readings and their immediately adjacent wet or dry operations.
3. A whole-statement editing pass scanned all 591 affected statements
   mechanically and read forty difficult statements spanning all five
   registers and all 29 GDT583 rule families.

The audit treats an exploratory reading as live until a better local reading
exists. It does not require a manuscript lexeme claim. For conflicting
material clues the working priority is:

```text
immediate wet process > direct governor argument > complete remote governor
argument > broad register fallback
```

This priority is applied only to the named collisions found in the audit; it is
not exported as a new universal grammar rule.

### 2. Occurrence revision

Every GDT583 target slot is copied with its surface, event, statement, register,
slot position and `primary_governor_key` unchanged. GDT584 adds a disposition:

- `RETAINED` for 1,653 slots;
- `REPHRASED` for 218 reader-only action wordings;
- `NARROWED` for 34 occurrence meanings;
- `UPGRADED_FROM_BROAD` for fifteen useful local process readings;
- `REVERTED_TO_BROAD` for one unsupported sieve occurrence.

The fifty semantic adjustments are bounded to their published occurrence IDs.
They do not change the portable meanings of T, SH, CHD or S.

### 3. Statement-wide governor composition

For each affected statement, all complete GDT582 slots are regrouped by the
unchanged GDT581 `primary_governor_key`. A governor is rendered once at its
action head. Written packets from later events are incorporated as arguments
of that action instead of being emitted as detached `beim …` fragments.

The reader channel may suppress a repeated identical German argument within
one governor. The exact host table retains every slot ID, written event packet,
surface order, governor key and working gloss. Arguments attached to different
governors are never deduplicated. OT and DY introduce readable paragraph
breaks; OL remains an explicit continuation instruction.

### 4. Editions and review

The compiler publishes:

- all 1,921 revised target assignments;
- 6,289 statement-wide host phrases covering 12,707 written slots;
- compact editions for 1,623 affected running events and 158 local cards;
- all 591 polished statements;
- the fixed twenty-passage book and a forty-statement review deck;
- a pre/post issue census and exact rule-disposition table.

## Decision rule and claim ceiling

Pass requires all fixed target IDs and source projections to remain exact, all
statement slots to occur once in both the statement trace and governor
partition, all 62 remote fine arguments to reach their action host, zero
detached `beim …` fragments, zero lowercase sentence starts, the named
collocation revisions, unchanged passage identity, and no forbidden page.

The result is an exploratory German reader channel for the same thirty admitted
pages. It may improve occurrence wording and select the fifty named contextual
alternatives. It confirms no manuscript word, stem, plaintext, language,
historical codebook, genre, object, substance, procedure, illness or remedy;
and it licenses no unseen surface or new page.
