# Artifacts

The exhaustive tables are retained because GDT584's main claim is exact
statement-wide governor composition: every written slot and remote packet must
be independently recoverable from the reader phrase.

- `gdt584_target_occurrence_revisions.tsv`: all 1,921 target slots and the
  bounded semantic/wording delta from GDT583.
- `gdt584_rule_dispositions.tsv`: aggregate old-rule → new-rule routes.
- `gdt584_pre_post_issue_census.tsv`: renderer and collocation issue counts.
- `gdt584_statement_wide_host_phrases.tsv`: all 6,289 governor groups with
  packet IDs, exact slot traces and reader phrases.
- `gdt584_1623_polished_event_edition.tsv`: compact event-facing index into the
  statement-wide hosts.
- `gdt584_158_polished_local_card_edition.tsv`: complete affected local cards.
- `gdt584_591_polished_statement_edition.tsv`: before/after reader text and
  exact complete-slot traces for every affected statement.
- `gdt584_20_polished_passage_edition.tsv` and
  `GDT584_POLISHED_PASSAGES.md`: the fixed four-per-register passage deck.
- `gdt584_40_statement_review_deck.tsv` and
  `GDT584_MANUAL_COLLOCATION_AUDIT.md`: manual review material and decisions.
- `gdt584_result.json`: compact outcome and input hashes.
- `gdt584_validation.json`: independent 40-check source, coverage, grammar,
  output-hash and sealed-page audit.
