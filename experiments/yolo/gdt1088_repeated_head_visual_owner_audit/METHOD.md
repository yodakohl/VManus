# GDT1088 method

## Question

Can the complete four-form/nine-page GDT1070 repeated-head set support a shared plant or organ referent from blinded official-image observations?

## Inputs

Fixed first-head population: GDT1070 `HEAD_MULTIPLICITIES.tsv`. Existing image observations: GDT1087 `BLIND_VISUAL.tsv`. New image scope: `src/PAGE_ADMISSIONS.tsv` and the additive scope note. Official source: Yale IIIF manifest `https://collections.library.yale.edu/manifests/2002046`. The earlier GDT812 and GDT791 visual admissions remain valid for f21r/f56r.

## Method

Record exact canvas IDs, URLs and download hashes for all nine fixed pages. Before showing their first-head strings or pair identities, one image annotator inventories every whole-plant drawing in a nine-row table with uncertain traits retained. Freeze that table and its hash; then join the four exact first-head groups and evaluate all six pairs. The two-letter/five-letter forms and the one-character `o` are not merged or morphologically normalized. For each pair, report whether it meets the two-diagnostic-trait same-taxon standard, shares a specific conspicuous organ architecture, or remains undecidable/different. Existing 23-image GDT1087 observations provide a descriptive background prevalence for any nominated organ trait. No pair is dropped for a poor fit.

## Decision rule and claim ceiling

The exact selection, prior exposure, possible outcomes, budget and caveats are frozen in `PREREGISTRATION.md`. This is an exploratory capacity audit. It can retain a C0 working class but cannot confirm any word meaning or derive a p-value from these selected, previously exposed pages.
