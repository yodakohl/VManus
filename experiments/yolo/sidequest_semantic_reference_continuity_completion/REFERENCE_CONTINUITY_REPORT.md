# Reference and continuity layer

This pass turns the scattered pointing glosses into a small apprentice's
register. It is a creative workshop reading of the fixed ten-page sidequest,
not a plaintext claim.

## The five pointers

The useful system is smaller than the previous dictionary made it look:

| card/component | workshop value | question answered |
|---|---|---|
| `Y ~ CHY` | **THIS ITEM** | what is active now? |
| `AR` | **FROM IT / FROM THERE** | where is material taken from? |
| `AL` | **THERE / TO THE TARGET** | where is it sent? |
| `OL` | **CONTINUE** | is the same operation still active? |
| `OT` | **NEXT** | do we advance to the next operation or item? |

These values compose with the already selected preparation, quantity and
operation cards. Thus `OK+AR` is “set from it”, `OK+AL` is “set there”,
`OT+AR` is “then from there”, `OT+AL` is “then there”, `OL+AIN` is “another
portion in the same run”, and `OT+AIIN` is the target measure of the next
run. `OL` is not translated as AND or OR in this working edition: it carries
an active operation forward.

## Learned reference cards

Two useful relations are not forced into the productive five-part system:

- `dchol|schol` = **PREVIOUS ITEM**. Both Herbal occurrences retrieve material
  established by the preceding local instruction.
- `ldalor` = **FINAL TARGET**. It closes the single B6 route without requiring
  every visible part of the card to be a separate word.

`olsaly` is shortened from the adverb “below” to **LOWER TARGET**. `oteey`
becomes **LONG NEXT ITEM**, and `otar` is repaired from the invented object
“next outlet” to the compositional instruction **THEN FROM THERE**.

## How an apprentice uses it

The master keeps four small registers while copying a cell:

1. the pictured or inherited owner;
2. the current item (`Y`);
3. the active source (`AR`) and target (`AL`);
4. whether the current operation continues (`OL`) or advances (`OT`).

The cards need not repeat the nouns supplied by the picture or preceding
cell. A compact teaching gloss could use *hoc*, *ex eo*, *ad*, *prosequere*,
and *sequens* as memory aids; this is a workshop analogy, not a claim that the
Voynich surfaces encode those Latin words.

## Resulting readings

The repaired passages now read naturally within the current theory:

- H3: “Prepare a draught from the previous item to the target measure.”
- H5: “Wash the marked site, set the previous item on it, and apply it.”
- B1: “Transfer to the work site, lead it out at the outlet, then continue
  from there.”
- B3: “Set the following measure, lead to the lower target, allow it to
  settle, and close.”
- B6: “Collect the raw item longer, open the side arm, continue to the target
  measure, insert the cloth, and lead the item to the final target.”

This pass revises six exact cards across 25 occurrences and seven continuous
instructions. The complete edition remains 173 card types, 381 prose events,
116 instructions and eleven records. Every event still has a concrete default
reading.
