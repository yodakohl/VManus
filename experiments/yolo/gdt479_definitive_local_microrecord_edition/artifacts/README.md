# Artifacts

- `GDT479_DEFINITIVE_SIX_PAGE_LOCAL_EDITION.md`: complete readable six-page
  edition, grouped by page and microrecord.
- `gdt479_183_definitive_local_events.tsv`: event-level active readings, all
  three alternatives, and exact OT/OL scope traces.
- `gdt479_146_definitive_local_bundles.tsv`: bundle-level model choices,
  alternatives, repairs, boundaries, and order traces.
- `gdt479_135_definitive_microrecords.tsv`: one complete working reading per
  GDT475 record.
- `gdt479_6_page_edition_summary.tsv`: compact per-page totals.
- `gdt479_result.json`: compact result and invariant counts.
- `gdt479_validation.json`: deterministic 83-check validation report.

All artifacts are regenerated by `src/run.py`; `src/validate.py` verifies an
exact rebuild and the complete source mapping.
