# GDT479 method

## Working question

Can the complete six-page local-address stream be printed as one current
working edition in which every event has a default meaning, every bundle keeps
all three grammatical alternatives, multi-locus continuations are read as one
microrecord, and OT/OL order is explicit?

## Inputs

- GDT474: 183 event triptychs and 146 exact page+locus+owner bundle triptychs.
- GDT475: 146 fixed boundary roles and 135 microrecords.
- GDT476: contextual selections for all 64 tied GDT474 bundles.
- GDT478: all 69 directional OT/OL occurrences in 60 events.

No transcription source is reopened. The six pages remain `f17r`, `f71v`,
`f72r`, `f77r`, `f88v`, and `f89r`; f84 and f84r are forbidden.

## Compilation

For each bundle, use GDT476's contextual selection when the bundle belonged to
the 64-tie deck; otherwise keep GDT474's selected model. Select the matching
coordinate, instruction, or catalogue event and bundle reading, while copying
all three alternatives into the definitive tables.

Attach every GDT478 occurrence to its original event. The active reading stays
unchanged, followed by an explicit directional trace: OT starts the next
sibling and OL keeps the current unit active. Join bundles through GDT475's
fixed record IDs. A later bundle in the same record is introduced as the same
work operation, a related address trace, or a continued catalogue entry,
according to its active model.

The readable edition prints all six pages, all 135 records, all 146 bundle IDs,
all 183 event IDs and their visible surfaces. Machine tables preserve exact
source order and every alternate reading.

## Integrity checks

The validator rebuilds every artifact byte-for-byte, checks all source and
output key sets and counts, verifies the exact six bundle changes and seven
event-reading changes, reattaches all 41 OT and 28 OL slots, checks all record
and page totals, confirms that every default and alternative is present, and
proves zero root/name/surface/recipe/page change. It passes 83/83 checks.
