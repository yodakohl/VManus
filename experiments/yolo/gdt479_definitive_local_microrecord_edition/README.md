pages. It integrates GDT474's three grammatical readings, GDT476's contextual
choices, GDT475's 135 microrecord boundaries, and GDT478's directional OT/OL

event, or page.

[`artifacts/GDT479_DEFINITIVE_SIX_PAGE_LOCAL_EDITION.md`](artifacts/GDT479_DEFINITIVE_SIX_PAGE_LOCAL_EDITION.md).

earlier editions. See [`REPORT.md`](REPORT.md) for the compact result.
