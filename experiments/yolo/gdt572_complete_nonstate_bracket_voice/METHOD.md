# GDT572 method

## Question

Can every bracketed audit marker in the 3,466 current nonstate clauses be
rendered as natural German from the existing carried-argument and duplicate-
scope structure, and does the inventory fill any previously unused owner-root
voice cell?

## Inputs

- GDT571's complete event, statement and page editions;
- GDT569's nineteen state carried-argument forms;
- the complete GDT416 and GDT539 context records for inherited-argument
  provenance.

No new page, transcription, recipe, atom or root value is introduced.

## Method

1. Inventory every square-bracket token in the complete GDT571 event edition
   and retain its event order and eleven observed token signatures.
2. Require each `[wie zuvor]` occurrence to follow an exact owner argument
   phrase and to agree with the event's inherited argument root. Reuse the
   nineteen GDT569 article forms. Add only the observed missing
   `CELESTIAL×AIN` cell: `den Sektoranteil` → `denselben Sektoranteil`.
3. Render nominal `[außen]` and `[innen]` hosts with outer/inner adjective
   inflection. On relation or control hosts use `im äußeren Zweig` and `im
   inneren Zweig`. Render `[Stufe 3]` as `auf Stufe drei`.
4. Assign all 1,536 occurrences to one of twenty argument cards or five scope
   cards, rebuild all events, statements and pages, and require every state
   clause to remain byte-identical.

## Decision rule and claim ceiling

Pass only if the complete source inventory consists of exactly four marker
types, 1,536 occurrences, 1,156 nonstate events and eleven signatures; all
1,292 prior markers must have matching inherited-root provenance; all twenty
owner-root carry cells must be used; every bracket must disappear; all 1,656
state clauses and all source order/boundaries must remain exact; and generation
must be deterministic. Scope wording is an exploratory German workshop voice,
not a new portable root value or a claim about historical plaintext, language,
genre, object identity or codebook identity.
