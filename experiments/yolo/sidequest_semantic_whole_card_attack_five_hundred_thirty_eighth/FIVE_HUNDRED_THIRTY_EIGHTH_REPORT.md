# Fünfhundertachtunddreißigste Runde: Angriff auf die Restkarten

## Ergebnis

Von den elf zunächst unteilbaren Ganzkarten lassen sich fünf vollständig
reparieren. Drei weitere werden zu ehrlichen Mischkarten aus bekannten
Komponenten und genau einem gelernten Fachstamm. Zusammen mit der bereits
teilbaren Befestigungskarte bleibt dieses Inventar:

- 166 vollständig komponierte Kartentypen / 374 Ereignisse;
- vier Mischkarten / vier Ereignisse;
- nur drei echte Ganzkarten / drei Ereignisse.

## Die sauberen Reparaturen

- `cheey|shey` → **SH + EE + Y** = halten + länger + dies;
- `cheoar` → **CH + E + O + AR** = abziehen + kurz + Arbeitsgang + von dort;
- `chokcheo` → **OK + CH + E + O** = ansetzen + abziehen + kurz + Arbeitsgang;
- `shckhedy` → **SH + CKH + E + DY** = halten + Durchlass + kurz + Schluss;
- `lcheckhedy` → **L + CKH + E + DY** = führen + Durchlass + kurz + Schluss.

Damit muss `CHEO` kein riesiges Wort „Auszugsmedium“ mehr sein und `CKHE` kein
eigener komplexer Fachbegriff. Die bekannten kleinen Achsen erklären die
Karten besser.

## Vier kleine gelernte Fachstämme

- `CFH` = auswringen, in `cfhy` zusammen mit Y=dies;
- `S` = teilen, in `ches` zusammen mit CH=abziehen und E=kurz;
- `LD` = befestigen, in `qokylddy` vor DY=Schluss;
- `DA` = zweite, in `daiiin` vor IIN=Sollstufe.

Diese vier Stämme sind bisher nur einmal vertreten. Die ganzen Karten bleiben
konkret lesbar, aber der neue Stamm wird nicht künstlich als bereits
produktives Paradigma ausgegeben.

## Drei echte Ganzkarten

- `os` = Arbeitsfach;
- `talam` = verwahren;
- `ls` = fortsetzen.

Sie besitzen auf den zehn Seiten keine wiederkehrende innere Achse. Ein
Lehrling nimmt sie deshalb als Ganzzeichen aus dem kleinen Deck.

## Nächster Angriff

Als Nächstes wird das nun fast vollständig kompositionelle Lexikon benutzt, um
noch nicht vorkommende Kartenkombinationen vorherzusagen. Besonders wichtig
sind OK/OT/OL mit AIIN/AIN/AL/AR/AIR und die Gradreihe E/EE/EEE vor Y oder DY.
