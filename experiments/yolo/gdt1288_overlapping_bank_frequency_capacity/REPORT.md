## The fixed mechanism and what is new

    abcdefghijklmnopqrs
    jklmnopqrstuvwxyzab
    stuvwxyzabcdefghijk

Keep the current row while it contains the next lowercase letter. Otherwise
write a visible absolute selector and use the fixed home row(a-i,j-r,s-z).
State persists across stored word spaces and starts0at each stored recipe.
Outside letters are paid quoted literals and preserve the state. No source case,
punctuation, rare character, token or recipe was dropped or normalized anew.

Overlapping source membership genuinely escapes1202's universal two-spelling
premise: 'as' has three different payload sequences from the three reachable
entry rows. Conversely, with DISJOINT source banks, even arbitrarily many absolute
selectors create at most two word forms: only the first selector can differ,
after which every decoded source character fixes the bank. This explains why
merely increasing disjoint table size would not have justified this experiment.
1180used previous-source-character classes; here the retained bank can persist
through several letters/words. The old1180and931failures remain unchanged.

Nevertheless, each fixed(source word,entering bank)cell must have one output.
Coalescing cells into identical written forms cannot increase the type count or
reduce the sum of the ten largest frequencies. We therefore used an optimistic
necessary bound, not a full glyph-rendered writer or optimized allocation. All
actual bank visits were fixed by source order, not balanced to favor the result.
No letter table, q/y rendering or entropy fit was attempted after the failure.
