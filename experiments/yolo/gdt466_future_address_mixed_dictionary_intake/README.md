# GDT466 — future-address mixed-dictionary intake

Status: `FROZEN_MIXED_DICTIONARY_INTAKE_READY`

This experiment turns the closed 107-label dictionary into an executable
reader for a visibly supplied address surface. It tries the exact label, 44
frozen function channels, eighteen owner-family markers, and finally an
owner-class whole-name fallback. Every input therefore receives a bounded
default without inventing a meaning for its learned name core.

Run one address with:

```bash
python3 experiments/yolo/gdt466_future_address_mixed_dictionary_intake/src/read_address.py \
  otxainy STAR_BEARING_RING_POSITION
```

See `REPORT.md` for the result and `METHOD.md` for the precedence contract.
