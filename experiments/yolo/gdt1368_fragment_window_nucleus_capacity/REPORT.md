## What the test changes

The older1042/1363/1364carrier bound assumed each retained written group contains
a carrier. IDEA1046 instead allows a sourceword to occupy one or two consecutive
visible groups, with no group mixing sourcewords. Every sourceword must still
retain a nonempty carrier from one globally fixed written inventory. Carriers
may cross fragment gaps, but their RAW_CHAR characters must remain intact.

Any true three-group window then contains a complete sourceword. Otherwise it
would consist only of two proper edgefragments, each at most one group long.
Choosing one character percarrier therefore yields a global hitting set for all
such windows. This is why an exact minimum4excludes at most3carriers under this
contract, but cannot exclude5. Kcounts written carrierforms, not vowel phonemes.
The B2limit is a tested hypothesis, not an inferred maximum syllable count.

These results prevent extending the old whole-group exclusions unchanged to
this different boundary model. They do not reverse those old results. Nor is
4versus1364's whole-group10–13a matchedsample estimate of a segmentation effect:
the windows have stricter adjacency eligibility and do not involve every old
group. The new result stands on its own fixed set of retained triples.

## What passing the window condition does not prove

A representative hit may occur outside any actual carrier. Window hits also do
not guarantee a consistent partition. For example, the fully framed hit-pattern
0,1,0,0,1,0hits every triple yet cannot be partitioned into blocks of length<=2
that each contain a hit: two hitgroups can cover at most two of the four zeros.
This is a synthetic counterexample, not a manuscript reading. Actual sourceword
framing is not supplied by native line ends. No partition or decoder was fitted.

The old1233cache excludes uncertain groups. We require exact indices i,i+1,i+2
on the same page+locus and definite seams, so filtered gaps create NOartificial
neighbors. However the retained triples are only a subset of all manuscript
triples. An exclusion witness would apply to a universal rule; passing here
establishes only non-exclusion on this subset. No GE2rarityfilter was used.
No source language, fixed vowel inventory or historical writing rule is selected.
