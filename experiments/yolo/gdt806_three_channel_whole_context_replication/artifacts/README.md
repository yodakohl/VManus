# GDT806 artifacts

- `SOURCE_LOCK.tsv`: hashes and guarded-access modes for all builder inputs.
- `GDT806_GUARDED_QUERY_STATS.tsv`: selector, requested-column and sealed-prefix
  audit for the mixed transcription source.
- `GDT806_GLOBAL_DECK_STAGE_AUDIT.tsv`: fail-closed row/surface counts through
  the nine global-deck gates.
- `GDT806_GLOBAL652_DECK.tsv`: 652 unconditionally exportable complete surfaces,
  with all GDT806 semantic and renderer credits fixed to zero.
- `GDT806_ELEVEN_TARGET_ATLAS_CAPACITY_AUDIT.tsv`: all-eleven and six-target
  channel capacities, kept distinct.
- `GDT806_TARGET_AND_K12_CONTACTS.tsv`: 967 target events and 1,737 K12-control
  events, split into exact, narrow and residual channels.
- `GDT806_K12_POOL_MEMBERSHIP.tsv`: twelve fixed target-specific controls for
  each of the six target wholes.
- `GDT806_CHANNEL_CAPACITY.tsv`: raw, alternate-reader-stable and all-opportunity
  capacity by target, side and channel.
- `GDT806_EXACT_RATIONAL_RIVAL_SCORES.tsv`: all target/control candidate scores
  as exact fractions.
- `GDT806_K12_MEDIAN_RANK_CONTRASTS.tsv`: individual-control medians, centered
  margins and oriented ranks with ties against the target.
- `GDT806_STABLE_LOFO.tsv` and `GDT806_STABLE_LOFO_SUMMARY.tsv`: synchronous
  leave-one-physical-folio-out folds.
- `GDT806_RAW_STABLE_LOCO.tsv` and `GDT806_RAW_STABLE_LOCO_SUMMARY.tsv`:
  raw/stable leave-one-control-out folds with fixed full-sample direction.
- `GDT806_6_ADJUDICATIONS.tsv`: the full gate chain; all six rivals remain
  unresolved and install no new role.
- `GDT806_7_ZERO_CREDIT_FRAMES.tsv`: repeated two-sided frames retained only as
  rival illustrations.
- `GDT806_12_PASSAGE_CARDS.tsv`: two concrete, display-only passages per target.
- `GDT806_GDT388_CONTEXT_EDGE_PACKET.tsv` and
  `GDT806_GDT388_EDGE_INTAKE.json`: 916 formal context edges and their explicit
  invalid/not-score-ready intake result.
- `GDT806_STRUCTURAL_CARD.tsv`, `RESULT.json` and `VALIDATION.json`: compact
  outcome, machine-readable result, and 100,821-check/two-replay independent
  validation record.
