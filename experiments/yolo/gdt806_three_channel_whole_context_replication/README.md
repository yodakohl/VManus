Status: `REGISTERED_POST_DATA__6_FIXED_WHOLES__12_EQUAL_WIDTH_RIVALS__RELATED_DECK_BREADTH_TEST__652_FAIL_CLOSED_GLOBAL_SURFACES__577_GLOBAL_RESIDUAL__7_ZERO_CREDIT_FRAMES`

This registered experiment compares fixed complete-whole role rivals for
`cheol, otal, okal, ol, qokeol, qokol` in an exact-local channel, a narrow
GDT739-derived projection and a disjoint GDT734 global residual. It then uses
seven already enumerated repeated frames only to illustrate the rival readings;
they have zero decision weight. Agreement between the related renderer decks is
reported as breadth concordance, not independent semantic replication.
Approximate deltas and ranks were visible while robustness gates were being
corrected, so this is explicitly outcome-aware exploratory analysis, not an
outcome-blind confirmation.

See `PREREGISTRATION.md`, `METHOD.md` and `experiment.json`.
