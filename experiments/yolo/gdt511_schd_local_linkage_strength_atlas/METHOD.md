# GDT511 method — local linkage strength for `S+CHD+Y`

## Question

How tightly connected are the 62 local `S`-on-`Y` × `CHD`-on-`Y` rectangles
behind GDT510's Celestial, Pharma and Source cards, and does any one reach the
immediate same-statement shared-argument standard already visible in GDT507?

## Inputs

- GDT416's 4,576 owner-local component recipes and clauses;
- GDT436's 4,576 ordered stream states;
- GDT507's thirteen immediate same-statement same-inherited-argument bridges;
- GDT510's three rectangle summaries and four local-upgrade cards.

## Method

1. Reconstruct every exact one-action-head `S` and `CHD` event whose explicit
   or inherited argument root is `Y` in each of the three target registers.
2. Emit their complete Cartesian products: 24 Celestial, 34 Pharma and four
   Source candidates.
3. For every candidate, retain direction, event distance, page, owner and
   statement identity. Replay the full inclusive GDT436 interval and report
   its active-argument roots, collapsed run trace, state-change count and the
   number of events not ending on `Y`.
4. Count target-register within-event `S>CHD` and reverse `CHD>S` sequences.
   Separately mark immediate and zero/one-gap pairs.
5. Compare against GDT507's stronger bridge shape: consecutive events in the
   same statement and owner carrying one uninterrupted inherited argument.
6. Select one readable corridor per register by the fixed hierarchy same
   statement → same owner → same page → shortest distance → least argument
   disturbance → event IDs. Publish every event in those three corridors.

## Decision rule and claim ceiling

The linkage tiers are descriptive working levels:

- `A_LONG_SAME_STATEMENT_OWNER_PAGE`;
- `B_LONG_SAME_OWNER_PAGE`;
- `C_LONG_SAME_PAGE_CROSS_OWNER`;
- `D_REGISTER_ONLY_CROSS_PAGE`;
- `R_REVERSE_CHD_BEFORE_S`.

Only a consecutive same-statement pair with one uninterrupted inherited
argument can match the existing GDT507 grade. A longer interval may remain a
useful local inventory link, but it is not a local pair occurrence.

The pass changes no target recipe, German phrase, root value, evidence label,
surface or occurrence claim. The old Biological `G407-E1883` carrier remains
the source of directed `S>CHD` order. No new page is used; `f84` and `f84r`
remain forbidden.
