# GDT747 — gestützte Ganzwörter in vollständigen Passagen

GDT747 setzt nur die gemeinsamen Form-/Verteilungsachsen aus GDT746 in alle 64
Vorkommen der zwölf gestützten Ganzwörter ein. Es rendert 62 vollständige
Cachezeilen und sechs mehrzeilige Blöcke, ohne EVA-Teilwerte oder alte
Pulver/Samen/Wurzel/Holz-/Flüssigkeitsidentitäten zu übernehmen.

Der stärkste neue Befund ist ein kontrastives Ganzwortparadigma für `qochey`:
`tchey qokchey qochey` entspricht im Arbeitsmodell kalt-trocken / heiß-trocken /
temperaturunspezifisch trocken, jeweils im Mittelbereich. Der [Bericht](REPORT.md)
und der [Passagenleser](artifacts/GDT747_SUPPORTED_WHOLE_PASSAGE_READER.md)
zeigen alle Grenzen und Gegenfälle.
