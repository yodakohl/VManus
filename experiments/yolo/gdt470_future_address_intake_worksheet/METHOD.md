# GDT470 method

## Question

When one opaque character is inserted inside each of GDT466's 89 learned name
cores, do the visible function channels retain not only their working reading
but also their exact channel signature, ordered recipe, provenance tier/rank
and bounded-shell identity? Can that contract be turned into an empty intake
sheet for four future pages without opening them?

## Replay

Hide the exact whole-label dictionary for both the old source form and its
synthetic `x`-insertion. Run both through the unchanged GDT469 supported reader.
The mutation passes only when all of the following remain identical:

- selected GDT466 channel IDs;
- ordered component recipe;
- GDT468 support tier and rank;
- GDT467 bounded-shell ID or the same explicit absence;
- the GDT466 working reading already recorded for the mutation.

The inserted `x` is an opaque probe marker, not a proposed Voynich spelling.
Group the result independently by owner content class and by the ordered
PREFIX/INTERNAL/SUFFIX shape of the selected channels.

## Worksheet

Publish four `UNRELEASED` page slots, an empty item table with a fixed schema,
seven complete intake actions and a command that fills one row after a visible
surface and owner class are supplied. Exact label cards retain first priority.
Otherwise the row records the visible function reading and keeps every
untranslated residue inside an explicit owner-class name placeholder.

Recipe provenance annotates the reading but never changes it. A form outside
the two bounded GDT467 shell templates can still retain visible one-sided or
internal function channels.

## Claim boundary

No page, channel, component meaning, surface prediction, object name,
plaintext, language or confirmed lexeme is added.
