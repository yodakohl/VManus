# GDT470 — changed name cores preserve the complete working address frame

## Result

All 89 label-derived unseen-core forms preserve all five requested layers:

| invariant | stable |
|---|---:|
| exact function-channel signature | 89/89 |
| ordered component recipe | 89/89 |
| recipe support tier and rank | 89/89 |
| bounded-shell ID or explicit absence | 89/89 |
| German working reading | 89/89 |

The mutation changes only the learned owner-bound name core. It never changes
the surrounding working function frame.

## The realistic probes are much narrower than the Cartesian atlas

The 89 forms divide into 25 running-backed recipes, one complete-address-only
recipe, sixteen hybrid-address-backed recipes and 47 shapes outside the bounded
two-template shell atlas. Thus 42/89 have an old exact recipe carrier. Seventeen
forms have a full GDT467 bounded-shell match, and all seventeen are old-carrier
backed. None of the 89 falls into `COMPOSITION_ONLY`.

That is a useful correction to the scale of GDT467: its 7,839 composition-only
synthetic probes remain possible working compositions, but the label-derived
core changes tested here occupy a far more conservative part of the space.

The 47 outside-atlas cases do not become unreadable. Most use one-sided or
internal-only channel arrangements that GDT467 deliberately did not enumerate.
The GDT466 reader still returns their visible functions and an explicit learned
name for the residue.
