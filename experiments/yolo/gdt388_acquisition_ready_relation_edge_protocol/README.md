# GDT388 — acquisition-ready relation-edge protocol

GDT387 validates a narrow anonymous parent-link instrument in a second readable
corpus. GDT386 shows that the current Voynich annotation archive has no target
edge homologous enough to use it. GDT388 turns that absence into an executable,
text-blind acquisition specification.

This experiment does not score Voynich text. It distinguishes local
text-to-drawing geometry from an independently ordered inscription-to-
inscription edge, publishes the exact edge packet schema, and freezes the first
admissible acquisition batch.

Run and validate with:

```sh
./vpy experiments/yolo/gdt388_acquisition_ready_relation_edge_protocol/src/run.py
./vpy experiments/yolo/gdt388_acquisition_ready_relation_edge_protocol/src/validate.py
```
