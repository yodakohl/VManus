# GDT596 method

## Question

Can GDT595's 254 fully specific bath-object clauses be reduced to a small
factorized workshop phrasebook that separates object typing from reference
direction and then compositionally rebuilds every complete German clause,
without opening a page or inventing a root, substring, or semantic exception?

## Inputs

- GDT595's complete 254-action object and clause table;
- GDT595's compact result, including the six retained host-attachment rivals;
- a complete manual workshop review deck over all 254 slots in their 793-reader
  context, retaining sixteen fluent-scope repairs and seven explicit rivals.

The inputs contain only f75r, f77r, f81r, f81v, f82r, and f83r. No image,
transcription, new page, or raw mixed-source table is opened.

## Method

The old seventeen provenance routes are factorized twice rather than treated as
seventeen separate grammar rules.

The ordered object-typing ladder is:

1. an object carrier written in the complete SH host: 100 actions;
2. a carrierless complete-host body blocker: 25 actions, all Station;
3. a bounded typed source on the left, right, or an accepted episode edge: 74;
4. an already stable AIN/OR type: 12;
5. otherwise the body-first working default: 43.

Typing and reference are deliberately separate. The 254 actions independently
receive one of three reference-scope cards:

- 70 left sources after the last cut, rendered anaphorically;
- eight right shared complements plus E2952's packet tie, rendered definitely;
- 175 in-host or default objects, also rendered definitely.

The five-by-three cross-product occupies seven exact cells. This preserves the
fact that five local AIN/OR occurrences share the same type card as seven reset
type defaults but use a different determiner.

The selected class and source-bound lemma then pass through a four-cell German
renderer: masculine `den/denselben`, feminine `die/dieselbe`. Seven observed
lemmas produce eleven observed noun phrases. A normal one/two/three-item list
rule preserves all written participant order.

The residual bath clause is factorized into `im Bad` or `im Badbetrieb` plus
fifteen already admitted modifier fragments. `AIIN_FILL` is the only special
composition: if followed by a grade, both first form one phrase (`bei der
angegebenen Füllung auf Grad …`). All remaining fragments use an ordinary
comma-and-final-`und` list. This reconstructs forty observed modifier sequences
without storing forty clause templates.

The complete replay retains the upstream route, source pointer, typing token,
reference card, object class and lemma, participant order, bath frame,
modifier sequence, reconstructed clause, and rival flag for every action slot.
The six host-attachment rivals keep their chosen default; no rival becomes a
stop or an empty reading.

The manual pass does not vote a default away. It records sixteen clauses whose
objects stay fixed but whose participant, location, path, or grade scope should
be spoken more naturally; six object-rival cards; and one binding-mechanism
rival. E2952 and E3224 alone are marked as immediate strong object forks.

## Decision rule and claim ceiling

The phrasebook succeeds if all 254 action slots receive exactly one typing card
and one reference card, the profiles are 100/25/74/12/43 and 70/9/175, all
eleven noun forms and fifteen modifier cards reproduce their observed counts,
and every full GDT595 clause rebuilds byte for byte with zero mechanical
exception. All twenty-three manual review rows must match their exact replay
clause and keep a default. The 253-event/254-slot distinction at E3243 must
remain visible.

This is an exploratory compression and executable German working renderer. It
does not freeze or reject alternative meanings. Exact replay means only that a
small rule deck expresses the current working edition; it does not confirm a
Voynich plaintext, language, global lexeme, real patient, substance, illness,
remedy, operation, or historical codebook. No page, surface, slot, root,
parser, segmentation, or occurrence meaning is changed.
