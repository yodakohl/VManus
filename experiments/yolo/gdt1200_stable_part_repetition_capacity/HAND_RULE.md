# Ein kleiner Handablauf, noch ohne Bedeutung

Für eine vorgegebene Folge B und einen bereits festgelegten Abschluss:

1. Schreibe B einmal.
2. In der hier untersuchten Doppelungsform schreibe B ein zweites Mal.
3. Schreibe dy einmal hinter die Folge. Die daneben belegten einfachen Formen
   verwenden keinen Zusatz, y, dy oder or; das sagt noch nicht, wann welcher gilt.

```
B = dal: dal + dal + dy -> daldaldy
B = al:  al  + al  + dy -> alaldy
B = ch:  ch  + ch  + dy -> chchdy
B = ol:  ol  + ol  + dy -> ololdy
```

Die getrennte Variante lässt nach dem ersten B eine Leerstelle stehen. Ihre
Gleichsetzung mit der geschlossenen Variante ist ausdrücklich eine zusätzliche
Annahme. Der kleine Ablauf passt zu belegten Formen, erklärt aber weder deren
Häufigkeiten noch Inhalte; er ist kein vollständiger sinnvoller Schriftcode.

Konkrete Mehrdeutigkeit, ohne neue Quellabfrage aus dem Ergebnistableau:

```
(B=ol,   Anzahl=2, Abschluss=dy) -> ololdy
(B=olol, Anzahl=1, Abschluss=dy) -> ololdy
```

Beide Basisfolgen kommen selbständig vor. Ohne festgelegte primitive Einheiten
oder eine anderweitig belegte Bedeutungsäquivalenz geht hier die Unterscheidung
zweier Eingangsnachrichten verloren. Eine längste/kurzeste-Schnittregel würde
lediglich einen Parser wählen; sie wäre nicht durch das Manuskript bewiesen.
Ein Konzeptwert für ol, eine Zahl für die Anzahl oder ein grammatischer Wert
für dy wird dem Manuskript nicht zugewiesen. Keine automatisch nachgeschobene
Tabelle oder zusätzliche Bedeutungsannahme heilt diese offene Stelle.
