# GDT544 method

## Question

Do any of GDT543's targets with an anchor-context difference or a new atom
interface possess an unselected equal-length old complete-recipe anchor, and
where do all 23 unused longest-anchor candidates actually reside?

## Inputs

- GDT543's 81 selected fragment-extension cards;
- all 104 longest-anchor candidates;
- all 93 directional extension arms.

## Method

1. Mark every card whose selected old-anchor context-mode set is disjoint from
   its observed target set.
2. Mark every card with at least one selected interface absent from all old
   complete recipes.
3. Form the union without double-counting cards that carry both flags.
4. Count selected and unselected equal-length candidates for every marked
   target.
5. Independently inventory all unselected candidates and their owner targets.

## Result conditions

- the twelve context flags, six interface flags, two overlaps and sixteen-card
  union replay exactly from GDT543;
- every one of the sixteen cards has exactly one longest-anchor candidate;
- all 23 unused candidates and all twenty owners are enumerated;
- no unused candidate belongs to a flagged card.

## Decision rule and claim ceiling

This is an availability correction, not a new rejection rule. When no
equal-length alternative exists, the GDT543 card remains unchanged and the
next search may inspect shorter exact old-recipe stems. No surface, recipe,
meaning, context contract, page, or root value changes.
