# GDT544 — Verfügbarkeit gleich langer Ersatzstämme

Status: `ZERO_FLAGGED_TARGETS_HAVE_ALTERNATIVE_LONGEST_ANCHOR__23_UNUSED_BELONG_TO_20_CLEAN_TARGETS`

Die zwölf GDT543-Kontextunterschiede und sechs neuen Andockkanten betreffen
wegen zweier Überschneidungen sechzehn Zielkarten. Jede dieser Karten besitzt
genau einen längsten alten Rezeptstamm. Alle 23 unbenutzten gleich langen
Anker gehören zu zwanzig bereits unmarkierten Zielen; ein Umranken kann die
markierte Gruppe daher nicht verändern.
