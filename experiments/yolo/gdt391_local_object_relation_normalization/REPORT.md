## Conservative corrections

The pharmaceutical first-label “attachments” are generally editor/source
pairing assumptions. With no author-visible leader or singular owner, they
remain `MULTIPLE_OR_ALTERNATIVE_OBJECTS`; they were not converted into
container or plant ownership. The f89v1.23 description says the writing
*almost* runs into a leaf, so the hedged extracted contact/enclosure tags remain
ambiguous rather than becoming a singular positive. Array segmentation claims
on f70v2/f75v and tube-versus-figure alternatives on f82v/f83 likewise remain
ambiguous.

## Interpretation

Local text-object geometry can be normalized more successfully than the
direct inscription-to-inscription pointer route, but current support is
ecology-concentrated and lacks matched within-unit mobility. A formal feature
could appear associated merely because it distinguishes f68 star labels from
pharmaceutical or diagram text. The frozen matched design cannot separate that
from a reusable relation code.

No formal score was authorized or run. This result closes the current B02
application unless genuinely new complete units add singular relation and
proximity states on additional folios. The four eligible cases remain an
acquisition seed, not a test panel.

## Provenance and limits

This was a source-aware, single-AI exploratory review of pages already exposed
in earlier repository work. It is not a second human review. The validator
checks complete-frame coverage, opaque ID construction, comparator/eligibility
logic, access assertions, hashes, and the capacity decision; it does not
independently repeat the visual ownership judgments.

No OCR, automated image classification, CLIP/embedding retrieval, or captions
were used. No new f84 content was accessed.
