## Fixed question and actual scope

One group contains one to three ordered actions, each written by the same
nonempty prefix-free 1–3-character code throughout a paired account. Exactly
six partial actions operate on three fixed states. A complete paragraph starts
in A, contains L, has at most 24 atoms, and ends with OA in A. M's permission
changes B to C while satisfaction remains due; D's permission goes directly
from B to A. Both fit their own dictionary. See the unchanged
[preregistration](PREREGISTRATION.md) and [finite specification](src/SPEC.json).

The modern semantic projection is inspired by the owned Rule of Benedict 43
proposal. It is not a diplomatic transcription of that chapter or evidence
that the manuscript contains monastic rules. No old gloss, nominal q-prefix,
Latin sound value or GDT978 code is inherited. GDT930 and GDT949 already tried
other common word-family readings; their attachment/meaning limits remain.

RF1b has no supplied paragraph boundaries and is **not testable** here. The
strict literal/source-boundary check leaves 32 ZL and 529 IT units suitable

## The consequence that actually decides the model

A positive result required a common dictionary for a complete permission account
and a complete no-permission account on different physical leaves. This was
checked for every saved dictionary, not only each paragraph's first fit.

| Model | All cross-class comparisons | Same-leaf pairs (ineligible) | Different-leaf pairs | Compatible different-leaf pairs |

Every different-leaf pairing already disagrees on the code for **L**. In M,
648 also disagree on S, 658 on OA and 261 on OB; causes overlap and are not
independent failures. All D cross-leaf pairs additionally disagree on OA.
[PAIR_CONTRADICTIONS.tsv](artifacts/PAIR_CONTRADICTIONS.tsv) retains all 840
comparisons, including the same-leaf exclusions, every shared-atom disagreement
and prefix conflict. The empty PAIRS.json.gz records the actual joint result.

This is a failure of the full stipulated conjunction: fixed actions, global
code, writing bounds, literal paragraph scope and cross-leaf contrast. More
local M fits than D fits is not evidence for outstanding institutional debt.
A generic procedural interpretation of M's identical transition table also
remains meaning-equivalent; no physical actor, permission or satisfaction has
been independently identified.
