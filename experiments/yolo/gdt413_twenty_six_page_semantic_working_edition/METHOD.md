# GDT413 method

## Question

Can the completed nineteen-core dictionary be propagated through the entire
current 26-page edition without an unmapped component, a local-label overread,
or a page-specific core retuning?

## Inputs

GDT407's unified 5,269-group, 4,576-event, 715-statement, and 26-page editions;
GDT405's forty-six component inventory; and GDT412's final nineteen-core
working dictionary.

## Method

Override only the nineteen portable core meanings in the forty-six-component
dictionary. Render every running recipe mechanically. Preserve every source
surface, recipe, order, owner, statement boundary, end mode, local group, and
admission status. Render the 693 non-running groups only as local
address/identifier copying, never as lexical content. Rebuild statement action,
argument, relation, order, and grade inventories from the final component map.

## Decision rule and claim ceiling

The edition must contain exactly 26 pages, 5,269 visible groups, 4,576 running
events, 693 local groups, and 715 statements; all recipe atoms must have a
nonempty value. The nineteen values are portable defaults, while concrete
nouns and techniques remain owner-local. This is a coherent working
translation layer, not confirmed plaintext.
