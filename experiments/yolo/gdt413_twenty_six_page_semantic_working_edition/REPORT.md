# GDT413 – Eine einzige aktuelle 26-Seiten-Ausgabe

## Ergebnis

Die Bedeutungsarbeit ist jetzt in einer vollständigen, widerspruchsfreien
Arbeitsausgabe zusammengezogen:

- **26 Seiten**;
- **5.269 sichtbare Gruppen**;
- **4.576 laufende Ereignisse**;
- **693 lokale Adressen/Kennungen**;
- **715 Aussagen**;
- **46 Komponenten**, davon **19 portable Bedeutungskerne**.

Jede laufende Karte erhält eine konkrete kompositionelle Kernlesung. Keine
Adresse, Figurenkennung oder Kreisbezeichnung wird dafür zum erfundenen Wort:
die 693 lokalen Gruppen bleiben ausdrücklich **lokal kopieren**.

## Aktuelles Kernwörterbuch

| Kern | Default | Kern | Default |
|---|---|---|---|
| `Y` | POSTEN | `OK` | SETZEN |
| `OL` | FORTSETZEN | `OT` | DANACH |
| `AL` | ZIELORT | `AR` | AUSGANG |
| `AIIN` | WERT | `AIN` | ANTEIL |
| `OR` | EINHEIT | `L` | VERBINDUNG |
| `AIR` | BAHN | `CH` | NEHMEN |
| `SH` | HALTEN | `K` | GEBEN |
| `S` | WÄHLEN | `CHD` | BEARBEITEN |
| `T` | EINSTELLEN | `R` | MARKIEREN |
| `P` | EINSETZEN |  |  |

Die übrigen 27 Komponenten sind Grade, Schluss-/Ausführungssteuerung oder
lokale Klassenzeichen. Sie werden in der Komposition angezeigt, aber nicht mit
den neunzehn Inhaltskernen vermischt.

## Was diese Ausgabe besser macht

Frühere Lesungen streuten „Wasser“, „Öl“, „Sud“, „Klarlauf“, „Kühlen“ oder
bestimmte Körperanwendungen in einzelne Karten. Die aktuelle Fassung hält den
Kern bewusst klein:

- `AIR=BAHN`, lokal Wasserlauf oder Himmelsbahn;
- `OR=EINHEIT`, lokal Ansatz, Becken- oder Sektoreinheit;
- `AIIN=WERT`, lokal Maß, Dosis oder Positionswert;
- `CHD=BEARBEITEN`, lokal umsetzen, auftragen, abführen oder weiterführen;
- `AL/AR=ZIELORT/AUSGANG`, ohne eine unsichtbare Flussrichtung zu erfinden.

Damit kann die nächste Seite zuerst mit denselben Werten gelesen werden. Erst
ein echter Widerspruch darf einen Kern ändern; ein neuer Gegenstand erweitert
nur den Besitzerkontext.

## Dateien

Die kompakte Lesefassung steht in
`artifacts/TWENTY_SIX_PAGE_WORKING_READING.md`. Die drei vollständigen Ebenen
— Gruppe, Ereignis und Aussage — liegen daneben als TSV und sind deterministisch
reproduzierbar.

## Grenze

Die Ausgabe ist unser bestes ausführbares Bedeutungsmodell, nicht entschlüsselter
Klartext. Die deutschen Wörter sind breite Arbeitswerte. Das lokale Sachwissen
bleibt weiterhin im Bild, in der Rubrik oder im Werkstattexemplar.
