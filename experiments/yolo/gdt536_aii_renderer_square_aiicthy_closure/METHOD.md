# GDT536 method

## Question

Can the last unresolved current surface, `aiicthy`, be composed from a bounded
old renderer family for `aii` and the exact old card `cthy`, without declaring
every short `aii` or terminal-`n` form equivalent?

## Inputs

- GDT407 old 26-page running edition: 4,576 events / 1,558 surface types;
- GDT516 current four-page contextual event edition: 597 events;
- GDT529's fixed twelve candidates for `aiicthy`;
- GDT535's 159-surface working edition.

Both `f84` and `f84r` remain forbidden. No new page is used.

## Procedure

1. Group the old running events by exact surface and exact recipe.
2. Build the four-cell cross of leading `s` present/absent and terminal `n`
   present/absent for `aiin`, `saiin`, `saii`, and missing `aii`.
3. Infer a missing cell only if the three observed cells are recipe-invariant,
   `aiin→saiin` adds `S`, and `saiin→saii` leaves the recipe unchanged.
4. Enumerate every exact old terminal-`n` neighbour and every exact `X/sX`
   pair as controls; do not generalize either operation beyond the selected
   family.
5. Require the remainder of the target to be the invariant old exact card
   `cthy=CH+T+Y`.
6. Compare all twelve already generated GDT529 candidates. Select a recipe only
   if exactly one matches both the inferred left card and exact right card.
7. Change only the target row in the inherited 159-surface edition.

## Pass conditions

- the three observed square corners are exact and invariant;
- `saiin/saii` is a same-recipe terminal-`n` pair;
- `aiin/saiin` is a literal `S`-prefix pair;
- `cthy=CH+T+Y` remains invariant over thirteen old events;
- exactly one of twelve target candidates matches both blocks;
- no other recipe changes and no unresolved surface remains;
- a second execution is byte-identical and the independent validator passes.

## Interpretation

The missing corner is a working renderer card inside one named analogue family.
It does not assert a universal spelling rule or a confirmed word boundary.
