# GDT574 method

## Question

Which repeated actions in the complete GDT573 edition are genuine adjacent
double slots that can be rendered with `zweimal`, and can this be done without
collapsing interrupted action order or losing either written slot?

## Inputs

- GDT573's complete event, statement and page editions;
- GDT568's twenty owner action frames;
- GDT500's fifteen reversible `zweimal` precedent cards.

No new page, transcription, recipe, atom, action root or root value is added.

## Method

1. Extract the nine action roots from every final context recipe. Inventory
   every event in which an action root occurs at least twice.
2. Distinguish exact raw-recipe adjacency from action repetition separated by
   another written atom or action. Only an identical adjacent pair is eligible
   for count voice. Interrupted ABA/ABCA order remains explicit.
3. Reuse GDT568's owner frames and GDT500's count precedent to compile five
   small forms: `entnimm X zweimal`, `nimm X zweimal`, celestial `nimm X
   zweimal auf`, objectless `nimm zweimal`, and Herbal `setze X im Arbeitsgang
   zweimal an`.
4. Preserve seven already compressed clauses. Transform the remaining exact
   pair fragments, store source and target spans, and retain a two-action-slot
   expansion for every eligible event.
5. Rebuild all events, statements and pages. Require the target to reproduce
   every GDT573 source clause exactly through its backchannel.

## Decision rule and claim ceiling

Pass only if the complete inventory contains 105 repeated-action events, 43
raw-adjacent identical pairs and 62 interrupted/nonadjacent repeats; all 43
adjacent pairs use one of five cards and retain two written action slots; the
62 interrupted events stay byte-identical; 36 new changes plus seven retained
forms yield exactly 43 `zweimal` occurrences; all 5,122 GDT573 clauses
roundtrip exactly; and generation is deterministic. Count voice is German
editorial realization, not a Voynich numeral, lexeme, plaintext clause,
language identification or historical codebook claim.
