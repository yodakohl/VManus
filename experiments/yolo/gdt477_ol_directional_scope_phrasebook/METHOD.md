# GDT477 method

## Question

Can all 28 admitted local occurrences of `OL=FORTSETZEN` be rendered through
one positional scope rule—forward opening, left-to-right bridge or backward
hold—while preserving GDT476's complete defaults and the literal order of every
function and learned name?

## Inputs

- GDT474's 183 event-level literal function/name traces and three grammatical
  readings;
- GDT475's 69 OT/OL occurrence positions and 146 bundle boundaries;
- GDT476's 64 contextual tie decisions;
- GDT460's calibrated left and right `ol` edge channels as already available
  running-text support.

The input contains only f71v, f72r, f77r, f88v and f89r for OL. No new page or
source transcription is opened.

## Method

1. Select exactly the 28 GDT475 OL occurrence rows.
2. Join each to its unchanged GDT474 literal trace. The number and order of
   `FORTSETZEN` tokens must equal the number and order of OL recipe atoms.
3. Mark one OL token at a time and inspect its complete function/name token
   context:
   - first token: `FORWARD_OPEN`, `OL · X = weiter mit X`;
   - medial token: `BRIDGE_LEFT_TO_RIGHT`,
     `X · OL · Y = X in Y weiterführen`;
   - final token: `BACKWARD_HOLD`, `X · OL = X weiterführen`.
4. Separately mark whether OL lies before, after, between or outside learned
   names. Name placement never changes the root value.
5. Carry the GDT476 selected model when available, otherwise the unchanged
   GDT474 selected model, and print its complete event reading beside the new
   local OL-scope phrase.
6. Collapse the 28 slots to 26 events, three rules and five page summaries.

The “literal position” is position in GDT474's full function/name working
trace, not a claim that every ignored renderer character is a morpheme or that
the OL letters occupy the same raw character offset. Actual left and right
surface channels are kept separately through GDT460.

## Decision rule and claim ceiling

The phrasebook succeeds if all 28 occurrences receive exactly one directional
default, all nine forward openings are event-opening, all sixteen event-internal
occurrences are bridge/backward forms, both double-OL events retain two distinct
slots, and no source reading, root, name, surface, recipe, model or page changes.

This is a compositional German working renderer. It establishes no plaintext,
language, confirmed syntax, historical abbreviation system, object identity or
confirmed lexeme.
