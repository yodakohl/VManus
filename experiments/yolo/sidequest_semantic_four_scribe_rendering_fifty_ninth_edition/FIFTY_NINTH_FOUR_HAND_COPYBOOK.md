# Vier Hände, dieselbe Werkstattanweisung

Jede Hand darf nur eine andere registrierte Oberfläche derselben Karte wählen.
Kartenfolge, Grad, Richtung, Referent und Schluss bleiben unangetastet.

## H1-S001

- S1_BARE_MASTER: `dchey cthoor char chty os kair otytchol oky daiin etyd`
- S2_Q_CELL_SCRIBE: `dchey cthoor sar chety os chair otytchol qokchy aiin etyd`
- S3_S_LINE_SCRIBE: `dchey cthoor sar chty os schedair otytchol qokchy saiin etyd`
- S4_MIXED_COMPACT: `dchey cthoor dar chety os kair otytchol okchy aiin etyd`

## H3-S001

- S1_BARE_MASTER: `tshol schoal cfhy shfydaiin cphy cheey tchody`
- S2_Q_CELL_SCRIBE: `tshol schoal cfhy shfydaiin cphy cheey tchody`
- S3_S_LINE_SCRIBE: `tshol schoal cfhy shfydaiin cphy shey tchody`
- S4_MIXED_COMPACT: `tshol schoal cfhy shfydaiin cphy shey tchody`

## B2-S012

- S1_BARE_MASTER: `lchy cheey qcthey okeey lcheey taiin chey qokeeedy`
- S2_Q_CELL_SCRIBE: `ly shey qcthey qokeey lcheey saiin sy qokeeedy`
- S3_S_LINE_SCRIBE: `lchy shey shecthy okeey lcheey saiin shy qokeeedy`
- S4_MIXED_COMPACT: `ly tshey qcthey okeey lcheey daiin dy qokeeedy`

## B4-S015

- S1_BARE_MASTER: `okain cheey chkain chckhal solkey lchedy`
- S2_Q_CELL_SCRIBE: `qokain shey kain chckhal solkey lochedy`
- S3_S_LINE_SCRIBE: `qokain shey chkain chckhal solkey lchedy`
- S4_MIXED_COMPACT: `okain tshey kain chckhal solkey lochedy`
