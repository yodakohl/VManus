# Pass 410 — bereit ist ein Tor, absetzen ist eine Handlung

```text
SOLLSTELLUNG → CTH/BEREIT → ARBEITEN/ÜBERGEBEN → SHED/ABSETZEN → SCHLUSS
```

CTH sagt: Der Posten darf in die nächste Handlung. Es kann am Anfang einer
Arbeitsphase stehen oder das Ergebnis der vorigen Vorbereitung freigeben.

SHED sagt: Lass den Posten stehen oder sich absetzen. Mit einer lizenzierten
Endkarte schließt es gewöhnlich den örtlichen Schritt. Mit AL bildet es dagegen
die nichtterminale Absetzstelle, an der später weitergearbeitet wird.

Beispiele:

- H2: Pflanzenposten bereit → zerstoßen → pressen.
- H3: zweiten Ansatz einsetzen → bereit für den Gebrauch.
- B3-S034: Sollstufe → bereit → bearbeiten → Folgemaß → untere Stelle →
  kurz absetzen und schließen.
- B3-S021: Phase A bereit → Übergabe → Absetzstelle/temperieren → Phase B
  bereit → lokal schließen.

SHECTHY/temperiert bleibt eine eigene Ganzkarte. Sie darf nicht als SHED+CTH+Y
zerlegt werden.
