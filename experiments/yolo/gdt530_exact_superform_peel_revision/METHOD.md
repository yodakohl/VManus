# GDT530 method

## Question

Can an exact, slightly longer old form decide between the previous working
recipe `chekchy=CH+K+CH+Y` and GDT529's top candidate `CH+K+Y`?

## Inputs

- GDT407's 1,558 invariant old surface recipes and their event contexts;
- GDT522's old visible-edit/recipe-edit signature atlas;
- GDT529's complete 159-form working edition and current candidate ranks;
- GDT516's current event readings for inherited German defaults.

No page beyond the already admitted thirty is used.

## Peel construction

For every current surface, inspect its previous working recipe and its GDT529
top candidate. A route exists when:

1. an invariant old surface is exactly one visible character longer;
2. deleting that one character yields the current surface exactly;
3. the old recipe is exactly one atom longer than the candidate;
4. deleting that atom yields the candidate exactly; and
5. the visible character, atom, and their left/inner/right positions match an
   edit signature already present in GDT522.

This produces 25 distinct routes over 14 current surfaces. Twenty-four support
a recipe that was already both the working selection and rank one. One route
supports rank one against the previous working selection:

```text
ychekchy = Y+CH+K+Y
- initial y / initial Y
-----------------------
 chekchy =   CH+K+Y
```

The corresponding old left-edge signature `y/Y@LEFT/LEFT` occurs in 54 of 59
eligible old comparisons (`p=0.886178862`, reliability `0.964285714`). No
equivalent strong peel route supports `CH+K+CH+Y`. The resulting `CH+K+Y`
recipe also occurs independently in exact old `ckhy` twice.

## Working-selection rule

A peel may revise a working recipe only when it points to the existing GDT529
top candidate, has a strong old edit signature, has no equally strong route to
the previous working recipe, and the current target has no contrary exact old
recipe. Under this rule only `chekchy` changes.

This is a working-recipe update, not a new score term: the GDT529 candidate
ordering is left untouched. The accumulated 159-form working top-one count
rises `152→153`, and rank sum falls `174→173`.

## Why `chy` is not one fixed unit

Among 54 invariant old surface types ending in visible `chy`, 28 types (69
events) end in recipe `Y` without a preceding `CH`, while 26 types (34 events)
end in `CH+Y`. The seven current `...chy` forms likewise require both tails:
after the revision, `chekchy` uses `Y`, while six retain `CH+Y`. The peel
therefore resolves this particular composition without declaring global
`chy→Y` or `chy→CH+Y`.

## Working meaning

The selected component string keeps the existing defaults:

```text
CH = NEHMEN
K  = GEBEN
Y  = POSTEN
```

The compact workshop phrasing is “Nehmen, geben und posten.” It remains a
functional working reading, not a confirmed plaintext sentence or language
identification.
