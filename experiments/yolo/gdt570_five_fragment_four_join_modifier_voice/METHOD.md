# GDT570 method

## Question

Can all modifier wording and joining in the complete GDT569 state edition be
reduced to five small German fragment cards and four order-preserving join
rules, without learning any complete modifier sequence as a meaning?

## Inputs

- GDT569's complete event, statement, state and page editions;
- GDT565's exact modifier atoms and four-type sequence for every state card;
- GDT567's eighteen actually used register×relation voice cells.

No new page, transcription, atom or root value is introduced.

## Method

1. Reconstruct the current modifier phrase of every state card directly from
   its ordered GDT565 modifier atoms, GDT567 relation terms and the universal
   owner-voice place term. Confirm that the phrase occurs in the GDT569 clause.
2. Replace five remaining generic German fragments: `O` becomes `als
   Ausführung`, `IIN` becomes `auf der bezeichneten Stufe`, `CARRIER_Q`
   becomes `als neuen Einsatz`, `AN` becomes `in der bezeichneten Klasse`, and
   `LOCAL_CHAR_G` becomes `mit der lokalen Variante`. O and CARRIER_Q select
   the dominant 26-page owner voice while retaining the sixteen four-page
   alternate realizations in the audit; the other three controls are unanimous.
3. Collapse the four modifier types to three join classes: grade and formal
   control form one operational-modifier class, relations a second, and
   local/class signs a third. Coordinate each contiguous same-class run with
   commas and final `und`; retain a semicolon at every class boundary.
4. Preserve every modifier atom and its written order. Apply no sorting, no
   deletion and no cross-event movement. Reassemble all events, statements and
   pages while leaving every nonstate clause byte-identical.

## Decision rule and claim ceiling

Pass only if all 1,042 modifier-bearing state cards and all 224 adjacent type
transitions reconstruct, the sixteen possible type pairs map to exactly four
join cards, all 154 observed register×modifier cells are present, all 5,122
events and 793 statements replay in order, and deterministic generation is
exact. The pass may select a uniform German workshop voice. It changes no
Voynich atom, root value, recipe, surface, event, statement, page, historical
lexeme, plaintext, language or object identification.
