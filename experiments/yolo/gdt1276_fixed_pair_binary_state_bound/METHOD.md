## Contract and proof
For fixed ordered stems A,B and fixed construction/slot conventions, one initial
state z in a set of size K completely determines both endings. No other input,
random choice, unrecorded construction switch or changing stem identity is allowed.
Then the pair-output image of that function has size at most K. Deterministic
updates between words do not enlarge it: the full two-output trace is still a
function of the initial state and fixed stems. Therefore K=2 cannot emit3cells.
For the narrower shared binary-feature/bijective-class case, write each ending
as z XOR c_stem; their XOR is constant. Such a pair is always SAME or always
MIXED, even when stems use opposite classes. This is only a corollary.
The words may have other context, meanings, referents or homographs. If those
change output independently, they are additional input and outside the contract.
Allowing different constructions for the same adjacent pair is also outside;
adjacency alone never establishes a common linguistic construction (949).
Thus the bound is NOT an inferred count of grammatical cases or global states.
Three-state compatibility is not a successful writer or an instruction to fit one.
