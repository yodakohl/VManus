# GDT1170 — registered external-context duplication test

Decision note, before target intake. Known: exact adjacent repeats exist; GDT820 already shows repetition alone determines neither word class nor sentence boundary. GDT574 translates inherited action atoms rather than testing raw duplication. GDT803 examines l/m neighbors, not maximal repeated runs; GDT910 tests exact short/long substitutions. Unknown here: whether duplication is exchangeable among occurrences of the same exact word on the same physical leaf and in the same line-position third.

Reading decision: a reproducible conditional context signal would prevent treating all such repeats as context-neutral copying when developing readings. Failure to detect it leaves this narrow rival open; it licenses neither deletion nor a meaning. This is a structural prerequisite test, not a translation experiment. No whole-book meaning or general scribal-error claim follows.

Smallest test and budget: one guarded intake and fixed permutation calculation, inclusive 20 minutes for preparation, implementation, validation and local closure. No parameter expansion at the budget limit. No public push of an inconclusive checkpoint under the user's latest instruction.

All 179 existing admitted selectors are development/exposed material. No image or new page, no held confirmation, f84/f84r and f116v excluded. Three editions are sensitivity readings of one manuscript. The allowlist and exact source columns are fixed in SPEC.json. No legacy tool changes.

Retain complete prose loci and raw groups with definite spaces. Build maximal identical runs inside definite-space, lowercase-only segments. Require both external neighbors to be present and definitely separated, so edge runs and uncertain strings cannot become evidence. Keep only lengths 1 or 2; retain counts and locations of longer excluded runs. A singleton adjacent to an identical group across an uncertain separator is excluded by the same boundary rule. No cross-line joins, stripping annotations or decoding entities.

Stratum = exact target word x physical leaf (f-number, both faces combined) x third of the observed source-line midpoint of the run. Third = min(2,floor(3*(start_zero+(length-1)/2)/line_group_count)). Include only strata with both run lengths. Minimum capacity: 20 double runs over 10 physical leaves per edition, otherwise STOP that edition without relaxed bins.

Neighbor features: binary character bigrams of ^word$, normalized to unit length. For each stratum let z=y-mean(y), y=1 for double,0 for single. Compute norm(sum z_i*feature(neighbor_i)) squared / sum z_i squared, separately left and right, then sum over strata. This measures association with EXTERNAL neighbors only; no X-X transition enters. Obtain left, right and right-minus-left scores for observed labels and 1999 within-stratum permutations of run-length labels with fixed seed. Standardize by permutation mean and SD, then calibrate the maximum of these three standardized statistics jointly. Report raw scores and upper-tail null fractions including observed; these are exploratory diagnostics for this registered comparison, NOT search-wide significance after thousands of selections.

A conditional signal is retained only if capacity passes, the max-calibrated null fraction for the named statistic is <=.01 in IT2a and ZL3b with the same direction. RF1b is a disclosed sensitivity channel, not another witness. Otherwise NO_RETAINED_CONTEXT_SIGNAL; failure of capacity is distinct. Even a signal does not establish intentional repetition, grammar, clause boundaries, or a word. Leaf/word/position controls do not remove semantic topic or all local copying mechanisms. No independent confirmation capacity.

Dependencies: source segmentation, exact identity, definite-space annotations, position binning, finite word-form kernel, conditional exchangeability. No inherited glosses. No new diagram relation edge is scored. Preserve all observations and all excluded longer runs. No post-hoc examples become predictions.
