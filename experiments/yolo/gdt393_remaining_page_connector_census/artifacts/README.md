# GDT393 artifacts

- `gdt393_residual_page_frame.tsv`: pre-image residual page universe.
- `gdt393_pre_image_freeze.json`: selection, access, and capacity freeze.
- `gdt393_pre_image_freeze_validation.json`: independent freeze checks.

Image mappings, complete page observations, candidate edges, result, and final
validation were added only after the public pre-image freeze:

- `gdt393_image_manifest.tsv`: exact official review canvases and hashes.
- `gdt393_page_observations.tsv`: complete page judgments.
- `gdt393_ambiguous_candidates.tsv`: four retained ineligible geometries.
- `gdt393_eligible_edge_packet.tsv`: header-only zero-edge packet.
- `gdt393_capacity_gates.tsv`: inherited capacity results.
- `gdt393_access_log.json`: chronology and exposure disclosures.
- `gdt393_result.json`: compact decision artifact.
- `gdt393_validation.json`: independent accounting and hash checks.
