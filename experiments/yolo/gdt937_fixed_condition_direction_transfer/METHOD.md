# Method

Apply the preregistered manual PRE/K/M/A/B partitions and F/P roles from
src/MODEL.json to the unchanged GDT930 safe source, using only the inherited
GDT932/934/935/936 lexicons. No learned parser or word changes. Preserve every
source group, entity and separator. Retain all P1 context and bind the old full
corpus alignment. Count assignments and show all unresolved contents; do not use
coverage to select meanings. Source exposure precedes registration.

The validator independently reconstructs partition membership and scope counts,
compares every old alignment row to the source and fixed lexicons, and checks
full local coverage, complete P1 raw lines, claim limits and deterministic replay.
See PREREGISTRATION.md for decisions and limits, REPORT.md for the executed outcome.
