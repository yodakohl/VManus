# GDT543 — gerichtete Ausbauten gelernter Fragmentstämme

Status: `PASS_81_FRAGMENT_TARGETS_MAPPED__72_ALIGNED_STEMS__13_RECURRENT_CHANNELS`

GDT543 macht aus den 81 Fragment-plus-Atom-Formen ein ausführbares
Stamm-und-Ausbau-Deck. 72 Zieloberflächen enthalten eine alte sichtbare
Schreibform ihres vollständigen alten Rezeptfragments exakt an derselben
linken/rechten Stelle. Dreizehn wiederkehrende sichtbare Ausbaukanäle behalten
eine einzige Rezeptabbildung; nur rechtes `dy` bleibt zweideutig.

Das vollständige Deck steht in `artifacts/GDT543_FRAGMENT_EXTENSION_BOOK.md`.
