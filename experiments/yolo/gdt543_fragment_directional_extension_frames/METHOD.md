# GDT543 method

## Question

Can the 81 final fragment-plus-atom target recipes be represented as old
learned whole-recipe stems with directional left/right extensions, and which
visible affixes, atom interfaces, old supercards, and actual statement modes
support those extensions?

## Inputs

- GDT407's 4,576 old running events and 715 fixed statements;
- GDT540's 145 final prose-surface context contracts and German working
  readings;
- GDT542's recomputed 145-target support tiers.

No unadmitted page, alternate recipe, or fuzzy surface match is used.

## Method

1. Select the 81 targets in GDT542's
   `OLD_COMPLETE_RECIPE_FRAGMENT_PLUS_ATOMS` tier.
2. Enumerate every occurrence of every longest contiguous target fragment
   that is itself a complete old GDT407 recipe. This yields 104 anchor
   candidates.
3. For each candidate, search only exact old carrier surfaces inside the
   target surface. A match is direction-aligned when its visible left/right
   residues occur on the same sides as the recipe extensions.
4. Select one deterministic anchor per target by, in order: an aligned exact
   visible stem; complete old support for its atom interfaces; number of
   supported interfaces; old anchor event count; visible stem length; leftmost
   position; lexical recipe order. Preserve all alternatives in the candidate
   table.
5. Emit one left or right arm for every nonempty extension. Count its exact
   boundary pair in old complete cards and find the deepest boundary-adjacent
   part of the arm that occurs together with the anchor inside an old card.
6. Group exact visible residues by side and complete arm recipe. Repetition
   with one recipe is an invariant working channel; repetition with multiple
   recipes remains explicitly ambiguous.
7. Replay the full target recipe against the real state immediately before
   every old anchor carrier. Separately find every longer old complete recipe
   that contains the whole target recipe as an exact contiguous sequence and
   replay the reduced target in that event's prior state.
8. Keep the GDT540 neutral phrase and contextual reading on every card.

## Result conditions

- all 81 final recipes reconstruct exactly as left extension + old anchor +
  right extension;
- the 104-candidate and one-selected-anchor inventories replay independently;
- every surface stem is an exact substring carried by the named old recipe;
- all 93 interfaces, joint-extension depths, 53 visible channels and 19 old
  supercard reductions recompute from GDT407;
- context never crosses a statement boundary;
- an ambiguity or context difference is reported, not silently normalized.

## Decision rule and claim ceiling

Every composition remains a working default. Missing pair support, absence of
an exact visible stem, or a different old anchor context lowers the named
support route but does not reject the target. Exact surface containment is a
scribal-form bridge, not proof of phonetic morphology. The German readings are
the inherited experimental dictionary, not confirmed plaintext. No page,
recipe, segmentation, root meaning, object identity, language, or historical
codebook changes.
