# Pass 342 — Ergebnis-/Ablagelexikon

Die letzten vier Mikrogänge jedes Biological-Records erzeugen fünf kurze
Werkstattbezeichnungen: Behandlungsportion, Klarabzug, Sammelgut, Transfergut und
Anwendungsposten. B2 und B4 teilen Klarabzug, obwohl ihre Wege verschieden sind;
alle anderen Klassen gehören je einem Record.

Vier Records legen auf einem Anwendungssims, zwei auf einem Arbeitssims ab. Das
Ergebniswort ist keine zusätzliche Voynich-Übersetzung, sondern die konkrete
Lehrlingsbezeichnung für den durch die letzte Kartenfolge erzeugten Posten.

Als nächstes werden diese fünf Ergebnisarten an die fünf Herbal-Eingangsarten
gespiegelt. Gesucht wird ein kleiner Kreislauf von Stoffrollen — Rohteil, Ansatz,
Klarauszug, Portion, Anwendungsposten — der die elf Laufkarten ohne neue
Kartenglossa verbindet.
