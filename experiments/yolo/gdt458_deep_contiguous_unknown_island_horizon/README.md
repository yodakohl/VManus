# GDT458 — tiefer Horizont zusammenhängender neuer Karten

Auf denselben 13 Aussagen und denselben Startpositionen wachsen sichtbare,
ergebnisblind gewählte Ersatzinseln von einer bis 32 Karten. Jeder Längengrad
wird als vollständiger 4.576er Strom gelesen.

```bash
python3 experiments/yolo/gdt458_deep_contiguous_unknown_island_horizon/src/run.py
python3 experiments/yolo/gdt458_deep_contiguous_unknown_island_horizon/src/validate.py
```

Ergebnis: Jede vorhandene erste unveränderte Folgekarte liest, alle 416 Inseln
erreichen wieder den Referenzzustand und kein Stopp springt aus der Insel heraus.
Das ist ein Quarantäne-/Wiedereinstiegsbefund, keine Übersetzung der Ersatzkarten.
