## Selected architecture

The four leading terminal families are anonymous entries in a local
Biological controlled-value deck:

```text
OPEN CELL      := optional local qualifier/card sequence
COMMITTED CELL := optional local qualifier/card sequence
                  + EXACT OPAQUE VALUE CARD
                  + COMMIT(DY)

ONE-CARD CELL  := inherited slot/question + EXACT OPAQUE VALUE CARD
                  + COMMIT(DY)
```

This is a local functional interpretation, not a license to decompose all
GDT327 tuples. All 38 events share the exact closure coordinate and
`DY=1, B3=0`, while their stable host-side payloads remain distinct. The common
punctuation-like information is therefore already carried by `DY`; collapsing
the complete cards into four punctuation variants would discard their
recurrent identity.

## What changed

- Terminal-only fields are no longer treated as empty punctuation. They carry
  a complete exact categorical payload under an inherited slot.
- The terminal layer is one of the densest content candidates in Biological B:
  exact value identity lives in the card; closure lives in `DY`.
- Binary YES/NO is rejected. The local deck has many more than two values.
- A rigid four-column form is rejected. Value identities are mobile across
  field ordinals and stencils.
- `f55v` contains committed short fields but none of these four leading value
  cards. The closure mechanism crosses the Herbal/Biological bridge; the value
  deck is register-local.

## Strongest rival and falsifiers

The strongest rival interprets the four identities as taught graphic cadence
models in a workshop repertory. It predicts that family choice will track
wrapper/ductus and copied graphic models better than inherited practical slots.
This rival is serious because wrapper locking is strong and external slot
ownership is absent.

The selected value model should be withdrawn if a larger fixed sample shows
that exact terminal identities are exchangeable after field length, wrapper,
position and page/register are controlled, or if cadence/model copying predicts
them better than record ecology. A lexical action/result model would overtake
it if an independently owned parallel maps one family consistently to an
operation or outcome.
