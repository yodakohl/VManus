## Fixed material

Use only the GDT791 thirty-page occurrence spine and the already published
special-circle text-blind inventory. Exact-locus intersection defines the
admitted panel. No new page or image is inspected, and no mixed transcription
source is queried.

## Fixed units

- Primary lexical unit: the complete local label string at one circle locus,
  with multiple GDT791 cells joined by one space in their existing order.
- Repeated-form atlas: every complete string occurring at least twice.
- Transfer unit: one occurrence of a string present on at least two physical
  folios.
- Formal sensitivity family: literal complete strings beginning `okal`; this
  is not a segmentation or morpheme claim.

target against the available positions in its own array. Joint transfer needs
at least eight targets, four strings, mean opportunity rank <=0.35 and >=60%
closest-quartile targets.

axis-class diagnostic. It cannot count as a Kluge/calendar success.

only when their Kluge-A values agree; missing Kluge values remain missing.
Build the true Kluge-09A comparison from all admitted rows, not from the raw
slot-4 subset.

## Concrete-candidate rule

A complete string may receive a C0 visible-coordinate candidate when it has:

- occurrences on at least two physical folios;
- a clock value for every such occurrence;
- a smallest covering clock arc <=0.75 hours;
- no two same-array occurrences at different slots.

The German display must say that it is a visible time/degree-position rival,
not an established clock word. Every other repeated form still receives a
nonempty default class or local-entry interpretation and explicit evidence and
counterevidence.

Audit the current V99R7 entries for all fifteen repeated complete labels. A
celestial standalone label does not prove a new meaning, but it does block an
unqualified universal pharmaceutical renderer. Circular multi-token labels
render once as label sequences; their component tokens do not compose a recipe
inside this context.
