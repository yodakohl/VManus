# GDT794 method — complete-label multiform circle transfer

## Question

Do several repeated **complete local label strings** predict the same visible
circle coordinate on other released physical folios, and does the earlier
`okal*` outer-`slot_index=4` observation survive when the diagrams are aligned
by a genuine catalogue homolog rather than by source-row order?

## Inputs and scope

- the GDT791 occurrence spine for the thirty released, visually reviewed
  pages;
- the published 45-array filler-blind special-circle inventory;
- GDT793 only as the predecessor claim being discriminated.

No new page, image, transcription or mixed alternate-reader table is opened.
The executable join retains a circle slot only when its exact locus already
has one or more `LOCAL_ADDRESS_OR_LABEL` cells in GDT791. Multiple cells at one
locus are concatenated in source order and treated as one complete label
string. A string such as `okeey ary` is therefore one two-token label here; it
does not license either token as a component meaning.

## Coordinates

Three deliberately separate coordinates are recorded:

1. `source_slot_fraction=(slot_index-1)/slot_count`, which measures catalogue
   or transcription order inside an array;
2. the first literal clock position in the human local comment, converted to
   a twelve-hour circle;
3. `Kluge NN A`, where the existing human comment supplies it, converted to a
   thirty-member circular coordinate.

The first coordinate is not called a day, degree or homolog. Clock angle is a
visible location, not necessarily authorial time. Kluge-A is the only supplied
cross-chart member homolog and is kept distinct from both.

An additional exploratory fourth diagnostic folds visible clock angle modulo
six hours. It asks whether the same complete inscription denotes an undirected
diameter/opposition class. It was added because several repeated inscriptions
fall close to opposite ends of a diameter; it is reported separately and does
not retroactively become a calendar result.

## Complete-label transfer

For every complete label occurring at least twice, report its arrays, physical
folios, clock positions, Kluge-A positions, within-array collisions, running
prose occurrences and circular spans. The cross-folio transfer panel retains
only targets whose same complete string occurs on at least one other physical
folio.

For each held physical-folio target and each coordinate:

- learn the circular mean from that string's occurrences on the other folios
  for clock/Kluge coordinates, but an ordinary mean for source order;
- measure circular distance for clock/Kluge and linear distance for source
  order;
- rank that distance against every coordinate-bearing slot in the target's
  own array.

This is a leave-one-physical-folio-out diagnostic. It cannot manufacture a
coordinate from a singleton, and an occurrence on the held folio never trains
its own prediction. A coordinate model counts as joint transfer only with at
least eight target events, four complete strings, mean within-array rank at or
below 0.35, and at least 60% of events in their array's closest quartile.

Source order is never silently turned into physical phase: f68r1 includes a
centre label and is not ordered around the circumference, while f72r2's five
outside labels cover only a partial upper arc. Its score is therefore an
editorial-rank diagnostic, not a cyclic calendar coordinate.

## Genuine Kluge homolog correction

The earlier five-row outer-`slot_index=4` series is rebuilt verbatim, but every
row now exposes clock angle and Kluge-A. Rows with the same raw slot number but
different Kluge-A values are not homologs. A separate Kluge-A grid lists all
admitted labels at each true catalogue member. Literal `okal*` concentration
at Kluge 09A is reported as a replaceable family association only; it gives no
meaning to `ok`, `al` or a suffix.

## Candidate meanings

Each repeated complete label receives a nonempty default candidate and explicit
counterevidence. Concrete coordinate candidates are allowed at C0 when a
complete string repeats across physical folios inside a narrow visible arc.
They remain owner-conditioned working hypotheses, not plaintext. Labels that
collide at remote positions instead receive a learned-entry/class default,
not an invented process instruction.

All fifteen repeated complete inscriptions are also looked up in the current
V99R7 whole dictionary. A universal pharmaceutical
gloss that now has standalone celestial-label uses is marked cross-scope HOLD;
the old provenance is preserved. Finally, every admitted circular locus gets a
single sequence-level override so that a multi-token inscription is no longer
rendered as a fluent pharmaceutical mini-sentence token by token.

## Decision rule and claim ceiling

GDT794 may:

- correct raw-slot versus true-homolog wording;
- select or reject a multi-form positional codebook;
- retain a concrete, replaceable whole-form coordinate candidate for a small
  number of exact strings;
- refine the exact-whole `okal` working rival without exporting a substring.

It cannot confirm a calendar, zodiac, day, degree, planet, substance, action,
word, sound, language, cipher or plaintext translation. It cannot transfer a
candidate to unseen forms or pages.
