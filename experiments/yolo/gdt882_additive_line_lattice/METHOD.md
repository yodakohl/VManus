# GDT882: fixed additive whole-line invariant

Frozen discovery contract, 2026-09-09; target not yet queried.
Question: is there a nonzero fixed assignment of the observed literal source
characters into any abelian group such that every admitted complete prose line
has the same sum? This is an exact universal mechanism, not an error-tolerant,
position-dependent, stateful, nonlinear, or phonetic code claim.

Decision note: IP014/GDT800 refutes an exact within-word rest-to-terminal rule.
Here the entire written line determines an algebraic sum; old okalal/okalam
is not a counterexample without their line contexts. GDT800 supplies only a
weak line-boundary motivation. No manuscript evidence currently supports this
mechanism. Budget20min for preparation, implementation, data, validation and
publication; reassess at limit, no automatic modulus/segmentation rescue.
A unit-lattice result closes this exact class on the declared alphabet. A
surviving quotient motivates separate orthographic-origin analysis and a frozen
held test, never automatic coding or meaning identification. Missing source
capacity stops the test as missing data.

Use only odd physical leaves within the inherited179selector scope, selected
explicitly in SPEC. Query the mixed atlas only through query-tsv. Reuse GDT829's
query and complete-record integrity reader. A locus qualifies only if all three
editions have kindP, every raw group matches[a-z]+, internal separators are
DEFINITE_SPACE or UNCERTAIN_SMALL_SPACE, and the concatenated literal character
string is identical in all three readings. Spaces are not alphabet characters;
uncertain small spaces therefore do not alter the endpoint. Drawing gaps,
markup, entities and uncertain characters exclude the whole locus. Do not
normalize, split, clean or substitute source characters. The alphabet is the
sorted set actually observed in the eligible discovery lines, not hypothetical
unused letters. Its elements are transcription characters, not proved glyphs.

Order eligible loci by SHA256(SPEC.order_salt + ':' + locus), tie by locus;
reference is the first line. Form exact integer count differences n_l-n_0.
Incrementally compute the row lattice, retaining integer coefficients over
original difference rows. A unit lattice gives a certificate C D = I. Any
symbol-value homomorphism annihilating all differences must then be zero,
for every abelian group. Rational full rank alone is insufficient: full rank
with index greater than1 leaves torsion; lower rank leaves a free quotient.
Process all rows unless the unit lattice is reached. Report survivor basis,
rank and index where applicable. No threshold tuning or statistical score.

The complete eligible source records and exclusions are retained compactly;
certificate references only a small subset if possible. Independently verify
source strings, counts and exact integer certificate multiplication. Validate
synthetic unit, torsion, free and rational-full-rank-but-nonunit cases before
source analysis. Alternate readings are one manuscript, not three replications.
Even leaves remain unqueried in this experiment. Old exposure remains disclosed.
f84/f84r sealed. No images, new pages, ordered relation packet or meanings.
