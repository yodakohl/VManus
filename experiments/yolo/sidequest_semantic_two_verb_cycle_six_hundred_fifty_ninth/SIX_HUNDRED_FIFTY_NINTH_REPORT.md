# Sidequest Pass 659: ANSETZEN und UMSETZEN als Arbeitszyklus

## Ergebnis

Die beiden produktiven Verben umfassen gemeinsam 43 exakte Kartentypen und
122 der 381 Prosaereignisse. Fünf Ereignisse enthalten beide Kerne in derselben
Karte. Achtzehn Aussagen verwenden sowohl OK als auch CHD.

Entscheidung:
`SET_AND_TRANSFER_FORM_A_BIDIRECTIONAL_RECONFIGURATION_CYCLE_NOT_FIXED_PRECEDENCE`.

## Keine feste Verbfolge

Unter den unmittelbar benachbarten Verbkarten stehen:

- 5× ANSETZEN → UMSETZEN;
- 6× UMSETZEN → ANSETZEN.

Auch über die ganzen 18 Aussagen ergibt sich keine starre Richtung. Vier
Aussagen bilden echte Dreierwechsel:

- `ANSETZEN → UMSETZEN → ANSETZEN` zweimal;
- `UMSETZEN → ANSETZEN → UMSETZEN` zweimal.

Die passende Werkstattlektüre ist daher ein Zyklus:

> konfigurieren/ansetzen → umsetzen/weiterleiten → neu konfigurieren → erneut
> umsetzen → schließen.

## Der Ein-Karten-Kurzweg

Fünf Aussagen verwenden nur eine verschmolzene Verbkarte:

> `OK+CHD+DY` = **ANSETZEN, UMSETZEN; SCHLUSS**

Alle fünf Karten stehen final. Die Werkstatt kann damit einen ganzen kurzen
Arbeitsgang in einer gelernten Karte buchen.

## Drei besonders lesbare Quellketten

- `chedchy qokal olchedy`:
  **Posten umsetzen → an der Zielstelle ansetzen → weiter umsetzen; Schluss**.
- `qokaiin chedy qokeedy`:
  **nach Sollmaß ansetzen → Posten umsetzen → lange ansetzen; Schluss**.
- `qoky saiin schedair otchedy`:
  **Posten ansetzen → Sollmaß → Laufflüssigkeit umsetzen → danach umsetzen;
  Schluss**.

Diese Folgen lesen sich als technische Mikroprozesse, ohne dass für jede Karte
ein eigenes langes Wort erfunden werden muss.

## Sechs Lehrzustände

Der praktische Automat unterscheidet READY, CONFIGURED, TRANSFERRED_ACTIVE,
RECONFIGURED und CLOSED. SET führt in eine Konfiguration, TRANSFER bewegt den
aktiven Posten, ein weiteres SET konfiguriert neu, und eine lizenzierte
Schlussvariante beendet den Gang. Der verschmolzene Kurzweg führt direkt nach
CLOSED.

## Nächster Schritt

Alle 18 gemeinsamen Aussagen werden nun in flüssiges Werkstattdeutsch
übertragen. Jede sichtbare Karte bleibt in Reihenfolge erhalten, aber die
zusammengesetzten OK/CHD-Formen werden als kurze Verben realisiert. Danach
werden die überzeugendsten vollständigen Prozessketten ins aktuelle
Übersetzungsbuch übernommen.
