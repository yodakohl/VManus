# GDT1094 method

## Question

Can one of three historically fixed Plantago treatment packages support a
coherent whole f25v reading under known formal constraints?

## Inputs

See PREREGISTRATION.md and src/PACKAGES.json. Root queried the complete already
admitted f25v through selector-first query-tsv; src/TARGET_RAW.tsv is the safe
projection. WORD_PROFILES.json is produced by the existing guarded words tool
over the unchanged179-selector contract. No mixed raw corpus is read by this
experiment runner. Profiles are exposed descriptive context, not confirmation.

## Method

Read all seven lines in all three readings. Inventory exact forms and all
positions. Import GDT1051's pure replay functions without invoking its main:
unchanged GDT012/062 wrapper-host and GDT605 merge transforms apply to every
saved group; uncertain small spaces retain GDT1051's hard-chunk treatment.
Leave marked source groups unresolved. Retain source packages separately from
target assignments: no complete lexical/argument assignment was obtained.

Reproduce with:
```
python3 experiments/yolo/gdt1094_f25v_source_package_whole_reading/src/run.py
python3 experiments/yolo/gdt1094_f25v_source_package_whole_reading/src/validate.py
```

The same-author validator checks exact replay and table coverage; it is not
an independent semantic evaluation. All raw instances and reader differences
are retained. No fitting, null search, decoder, or source-rule modification.

## Decision rule and claim ceiling

Exploration stops without a selected package because a coherent full target
reading was not constructed. Do not call this an empirical package rejection
or an exhaustive search over possible readings. Confirmed words0; fixed
semantic tests0; independent meaning capacity0. The source-only packet was
fixed before root's current target selection, but the image, plant suggestion
and underlying target corpus were historically exposed.
