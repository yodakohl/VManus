# Method

## Question

Do the 23 named GDT548 defaults still contain any surface that lacks an exact
visible component route, and which context/interface cautions gain an exact
peer elsewhere in the already admitted current prose deck?

## Visible cover

For each fixed surface/recipe pair, enumerate monotone paths through the
`FULL_OLD26` GDT519 alias lexicon. A path is accepted only when its aliases
concatenate to the complete surface and its mapped atom sequences concatenate
to the complete recipe. Retain all paths. Select the most compressed route,
then lower alias penalty and greater support, for display only.

The three surfaces with no complete old-deck path use already bounded routes:

- GDT546's `aii` extension plus exact old `cthy` stem;
- GDT547's S-prefix-conditioned `aiis` channel;
- GDT546's exact old `okaiir` stem plus recurrent `sh` extension.

No substring is assigned a new recipe in this pass.

## Context peers

The nine fragment cards marked `ANCHOR_CONTEXT_MODE_DIFFERENCE` keep their
GDT546 primary anchor. Search the 546 GDT539 current prose events for another
surface containing the same contiguous anchor recipe in one of the target's
observed requirement modes. Requirement mode is reconstructed from the stored
same-statement inherited action and argument fields. The target surface itself
is excluded.

## Interface peers

Take the five zero-old-count GDT546 interfaces and `SH>S` from `shso`. Search
the same 546 current events for the exact adjacent pair and exclude the target
surface when counting peers.

A card leaves the default queue only if every one of its original named
context/interface dimensions has a peer. Full-tile cards retain their distinct
higher-order sequence caution. All meanings and visible routes remain present
whether or not a peer is found.

## Validation

The validator independently replays all 96 alias paths, alias membership,
surface and recipe reconstruction, the three bounded routes, all current
context/interface queries, the four promotions, the 10/4/5 residual partition
and deterministic regeneration.
