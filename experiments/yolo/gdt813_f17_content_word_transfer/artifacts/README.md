# Compact reproducibility artifacts

CONTEXTS.tsv contains all f17r loci and all exact target-containing loci in
any reader within the declared 39-selector scope. It is not a complete
external-paragraph reader. LITERAL_TRIALS.tsv has two token-conserving trial
displays for each of three readings, including blank readings and unknowns.
RESULT.json records guarded provenance, counts and the zero-meaning ceiling.
VALIDATION.json records independent reconstruction and software negative checks.
EDGE_GATE.json records the explicitly non-score-ready label/prose comparison.
