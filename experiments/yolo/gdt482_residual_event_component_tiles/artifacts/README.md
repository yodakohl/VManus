# GDT482 artifacts

- `GDT482_RESIDUAL_EVENT_COMPONENT_TILES.md`: readable edition of all 45
  residual-event tilings.
- `gdt482_183_event_component_sequences.tsv`: normalized ordered component
  sequences for the complete 183-event donor pool.
- `gdt482_model_conditioned_component_fragment_atlas.tsv`: all one- to
  three-component spans keyed by active model.
- `gdt482_model_free_component_fragment_atlas.tsv`: the same spans with model
  removed for marked backoff use.
- `gdt482_45_residual_event_internal_tiles.tsv`: one same-model and one
  model-free tiling summary for each residual event.
- `gdt482_residual_tile_segments.tsv`: every selected tile segment and its
  donor events.
- `gdt482_residual_tile_summary.tsv`: compact class counts.
- `gdt482_result.json`: machine-readable result.
- `gdt482_validation.json`: 95-check validation report.
