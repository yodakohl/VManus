# GDT793 — `okal` whole-record candidate discriminator

This experiment asks whether the complete form `okal` is better rendered as a
page-local address, unique member/name, number/grade, upper-zone marker, or a
class/slot/system-entry code.

Run:

```bash
./vmanus-exp run experiments/yolo/gdt793_okal_whole_record_candidate_discriminator
./vmanus-exp validate experiments/yolo/gdt793_okal_whole_record_candidate_discriminator
```

The authoritative result is in `REPORT.md`; machine-readable tables are under
`artifacts/`.
