# GDT558 method — grade carrier envelope grammar

## Question

When `E/EE/EEE` occurs in an OT/OL state card, is the grade a value carried
inside the visible OT/OL/DY control block, or does it change operator scope or
attach freely to an action inherited from before that control boundary?

## Inputs

- GDT557's complete 1,870-row state-marker occurrence atlas;
- GDT416's 4,576 old running clauses, solely for their explicit/inherited
  action-state fields;
- GDT539's 546 current contextual events for the same fields on the current
  four pages;
- GDT420's nine single-action grade licenses;
- GDT421's 81 ordered-action-pair grade licenses.

These are cached artifacts on already admitted pages. No transcription, image
or new page is opened.

## Method

1. Collapse GDT557's occurrence rows to 1,656 exact marker-bearing events and
   verify that every duplicated event field agrees.
2. Select every event containing OT or OL and at least one exact grade atom.
   This yields 326 cards and 333 grade occurrences.
3. For each grade, stop at the nearest state control on its left and right.
   Replace the grade by `G` and name the resulting envelope, for example
   `OT>G<DY` or `START>G<OL`.
4. If an action chain is visibly left of the grade inside that envelope, use
   the single head or final ordered pair as its host and check its existing
   GDT420/GDT421 grade license.
5. If no action is visible inside the same envelope, render a short
   `Träger auf Grad I/II/III` value. Record the prior inherited action but do
   not force attachment across OT, OL or DY. Count which such forced readings
   would contradict the existing head cards.
6. Project every card onto state+grade atoms to obtain a complete template
   inventory. Separately replace its sole grade by `G` and collect every
   normalized recipe observed at two or three rungs.
7. Render every occurrence, every projection and every multi-rung family; then
   rebuild the counts and all artifacts independently.

The eight default formulas are:

```text
OT>G<END     danach X auf Grad n
START>G<OL   X auf Grad n; X weiterführen
OT>G<DY      danach X auf Grad n; X abschließen
OL>G<DY      X weiterführen auf Grad n; X abschließen
OL>G<END     X weiterführen auf Grad n
OT>G<OL      danach X auf Grad n; X weiterführen
OL>G<OL      X weiterführen auf Grad n; weiter aktiv halten
START>G<DY   X auf Grad n; X abschließen
```

## Decision rule and claim ceiling

Adopt the envelope reader if every grade occurrence is covered, every visible
same-envelope action host has an existing grade license, and rung substitution
inside recurrent normalized recipes preserves the control envelope. A prior
inherited action may be displayed as context but is not made the grade host
across a state control.

This is a creative working scope grammar for existing components. It changes
no grade value, root, recipe, surface, action state, statement boundary or page
and establishes no plaintext, language, historical syntax, codebook identity
or object.
