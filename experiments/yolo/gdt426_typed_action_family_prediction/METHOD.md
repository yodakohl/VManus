# Method

## Inputs

- GDT416's complete component recipes;
- GDT425's 5,051 focus-edge replay and nine local action cards.

No new page, image, transcription, root, or meaning is used.

## Fixed working families

The current German workshop values supply four coarse action families:

- `SELECT`: CH, S;
- `MOVE_SET`: K, OK, P;
- `HOLD_PROCESS`: SH, CHD;
- `CONTROL`: T, R.

The existing focus inventory supplies `GRADE` (E/EE/EEE), `ITEM`
(Y/AIIN/AIN/OR), and `RELATION` (AL/AR/L/AIR). These are sidequest teaching
classes, not claimed historical parts of speech.

## Prediction ladder

For each local pair, first search the same exact ordered pair on another page
with intervening slots, then the same action-class transition. For each local
focus edge, search a same-head family rectangle, then a same-action-class exact
focus. Keep all successful results amber rather than promoting them to exact
portable cards.

## Claim ceiling

This supplies a compact prediction mechanism for the working deck. It does not
confirm the classes, German values, plaintext, language, or source, and it does
not reopen scientific latent-class routes.
