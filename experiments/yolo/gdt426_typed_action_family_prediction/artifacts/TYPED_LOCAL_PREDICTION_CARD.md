# Gelbe Vorhersagekarte für lokale Handlungsformen

Vier Handlungsklassen: SELECT, MOVE_SET, HOLD_PROCESS, CONTROL.
Drei Fokusfamilien: GRADE, ITEM, RELATION.

- `FOCUS:R<-AIR` → `CONTROL<-RELATION` → AMBER_HEAD_FOCUS_FAMILY_RECTANGLE
- `FOCUS:R<-EE` → `CONTROL<-GRADE` → AMBER_ACTION_CLASS_FOCUS_FAMILY
- `FOCUS:S<-EEE` → `SELECT<-GRADE` → AMBER_HEAD_FOCUS_FAMILY_RECTANGLE
- `PAIR:CH>OK` → `SELECT>MOVE_SET` → AMBER_ACTION_CLASS_TRANSITION
- `PAIR:CHD>S` → `HOLD_PROCESS>SELECT` → AMBER_ACTION_CLASS_TRANSITION
- `PAIR:K>OK` → `MOVE_SET>MOVE_SET` → AMBER_ACTION_CLASS_TRANSITION
- `PAIR:OK>S` → `MOVE_SET>SELECT` → AMBER_EXACT_ORDERED_PAIR_WITH_INTERVENING_SLOTS
- `PAIR:R>T` → `CONTROL>CONTROL` → AMBER_ACTION_CLASS_TRANSITION
- `PAIR:SH>T` → `HOLD_PROCESS>CONTROL` → AMBER_EXACT_ORDERED_PAIR_WITH_INTERVENING_SLOTS

Diese neun Formen sind damit typisiert vorhersagbar, bleiben aber gelb.
Eine neue Seite darf ihre genaue Karte bestätigen; sie darf die Klassen nicht nachträglich verändern.
