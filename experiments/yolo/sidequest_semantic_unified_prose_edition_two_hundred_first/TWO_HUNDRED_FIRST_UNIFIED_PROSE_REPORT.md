# Two-hundred-first pass: one current prose edition

## Unified release

The four normalized sub-editions now form one continuous current prose reader:

- 381 visible events;
- 380 logical source tokens after the one line-edge read-once correction;
- 135 fields;
- 116 translated statements;
- eleven records on seven fixed prose pages;
- 173 exact cards with 230 unambiguous registered surfaces.

Every event has a visible form, normalized master form, exact card, short value,
field mode, owner and close status. Every statement has a literal card sequence
and a fluent German working translation.

## Dictionary architecture

The compact component/codebook architecture joins exactly to the current cards:

| layer | card types | events |
|---|---:|---:|
| productive composition | 151 | 353 |
| learned whole card | 22 | 28 |

This is a workable small-shop system. Most running text is built from reusable
components; the memorized deck is only twenty-two cards, several of which share
short teaching heads such as vessel, clear run or previous item. The 57 written
aliases are handled by the ten-rule reader sheet.

## Important editorial warning

The new dictionary deliberately keeps two columns: the current card value and
the older component-closure reading snapshot. The current value controls the
new translations. The snapshot is not silently treated as current because it
exposes unresolved historical conflicts, notably:

- `tchody`: final addition versus cool/store;
- `qekey`: brief processing versus raw;
- `dchey`: base part versus root;
- `sh`: hold versus stalk;
- `dshedy`: short settle versus fresh water.

These are now the highest-value next targets. A compact audit of all twenty-two
whole cards should choose one short default for each from their complete local
occurrences and visible owners. No new component is needed until that deck is
internally consistent.
