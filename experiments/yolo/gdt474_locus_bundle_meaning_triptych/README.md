# GDT474 — locus bundle meaning triptych

Status: `MIXED_LOCUS_GRAMMAR_REQUIRES_FEWEST_WORKING_REPAIRS__COORDINATE_BEST_SINGLE_DEFAULT`

Every one of the 146 visible GDT473 locus/owner bundles now has three complete
German working readings:

- address or coordinate trace;
- ordered workshop instruction;
- catalogue entry plus qualifiers.

The best universal default is the address reading (89 small grammatical
recasts, versus 120 for instruction and 146 for catalogue). A visible mixed
choice needs only fourteen: 27 bundles select address, 54 instruction and 65
catalogue. This makes the current working object a mixed micro-record rather
than one universal sentence type.

[`artifacts/GDT474_LOCUS_BUNDLE_READING_BOOK.md`](artifacts/GDT474_LOCUS_BUNDLE_READING_BOOK.md).
