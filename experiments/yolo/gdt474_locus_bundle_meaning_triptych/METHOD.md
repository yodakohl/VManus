# GDT474 method

## Question

When the complete GDT473 address events are read in their visible locus/owner
bundles, do they behave most naturally as coordinates, instructions or
catalogue qualifiers—and can all three readings be written without changing a
root or learned name?

## Inputs

- GDT473's complete 183-event source-ordered local-address edition;
- GDT412's nineteen-root working dictionary;
- GDT413's component/control dictionary;
- GDT416's owner-local verbs, nouns, relations and imperative compiler rules.

## Method

Events are grouped by exact physical page, locus and visible owner, preserving
source order. This yields 146 bundles: 116 single-card, 23 two-card and seven
three-card bundles.

Each event and bundle receives three grammatical recasts of the unchanged
literal reading:

1. **Coordinate/address:** relations, arguments, order controls and names form
   an ordered address trace. An action root or process-only `O`/`DY` must be
   nominalized and costs one visible repair.
2. **Instruction:** GDT416's owner-local vocabulary supplies the imperative.
   A card before any explicit action in its bundle needs one generic `beziehe`
   or `verwende`; after an explicit action, same-bundle carry is allowed.
3. **Catalogue:** learned names are headwords and the function trace becomes
   qualifiers. Every action root must be nominalized. An unnamed card needs an
   implicit headword unless an adjacent named card can host it.

The repair count is a workshop fluency measure, not evidence of truth. The
lowest count supplies the bundle's working choice. Ties go to catalogue when a
visible learned name supplies a headword, then to instruction when an explicit
action supplies a verb, otherwise to the address default. All ties remain
printed.

## Decision rule and claim ceiling

The pass is complete only if all 183 events, 146 exact bundle keys, nineteen
roots and learned name strings replay unchanged; all 438 bundle readings are
nonempty; the selected reading is always one of the minimum-repair candidates;
and both exact packages retain their old recipes.

This is an exploratory grammatical recast. It claims neither that the cost
measure identifies the historical syntax nor that German address, imperative
or catalogue wording is plaintext. It adds no component meaning, learned name,
surface, event, page, object identity, language or confirmed lexeme.
