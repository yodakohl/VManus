# GDT474 — locus-bundle meaning triptych

## Result

The local address material does not want to be forced into one universal
sentence type. All 146 visible locus/owner bundles can be read three ways, but
the amount of invisible grammatical help differs:

| whole-deck model | added grammatical repairs | unique lowest bundles |
|---|---:|---:|
| address / coordinate | 89 | 25 |
| ordered instruction | 120 | 52 |
| catalogue + qualifiers | 146 | 5 |
| visible mixed choice | **14** | — |

Address is the best single fallback. The much better working theory, however,
is a mixed micro-record. The deterministic visible choice uses catalogue for 65
bundles, instruction for 54 and address for 27. Fifty-eight bundles tie between
address and catalogue because the same name-plus-relation string naturally
works as either an address trace or a qualified headword.

## What changed—and what did not

No stem meaning changed. The same root is simply placed into three grammatical
frames. For example:

| root | fixed working value | address | instruction | catalogue |
|---|---|---|---|---|
| `OT` | DANACH | Folgestelle | danach | Folgevermerk |
| `AL` | ZIELORT | Zieladresse | zum Zielort | Zielzuordnung |
| `OK` | SETZEN | Setzpunkt | setze | Setzvermerk |
| `AIIN` | WERT | Wertposition | den Wert | Wertangabe |
| `AIR` | BAHN | Bahnadresse | entlang der Bahn | Bahnvermerk |

This is the grammatical distinction we had been missing. `OT` need not be a
separate complicated “word” in each setting: one broad follow/next value can
surface as an address step, an adverb or a catalogue qualifier.

## Bundle topology

The 183 events form 146 exact page+locus+owner bundles. There are 116 singleton
bundles, 23 pairs and seven triples; the 30 multi-event bundles contain 67
events. Those bundles make local carry visible without inventing an arbitrary
word boundary.

Examples of uniquely favoured address readings:

- f71v.7 `otaiin`: “danach → Positionswert”;
- f71v.9 `otar / ar / aly`: “danach → Ausgangsposition / Ausgangsposition /
  Zielposition → Positionsposten”;
- f72r1.9 `otaiin / otain`: “danach → Positionswert / danach → Sektoranteil”.

Examples of uniquely favoured instructions:

- f71v.8 `okaraiin`: “Setze den Positionswert von der Ausgangsposition”;
- f72r1.2 `oshodady`: “Halte den Sternstelleneintrag »o« und den
  Sternstelleneintrag »odady«”;
- f89r2.10 `okol / shol / dy`: two explicit actions followed by the carried
  Drogenposten.

The five unique catalogue cases are dominated by execution/stage qualifiers
around a name, for example f71v.13 `ofaom`: “Sternstelle »aom« —
Ausführungsvermerk, Hier-Vermerk.”

## Better working theory

The ten-page sidequest should no longer imagine every local string as either a
single encrypted noun or a miniature imperative. The more economical object is
a compact micro-record language with three card roles:

- address cards locate or order a value/name;
- action cards say what to do with it;
- catalogue cards identify the memorized entry and its qualifiers.

That also explains why name cores and technical roots coexist inside one
surface. A function shell can be grammatical metadata around a learned
headword rather than part of the object's spoken name.

## Next route

The next creative pass should connect these micro-records across the page. Use
`OT` and `OL` at the starts of successive locus bundles to decide whether a
bundle begins a sibling record, continues the previous record or merely carries
a local qualifier. Then publish six page-level itineraries while retaining all
GDT474 alternatives and every old root/name.

bundle keys, all three readings, minimum-cost choices, page totals, learned-name
preservation, all nineteen roots, both exact-package recipes and a byte-identical
rebuild.

The fluency cost is a creative working heuristic, not historical proof. No
