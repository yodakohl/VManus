## Method

First enumerate exact old right-edge pairs `BASE→BASEm` whose recipes differ
only by one final structural tag. Eight exist: six add `AM_ADDR`, while
`cho→chom` and `lo→lom` add `M_LOCAL`.

A candidate receives the selected feature only if all of the following hold:

1. deleting final visible `m` yields an exact old base whose recipe ends in
   `O`;
2. the remaining visible stem carries at least two established action roots;
3. that stem has all three exact right-slot siblings `stem-o`, `stem-ol` and
   `stem-or`, with recipes `STEM+O`, `STEM+OL` and `STEM+OR`;
4. an exact old `BASE→BASEm` pair lies exactly one visible edit from the target
   base, and every nearest pair adds the same one of `M_LOCAL` or `AM_ADDR`;
5. the candidate recipe is the exact base recipe plus that predicted tag;
6. an exact old target carrying another recipe overrides the rule.

For `cthom`, the family certificate is
`ctho/cthol/cthor = CH+T+(O/OL/OR)`. Its base `ctho` is one visible insertion
away from `cho`, and the exact old pair `cho→chom` adds `M_LOCAL`. The fourth
corner is therefore `ctho→cthom = CH+T+O+M_LOCAL`.

The selected binary feature has weight `1.25` after GDT528. A comparator keeps
only the nearest-pair condition and omits the action-slot triad. It happens to
match the aggregate old/current scorecard here, but it is kept as the broader
model: the triad supplies the compositional reason and restricts prospective
use to four actual old action families.

## Decision rule and claim ceiling

The selected rule must improve current top one, lose no current correct case,
and preserve the complete old aggregate scorecard. GDT529 passes. Inherited
current top one rises `149→150`, accumulated working-revised top one rises
`151→152`, and the old four-fold scorecard remains exactly unchanged.
