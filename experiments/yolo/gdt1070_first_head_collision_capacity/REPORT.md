# GDT1070 — first Herbal-head collision capacity

**Decision: f9v `fochor`'s exact uniqueness has no discriminating force for
the proposed plant-name reading.** Among the 89 already admitted Herbal-A
first-page heads in the fixed GDT1059 ZL3b projection, **80 (89.9%)** occur
on exactly one page. `fochor` is one of those 80. Removing the previously
selected two-page `kooiin` case leaves the same 80 singleton heads among 87
pages (92.0%). The name and opaque entry-address alternatives both predict
that a manuscript with mostly unique heads can contain a unique `fochor`.

examples. There are 84 distinct forms and six unordered same-form page

plants, so that exact string cannot simply be assumed to be one unique
species name. The other repeated heads are formal countercases only;
GDT1069 records a weak ZL3b separator after f53v `tshor`, so an exact
ZL3b head token there need not be a definitely bounded standalone word.
