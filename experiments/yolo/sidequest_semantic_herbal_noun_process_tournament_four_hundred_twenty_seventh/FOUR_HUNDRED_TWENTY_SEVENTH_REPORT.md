# Pass 427 — Bildnomen und Prozessnomen getrennt

Fünf weitere Karten wurden jeweils gegen drei Rivalen gelesen. Drei bleiben,
zwei werden einfacher.

```text
H1  KNOLLE             bleibt
H2  GLASIERTES GEFÄSS → SCHÜSSEL
H3  BLÜTENKRAUT        bleibt
H4  ABKÜHLEN           bleibt
H5  GEBRAUCHSAUSZUG   → AUSZIEHEN
```

KNOLLE und BLÜTENKRAUT haben echte Bildanker: rote unterirdische Schwellkörper
auf f10r und eine Krone aus vielen kleinen blauen Blüten auf f11r. SCHÜSSEL
kommt dagegen nur aus dem Prozess: Zwei Ansätze werden vor dem weichen Brei in
einem Behälter vereinigt. Das Adjektiv „glasiert“ war unsichtbar und wird
gestrichen.

ABKÜHLEN ist ebenfalls prozessgestützt, aber nicht isoliert: H3, B1 und B3
besitzen unabhängige Kühlkarten. H5 wird grammatisch besser, wenn KCHOAR ein
Verb ist:

```text
ZUTAT → NIMM DIES → AUSZIEHEN → GEBRAUCHEN
```

Das alte GEBRAUCHSAUSZUG verdoppelte die Produkt-/Gebrauchsinformation und
machte die Folge holprig. AUSZIEHEN sagt genau eine Sache.

Als nächstes werden die fünf Artikel auf Handlungsrollen reduziert:
ENTNEHMEN, ZERKLEINERN, PRESSEN, WÄRMEN, KÜHLEN, TRENNEN, LAGERN, AUFTRAGEN,
GEBRAUCHEN. Ziel ist ein kleines Operationswörterbuch, das neue
Kartenkompositionen vorhersagt, während Bildnomen im Nomenklator bleiben.
