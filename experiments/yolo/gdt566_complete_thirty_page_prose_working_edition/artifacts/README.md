# GDT566 artifacts

- `gdt566_5122_complete_prose_event_edition.tsv`: every running card in fixed
  order, with selected and owner-bound control readings.
- `gdt566_793_complete_statement_edition.tsv`: both complete statement channels.
- `GDT566_COMPLETE_THIRTY_PAGE_PROSE_EDITION.md`: readable selected edition,
  ordered by page and statement.
- `gdt566_30_page_edition_profiles.tsv`: complete page accounting, including two
  zero-running pages.
- `gdt566_3_statement_mode_profiles.tsv`: all-state, mixed and no-state totals.
- `gdt566_3_reading_layer_profiles.tsv`: exact source-layer partition.
- `gdt566_10_later_context_recipe_repairs.tsv`: all recipe differences between
  the GDT515 navigation snapshot and later authoritative context editions.
- `gdt566_result.json`: compact result.
- `gdt566_validation.json`: independent 45-check validation record.

The two exhaustive TSV editions are retained because sampled output could hide
an omitted card, statement-boundary drift or accidental replacement of one of
the two reading channels.
