# Compact artifacts

REGISTRATION_LOCK binds the frozen channel, preregistration, source/target and
three implementations before measurements. DEFAULT_TABLE contains all learned
default cells and source-only event counts. RECIPE_RECEIPTS stores full-source
coverage and sequence hashes without copying source prose. RESULT preserves
all five necessary conditions per source and reader; VALIDATION separately
checks the construction and decision. No validator PASS implies model PASS.
