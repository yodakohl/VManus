# Method

The full fixed channel is in the registered proposal contract. src/writer.py
implements the complete source-to-body transform,126-cell b4/w1 training,
framing and canonical inverse. No default or body assignment uses target data.
src/run.py retains the five rational comparisons of1217, then records all full
recipe inverses and compact artifacts. src/validate.py independently rebuilds
source atomization with a regex scanner, defaults, writing, reading, histograms,
sequence hashes and decisions. It imports neither runner nor writer. Same author
and exposed material: this is implementation validation, not blinded confirmation.

Existing CoReMA expanded-edition source projection only, provenance/license as
1177 SOURCE_TEXTS and1159 SOURCE.json (University of Graz, CC-BY4.0).
No source words are omitted or normalized anew. No native raw transcriptions,
images, relation packets or protected data are opened. Paragraph resets are an
explicit construction assumption; they are not inferred Voynich paragraph syntax.

The first attempt to replace the scaffold validator used a rejected multiple-
operation apply_patch and wrote nothing. The complete validator was then written
before source counts. A route formatting check caught fixed test instead of the
required fixed_test enum; corrected before execution. Neither changed the design.
