Status: `FIFTY_ONE_OF_FIFTY_TWO_CLOSE_RECIPES_RESOLVE_IN_ALL_CONTEXTS__TWO_GRADE_III_STOPS_REMAIN`

Handlungsköpfen und zwei Scope-Lagen gelesen. 934/936 Zellen gehen durch; nur
`OL+EEE+DY` bleibt nach `CHD` oder `R` im selben Aussage-Scope rot.
