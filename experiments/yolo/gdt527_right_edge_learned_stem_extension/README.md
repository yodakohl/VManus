# GDT527 — Certified right-edge learned stem extension

Status: `PASS_CERTIFIED_S_STEM_AND_ATOMIC_OL_REVISION`

GDT527 generalizes GDT526's learned-stem layer without making every old prefix
productive. A stem must have either three old surface carriers of its recipe or
one old non-null one-character right child. The selected transparent
`s→S` rule repairs `okedals`; the parallel `l→L` proposal is rejected
because old visible `ol` is atomic `OL` on 103/112 types. This revises
`keeol` to `K+EE+OL`.

See `REPORT.md`, `METHOD.md`, the compact working book under `artifacts/`,
and the executable scripts under `src/`. No new page is used.
