# Method

## Inputs

- GDT423's 4,576-event held-page replay and its 57 red page×slot cells;
- GDT407's already fixed 5,051 focus-to-action attachments.

No new page, image, transcription, root, or meaning is used.

## Factorization

GDT423 deliberately treated each clean card as one composite action-head or
ordered-pair cell. GDT424 restores the older, finer bindings:

1. replay every argument, grade, and relation at the exact individual action
   head selected in GDT407;
2. attach a visible close to the last action of its own recipe and ask whether
   that action closes on another page;
3. for a page-private ordered pair, split it only when an intervening atom or
   already fixed R topology visibly separates the action packages;
4. retain an adjacent pair with no separator as a local ordered-pair card;
5. combine multiple local requirements inside the same surface card into one
   learned local package.

## Decision rule and claim ceiling

A factor edge is portable here only if the same action←focus or action→close
role occurs on a different page. A local pair or package remains local until
the same factor role appears on a second page. This compresses exceptions; it
does not confirm the German root values, plaintext, language, or source.
