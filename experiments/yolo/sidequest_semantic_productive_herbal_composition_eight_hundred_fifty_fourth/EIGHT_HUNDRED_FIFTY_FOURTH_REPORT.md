# Sidequest Pass 854: productive six-step herbal composition

Using only fifteen of the sixteen model-leaf cards, the workshop composes a
new six-step preparation: take the ingredient; draw measured water; add it to
the batch; prepare and hold; take a measured continuation; leave it at the
target and close.

All four surface styles render the fifteen-card sequence and decode to the
same six commands. No new card type or meaning was introduced. This is the
first compact demonstration that the reconstructed mixed system is productive,
not merely an interlinear gloss list. It remains a creative workshop model.

Next, make the inverse exercise: give four apprentices only the German commands
and require them to choose the same card sequence before rendering their styles.
