particular code table, not an exclusion of all two-word compression or a finding
that the manuscript itself contains such a source. No source words are assigned.

Every reader independently permits exactly the same relaxed head set:
`cfh,cph,q`. Every retained group containing none of these units consists entirely
of singleton BOTH columns in IDEA999, hence decodes to two identical nonempty
words under every possible remaining singleton-letter assignment. It cannot be
an odd final unpaired word. The denominator is retained groups and their
hypothetical source pairs, not every manuscript token or an unknown source book.

The screen allows all66 two-unit slots although the real carrier uses59, ignores
canonical LCS and ignores source vocabulary. Thus compatibility is necessary
only. Full checks can increase the bound or eliminate the carrier, never lower
this minimum. A deliberately doubled source sequence is possible, but no
independent evidence supports that source contract. The fixed candidate is not
selected for ordinary-prose decoding. No automatic code-table repair, head
expansion, source search or fitted key follows this result.
