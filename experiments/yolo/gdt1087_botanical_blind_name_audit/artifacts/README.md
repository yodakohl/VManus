# Artifacts

`BLIND_VISUAL.tsv` is the pre-join 23-row image inventory; `SOURCE.tsv` gives
the official Yale canvas URLs and image hashes. `RESULTS.tsv` is the complete
join of those rows to fixed GDT1062 names and manual `src/ASSESSMENTS.tsv`.
`RESULT.json` gives counts, provenance hashes and decision. Original image
bytes remain out of the repository. The independent validator checks
population and reproducibility, not human image interpretation.
