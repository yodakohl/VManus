# GDT1087 method — fixed botanical image/name audit

This is a prospective visual plausibility audit of the 23 page/name pairs
fixed in GDT1062, not a cipher test. GDT1062 established their IT2a first
prose positions, but no botanical referents. GDT1063 already exposed f2v,
f9v, f11r and f24v and found one pansy-like candidate, two conflicts and one
unresolved case. GDT1064 corrected historical *Jacea* polysemy. The earlier
BOTANICAL_TRAITS_AND_NAMES route found no transferable medicinal-use bridge;
this test asks only whether the specific 23 public names fit the pictures.

The exact 23 folios are in `src/PAGE_ADMISSIONS.tsv`, copied by page from
GDT1062's fixed `claims.tsv` before any new image access. The other 19 folios
receive new image admission in `docs/VOYNICH_DATA_SCOPE_20260929_BOTANICAL_23.md`.
The agent doing the visual inventory gets only page IDs and Yale official
canvases, not the public claimed names or their Voynich first groups. The
agent records visible flower/leaf/root/fruit traits, up to three plausible
botanical identifications and an undecidable option, with uncertainty. The
four already reviewed pages remain exposed calibration cases, not blind
confirmation. The 19 newly admitted pages are visually prospective for that
agent, but the root and project have prior botanical and source exposure;
neither a fresh agent nor a new image grant makes the manuscript a reserve.

After all 23 inventory rows are frozen, join them to the fixed GDT1062 names
and IT2a first groups. Classify each asserted name as `SUPPORT`, `CONFLICT`,
or `UNDECIDABLE` under visible diagnostic morphology; support requires at
least two distinct diagnostic features and no decisive contradictory organ.
The 19 asserted-name morphology references were written in
`src/BOTANICAL_REFERENCE.tsv` before the root opened the name-blind image table.
For f9v, the public `JACEA (knapweed)` expansion is assessed literally, while
GDT1064's historically attested pansy use of bare *Jacea* remains a separate
compatibility note.
Report every row and alternatives. Also report every duplicate asserted taxon
and every duplicate Voynich whole form, regardless of its match. This is a
source-conditioned exploratory assessment, so no p-value, significance claim,
confirmed name, inferred grapheme value or first-head-as-name claim follows.
Cross-reader forms and the 179-selector `words profile` are checked only for
the strongest surviving C0 candidates after the full image table is closed.

Decision changing outcomes: two or more strong, independent image/name fits
on different physical leaves would nominate their complete first groups as
C0 candidates for a separate whole-passage consequence; widespread conflicts
would demote this published name list as a meaning source. Even many visual
fits leave the `entry-address` alternative open. No holdout is consumed.

Work cap for this unit: 3 hours total including source acquisition, 23 native
visual notes, join, validation and publication. At the cap, preserve a partial
table and report remaining capacity rather than extending the test by default.
Dependencies: Yale canvas-to-folio identity; GDT1062 fixed source table and
position alignment; independent botanical morphology; uncertain manuscript
stylization. No old semantic gloss, phonetic rule, or Latin default is used.
