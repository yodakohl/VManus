# Einundzwanzigste Ausgabe: die Bilder übernehmen die stillen Argumente

Die Wortzerlegung ist weitgehend geschlossen. Der nächste Gewinn kommt aus
der Schreibpraxis: Bilder wurden zuerst gesetzt, der Text füllt danach die
Restflächen. Der Schreiber muss deshalb Pflanze, Becken, Figur oder Station
nicht jedes Mal ausschreiben.

Die aktuelle 116-Aussagen-Prosa ist nun an die bereits ausgewählte
Bildbesitzerkarte gebunden:

- 19 Herbal-Aussagen erhalten einen von fünf sichtbaren Gesamtpflanzenbesitzern;
- 97 Bio-Aussagen erhalten den lokalen Becken-, Figuren- oder Stationsbesitzer;
- die aktuelle Kartenlesung bleibt daneben wörtlich sichtbar;
- jede Aussage bekommt eine konkrete praktische Lesung und einen kurzen
  technischen Rivalen.

Das Ergebnis liest sich erheblich natürlicher. `AL = Ziel` muss nicht
„Zielstelle“ aussprechen, wenn rechts im Bild bereits das Becken steht. `HO =
Eingangsposten` kann schlicht die gezeichnete Pflanze oder den nächsten
Beckeninhalt aufnehmen. `AIR = Lauf` wird nur dort Wasserlauf, wo die lokale
Bildszene ein nasses System zeigt.

`COMPLETE_TEN_PAGE_OWNER_FILLED_TWENTY_FIRST_EDITION.md` verbindet diese 116
Prosa-Aussagen mit den 142 aktuellen Himmelsloci. Die Ausgabe ist eine konkrete
Werkstattlektüre, keine neue Buchstabenchiffre.
