## The short argument behind the enumeration

A whole one-sign word must be its own code. Let S be the exact set of all
singleton codes in a proposed table. A whole two-sign word ab either is one
code or consists of the two singleton codes a,b. If either singleton is absent,
ab itself is mandatory. This gives a finite mandatory subcode B(S) for every
possible S, irrespective of how long other codes might be.

A collision inside B cannot be repaired by adding more entries. For example,
if a,c are singleton codes and whole words ab,bc exist, omitting singleton b
forces codes ab,bc. Then [ab,c] and [a,bc] both write abc: the table is not
freely uniquely decodable. The collision text need not occur as a native word;
free uniqueness on every source-letter sequence is an explicit premise.
A grammar-restricted writing system is outside that premise.

For each sign h absent from S, a whole word beginning h needs a first code
at least two signs long. Different second signs need different h-headed codes.
Those already forced in B are counted once, and only the deficit is added.
Every missing observed singleton also requires at least one actually used
longer code, so the table has at least |S|+1 entries. The minimum lower bound
across every surviving proper S is necessary; it need not be attainable.
Longer codes MAY begin a singleton sign: {a,ab} is UD. No prefix-quotient rule
or forced-singleton conclusion from1234is imported.
