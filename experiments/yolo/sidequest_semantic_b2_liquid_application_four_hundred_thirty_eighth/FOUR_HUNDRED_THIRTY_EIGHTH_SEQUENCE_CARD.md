# B2-Flüssigkeitskarte

```text
FRISCHWASSER / SPÜLWASSER
→ SEIHTUCH / DURCHLASS
→ KLARAUSZUG
→ DIES ABZIEHEN oder DIES LÄNGER ABZIEHEN
→ WASCHFLÜSSIGKEIT AN DIE STELLE
→ WASCHUNG
→ VON DORT ABFÜHREN
```

Die Reihenfolge ist eine Zusammenfassung mehrerer lokaler f82r-Stationen,
kein behauptetes durchgehendes Rohrnetz.
