# GDT481 — microrecord fragment grammar

GDT481 decomposes GDT479's 135 complete microrecords into all 183 one-event
fragments and all 48 real adjacent-event pairs. Every fragment receives a
strict owner-neutral meaning template and a broad role shape. The resulting
atlas measures how much of GDT480's singleton whole-record tail is nevertheless
built from familiar smaller units.

The readable result is
[`artifacts/GDT481_MICRORECORD_FRAGMENT_GRAMMAR.md`](artifacts/GDT481_MICRORECORD_FRAGMENT_GRAMMAR.md).
See [`REPORT.md`](REPORT.md) for the compact interpretation.

```bash
python3 experiments/yolo/gdt481_microrecord_fragment_grammar/src/run.py
python3 experiments/yolo/gdt481_microrecord_fragment_grammar/src/validate.py
```
