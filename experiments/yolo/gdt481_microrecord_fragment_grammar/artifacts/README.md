# Artifacts

- `GDT481_MICRORECORD_FRAGMENT_GRAMMAR.md`: readable recurrent event and pair
  atlas.
- `gdt481_183_event_fragment_assignments.tsv`: strict and role assignment for
  every event.
- `gdt481_event_strict_templates.tsv` and `gdt481_event_role_shapes.tsv`: all
  event-level template families.
- `gdt481_48_adjacent_pair_assignments.tsv`: every true within-record event
  adjacency with its boundary.
- `gdt481_pair_strict_templates.tsv` and `gdt481_pair_role_shapes.tsv`: pair
  families.
- `gdt481_135_record_fragment_coverage.tsv`: fragment coverage of every record,
  including the GDT480 singleton flag.
- `gdt481_fragment_coverage_summary.tsv`: all-record and singleton-record
  coverage totals.
- `gdt481_result.json`: compact result.
- `gdt481_validation.json`: deterministic 118-check validation report.

All files are regenerated by `src/run.py` and checked by `src/validate.py`.
