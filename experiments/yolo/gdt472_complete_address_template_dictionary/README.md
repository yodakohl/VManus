# GDT472 — complete address template dictionary

GDT472 joins GDT471's 89 learned-slot cards with all eighteen complete function
labels. Sixteen full labels become general zero-name templates; `ykyd` and
`yddy` remain exact-surface package cards. The result assigns all 107 labels and
extends the ranked GDT470 worksheet command.

Build and validate:

```bash
python3 experiments/yolo/gdt472_complete_address_template_dictionary/src/run.py
python3 experiments/yolo/gdt472_complete_address_template_dictionary/src/validate.py
```

Prepare one complete ranked row:

```bash
python3 experiments/yolo/gdt472_complete_address_template_dictionary/src/prepare_complete_future_address.py \
  otainy STAR_BEARING_RING_POSITION --page-slot PAGE_SLOT_1 --item-slot ITEM_001
```

Exact package cards can replay only their exact old surfaces. They never
license a generated or component-matched future form.
