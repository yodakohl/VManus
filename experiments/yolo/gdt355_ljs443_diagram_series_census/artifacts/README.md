# GDT355 artifacts

- `gdt355_external_sources.tsv`: official TEI plus all 38 official facsimile
  surfaces and byte digests.
- `gdt355_diagram_census.tsv`: neutral external visual observations.
- `gdt355_family_summary.tsv`: mechanically derived topology/family counts.
- `gdt355_counterexamples.tsv`: source-family specificity counterexamples.
- `gdt355_result.json`: compact result and bindings.
- `gdt355_validation.json`: nonimporting integrity validation.

Remote manuscript images are not stored in the repository.
