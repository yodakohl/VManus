# GDT803 — recurrent context rarity discriminator

Status: `PARTIAL__14_STABLE_CONTEXTS__450_CORE_NEIGHBOUR_EVENTS__12_ALL_L_DOUBLE_BRACKETS__LEFT_IDENTITY_BEATS_RARITY__RIGHT_UNRESOLVED__ZERO_LEXEMES`

GDT803 turns GDT802's diffuse neighbour signal into an enumerated working
construction: four complete left contexts and three complete right contexts
form twelve exact three-token brackets across eleven target stems and eleven
folios, all with an `l` middle surface.  Exposure-matched rarity controls do
not reproduce that breadth.  This remains an exploratory field grammar, not
a translation or component reading.

Reproduce with:

```bash
python3 experiments/yolo/gdt803_recurrent_context_rarity_discriminator/src/run.py
python3 experiments/yolo/gdt803_recurrent_context_rarity_discriminator/src/validate.py
```
