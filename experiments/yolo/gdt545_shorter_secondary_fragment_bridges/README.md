# GDT545 — kürzere sekundäre Fragmentbrücken

Status: `FOUR_FLAGGED_TARGETS_GAIN_SHORTER_SECONDARY_BRIDGES__TWELVE_DEFAULTS_REMAIN`

Zwölf kürzere alte Mehrkomponentenstämme existieren für sieben der sechzehn
GDT544-Restkarten. Sechs Kandidaten auf vier Karten verbessern eine markierte
Dimension ohne sichtbaren, kontextuellen oder atomaren Verlust. Sie werden als
Sekundärbrücken ergänzt; alle längsten GDT543-Hauptstämme bleiben erhalten.
