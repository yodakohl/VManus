# GDT545 method

## Question

Can a shorter complete old multi-atom recipe provide a secondary visible stem
for any of GDT544's sixteen flagged cards while preserving the current visible,
context, and interface support and concretely repairing at least one flag?

## Inputs

- GDT407's 4,576 old running events and same-statement order;
- GDT543's 81 primary cards and 93 interface records;
- GDT544's sixteen-card flag union.

## Method

1. Enumerate every contiguous target fragment of length at least two and less
   than the GDT543 primary-anchor length that is itself a complete old recipe.
2. For each candidate, locate exact old carrier surfaces inside the target and
   classify left/right direction as aligned, mismatched, or absent.
3. Replay the complete target recipe in the actual pre-event state of every
   candidate-anchor carrier and compare its mode set with GDT540's target set.
4. Count every atom interface between candidate anchor and target extension.
5. Require visible rank, context-relation rank, and supported-interface
   fraction to be no worse than the primary card. Additionally require a
   previously missing target mode or new interface to be repaired.
6. Where several candidates qualify, prefer visible alignment, exact context
   equality, complete old interfaces, then longer/frequent stems and fixed
   surface/position tie breaks.
7. Add the winner as a secondary evidence route; never replace the longer
   primary GDT543 anchor.

## Result conditions

- all shorter old multi-atom candidates on the sixteen targets are enumerated;
- qualification and selection replay independently;
- every selected secondary bridge has the exact target context-mode set and
  only old interfaces;
- primary recipes, anchors, and German readings remain byte-for-byte values
  from GDT543.

## Decision rule and claim ceiling

A shorter stem is auxiliary support, not a new segmentation or replacement
word. A direction-mismatched exact surface match remains visibly marked. Cards
without a qualifying candidate remain valid exploratory defaults. No page,
recipe, primary anchor, working meaning, root value, plaintext, or historical
codebook changes.
