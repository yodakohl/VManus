## Finite content consequences

R reads a two-word phrase's second ending as source and first as destination.
For a left event y→x and right event w→z:
THEN executes both in order; x must equal w. ONCE needs one complete execution.
REPEAT additionally needs z=y so the same portion can start again without an
unwritten reload, vessel switch or state reset. Test two executions explicitly.
NOT affirms the left route and prohibits using the right route in the SAME
instruction execution. If the two routes are identical, this is P and not P.
Otherwise NOT_ONCE ends at x; NOT_REPEAT needs x=y to execute the left route
again. A prohibition is never executed as a positive reverse transfer.
This is contrastive negation, not the old W30 next-predicate grammar.
DESCRIPTION records both directed possibilities without asserting an executed
trajectory; it is not scored as passing a process condition it does not make.

For the already known seed B→A, A→B: THEN returns the portion to B, NOT leaves
it at A, and DESCRIPTION asserts no current location. Therefore THEN_REPEAT
can repeat, NOT_REPEAT cannot under SAME portion/no reset. This anticipated
consequence is an internal semantic consistency test, not an unseen prediction
or evidence that aiin actually means repeat. NOT_ONCE remains a full rival.
We do not pick repeat merely to force then. No p-values or search significance.
