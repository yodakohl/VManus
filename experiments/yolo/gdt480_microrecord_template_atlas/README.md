# GDT480 — microrecord template atlas

GDT480 assigns every one of GDT479's 135 complete microrecords to an
owner-neutral strict meaning template and a broader role shape. It distinguishes
real repetition across different surfaces from literal duplicate records and
keeps every singleton as an explicit default rather than discarding it.

The readable result is
[`artifacts/GDT480_MICRORECORD_TEMPLATE_ATLAS.md`](artifacts/GDT480_MICRORECORD_TEMPLATE_ATLAS.md).
See [`REPORT.md`](REPORT.md) for the main findings and the artifact tables for
all 135 assignments.

```bash
python3 experiments/yolo/gdt480_microrecord_template_atlas/src/run.py
python3 experiments/yolo/gdt480_microrecord_template_atlas/src/validate.py
```
