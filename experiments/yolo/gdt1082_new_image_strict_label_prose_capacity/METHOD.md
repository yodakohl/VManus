GDT1071 found one truly singular local-star label/prose same-page candidate
`otor` among the original 29 image-reviewed physical pages. Its source-first
annotation census did **not** include the eleven later full-page image
admissions. GDT790's ten bath label/prose edges and GDT1071's false strict
`cheody` group ownership warn that exact reuse and unit-level attachment do
not by themselves confer word meaning. Unknown: whether the changed image
scope contains any new *locally* singular, exact same-page label/prose bridge.

The research decision changes only if one exists: it nominates a new complete
word for a separate native image plus complete-context rival test. Zero leaves
the strict bridge supply at `otor` for this batch. Neither outcome confirms a
meaning, plant name, numeral or language; alternate readings are not
independent witnesses.

Smallest test: query the entire eleven-selector annotation source by raw
`page` allow-values and the full eleven-selector group source separately,
rejecting `f84*` **before materialisation**. Keep all one-group local C/L
loci, including zero-hit and nonstrict cases. The primary strict owner rule
uses `certainty=UNHEDGED`, `context_class=OBJECT_BEARING`, and one of
`REL_EXPLICIT_ATTACHMENT`, `REL_DIRECT_ENCLOSURE`, or
`REL_EXPLICIT_IDENTITY` in **local_relation_tags only**. Unit tags are retained
for a separate diagnostic but cannot qualify a candidate. The primary match
is exact complete ZL3b surface (minimum two characters) at one strict local
locus and one running P group on the same physical page. Count duplicate
prose occurrences; do not select one matching point. Give complete analogous
IT2a/RF1b same-locus correspondence as transcription sensitivity, not a
second semantic witness. Report all candidates and noncandidates; no
search-wide p-value. No visual or text meaning assignment in this stage.

If a primary candidate exists, register a later, separate complete-context

independent confirmation capacity here: zero. No reserve opened.
