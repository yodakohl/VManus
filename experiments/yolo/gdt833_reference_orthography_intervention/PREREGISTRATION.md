# GDT833 prospective fit registration

Public registration follows source-only preparation and capacity inspection;
it precedes every decoder fit and original-spelling recovery score. Source
counts are developmental. No capacity gate, encoding deck or text partition
was changed following a failed gate. The paired reference differs exactly by
reference-side `v→u`; gold and all candidate support remain common.

SPEC.json, ENCODER_SPEC.json, METHOD.md and all executable fit/evaluation code
are fixed by PREREG_LOCK.json. Upstream GDT832 code is separately hash-bound
and unchanged. Discovery inputs, held ciphertext commitments and sealed truth
commitments are separate. All 48 restarts and six selected fits must be fixed
before evaluation opens key truth; original spelling is always the target.

Decision order:

1. SOURCE_CAPACITY_STOP if input prerequisites fail.
2. ORTHOGRAPHY_EFFECT_NOT_CONFIRMED if any specific intervention criterion fails.
3. ORTHOGRAPHY_EFFECT_CONFIRMED_RECOVERY_FAIL if the specific effect passes but
   one or more general reconstruction floors fail.
4. ORTHOGRAPHY_EFFECT_AND_RECOVERY_PASS if both sets of criteria pass.

The v/z oracle is the one predeclared legal two-output swap, never an optimized
competitor panel or a replacement fit. No new fit, metric normalization or
threshold change follows the results. A pass does not authorize a Voynich target
run or revise GDT832's failure status.
