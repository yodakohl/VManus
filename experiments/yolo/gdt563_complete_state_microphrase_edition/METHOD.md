# GDT563 method

## Question

Can the 950 state cards with a visible action and the 706 actionless cards
resolved by GDT562 be compiled into one complete, fluent 1,656-card workshop
edition without changing any written atom, root value, recipe or admitted page?
How often does one exact written recipe keep one microphrase, and how often is
its concrete reading selected by the active statement context?

## Inputs

- GDT561's complete 1,656-card typed state deck;
- GDT561's 36-entry state-atom dictionary;
- GDT562's complete 706-card actionless-state reader.

No new manuscript page, transcription, image or surface is opened. The old
26-page and current four-page cohorts remain distinguished in every output row.

## Compilation

Each output card keeps three separate channels:

1. the exact ordered written-atom trace and one alignment fragment per atom;
2. an owner-free, event-context microphrase;
3. the inherited owner-bound contextual clause already available upstream.

For the 706 actionless cards, the owner-free microphrase and its contextual
action source are copied byte-for-byte from GDT562. For the 950 visible-action
cards, the compiler renders every visible action slot in written order. A
currently effective argument is attached where available; grades, relations,
local signs and state controls remain explicit modifiers. Only an immediately
adjacent repetition of the same action root is shortened to “zweimal”. The
expanded action chain is retained beside the fluent rendering, and repetitions
separated by another written atom are never collapsed.

The state-control subsequence is classified independently of the action:
`OL`, `OT`, `DY`, `OT+DY`, `OL+DY`, `OT+OL`, `OL+OL`, `OL+OT` and `DY+OL`.
The resulting cards are also classified into eight resolution modes, separating
visible and inherited full operations, visible and inherited objectless
operations, and the four genuinely action-free editorial roles from GDT562.

## Recipe-context profiles

Cards are grouped by their exact recipe. A recipe is `ONE_MICROPHRASE` only if
all its current event contexts yield the same owner-free phrase. Otherwise it
is context-variable. The profile records event count, distinct phrase count,
distinct effective action signatures, distinct effective argument signatures,
resolution modes and state sequences. Singleton recipes are reported apart so
that one observed phrase is not mistaken for demonstrated stability.

## Validation

The independent validator reconstructs card identity, atom alignment, visible
action rendering, GDT562 byte identity, resolution modes, state sequences,
repeat handling and all 402 recipe profiles from the three inputs. It then
reruns the compiler and requires every retained artifact hash to be unchanged.

## Decision rule and claim ceiling

Pass requires one and only one output row for every GDT561 card, full retention
of every written atom and visible action slot, exact reuse of all 706 GDT562
microphrases, complete recipe/context accounting and deterministic replay.

This is an exploratory practical edition of the existing workshop dictionary.
Its inserted action and argument values are explicit context, not hidden
characters or new meanings of `OT`, `OL` or `DY`. A phrase attached to an event
is not promoted to a universal whole-word translation. No plaintext, historical
language, syntax, genre, object identity, new root, future surface or page is
claimed.
