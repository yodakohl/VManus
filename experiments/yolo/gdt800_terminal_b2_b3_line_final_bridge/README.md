# GDT800 — terminal B2/B3 line-final bridge

This pass asks whether the source-native final-member contrast exposed by the
homologous A09 labels (`okalal`/`okalam`) is a one-off image-label change or a
recurrent bound field. It joins no unopened page. It compares the validated
101-label source-family atlas with the f84-free V99R7 running-text cache and
retains the GDT799 clothing state only as a negative control.

The experiment produces an occurrence-level matched-stem atlas, a complete
156-pair homolog census, exact conditional position tests, four cross-register
stem cards, and a structural candidate adjudication. Native A09 inspection is
source-bound by crop geometry and hashes; the image crops themselves are not
published.

Run:

```bash
./vmanus-exp run experiments/yolo/gdt800_terminal_b2_b3_line_final_bridge
./vmanus-exp validate experiments/yolo/gdt800_terminal_b2_b3_line_final_bridge
```
