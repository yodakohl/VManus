# Reproducible result artifacts

- RESULT.json: full selector command, scope accounting, all stratum cells and decisions.
- RUNS.json: every inventory run, source positions and two directional decisions.
- BLOCKS.json: complete raw groups of all74 unique contradiction blocks.
- VALIDATION.json: independent reconstruction and synthetic/mutation checks.

All data here come from the179 admitted selectors; alternate transcriptions are one manuscript. Runtime projection excluded from publication.
