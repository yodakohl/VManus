`artifacts/GDT599_COMPLETE_OBJECT_READER.md`; `REPORT.md` fasst Ergebnis,
Schwachstellen und nächste Route zusammen.

python3 experiments/yolo/gdt599_remaining_action_object_completion/src/run.py
python3 experiments/yolo/gdt599_remaining_action_object_completion/src/validate.py

Evidenz, ergänzte Defaults und manuelle Werkstattentscheidungen bleiben in den
Tabellen getrennt sichtbar.
