# Artifacts

`REGISTERED_SEARCH.json` is the prospective, deterministic machine-readable
contract. It binds the exact GDT608/GDT614/GDT615 sources, recursive X/Z model,
access boundary, objective order, and terminal outcomes without containing a
candidate mapping or score.

Later compact artifacts must expose enough mapping, paid-assignment, child and
effective renders, labelled spans, traces, tilings, objective queries, and
independent certificates to replay every decision. Large exhaustive tables
require an explicit retention justification. Transient solver work and
nondeterministic statistics are not canonical artifacts.
