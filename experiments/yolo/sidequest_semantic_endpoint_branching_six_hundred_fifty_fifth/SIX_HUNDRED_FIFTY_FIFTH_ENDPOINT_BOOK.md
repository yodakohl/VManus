# Neun Motive am Aussageende

Aussageende und exakte Schlusskarte werden getrennt. Nur die Kartenlesung `SCHLUSS` lizenziert einen expliziten Abschluss.

## H2-S001 — STATEMENT_END_WITHOUT_CLOSE_CARD

`chy taiin shy` = ARBEITSPOSTEN -> SOLLMASS -> ARBEITSPOSTEN

## H3-S003 — STATEMENT_END_WITHOUT_CLOSE_CARD

`dy daiin` = ARBEITSPOSTEN -> SOLLMASS

## B1-S008 — EXPLICIT_CLOSE_AT_END

`ol shedy` = FORTSETZEN -> ABSETZEN; SCHLUSS

## B1-S016 — EXPLICIT_CLOSE_AT_END

`qol cheedy` = FORTSETZEN -> ABSETZEN; SCHLUSS

## B3-S007 — EXPLICIT_CLOSE_AT_END

`chedy qokeedy` = UMSETZEN · ARBEITSPOSTEN -> ANSETZEN · LANG; SCHLUSS

## B3-S028 — EXPLICIT_CLOSE_AT_END

`qokeey qokedy` = ANSETZEN · LANG · ARBEITSPOSTEN -> ANSETZEN · KURZ; SCHLUSS

## B4-S002 — EXPLICIT_CLOSE_AT_END

`qokeey qokedy` = ANSETZEN · LANG · ARBEITSPOSTEN -> ANSETZEN · KURZ; SCHLUSS

## B4-S003 — EXPLICIT_CLOSE_AT_END

`tol shedy` = FORTSETZEN -> ABSETZEN; SCHLUSS

## B4-S005 — EXPLICIT_CLOSE_AT_END

`chedy qokeedy` = UMSETZEN · ARBEITSPOSTEN -> ANSETZEN · LANG; SCHLUSS

# M09-Zweigpaar

- `qokeey qoky` — **M09O_OPEN_CONTINUATION** — LANG ANSETZEN, DANN DEN POSTEN WEITERSETZEN — ENTRY
