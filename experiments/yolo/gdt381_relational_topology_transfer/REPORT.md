# GDT381 — cross-domain relational-topology transfer report

## Final decision

`COMPARATOR_TOPOLOGY_SUPPORTED_TARGET_TRANSFER_UNIDENTIFIABLE_DEFINITION_OVERLAP`

One anonymous relation topology transferred across readable comparator domains.
Its frozen Voynich target produced a strong numerical pass, but a mandatory
post-score audit showed that the target definition and predictor shared the
same source-side topology. The target pass is therefore nonpromoting. No formal
realization was inspected and no Voynich functional class is assigned.

Each readable domain independently learned unaligned latent classes from
form-blind structural behavior. CoReMA, Curious Cures, Harleian, and Quinte
selected 12 classes; PCEEC2 selected 16. Only class-label-invariant graph
topology crossed domains.

`CMP_TOPOLOGY_04` passed the frozen comparator gate:

- held-domain AUC floor: 0.716304;

The readable oracle used to calibrate this topology was coordination, but that
label was not transferred. Curious Cures loses 31.589 bits against the trivial
baseline, and Quinte loses 3,762.638 bits against nuisance; these remain
important comparator counterexamples. The other four topology families fail.

## Why the pass is not promoted

The topology class was defined by the full comparator score, which contains
both source-side state and downstream transformation features. The target
predictor then reused source-side class topology. That creates an endpoint
overlap even though exact tuple identity, PAGE_HOST, wrappers, and coordinates
were forbidden.

A conservative decomposition of the 59 frozen comparator features assigns only
18 clearly source-side features to the source component. Nevertheless:

- source-only contribution AUC for frozen target membership: **0.895386**;
- source-only/full-logit correlation: **0.903827**;
- source-only logit variance: 6.601716 versus full-score variance 7.152151;
- the remaining post-or-mixed component has AUC 0.720895.

Thus most of the spectacular held prediction is available from the same
source-side variables that helped define membership. Whole-folio prediction
does not turn this into an independent downstream consequence. The result is
`UNIDENTIFIABLE_DEFINITION_OVERLAP`, not a transferred operator class.

The exact corrective design is now clear: a future comparator must define the
anonymous outcome solely from post-pivot transformation, or residualize it
against every source-side topology feature before thresholding. Prediction
must then use a disjoint source-side feature set. That correction must be
frozen and comparator-validated before another Voynich score; GDT381 itself may
not be repaired post hoc.

## Claim ceiling

GDT381 supports one cross-domain **readable-comparator** relation-topology
instrument. It does not establish a Voynich coordination class, AND, OR, NOT,
UNTIL, POS, meaning, language, plaintext, or translation. Exact formal
realizations were not inspected. f84 remained sealed.
