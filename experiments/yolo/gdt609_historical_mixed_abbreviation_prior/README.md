# GDT609 — historical mixed-abbreviation prior

Status: HISTORICAL_MIXED_ABBREVIATION_FST_34_V1_SELECTED.

The best historically grounded architecture for GDT608 is a common
late-medieval abbreviation finite-state transducer with a small
medical/recipe overlay: literal and syllabic carriers, bound prefix/suffix and
context marks, connectors, few whole forms and at most one null/layout slot.

The exact 34-slot prior is 18 literal + 4 syllabic + 3 prefix + 3 suffix + 2
connector + 2 context + 1 whole-form + 1 optional null. It is a decoder prior,
not a recovered historical key.

See REPORT.md for the source comparison and artifacts/model_v1.json for the
executable capacity contract.
