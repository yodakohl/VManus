# GDT1157 — cross-situational visual predictors of whole-word presence

Local preregistration before new scoring. This is a fixed development test on an already exposed and historically selected image roster and word inventory, not independent confirmation. Primary representation: ZL3b only. No new images or manuscript transcription, no reserved material, no alternate-reader replication claim. No word meanings assigned.

Decision note: GDT1089/1090 constrain an image-selected local coincidence; the absence of an authorial pointer does not logically forbid cross-situational learning. Here page-level visual evidence must improve prediction of a fixed whole-word's presence across excluded physical leaves, beyond both a background model and a fixed generic visual-count competitor. Positive yields only a feature-compatible whole-word lead requiring further interpretation, not an authorial owner, organ name or translation. Negative closes this fixed model, not cross-situational learning generally. Generic COUNT is one limited competitor, not all generic bottlenecks. Roster/word selection and previous exposure prevent project-wide significance claims. Budget90minutes including preparation, implementation, independent validation and publication; no automatic model repair.

Inputs:38 existing GDT1089 image pages and both frozen observers' six YES/NO/UNKNOWN codes; all169 rows of GDT1090 ALL_WORDS with word presence from image_folio_ids only. Historical union_yes/all_image_yes/yes_folio_ids and other outcome columns are ignored. Whole-form inventory is copied exactly, not normalized or newly selected. Page metadata derives only from admitted915 cache metadata, pinned with the roster and prior inputs. All38 pages share H/A/1 metadata in the inspected cache; the specified general hand×Currier adjustment is retained. No content/word frequencies or visual intersections inspected during this registration's schema check. f84/f84r sealed, f116v unadmitted, reserves closed.

Rows lexicographically sorted page selectors; physical leaf is integer folio number, so r/v are jointly excluded. All169 words scored in every outer leave-physical-leaf-out fold. Baseline fitted on outer training pages: global word probability g=(present_pages+.5)/(training_pages+1); stratum(hand,Currier) p=(present_stratum+10*g)/(pages_stratum+10). Use same p in all model arms. Training baseline probabilities include each training label in the fitted counts; this fixed self-fit is disclosed and identically applied in every permutation. Test labels never fitted. Score mean page log2 probability within held leaf, then equal mean over all outer held leaves.

Six features, in this exact order: HORIZONTAL_BEADS, BASAL_SWOLLEN_BRANCHES, RADIATE_HEAD, SPINY_ROUND_HEAD, BROAD_PETAL_FLOWER, MULTI_UNIT_SPIKE. A page/feature is definite only if both observers agree YES or both agree NO. Disagreement or either UNKNOWN is unknown. The64 binary states are lexicographic itertools.product([0,1],repeat=6).

In each outer training fold, only training rows whose six features are all definite contribute state counts. Add a joint Dirichlet total mass1, i.e.1/64 to each state. For every training and test row condition this joint distribution on that row's definite mask. Thus uncertain feature and COUNT distributions preserve learned joint correlations; never use independent Bernoulli or Poisson-binomial uncertainty. COUNT is the sum of all six latent bits. For each feature and COUNT compute training expected mean and variance including latent-state variance: mean over training pages of E[X], variance=mean E[X²]-mean². Standardize every latent value with those fixed training quantities. Variance<=1e-12 permits only beta0.

Visual model per feature j: predicted probability E_state sigmoid(logit(p)+beta*z_j(state)). Generic COUNT substitutes standardized latent count. Fixed beta grid[-4,-2,-1,-.5,-.25,0,.25,.5,1,2,4]. Fit beta by sum of training-page natural-log likelihood minus beta²/2. No hyperparameter search. Betas tied within absolute objective tolerance1e-12: prefer0, then smaller absolute value, then numerically smaller beta. A feature is eligible only if outer training has definiteYES on>=2 different physical leaves AND definiteNO on>=2 different leaves. Word capacity additionally requires presence on>=2 training leaves; otherwise BOTH visual and COUNT arms are background. COUNT needs word capacity and its own nonzero variance but does not require any individual feature eligibility.

Compare the six eligible feature models with one separate beta0 background model, equal feature prior with no further feature preference or penalty. Keep ALL feature/background models within1e-12 of maximum objective. Their held predictions are equal-weight mean probabilities, including background if tied. If several beta0 feature models tie background, preserve all aliases; their identical predictions are harmless, but uniqueness fails. Generic COUNT independently selects its beta using the same grid/penalty/tie rule.

For each word report equal-leaf OOF gain over background and equal-leaf OOF gain over COUNT. Candidate w,j requires both gains>=.01bits/leaf, >=80percent of ALL outer folds uniquely selecting the SAME feature j with positive beta, and word-present pages with observers' definiteYES for j on>=3 distinct physical leaves. Ineligible folds and feature/background ties count as failure, not omitted denominator. Statistic T_w=min(the two gains) only when these gates pass; otherwise unavailable (-infinity mathematically, encoded null with gate reasons). Keep all169 candidate rows, every observed fold choice and page prediction, all failures and feature aliases. No uniqueness claim from correlated/tied features.

Null:199 draws with replacement from one random.Random(1157). Group physical leaves by identical sorted signature of(face,hand,Currier) for their roster pages. Blocks/signatures lexicographic; leaf IDs sorted numerically. At each draw start each block's donor list in sorted leaf order and shuffle it, moving the complete six-code A/B image/uncertainty bundle jointly and preserving face positions. Text, page metadata and folds stay fixed. Refit the ENTIRE joint-state estimation, baseline/visual/COUNT pipeline, all selection and nomination gates in every world. Export all169 world candidate summaries and maximum T over nominated words; maximum0 when none. Primary rank for each observed nominated word=(1+number null maxima>=T_w)/200, inclusive1e-12 numerical-roundoff tolerance. Require rank<=.05 in addition to all gates. Do not adaptively deduplicate or extend the null schedule; report distinct raw and model-observable worlds.

Permutation capacity requires>=12 physical leaves that can receive a DIFFERENT model-observable bundle within their block AND at least100 distinct observable assignments. Observable bundle means six consensus ternary YES/NO/UNKNOWN values per roster face; raw observer disagreements that collapse to identical unknown masks do not artificially expand capacity. Observable orbit per block=n!/product(bundle_multiplicity!), multiply across blocks. A block with one observable bundle type supplies zero mobile leaves. Raw A/B codes still move together. Capacity failure suppresses all nominations, while diagnostics and fixed199 worlds remain reported.

Overall result: NO_CAPACITY if permutation capacity fails; otherwise FEATURE_COMPATIBLE_WORD_LEADS if at least one complete-gated word has rank<=.05; otherwise NO_SUPPORTED_VISUAL_WORD_LEAD.
