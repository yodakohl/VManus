## What a scribe's table would have to do

Source letters have fixed nonempty spellings of arbitrary finite length, and
several spellings may share an initial mark. Prefix freedom means that a whole
letter spelling is never the beginning of another: a reader can recognize each
letter without lookahead into an unknown longer code. Original source-word
boundaries coincide with the retained complete written groups. These are
hypotheses, not established properties of the physical writing or language.

If a complete word u is the beginning of another complete word u+r, decoding
the latter must finish the entire decoding of u at the same place. Therefore
r must also be a complete sequence of letter codes. Repeating this implication
forces19of the22working signs to be singleton codes:
a,ch,ckh,cth,d,e,f,i,k,l,m,n,o,p,r,s,sh,t,y.
The derived remainders are formal code sequences, not newly attested words.

All22signs begin some complete remainder, so all22heads need at least one
entry. A used longer code can therefore start only cfh,cph or q. Both cfh and
cph are followed by six different second signs among complete remainders.
A longer spelling beginning there cannot cover two different second signs,
so that head needs at least six entries, plus at least one for each of the
other21heads:27in total. The q alternative requires at least32entries in IT/ZL
and33in RF. There is no source-letter value or word meaning attached to these
formal heads. The stronger short-word predecessor bound happens not to improve
the direct-head count on this panel.
