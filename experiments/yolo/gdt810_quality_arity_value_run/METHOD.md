of the GDT631 179-selector allow-list. Query ZL3b lines and cross-reader lines
once each. Every exact head receives a maximal immediately following run of
dan/dain/daiin/daiiin and the next stopping word or LINE_END.

An alternate reader supports a row only if its total count of the exact head
equals ZL3b's and the same occurrence rank has the same value run and next
stop. Readers are alternatives, not independent manuscripts. Arity is an
inherited meaning hypothesis, never an independently observed semantic feature.

Produce18 summaries: ALL, EXCLUDE_DISCOVERY_LOCUS, EXCLUDE_DISCOVERY_PAGE,
crossed with OL/OR and arities0/1/2. Eligible rows have reader_support3,
at least one following value and right_censored0. Compare external-page
OL arity2 versus arity1; retain all OR/zero controls. Counts cannot identify
numbers or qualities. Fused values, separately named qualities and cross-line
continuations are outside this exact-format test.

previously inspected text supplies no sealed visual-owner evidence.
An independent validator reconstructs events and summaries without importing
the builder. GDT809 and the larger renderer remain unchanged.
