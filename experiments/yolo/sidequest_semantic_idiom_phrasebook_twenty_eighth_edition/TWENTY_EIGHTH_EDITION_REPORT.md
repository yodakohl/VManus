# Achtundzwanzigste Ausgabe: wiederkehrende Werkstattwendungen

Die Übersetzung besitzt nun eine Phrasebene zwischen Karte und Satz.
Siebzehn wiederkehrende Kartenfolgen und siebzehn wiederkehrende Folgen von
Handlungsköpfen erhalten eine kurze, einheitliche Aussprache. Beispiele sind
„den aktuellen Posten auf Sollmaß setzen“, „danach im selben Gang weiter“,
„umsetzen, länger ansetzen und schließen“ sowie „ansetzen und absetzen lassen“.

Nur Folgen, die in mindestens zwei Records vorkommen, stehen im Phrasebuch.
Die Wendung ersetzt keine Karte und darf überlappen; sie macht eine bereits
vorhandene Komposition sprechbar. Eine vollständige Auftretenstabelle bindet
jede Wendung an ihre echten Oberflächen und Aussagen, und ein 116-zeiliger
Index zeigt, wo eine Aussage solche Wendungen enthält.

Damit nähert sich das Modell einer realen Werkstattlehre: Der Lehrling merkt
sich einzelne Zeichen, produktive Kerne und eine kleine Zahl häufig gesprochener
Arbeitswendungen—nicht 381 isolierte deutsche Mikrosätze.
