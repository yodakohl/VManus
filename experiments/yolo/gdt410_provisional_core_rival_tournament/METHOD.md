# GDT410 method

## Question

Which of the ten GDT409 provisional verbs or relations can retain one short
working value when read inside complete statements from every running
register, and which still have a genuinely competitive rival?

## Inputs

GDT407's 715-statement and 5,051-attachment unified editions, the GDT405
46-atom dictionary, and GDT409's nineteen-core dictionary and occurrence
audit. No new manuscript page, image, transcription, or root is admitted.

## Method

For each target core, collect its positional and complement profile over all
4,576 running events: occurrences, pages, registers, first/middle/last
position, governed argument/grade/relation focuses, and—where relevant—the
action heads governed by a relation. Score one selected short value and two
concrete rivals on four deliberately simple 0–3 dimensions: role fit,
cross-register fit, atomic brevity, and resistance to local overfit.

Then choose one real complete statement containing the core in each of the
five registers and render the same recipe three times with only that value
changed. This produces fifty directly comparable statement triptychs. All
other roots retain the GDT409 values.

## Decision rule and claim ceiling

A value is promoted from `KEEP_PROVISIONAL` to `KEEP` only when the selected
candidate beats both rivals, has a useful complement-profile explanation, and
does not smuggle a page-local material or object into the portable core. A tie
or one-point margin stays provisional. The scores order explicit working
hypotheses; they do not confirm German lexemes, plaintext, language, or a
historical source.
