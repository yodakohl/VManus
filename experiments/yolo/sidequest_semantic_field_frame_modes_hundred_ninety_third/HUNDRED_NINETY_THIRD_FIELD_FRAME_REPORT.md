# Hundred-ninety-third pass: field-frame concord

## New working idea

The remaining surface variants are not all personal handwriting. Some fields
put several unrelated exact cards into the same initial frame. I therefore read
q-, s-, d-, ch- and o- as a small field-mode layer laid over learned cards.

Among 135 fields, 20 contain at least two variable-card occurrences and a
repeated dominant frame. They contain 74 diagnostic occurrences, 46 aligned to
the local mode:

| mode | fields | closed | working reading |
|---|---:|---:|---|
| CH | 5 | 1 | build or prepare the base item |
| D | 1 | 0 | resume/take over from the prior item |
| O | 4 | 3 | continue within the active preparation |
| Q | 5 | 2 | activate a particular substep |
| S/SH | 4 | 3 | state, result or secondary branch |
| unframed | 1 | 0 | bare item/parameter field |

The closure pattern is useful for the scribe model. CH fields are usually open
construction fields; O and S fields usually finish a cell. Q sits between them
as an executable instruction mode. This is exactly more economical than giving
`saiin`, `shcthy`, `sy`, `sol`, `qol` and every sibling a separate lexical
meaning.

## Concrete examples

- H3 F008 is the only strong D field: `dchol chy kchy dy daiin`. It reads as a
  carried/resumed item with its current treatment and measure, and stays open.
- B1 F022 is an O field with five O-framed variable cards: an extended ongoing
  preparation/transfer clause.
- B1 F038 is a Q field: `qokal okeey qol cheedy`, an activated target step that
  closes.
- B3 F092–F093 form the richest S passage. Across the two fields the scribe uses
  `shcthy`, `sy`, `saiin`, `shedal`, `shecthy`, then closes the second field.
  These are best read as a state/result or secondary-path register, not six new
  s-words.

## Limits that help the model

Eighty-two fields have fewer than two variable-card events and cannot announce
a frame concord. Thirty-three are genuinely mixed. The rule is therefore an
optional workshop device, not obligatory agreement on every word. A restart
inside a field may also switch mode.

## Consequence

The notation now looks more like a mixed medieval technical register:

`FIELD MODE + learned card body + positional grade/target/close`.

The next forward-writing test should compose a fresh multi-field instruction
with deliberately chosen CH, D, O, Q and S modes, then render several compatible
cards from each mode. If another scribe can read back the same card values and
field intent, the frame layer is teachable rather than post-hoc decoration.
