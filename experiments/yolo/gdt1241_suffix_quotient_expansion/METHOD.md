# Mathematical consequence and scope

If C is suffix-free, its reverse rho(C) is prefix-free. Reversal here acts on
whole working units: rho((ch,a))=(a,ch), not (a,h,c). Every u in C* ends at a
code boundary. If u and r u are both in C*, end-first uniqueness cancels the
same terminal code sequence, so r is in C*. This does not hold for arbitrary
uniquely decodable codes: C={a,ba} is prefix-free but not suffix-free; a and
ba are in C*, b is not. Conversely {a,ab} is suffix-free, so a,ab do not
license the LEFT quotient b. Direction is a substantive premise.

Starting from complete original groups, repeatedly add nonempty r when
u and r u are already present. Every result is a prefix of an original group,
so closure is finite. A length-one element (g) in C* requires g itself in C,
because all codes are nonempty. If all used signs are forced, no used longer
code can be suffix-free: its last unit already is a code. This permits the
ordinary singleton identity code and any assignment of source expansions;
it rules out used multi-unit entries in this exact class, not meaningfulness.

If k,e,s are forced, keeees has the unique code sequence k|e|e|e|e|s.
A homomorphism with fixed nonempty literal expansions gives X U U U U Y,
with nonempty X,U,Y. Equal expansions/aliases do not avoid this condition.
The five fixed1240source populations contain no such word; this old result
is an input, not a newly counted outcome. Any reader for which the exact
premises hold excludes each of these five whole-word source contracts.
Without those premises, no such exclusion is claimed. No assumption of
one-source-letter expansion or maximum code-table size is used.

The runner applies the existing frozen left-closure engine to reversed unit
tuples. The validator independently saturates original tuples with direct
right cuts and verifies every proof edge. Compact proof leaves include all
original occurrence IDs and counts, without silently replacing weak proofs
by a favorable one. Same-author software validation is not independent
palaeography. All original readings remain separate alternate readings of
one manuscript; they are not three independent historical documents.
