# GDT445 — Prospektives Aufnahmezertifikat

Ein einziger ausführbarer Leser bündelt die bisher getrennten Wege für eine
sichtbar vorgelegte Komponentenfolge:

1. exakter Katalogschlüssel;
2. neue Komposition alter Faktoren;
3. Schluss mit geerbtem Handlungskopf;
4. zwei durch einen sichtbaren Fokus getrennte Handlungen;
5. benannter, zustandssicherer Stopp.

Build und Prüfung:

```bash
python3 experiments/yolo/gdt445_prospective_intake_certificate/src/run.py
python3 experiments/yolo/gdt445_prospective_intake_certificate/src/validate.py
```

Einzelne sichtbare Folge zertifizieren:

```bash
python3 experiments/yolo/gdt445_prospective_intake_certificate/src/intake_certificate.py \
  --recipe CHD+Y+K
```

Der Befehl nimmt eine bereits sichtbare Segmentierung entgegen. Er erzeugt
weder eine Voynich-Oberfläche noch ein erwartetes Vorkommen.
