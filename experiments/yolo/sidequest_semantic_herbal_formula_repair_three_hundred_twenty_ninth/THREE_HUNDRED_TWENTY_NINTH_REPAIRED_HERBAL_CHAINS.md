# Reparierte Herbal-Kartenketten

## Was gestrichen wurde

Die folgenden alten Inhalte waren nicht aus ihren angegebenen Komponenten
ableitbar und werden zurückgezogen:

- `CHO+AIIN` ist nicht **Geschwür**, sondern **Zutatsollmaß**.
- `K+Y` ist nicht **Trank**, sondern **Bindeposten**.
- `CHO+AL+Y` ist nicht **Blütebeginn**, sondern **Zutatstelle**.
- `K+OL` ist nicht **Auflegen**, sondern **Bindefortsetzung**.
- `CHO+Y` ist nicht **Waschen**, sondern **Zutatposten**.
- `K+E+Y` ist nicht **Grobzerreiben**, sondern **Kurzbindeposten**.
- `K+AL` ist nicht **Abseihen**, sondern **Zielbindung**.
- `K+CHO+AR` ist nicht **Gebrauchsauszug**, sondern
  **Quellenzutatbindung**.
- `OT+Y` ist **Folgeposten**, nicht „zurückbehaltene Blüten“.
- `OL+TCH+Y` ist **Fortsetzungszubereitung**, nicht Anwärmen; Wärme braucht
  den CHK-Kern.

## Die fünf Artikel als reine Kartenketten

### H1 / f10r

```text
Wurzelteil → Bereitansatz → Quelle → Zerkleinern → Gefäß → Wasserzulauf
→ Folgeteilfortsetzung → Einsetzen → Sollmaß → Kurzrest

Einsetzen → Folgefortsetzung → Fortsetzung → Bereit
```

### H2 / f10r

```text
Auszugsansatz → Bereit → Ansatz → Bereitsollmaß
→ Folgefortsetzungsposten → Diesposten → Diesposten → Sollmaß → Diesposten

Folgeansatz → Ansatz → Folgefortsetzung → Fortsetzung
→ Fortsetzungsansatz → Fortsetzung → Sollmaß → Quelle

Gefäßansatz → Ansatz → Ansatz → Diesposten → Bindestufe
→ Diesposten → Zutatsollmaß
```

### H3 / f11r

```text
Blütenkraut → Zieleingabe → Auswringen → Standzeit → Nachseihen
→ Klarauszug → Rücknahmeschluss

Zutatfolgeteil

Vorfortsetzung → Diesposten → Bindeposten → Diesposten → Sollmaß

Folgeposten → Fortsetzungseinsatz → Bereit → Diesposten
```

### H4 / f55v

```text
Sollstellung → Sollmaß → Postenportion → Postenzweitportion → Rücknahmeschluss

Sollmaß → Umsetzen → Verwahren

Postensollmaß → Auszugnahme → Langwärme → Fortschluss

Sollmaß → Zieleinsatz → Fortsetzungszubereitung → Ansatz
→ Diesposten → Ansatzportion
```

### H5 / f56r

```text
Zutatenansatz → Zutat → Zutatstelle → Sollmaß → Zutat
→ Bindefortsetzung → Folgeansatz → Einsetzen → Stelle

Vorfortsetzung → Zutatposten → Einsetzen → Auftragsschluss

Pflanzenteil → Zutat → Kurzbindeposten → Wiedereinsatz

Einsetzen → Auszugzugabe → Zielbindung

Zutat → Einsetzen → Quellenzutatbindung → Gebrauch

Folgeposten → Kurzbindefortsetzung → Sollmaß
```

Die Ketten sind absichtlich knapper als flüssige deutsche Sätze. Im nächsten
Pass werden sie wieder in konkrete Werkstattanweisungen expandiert – diesmal
ohne Inhalte, die im Wörterbuch nicht vorkommen.
