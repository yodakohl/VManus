# Pass 405 — B3-S021 als zweiphasige Übergabe

Miss die erste Badeportion ab, prüfe, ob sie bereit ist, und bringe diesen
Posten an die erste bezeichnete Stelle. Übergib ihn danach an die zweite
Arbeitsphase: miss ihn dort erneut, lass ihn an der Absetzstelle stehen und
bringe ihn auf den temperierten Zustand. Nimm diese Portion wieder auf, bringe
sie an die zweite bezeichnete Stelle, prüfe die Bereitschaft und schließe die
örtliche Umsetzung ab.

```text
Phase A: SOLLMASS → BEREIT → ZIEL A → DIESER POSTEN
                                      │ Zeilenübergabe
Phase B: SOLLMASS → ABSETZSTELLE → TEMPERIERT → DIESER POSTEN → ZIEL B → BEREIT → SCHLUSS
```

Die Badefassung ist der aktuelle konkrete Favorit, weil f83r Menschen in
Gefäßen zeigt. Eine technische Gefäßfassung liest dieselben Karten als
Vorratsgefäß → Absetzgefäß → Empfänger. Die Textstelle liegt jedoch in einer
sichtbar unverbundenen Lücke; weder Pfeil noch Rohr erlaubt, die beiden Phasen
einem bestimmten gezeichneten Beckenpaar zuzuweisen.
