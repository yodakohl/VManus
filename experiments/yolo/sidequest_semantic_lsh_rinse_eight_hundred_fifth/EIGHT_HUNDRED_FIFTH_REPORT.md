# Sidequest Pass 805: LSH is the rinse root

All three `LSH` events occur at the shared two-row basin on f81v. The old value
`WASCHEN` works, but it hides a sharper composition:

- `lsho = LSH+O` reads naturally as **SPÜLVORGANG**;
- `lshedy = LSH+E+DY` reads as **kurz spülen; Schluss**.

`AUSWASCHEN` would additionally claim that material is extracted from a
substrate, which neither card requires. `SPÜLEN` is therefore the smallest
value that works as both the first member of a process noun and as an
imperative verb.

The complete f81v sequence becomes:

> Einen Spülvorgang ausführen, den Posten kurz ansetzen, nochmals kurz spülen
> und den Schritt schließen.

The single-card follow-up simply says:

> Kurz spülen und den Schritt schließen.

five unused cells in the existing E/EE/EEE × Y/DY grid (`lshey`, `lsheey`,
`lsheeey`, `lsheedy`, `lsheeedy`); none collides with a fixed-page surface.
