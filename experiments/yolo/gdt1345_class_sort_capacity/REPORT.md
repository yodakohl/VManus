## Why this excludes all smaller class counts

If two distinct signs belong to the same sorted class, their relative order
must be the same in every whole group. Finding both orders forces them into
different classes. A set of ten signs with both orders witnessed for EVERYpair
therefore needs ten different classes, irrespective of the chosen sign values,
source language, vocabulary, source class mask or arbitrary interleaving pattern.

For example the recurrent ZL panel has a-before-l in otal at f100r.14 G009 and
l-before-a in choldaiin at f100r.22 G002. Similarly cheky at f100r.25 G007 contains
e-before-k, while qokeey at f100r.13 G003 contains k-before-e. The exact complete
source records and positions are retained, with counts of forms and physical
leaves for every directed constraint. These are order witnesses, not word meanings.

The ZL recurrent ten-sign complete conflict set is:

    a ch d e k l o s sh y

All45pairs have both orders. IT has a different ten-sign certificate, RF eleven;
no pooled graph manufactures the bound. Full panels supply complete conflict
sets of14/15/15signs. Every such clique is a short, independently checkable
impossibility certificate for every smaller number of classes.

A clique ordinarily supplies only a LOWERbound. Directed cycles longer than two
could require more classes even when no pair conflicts. Here a separate explicit
partition with exactly the bound's number of classes is supplied for each panel;
each class has a topological order replayed against EVERYretained whole group.
Matching lower and upper bounds establish the exact minimum for this output-order
condition. The arbitrary constructed partitions are capacity witnesses, NOT actual
Voynich classes, a source alphabet, sound values, semantics or a historical writer.

## Scope and research consequence

Stop searches over up to9fixed sorted tracks under this contract; neither a
larger key search nor a new source language can help. Under the complete strict
panels the exclusion extends through13classes in ZL and14in IT/RF. At least one
fixed class per sign always permits any text, so the broad category of sorting
cannot be rejected without a class-count bound. The exact minimum shows where
this particular test ceases to discriminate; it is not a recommendation to add
14or15classes as a repair.

The mechanism sorts distinct signs within each class while permitting arbitrary
interleaving and repeated visits to classes. Ascending/descending choices per
class are covered by arbitrary fixed orders. A global bijective relabeling or
global reversal preserves the necessary conflict graph. Equal ranks, per-word or
per-page classes/orders, overlapping sign memberships, changed physical units,
changed complete-group boundaries and exception allowances are outside the test.
Ordinary spelling/morphology does not require this within-class sorting and is
not excluded. No native alphabet has been established. Distinct order roles
could be encoded by a different representation; no such repair is selected here.

GDT1263 instead orders weak CLASSranks through whole groups; GDT1321 forbids
returning to a class. Their old certificates cannot establish this result.
