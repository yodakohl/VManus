# GDT1358 — Word-reordering orbit envelopes

See REPORT.md and PREREGISTRATION.md. From this directory run:
`python src/run.py --controls`, `python src/validate.py --controls`,
`python src/run.py`, `python src/validate.py`. Standard Python3 only.
The test grants arbitrary fixed whole-word base spellings and unconstrained
ordering variants. It checks necessary frequency bounds, not a full decoder.
