# GDT610 method

## Question

Can explicit agreement between six independently initialized carrier maps
recover a stable mixed-codebook key, and does that stability produce any
concrete non-injected held text?

## Inputs and correction

The canonical input is GDT606's published 98-unit sequence artifact. The
original computation used an earlier scratch copy with an obsolete schema
label; deleting that one inert field makes the two complete JSON payloads
identical. GDT610 binds the canonical published hash and source code.

The language references are the same hash-pinned Latin, Old Italian and Middle
High German corpora used by GDT604/GDT606.

## Decoder

The fixed inventory has 42 letter, 4 double-letter, 34 syllable, 7 null and 11
whole-word carriers. Six leave-one-folio-block views optimize character
4-gram typicality, word-length likelihood and explicit codebook description
cost. A coupling reward favors exact carrier-map agreement.

The coupling grid 0, .03, .10, .30 and 1.00 is selected on a planted Latin
control with the exact target chunk-length sequence and nearly identical
rank-frequency form. The selected .10 weight is then applied unchanged to all
three target languages.

## Concrete-output audit

Every exact reference fragment is separated into:

- direct whole-word candidate injection;
- a span containing any injected whole-word candidate;
- a span composed entirely from non-W carriers.

Only the last class can supply new lexical evidence. The compact table retains
all eight surviving rows.

## Decision

Consensus is rejected as an identifying signal because all 11/11 control W
keys are stable and wrong, control held character recovery is 33.7%, and
target syllable stability is only 1/34, 0/34 and 2/34. No concrete target word
or passage survives the non-W audit.

This result removes one decoder mechanism. It assigns no Voynich sound, word,
language, plaintext, object or meaning and does not access f84/f84r.
