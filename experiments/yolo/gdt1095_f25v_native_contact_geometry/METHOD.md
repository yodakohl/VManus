# Method

Use the unchanged official Yale source. Native root inspection is informed,
not blind. View the complete3000px page before the preregistered lower-right
region. Record all five judgments in src/OBSERVED.json. run.py reproduces only
the decision and table from those judgments and the source receipts; it does
not decide pixels. validate.py independently checks the fixed roster, sealed
scope, result and optional image hashes. No target word assignment or new
relation-scoring packet is produced. PREREGISTRATION.md owns the exact limits.
