# GDT757 — initial formula role atlas

Status: `PARTIAL__11_COMPLETE_FORMULA_WHOLES__79_INITIAL_LINES__PCHOR_RECIPE_OPEN_6_OF7_PARAGRAPH_START__YCHOR_ITEM_0_OF13_START__YCHEOL_YCHOL_DCHEOL_YCHEOR_FAMILY_1_OF26_START_9_OF26_END__4_LOW_PURITY_CONTROLS_NOT_PROMOTED__ZERO_CONFIRMED_LEXEMES__NO_NEW_PAGE`

GDT757 turns the eleven high-triad, high-line-initial-purity complete forms from
GDT756 into a concrete formula inventory. The main working split is:

```text
pchor   → nimm                       paragraph/rezept opening
ychor   → ferner / ebenso            Item-like continuation
ycheol  → danach                     internal continuation
ychol   → danach / als Nächstes       internal continuation
dcheol  → danach / darauf             internal continuation
ycheor  → zum Schluss                closure
```

All eleven wholes receive a primary candidate, two rivals, confidence,
evidence and counterevidence. These are replaceable whole-form hypotheses, not
confirmed words. The complete German-marker/EVA-body reader is
`artifacts/GDT757_FORMULA_ROLE_READER.md`.

Reproduce with:

```bash
python3 experiments/yolo/gdt757_initial_formula_role_atlas/src/run.py
python3 experiments/yolo/gdt757_initial_formula_role_atlas/src/validate.py
```
