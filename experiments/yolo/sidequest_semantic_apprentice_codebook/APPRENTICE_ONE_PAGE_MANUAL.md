# Einseitiges Lehrlings-Codebuch

## 1. Drei Zeichenklassen

- `P`: aus bekannten Bauteilen zusammensetzen.
- `p`: bekannten Bauteil lesen, kleinen lokalen Traeger auswendig kennen.
- `W`: exakte Ganzkarte in der folgenden Liste nachschlagen.

## 2. Satzgang

```text
BILDBESITZER
-> QUELLE / ZUTAT / ANSATZ
-> PORTION / SOLLMASS
-> ZIEL / FOLGE / FORTSETZUNG
-> BEARBEITEN / UMSETZEN / DURCHLEITEN / SAMMELN
-> KURZ / LAENGER / VOLL / BEREIT
-> optionale exakte SCHLUSSKARTE
```

Eine physische Zeile beendet den Satz nicht automatisch. Der aktive Posten kann in die naechste Zeile weitergetragen werden.

## 3. Die sechzehn gelernten Kopfwoerter

| Nr. | Kopfwort | sichtbare Karten | Variantenregel |
|---|---|---|---|
| W01_ZUSATZ | ZUSATZ | `dl` | allgemeiner Zusatz |
| W02_GEFAESS | GEFAESS | `os;ly;oykchor` | allgemein | Empfaenger | Zubereitungsgefaess |
| W03_KUEHLEN | KUEHLEN | `tchody;ody` | fertiger Klarauszug | abgemessene Portion |
| W04_ROH | ROH | `qekey` | unbehandelter Ausgangsposten |
| W05_TUCH | TUCH | `dain` | allgemeines Arbeitstuch |
| W06_SCHWENKEN | SCHWENKEN | `sshkchdy` | einmal schwenken oder bewegen |
| W07_PFLANZENTEIL | PFLANZENTEIL | `dchey;sh` | Wurzel | Staengel |
| W08_WASCHEN | WASCHEN | `rshedy;lkedy` | Waschgang | nachwaschen |
| W09_AUFTRAGEN | AUFTRAGEN | `cheeckhody` | bereiteten Posten auftragen |
| W10_FUELLEN | FUELLEN | `ytey` | aktives Gefaess oder Station fuellen |
| W11_KLARLAUF | KLARLAUF | `cheey|shey` | klarer Ablauf oder Klarauszug |
| W12_TRENNEN | TRENNEN | `cfhy;cphy` | auswringen | nachseihen |
| W13_FRISCHWASSER | FRISCHWASSER | `dshedy` | Frischwasser zugeben und schliessen |
| W14_VORIGES | VORIGES | `dchol|schol` | vorigen Posten wiederaufnehmen |
| W15_TEILEN | TEILEN | `ches` | aktuellen Posten teilen |
| W16_BEFESTIGEN | BEFESTIGEN | `qokylddy` | aktuellen Posten befestigen und schliessen |

## 4. Kopierregel

1. Lies zuerst Bildbesitzer und laufenden Posten.
2. Setze alle `P`-Karten aus dem Bauteilkasten.
3. Bei `p` schreibe den bekannten Kern und nimm den lokalen Traeger aus dem Muster.
4. Schlage nur `W` in der 22-Karten-Liste nach.
5. Kopiere eine terminale Ganzkarte als unteilbaren Schlussbefehl.
6. Lies die gesamte Arbeitsfolge rueckwaerts; kein Kartenwert darf sich dabei aendern.

## 5. Merksatz

> Bauteile werden gelesen; Ganzkarten werden erkannt; das Bild liefert den Gegenstand.
