# GDT508 — Auch Source `CH+CH` hat eine lokale Paketbrücke

Status: `SOURCE_CHCH_GAINS_LOCAL_REPEATED_PACKAGE_BRIDGE__ALL_FOUR_CONTEXT_TARGETS_HAVE_LOCAL_SUPPORT`

## Ergebnis

GDT507 ließ nur einen Unterschied stehen: Source `CH+CH` hatte konkrete
Kontextträger, aber nicht im eigenen Register. GDT508 findet keine nackte
Source-Karte `CH+CH`; es findet jedoch zwei lokale Wiederholungen eines
CH-tragenden Pakets auf demselben geerbten Argument.

Die stärkste ist unmittelbar und exakt:

- `G407-E0019→G407-E0020`;
- gleiche Seite, gleicher Satz, gleicher Besitzer;
- zweimal dieselbe Oberfläche `cthar`;
- zweimal dasselbe Rezept `CH+T+AR`;
- zweimal dieselbe vollständige deutsche Arbeitsklausel;
- beide Karten erben `AIIN`.

> Entnimm den Kennwert [wie zuvor] und lege den Kennwert [wie zuvor] fest; von
> der Ausgangszeile. Entnimm den Kennwert [wie zuvor] und lege den Kennwert
> [wie zuvor] fest; von der Ausgangszeile.

Für die Paketprojektion bleibt aus jeder Hälfte genau `CH`; der identische
`T+AR`-Rahmen wird sichtbar nicht übertragen. Zwei erhaltene CH-Slots ergeben
genau die schon seit GDT500 feste, rückführbare Arbeitsphrase:

> Entnimm das zuvor Genannte zweimal.

## Zweite lokale Folge

`G407-E0187→G407-E0188→G407-E0189` liefert eine zweite Form. Die äußeren
Karten teilen `CH+T+OL`, erben beide `AIIN`, und die mittlere sichtbare
`AIIN`-Karte setzt dasselbe Argument ausdrücklich fort. Rechts kommen nur
`D_ADDR+AR` hinzu. Diese Folge ist keine exakte Doppelkarte, bestätigt aber,
dass ein CH-tragendes Source-Paket auf demselben Argument erneut angesetzt
werden kann.

## Neue Einordnung

Source `CH+CH` wechselt von
`B_CROSS_REGISTER_WITHIN_AND_ADJACENT_CONTEXT_BRIDGE` zu
`LOCAL_REPEATED_PACKAGE_CANCELLATION_PLUS_CROSS_REGISTER_DIRECT_PAIR`. Damit
haben alle vier GDT507-Kontextziele irgendeine lokale Unterstützung im
Zielregister:

- drei auf direkter bzw. unmittelbar benachbarter Kontextebene;
- Source `CH+CH` auf der schwächeren, aber konkreten Paketwiederholungsebene.

Das ist bewusst keine Beobachtung des nackten Zielrezepts. Keine Karte wird
aus dem Manuskript gelöscht; die vier entfernten Rahmenlisten sind nur die
explizite Vergleichsdifferenz. Phrase, zwei Handlungsslots, Wurzelwerte,
Evidenzklasse, Oberflächen und Vorkünfte bleiben unverändert. Der unabhängige
Validator besteht 113/113 Prüfungen.

## Nächster Arbeitsgriff

Die elf schwachen Paarziele besitzen nun für jedes Problem eine konkrete alte
Mechanik. Der nächste Pass sollte sie zu einer einzigen kompakten
Elf-Karten-Ausgabe zusammenziehen und die bisher verteilten Labels
`argument-compatible`, `context-bridged` und `local-package-bridged` in eine
einheitliche Lesestärke übersetzen. Keine neue Seite und keine neue Bedeutung
wird dafür benötigt.
