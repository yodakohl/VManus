# GDT508 method

## Question

Does the final cross-register target, Source `CH+CH`, have a local contextual
analogue at the repeated-package level when zero or one visible intervening
card is allowed?

## Inputs

- GDT413's fixed component dictionary;
- GDT416's complete ordered clause stream;
- GDT425's factorized action replay;
- GDT436's live owner-state replay;
- GDT500's fixed reversible `zweimal` card;
- GDT507's four contextual bridge cards.

## Method

Within Source only, compare endpoint cards separated by zero or one card.
Retain a pair when both endpoints:

- lie in the same statement, page and owner;
- have the same explicit action sequence, beginning with exactly one `CH`;
- state no argument and inherit the same nonempty argument;
- remain executable through GDT425 and preserve that argument in GDT436.

For every retained endpoint, keep its single `CH` and list every removed
action/relation/address atom explicitly. The two retained `CH` slots are then
compared with GDT500's already fixed, reversible Source `CH+CH` default. Exact
package duplication and shared-prefix extension remain separate evidence
types.

## Decision rule and claim ceiling

An exact duplicated local package on one inherited argument supplies the main
bridge. A one-gap shared-prefix repetition may corroborate it, provided the
middle card preserves or explicitly reasserts the same argument.

This licenses only `LOCAL_SOURCE_PACKAGE_LEVEL` support. It does not observe
the bare `CH+CH` target, delete atoms from the manuscript, or transfer the
removed package frames into the target. The phrase, two action slots, root
values, evidence class, surfaces and occurrence counts remain unchanged. f84
and f84r remain forbidden.
