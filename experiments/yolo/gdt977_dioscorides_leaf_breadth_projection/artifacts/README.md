# Reproducibility artifacts

SPEC gives every source-derived event and gap. CANDIDATE_RESULTS.tsv will cover
every old candidate; CASES.json.gz stores witness supports or exhaustion trees.
RESULT.json contains exact aggregate counts; VALIDATION.json checks certificates.
SOURCE_VALIDATION.json checks source-only structure and fixtures before fitting.
The one saved LEAF/BROAD witness per successful base row is not an exhaustive
lexicon. Source-unknown pages and capacity-limited readings retain their status.
