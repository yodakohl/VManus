# GDT517 — Thirty-page surface-recipe intake compiler

GDT517 turns a visible Voynich surface into ranked working recipes, supplies an
exact role-aware dictionary for all 5,866 current groups, and executes selected
prose without confusing local labels with action cards.

Start with [REPORT.md](REPORT.md), then the compact working book in
`artifacts/GDT517_COMPILER_WORKING_BOOK.md`. Rebuild with `python3 src/run.py`,
validate with `python3 src/validate.py`, or query one surface with
`python3 src/intake_surface.py --surface SURFACE`.
