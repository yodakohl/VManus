# Pass 406 — die mittlere Phase in kleinen Kartenwerten

Miss die übernommene Portion auf das Sollmaß. Halte sie an der Absetzstelle, bis
sie temperiert ist. Nimm diesen Posten wieder auf, bringe ihn an die bezeichnete
Stelle, prüfe seine Bereitschaft und schließe die örtliche Umsetzung ab.

```text
SAIIN      SHEDAL         SHECTHY      CHEY     TAL       SHCTHY   DALCHDY
Sollmaß → Absetzstelle → temperiert → dieser → Stelle → bereit → umsetzen/Schluss
```

`saiin` ist keine eigene Dauerkarte. Es ist eine Oberfläche derselben exakten
AIIN-Karte, die auf allen elf Prosa-Records als Sollmaß benutzt wird. `shedal`
ist die kleine Komposition SHED+AL, also Absetzen an einer Stelle. `shecthy`
bleibt eine gelernte Ganzkarte für den erreichten temperierten Zustand.

In der Badefassung ist das eine temperierte Badeportion. In der
Werkstattfassung ist es eine Charge, die im Absetzgefäß auf Arbeitstemperatur
kommt. Die Kartenwerte ändern sich zwischen beiden Fassungen nicht.
