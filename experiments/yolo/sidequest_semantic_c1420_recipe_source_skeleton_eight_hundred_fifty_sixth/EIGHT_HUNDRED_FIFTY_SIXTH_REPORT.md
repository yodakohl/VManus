# Sidequest Pass 856: ca. 1420 recipe-source skeleton

The six modern German commands now have a compact Latin-like formulary layer
and a mixed workshop shorthand layer. All fifteen semantic prompts survive
the shortening and select the same fifteen exact cards as before. This adds a
historically plausible source stage without claiming that Voynich is Latin,
German, English or Occitan.

The mechanism has close real analogues: [Wellcome MS.683](https://wellcomecollection.org/works/w6ne7k4t)
is a multi-hand North-East Italian Latin receptarium using short imperative
formulae; [MS.418](https://wellcomecollection.org/works/f6nzyzh4) combines
Latin and Langue d'Oc medicinal-water material; [MS.5262](https://wellcomecollection.org/works/nuckbt25)
is a first-quarter fifteenth-century English/Latin recipe collection with
direct vernacular instructions.

The working production chain is now: ordinary recipe intention -> shortened
semantic prompts -> shared exact cards -> scribe-specific registered surfaces.
