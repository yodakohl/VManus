# GDT578 method

## Question

Can GDT577's 60 renderer-ready interrupted-repeat groups be spoken naturally
inside one complete event-keyed edition, while preserving every written slot,
its selected head, raw modifier order and an exact GDT576 inverse?

## Inputs

GDT576 supplies the complete 5,122-event, 793-statement, thirty-page readable
edition and all 773 learned-sigla spans. GDT577 supplies 125 interrupted-repeat
slots, 62 group profiles and 59 event profiles. GDT575 supplies the disjoint
seventeen outer/inner scope pairs and all 96 duplicate groups. GDT568 supplies
the already used owner/action voices from which twenty short German action-head
nominals are taken.

No page, image, transcription, event, statement, recipe, atom, root value or
scope is added. Sealed f84 and f84r remain forbidden.

## Method

The one GDT577 conflict event, `G407-E1755`, is quarantined. The remaining 60
groups occupy 58 events because `G407-E0966` and `G407-E3605` each contain two
overlapping groups. The renderer therefore works once per event, never once per
group.

For each target event it retains GDT576's complete action/argument block. It
then walks the written recipe from left to right and rebuilds the modifier
trail:

1. each of the 121 repeat positions receives the exact GDT577 head identity;
2. the other 52 modifier positions remain unbound and in raw order;
3. the five topology cards decide whether the fragment belongs to a distinct
   action occurrence, brackets one head, sits on the same side of one head,
   continues an active context head, or belongs to the OL carrier; PRE/POST
   remains structural metadata and is not turned into process chronology;
4. later written slots receive one explicit editorial particle: `ebenfalls`
   for a parallel head, `erneut` for a return around the same head, `wieder`
   for D_ADDR/AR return, and `nochmals` for the sole third mention;
5. when the same action root occurs more than once, the head is called the
   first, second, third or fourth occurrence rather than merely repeating the
   action name.

The result stores 58 explicit source/target cards keyed by `event_id`. The
inverse never uses source text as its key: `G407-E1955` and `G407-E2638` have
byte-identical source clauses but remain distinct cards. Statements are rebuilt
only from their fixed event-ID sequences, and page membership is copied from
the source edition.

All root-expression, repeat-particle and learned-sigla spans are recomputed in
the new clauses. A particle is outside the root-expression span, so the German
word `erneut` cannot silently become part of E, O, D_ADDR or AR.

## Decision rule and claim ceiling

Pass only if all 5,122 event clauses and 793 statements reconstruct the GDT576
source byte-for-byte, all 121 written repeat slots occur once, all 173 modifier
fragments retain raw atom order, all 35 affected sigla spans are respanned, and
the conflict event, its statement and its page remain unchanged. The seventeen
outer/inner scope events and the three raw-adjacent relation-repeat events must
also remain outside this pass.

This is the current exploratory German working voice for the selected
attachments. The inherited E/EE/AR heads and exploratory O/D_ADDR heads remain
what GDT577 says they are. The pass adds no Voynich word meaning, pronunciation,
plaintext, language, syntax, genre, chronology or object identity.
