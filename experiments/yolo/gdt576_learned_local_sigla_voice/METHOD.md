# GDT576 method

## Question

Can the seven local-address atoms and five local variant/label atoms receive a
short, compositional workshop voice that removes GDT575's 31 different-root
surface collisions without inventing twelve long lexical meanings?

## Inputs

- GDT574's 5,122-event, 793-statement and thirty-page complete editions;
- GDT575's exhaustive 96-group repeated relation/modifier atlas.

No new page, surface, atom, recipe, boundary or portable root value enters the
experiment. Sealed f84/f84r remain forbidden.

## Method

The voice separates a common grammatical function from a learned technical
head. Four German frames are fixed:

| function frame | realization |
|---|---|
| feminine place | `an der {head}` |
| feminine place mark | `bei der {head}` |
| note/label | `beim {head}` |
| variant | `mit der {head}` |

Twelve atom cards fill the head slot: D-, A-, AM- and S-Stelle; f-Kennmarke;
m-Ortsmarke; d- and G-Vermerk; and i-, g-, b- and j-Variante. These strings
are learned analytical sigla. Their letters name the existing atom IDs and are
not asserted Voynich sounds, medieval abbreviations or decoded object names.

The compiler finds the existing generic address and variant phrases with
Unicode word boundaries and longest-first matching. Within each event their
occurrence order is aligned to the fixed recipe positions. The selected card
replaces only that phrase and carries any outer/inner suffix unchanged. Source
and target spans retain an exact inverse replacement.

All statements and pages are rebuilt from event order. Every one of GDT575's
31 different-root duplicate groups is then traced through its atom positions;
its new phrase list must be pairwise distinct.

## Decision rule and claim ceiling

Pass requires all 773 eligible atoms to receive exactly one card, zero generic
address/variant phrase to remain, all 31 different-root collisions to become
distinct, all source recipes/order/scopes to remain fixed, and all 5,122 GDT574
clauses to expand byte-exactly.

The result is a readable working codebook layer. It does not claim that the
analytical labels are manuscript pronunciations or plaintext lexemes.
