# GDT564 method

## Question

Which smallest practical context key selects the concrete owner-free
microphrase of GDT563's 101 recurrent context-variable recipes? Can one common
composition rule cover them without using owner, page or register as a hidden
whole-word dictionary?

## Input and scope

The sole source is GDT563's complete 1,656-row state-card edition. The pass uses
the same 30 admitted pages and does not open an image, transcription or surface.
The target phrase is the existing `owner_free_microphrase_de`; no phrase or root
value is revised here.

## Candidate selectors

For each of the 101 variable exact recipes, the compiler groups events under
ten candidate keys:

- recipe only;
- effective action;
- effective argument;
- effective action plus argument;
- resolution mode;
- microphrase source layer;
- statement position;
- register;
- physical page;
- page cohort.

A key resolves a recipe only when every observed selector cell contains exactly
one microphrase. Modal-hit counts are retained as a practical comparison, but a
partially correct key is not used to erase the remaining variants.

## Portable visible-slot rule

The primary selector is derived from written slots rather than selected
separately for every recipe:

1. A fixed observed recipe needs no context field.
2. If the recipe writes an action, that action is already fixed; select the
   effective argument.
3. If it writes an argument but no action, select the effective action.
4. If it writes neither, select both effective action and argument.

The corresponding four-route table covers all 402 recipes. The 101 variable
recipes create 415 observed selector cells. Each cell retains its exact recipe,
selector value, phrase, event IDs, pages, registers, cohorts and resolution
modes.

## Empirical minimization

A secondary atlas records when the current sample admits an even smaller key.
For example, action and argument may happen to co-vary one-for-one. Such ties
are reported as equivalence classes rather than silently treated as a causal
choice. For one executable canonical choice, argument is preferred at a tie,
then action, then the pair. The visible-slot rule remains the portable default
because it identifies which semantic slot is actually unwritten.

## Validation and decision rule

The independent validator reconstructs all 402 recipe routes, 1,010
recipe-candidate tests, 415 observed cells, ten candidate profiles, four
portable routes and five empirical minimal classes directly from GDT563. It
requires exact event partition, unique phrases in every selected cell and
deterministic regeneration.

Pass requires action-plus-argument to resolve all 101 variable recipes and all
1,277 affected events with zero ambiguous cells, and the visible-slot rule to
do the same with its three context routes. Page, owner and register may remain
descriptive columns but are not allowed in the selected key.

This is a compact selector for an exploratory working translation. It does not
show that the root meanings, language or genre are historically correct. An
unseen action-argument combination can be rendered compositionally, but this
pass does not license its occurrence or a future manuscript surface.
