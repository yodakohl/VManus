- `gdt564_result.json`: headline machine-readable result.

The 415-cell atlas is observational: each cell records a context combination
that actually occurs. The four-route table is the practical composition rule.
It may render a later combination of known values, but it does not assert that
the combination or a corresponding surface must occur.
