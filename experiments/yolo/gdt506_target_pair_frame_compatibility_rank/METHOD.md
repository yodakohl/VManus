# GDT506 method

## Question

Which of the eleven GDT505 pair targets can be obtained from an old carrier by
ordered frame deletion while preserving its explicit or contextual argument
policy, and which retain only the action handgrip?

## Inputs

- all 55 exact GDT505 pair carriers;
- the five fixed GDT505 neutral handgrips and eleven target cards;
- the complete GDT413 component dictionary, including factor families.

No new page, image, transcription, phrase or component meaning is used.

## Method

1. Extract each target's explicit argument roots from GDT413 factor families.
   A target with none uses the current contextual-pronoun policy.
2. For every old carrier of the same pair, require the complete ordered target
   recipe as an exact token subsequence. Publish aligned positions and every
   removed carrier component.
3. An explicit target is argument-compatible only when its argument roots are
   explicit in the carrier. A contextual target is compatible only with an old
   inherited-argument or argument-free carrier.
4. Rank targets as local compatible reduction, cross-register compatible
   reduction, or action-handgrip-only/open argument mode.
5. Select one transparent comparison carrier by compatibility, target register,
   fewest removed atoms, direct pair and stable event order.
6. Retain every target phrase, composed label and assumption regardless of
   tier; summarize pair and argument-policy coverage.

## Decision rule and claim ceiling

An ordered subsequence proves only that deleting visible carrier context leaves
the target components in order. Argument compatibility is separately required
before calling the complete frame supported. A Tier-C card is not rejected:
its action handgrip remains old while the explicit-to-contextual argument shift
stays exploratory. No tier promotes a target to observation or predicts a
surface or occurrence.
