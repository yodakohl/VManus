## Preserved ambiguities and interpretation limits

permits either reader's expression or genuine uncertainty. The deliberately
conservative joint upper bound permits each concept to be supplied by a
different reader. Coarsening occurs inside each observer before comparison,
so a200-word co-occurrence is not the sum of100-word co-occurrences. None of
