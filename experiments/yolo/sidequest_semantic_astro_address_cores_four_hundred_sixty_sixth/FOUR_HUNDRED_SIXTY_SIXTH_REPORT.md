# Pass 466 — das kleine Astro-Adressalphabet

Die 77 Restetiketten werden mit acht kurzen, diagrammlokalen Kernen geprüft:

- `D = TEILADRESSE`,
- `S = STERNBEZUG`,
- `A = NEBENADRESSE`,
- `F = AUSSENBEZUG`,
- `AM = GEGENFELD`,
- `CPH = STERNFIGUR`,
- `CFH = STERNHAUFEN`,
- `G = STRAHLMARKE`.

Diese acht Zeichen erklären 65 Gruppen in Kombination mit dem bestehenden
Prosa-Baukasten. Beispiele sind `dair = TEILADRESSE + LAUF`,
`ofar = ARBEITSGANG + AUSSENBEZUG + VON DORT`,
`cphocthy = STERNFIGUR + ARBEITSGANG + BEREIT + DIES` und
`chocfhy = GABE + STERNHAUFEN + DIES`.

Damit sind 383 von 395 Astrogruppen zusammengesetzt. Nur zwölf Oberflächen
bleiben als gelernte Himmelsnamen stehen. Das ist nun tatsächlich das gesuchte
Mischsystem: ein kleiner gemeinsamer Werkstattkern, zwei Etikettenrahmen, acht
Astro-Adresszeichen und ein winziger lokaler Nomenklator. Die Werte sagen noch
nicht, welcher reale Stern, Planet oder Kalendertag gemeint ist; sie machen aber
die Kartenkomposition vorhersagbar.
