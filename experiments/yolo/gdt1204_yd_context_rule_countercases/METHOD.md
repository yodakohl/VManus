# Deterministic context rule versus literal countercases

For input x, a deterministic function must choose one output. If n_y(x)>0 and
n_dy(x)>0, either output conflicts with some observed event. Its least possible
in-sample error is min(n_y,n_dy). Choices at different x are independent when
arbitrary lookup is allowed, hence summing gives an exact minimum. This generous
lookup capacity is stronger than a small general spelling rule: a contradiction
excludes every deterministic rule of exactly these inputs without training one.

Coarsening neighbour identity to boundary characters merges cells. Every mixed
FULL cell therefore maps into a mixed EDGE cell, and the minimum error cannot
decrease under coarsening. Absence of a mixed cell proves only a lookup exists
on observed inputs, not that it predicts an unseen input or has a small rule.
Unknown scribal metadata, source transcription alternatives and earlier exposure
are explicit scope limits. The two written outputs need not differ in meaning.

This asks a categorical question distinct from known suffix-prefix associations
and from the old stochastic wrapper choice. No abstract semantic role from an
old parser or exploratory working translation enters the input or output.
