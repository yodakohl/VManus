# GDT525 method

## Question

Can two licensed local edits compose through one explicit intermediate surface
and recipe, thereby closing a recurrent stem family without a target whole-form
score card?

## Inputs

- GDT407's 1,558 invariant old surface recipes;
- GDT516's inherited 159-form current benchmark and current contexts;
- GDT517's finite parser and exact-event/surface-role dictionaries;
- the complete GDT524 scores and local-edit model reconstructed in code.

No new page is admitted.

## Two-hop construction

For a target surface and finite candidate recipe, delete one visible block and
one atom block to obtain an explicit intermediate. Repeat once to obtain an old
base surface and its old recipe:

```text
old base --licensed edit 1--> intermediate --licensed edit 2--> target
```

Each visible deletion is one to three contiguous characters. Each matching
recipe deletion is zero to two contiguous atoms. Both visible-to-atom edit
signatures must have a positive GDT522 license, and the two normalized channels
must differ.

The old triples contain 4,833 ordered edit-pair types over 6,141 carriers; 749
types recur at least twice. The model ladder tests unrestricted sums, weakest
links, geometric means, pair counts and pair support. Those broad variants are
retained as diagnostics because they over-reward plausible but wrong
over-segmentations.

## Selected K-base card

The selected feature activates only when:

1. the old base recipe begins with `K`;
2. edit 1 is right-edge visible `y` inserting atom `Y` at the right;
3. edit 2 is inner visible `e` inserting atom `E` internally; and
4. that ordered pair occurs in at least two old triples.

The full old deck has six carriers:

```text
cth > cthy > cthey
ok > oky > okey
ot > oty > otey
qot > qoty > qotey
chcth > chcthy > chcthey
k > ky > key
```

The feature is `log(1 + pair support)` at weight 1. Exact event and known
surface cards normally retain precedence. GDT525 records one explicit working
revision, `kcheody`, because GDT515 itself marked its direct visible default as
retained only until a better parse; the two-hop family is that better parse.

This is an exploratory component-recipe rule, not a word translation or a
confirmed lexeme.
