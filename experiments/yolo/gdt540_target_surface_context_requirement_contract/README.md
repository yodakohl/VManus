# GDT540 — Kontextvertrag der neuen Prosaoberflächen

Status: `PASS_149_OCCURRENCES_CLASSIFIED__145_SURFACE_CONTRACTS__ONE_CONTEXT_SWITCH`

GDT540 macht aus GDT539s vollständiger Vier-Seiten-Lesung einen ausführbaren
Intake-Vertrag für alle 145 neuen Prosaoberflächen. Er trennt sichtbare
Handlung und sichtbares Argument von zwei kleinen Satzspeichern und zeigt den
einzigen beobachteten Oberflächenwechsel: `qokees` funktioniert mit demselben
Rezept sowohl objektlos als auch mit übernommenem `Y`.

Der vollständige Vertrag steht in
`artifacts/GDT540_TARGET_SURFACE_CONTEXT_CONTRACT.md`; `src/context_surface.py`
wendet ihn auf eine einzelne Oberfläche und einen optionalen Satzkontext an.
