# GDT507 method

## Question

Do GDT506's four contextual `CH+CH`/`CH+SH` targets have concrete old bridges
once two previously excluded scopes are admitted: broader within-event action
chains and consecutive cards in the same statement that inherit the same
argument?

## Inputs

- GDT416's complete 4,576 imperative clauses;
- GDT425's complete factorized action replay;
- GDT426's complete 81-pair action profile;
- GDT436's oracle-free owner-state replay;
- GDT506's eleven ranked target frames.

## Method

1. Read action heads from the fixed component recipes.
2. Inventory every event whose adjacent action-head sequence contains
   `CH>CH`, without requiring the whole event to have exactly two heads.
3. Class each carrier as explicit-argument, inherited-argument, or
   argument-free and join its live GDT436 owner state and GDT425 factor replay.
4. Scan consecutive GDT416 cards. Retain a bridge only when both cards are in
   the same statement, page, register and owner, their card ordinals are
   consecutive, the first has only `CH`, the second only `CH` or `SH`, neither
   states an argument, and both inherit the same nonempty argument root.
5. Give each of the four Tier-C targets one within-event pair-order witness and
   one adjacent same-argument witness. Prefer the target register, inherited
   over argument-free carriers, smaller frames, and earlier event IDs.

This is deliberately a compositional workshop pass. It asks whether the
existing defaults have an old mechanism, not whether the manuscript has been
translated.

## Decision rule and claim ceiling

A target becomes `CONTEXT_BRIDGED_WORKING` when its action order and contextual
argument policy both have concrete old witnesses. They may occur in the same
event (`CH>CH`) or in an old within-event pair plus a local adjacent-event
same-argument chain (`CH>SH`). Local and cross-register bridges stay distinct.

No target is promoted to `OBSERVED_CLAUSE`: none of the four bare target
recipes is observed. No phrase, root meaning, surface, occurrence, page, or
foreign frame value may change. f84 and f84r remain forbidden.
