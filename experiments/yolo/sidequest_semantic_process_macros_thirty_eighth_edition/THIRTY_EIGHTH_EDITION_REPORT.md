# Achtunddreißigste Ausgabe: eingeübte Abläufe über den Wörtern

Zwanzig wiederkehrende Prozessmakros komprimieren die 254 Handlungsklauseln,
ohne neue Wortbedeutungen zu erfinden. Ein Makro verbindet zwei oder drei
bereits getrennt gelesene Handlungen, etwa:

- ansetzen → durchleiten;
- durchleiten → am Folgeposten ansetzen;
- ansetzen → absetzen lassen;
- weiterführen → abführen;
- umsetzen → weiterführen → abführen;
- bereitstellen → einen Teil abtrennen.

Diese Ebene entspricht einem gelernten Werkstattgriff oder einer häufigen
Rezeptwendung. Sie sitzt über den Karten: `SET>PASSAGE` darf als „ansetzen und
durch den örtlichen Gang führen“ gesprochen werden, aber diese ganze Wendung
darf niemals zur Bedeutung einer einzelnen Voynich-Form erklärt werden.

Alle 116 Aussagen werden als Folge von Makro- und Einzelbefehlen ausgegeben.
Jedes Programm bewahrt die ursprüngliche Klauselreihenfolge und rekonstruiert
sie exakt. Zusätzlich liegt für den vollständig durchgespielten D2-Auftrag ein
eigenes 26-Aussagen-Makroprogramm vor.
