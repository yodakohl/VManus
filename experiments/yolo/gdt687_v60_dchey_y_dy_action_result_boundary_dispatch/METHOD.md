# GDT687 method

## Question

Can every current exact `dchey`, naked `y`, free `dy` and surface containing
contiguous `dy` receive one concrete action, finished-result, local-reference
or structural-boundary reading without letting `y` or `dy` invent a physical
operation in fluent prose?

## Inputs

- GDT686's complete 51-line V59 reader and frozen totals;
- GDT684's 479-position semantic-debt audit;
- GDT675's fifteen exact `dchey` occurrence contexts, including the f81r
  source card and fourteen external positions;
- GDT659's 270-position naked-`y` context census;
- GDT557's 705 formal-DY position prior;
- GDT559's four Y/DY distinction classes and 28 joint cards;
- 21 keyed `dchey`/naked-`y`/free-`dy` decisions in
  `src/V60_TARGET_DISPATCH_SPECS.tsv`;
- 60 keyed whole-surface decisions in
  `src/V60_BOUND_DY_SURFACE_SPECS.tsv`.

No page, image or raw transcription is opened. All evidence comes from
already admitted cached artifacts. `f84` and `f84r` remain forbidden.

## Method

1. Explode the 51 V59 lines into all 479 exact token positions.
2. Select a position if its surface is exactly `dchey`, exactly `y`, exactly
   `dy`, or contains contiguous `dy`. This yields 95 positions on 40 lines.
3. Keep `dchey` as an exact learned surface whose grammatical orientation is
   local: nine current line-entry positions are actions and five
   value-bound/medial positions are nominal results. Add the f81r source only
   to the global fifteen-position census, never to the V60 patch population.
4. Dispatch naked `y` locally as a right-binding `Hierzu:` or line-final
   punctuation. Do not export one universal
   word value from the four current cases.
5. Render all three free `dy` as punctuation. The formal 705-DY prior is used
   only as a role analogy because it is an atom-layer count, not an exact
   surface-`dy` census.
6. For each of the 60 bound-`dy` surfaces, consult the complete current
   whole-token action set. A verb survives only when the whole surface has an
   independent action license. Otherwise emit a nominal finished state.
7. Apply a stricter core test to `qody`: its old action was only the
   `dy`-derived verb *fertigstellen*, so V60 demotes it to *fertige
   Zubereitung*. This changes the complete source action count 86 to 85.
8. Rewrite literal and aligned layers at the exact target positions. Rebuild
   practical prose solely by walking the written token glosses in order;
   punctuation produces no spoken clause.
9. Preserve all non-target literal glosses and every action ordinal except
   `f105r.2#13 qody`. Recompute strict, mechanical, broad and
   provenance-aware debt without hiding the 22 target states that still lack
   an explicit object or the one inherited low-confidence card.
10. Rebuild all fourteen generated result artifacts byte-for-byte in a
    temporary directory and independently validate target selection,
    partitions, changed ordinals, action sets, debt totals, hashes and sealed
    exclusions.

## Decision rule and claim ceiling

A surface containing `dy` is an action only if the complete whole-token card
has a surviving non-`dy` action license. Free `dy` is punctuation only.
`dchey` is oriented by the already observed local scope rather than forced to
be universally verbal or nominal. Naked `y` receives one local working
function at every current position, but no global word meaning.

This is an exploratory and replaceable workshop renderer. Its concrete
German defaults are designed to make the current model usable and
falsifiable; they are not recovered plaintext. In particular, V60 does not
settle the competing `CH+E+Y` versus `D+CH+E+Y` analyses of `dchey`, does not
equate the formal GDT557 DY atom with the exact written surface `dy`, and does
not identify a language, phonetic value, historical codebook, ingredient,
disease, patient or cure. It opens no page.
