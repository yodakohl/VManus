# GDT427 method

## Question

Can the broad GDT426 prediction classes be made discriminating—retaining most
of the nine useful amber forecasts while blocking at least some genuinely
absent ordered action pairs?

## Inputs

- GDT416's complete 4,576-event component recipes;
- GDT425's 5,051 focus-edge portability table;
- GDT425's nine-card local appendix.

## Method

The nine working action cores are partitioned seven ways: the original four
classes and six five-class variants, each splitting one plausible contrast.

For every model:

1. collect all adjacent ordered action pairs from the complete GDT416 recipes;
2. hide the sole page of each of the fifteen one-page pair types and ask whether
   its typed transition is present on another page;
3. treat the seventeen never-observed ordered pairs as negative controls and
   ask whether the typed transition wrongly licenses them;
4. report sensitivity, specificity, and their unweighted mean;
5. replay the nine GDT425 local cards through the selected partition.

The selected partition separates `T=EINSTELLEN` from `R=MARKIEREN` while
retaining `CH/S`, `K/OK/P`, and `SH/CHD` as broader families. Focus rectangles
are carried over separately because the current focus-family layer has no
useful negative inventory.

## Decision rule and claim ceiling

Select the tested partition with the highest balanced accuracy, but do not
promote a page-local exact card merely because its class is old. A local card is
amber only when another page supplies its exact pair, its selected typed
transition, or both sides of its explicit head×focus rectangle. Otherwise it
stays red-local.

This is a creative specificity repair for the current working dictionary. It
does not establish natural-language word classes, lexemes, plaintext, a
language, or a source.
