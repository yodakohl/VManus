# Executable method

`src/codec.py` learns merge tables from b4/w1 only, builds six prefix trees and writes/reads complete words using an explicit four-state counter. `src/run.py` saves every full encoded book and every table and scores only the inherited summary. `src/validate.py` decodes published texts with their public tables, checks all complete source recipes and canonical rewrite, prefix/alphabet properties and score decisions.

CoReMA University of Graz CC-BY4.0 source provenance remains in1159 SOURCE.json and1177's projection records. All material is previously exposed expanded-edition control text. There is no acquisition of native or sealed manuscript data.
