## Decision before implementation
1200 records repeated dal/al/ch/ol forms and the two possible ololdy analyses.
Its collision is a loss of content only IF olol is given an independent value
other than two ol components. The project does not know that. A unique parse
tree is not necessary when all legal parses expand to one complete message.
The stronger616 strict failed contract required paid macros to DIFFER from
child concatenation; it did not refute transparent learned chunks.995 concerns
a conditional already-given suffix map and is not a general native solution.
1174demonstrates why a reversible finite writer need not fit native statistics;
1193passes only a basic screen and retains serious shape/cost mismatches.
No repair, additional fitting or change to those decisions is attempted.

Smallest adequate construction: seven opaque source symbols U0..U6, encoded
respectively as dal/al/ch/ol/y/dy/or. These are explicitly INVENTED code values
for uninterpreted test symbols, NOT proposed meanings or primitive units of
Voynich. There is no English/German/native lexicon or content inference. The
seven surface words form a prefix-free table, allowing deterministic primitive
reading. Surface atoms need not equal one manuscript glyph.

Learned chunks are only aliases: for each of the first four bases retain its
single-base+y, single-base+dy, single-base+or, double-base and double-base+dy
expansion. Also allow a teaching alias for each complete representative form.
All aliases must expand literally to their source-symbol sequence, in order;
no contents are erased or created. Rendering concatenates the primitive surface
codes. Thus macro lookup changes reader convenience, not the written string.
All macro spellings are generated from definitions rather than fitted to data.

Add three explicitly artificial source-structure symbols WORD_BREAK, OPEN,CLOSE,
encoded m,p,f. They are paid extra symbols in THIS demonstration, not native
interpretations of m,p,f. No code starts with one of those single-symbol codes.
A macro may preserve an explicit structural symbol; it cannot silently drop it.
Visible extra spaces are not made semantically optional by this construction.

Positive verification: all source strings of lengths0..4 over the seven opaque
symbols must have exactly one fully expanded message across EVERY legal parse
using primitives and aliases, equal to their original source. No need to recover
the tree. Also check fixed word-boundary, scope and order examples using the
three structure symbols. Prove extension to arbitrary finite strings from
prefix freedom and alias definitions, separately from the finite enumeration.

Negative witnesses: inserting a whole chunk with a NEW opaque value under the
same olol spelling must produce two different expansions; a longest-match-only
choice must then fail to recover at least one legal input. Omitting WORD_BREAK
must collide U3/WORD_BREAK/U3 with U3/U3. Erasing scope markers must collide
OPEN/U0/CLOSE/U1 with U0/OPEN/U1/CLOSE. Dropping a second U0 must change source.
These are known constructed counterexamples, not empirical Voynich failures.

Decision: if implementation satisfies the explicit construction, retain
transparent learned chunks as an available mechanism and remove unique parse
tree selection as a prerequisite for a future writer. Do NOT declare the
primitive inventory, macro meanings or boundary markers established in Voynich.
If source information is lost, correct or reject this construction only; do
not reinterpret the failed messages. This tiny control will not be expanded
into a decoder/search infrastructure or new statistical corpus. It explains
one design issue; zero new native meanings, independent confirmations or
source-language choices follow. A whole meaningful statistical writer remains
an unsolved separate duty. No count of software checks is decipherment progress.

## Assumptions and remaining burden
Fixed finite prefix-free primitives; finite acyclic exact-expansion aliases;
all meaningful order, word boundaries and scope retained as source symbols.
These are construction assumptions, not empirical manuscript findings. Learned
whole lexical values that DIFFER from their parts need distinguishable spelling
or a fixed meaning-recovering context rule. Natural language homonymy is not
generally refuted by this lossless-code criterion. The classifier is a finite
teaching check, not a new generic audit tool. Existing1200counts remain frozen.

The implementation emits a finite explicit table, teaching examples, complete
ambiguous-parse witnesses and compact result. A separate validator verifies
primitive prefix freedom, all alias render/expansion equalities and source tests.
