# GDT457 — Horizont zusammenhängender neuer Karten

Auf denselben 55 Aussagen und denselben Startpositionen wachsen sichtbare,
ergebnisblind gewählte Ersatzinseln von einer bis 16 Karten. Jeder Längengrad
wird als vollständiger 4.576er Strom gelesen.

```bash
python3 experiments/yolo/gdt457_contiguous_unknown_island_horizon/src/run.py
python3 experiments/yolo/gdt457_contiguous_unknown_island_horizon/src/validate.py
```
