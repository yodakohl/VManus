# GDT468 artifacts

- `gdt468_2300_recipe_support_atlas.tsv`: one row per flat recipe with running,
  complete-address and hybrid-shell carriers plus rank/tier.
- `gdt468_old_recipe_carriers.tsv`: 154 running surfaces, fourteen full labels
  and 42 hybrid labels tied to their recipes.
- `gdt468_2760_supported_shell_phrasebook.tsv`: GDT467 phrasebook with support
  tier propagated to every visible factorization.
- `gdt468_423_factorization_family_support.tsv`: repeated-recipe families ranked
  by shared old-carrier support.
- `gdt468_result.json`: compact result.
- `gdt468_validation.json`: 50-check validation report.
