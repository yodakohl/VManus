# GDT468 — 103 shell recipes already have old carriers

## Result

The 2,300 compositional meanings split into four useful drawers:

| recipe support | recipes | visible shell templates |
|---|---:|---:|
| exact running recipe | 75 | 105 |
| complete address formula only | 14 | 24 |
| hybrid address function trace only | 14 | 18 |
| composition only | 2,197 | 2,613 |

Thus 103 recipes and 147 visible shell templates have an old carrier somewhere
in the admitted material. The exploratory drawer remains large, but it is now
clearly labelled instead of being mixed with already observed combinations.

## Running support is not marginal

The 75 running-backed recipes account for 757 events, 154 exact surface types
and 24 of the 26 admitted pages. The top five by the frozen ranking are:

1. `OK+Y` — `SETZEN · POSTEN`: 59 events on eighteen pages;
2. `OK+EE+Y` — `SETZEN · GRAD II · POSTEN`: 67 events on sixteen pages;
3. `OK+AIIN` — `SETZEN · WERT`: 64 events on fifteen pages;
4. `OT+Y` — `DANACH · POSTEN`: 33 events on fifteen pages;
5. `OK+OL` — `SETZEN · FORTSETZEN`: 27 events on fifteen pages.

This matters operationally. If a future visible label reduces to one of these
recipes, both its component channels and its complete ordered recipe already
exist elsewhere. That is a stronger working reading than a merely possible
combination.

## Address-only support remains distinct

Fourteen recipes occur as complete address formulae but not as exact running
recipes in this join. Another fourteen occur only as function traces on 42
hybrid labels, where learned name material lies between the function pieces.
The latter are useful shell precedents but are not claimed as contiguous
whole-card recipes.

The carrier artifact therefore records three source layers separately:

- 154 running surface carriers;
- fourteen complete-address carriers;
- 42 hybrid-address shell carriers.

## Exploratory combinations stay available

The remaining 2,197 recipes are not discarded. Their 2,613 templates still
execute perfectly under GDT467 because every local channel is old. They simply
receive `COMPOSITION_ONLY`: readable after a surface is shown, but lacking an
old complete recipe or shell trace.

The same split sharpens the 423 renderer-factorization families. Twenty-nine
have running support, five complete-address-only support, four hybrid-only
support and 385 remain composition-only. All visible factorizations stay
available under their shared recipe tier.

Validation passes 50/50 checks with a byte-identical rebuild. No new page,
channel, component meaning, spelling prediction, occurrence, name, plaintext,
language or confirmed lexeme is added.
