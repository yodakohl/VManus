# GDT1179 method and claim scope

Three exact source-forward writers differ in how they pay for source words:
literal shorthand, a fixed learned abbreviation dictionary, and explicit
backward token references with literal introduction of unavailable words.
Each uses the inherited22 working glyph labels. These are invented signs
and codes, not values assigned to real Voynich words.

Every word, spelling, punctuation token and paragraph in the normalized input
must survive. Punctuation remains attached exactly as in the frozen edition.
The underlying source-language semantics come from those preserved words;
no manual new ingredient or operation tree is required. This is not a
lossless diplomatic manuscript transcription: the upstream edition projection
and capitalization/whitespace normalization remain explicit.

The contract specifies all modes, table sizes, boundaries, state and comparison.
The fixed whole-word dictionary costs503 learned/consulted correspondences,
in addition to the carrier. The reference writer requires sequential access
and a503-source-token backward search, not a modern hidden language model.
Its cognitive practicality is unestablished even if statistics should pass.
A deterministic global transformation supplies all displayed source content;
no copied Voynich word list or whole-recipe code is permitted.

A/B are injective per complete source tuple and must share word frequencies.
C can reuse the same surface for different source words under different public
histories. Therefore a source-tuple frequency failure cannot alone pre-reject C;
its actual output must be counted and completely reverse-read.
