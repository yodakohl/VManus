# GDT746 — Ganzwortanalogien im realen Verteilungskontext

GDT746 prüft GDT745s 17 stärkste vollständige EVA-Ganzwortfamilien an 1.523
bereits zwischengespeicherten Vorkommen von 63 Formen. Es vergleicht Abschnitt,
Zeilenposition, linke/rechte Ganzwortumgebung und Abschlussnähe, ohne eine Form
zu zerlegen oder einen EVA-Buchstaben zu deuten.

Ergebnis: 15/52 direkte Distanz-1-Paare werden durch ihre Verteilung verstärkt,
zehn weitere sind kompatibel. Vier Kandidaten besitzen mehrere verstärkte
Nachbarn, acht weitere mindestens einen tragenden Vergleich; fünf bleiben
offen oder singletongebunden. Vollständige Karten stehen im [Bericht](REPORT.md)
und im [Leser](artifacts/GDT746_WHOLE_DISTRIBUTION_READER.md).
