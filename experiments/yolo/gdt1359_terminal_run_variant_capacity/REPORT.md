## What changed from the old two-variant bound

For a stored source word of length L with t identical terminal code points,
the proposed run-sharing rule can produce at most a=1+min(t,L-1) nonempty
shortened forms. Thus longer endings genuinely permit more than two variants;
we did not apply1202unchanged. A one-character token permits only one variant.
We retain Unicode code points, case, punctuation and the exact old projection.

## A generous family, not a full decoder

We grant every exact source word a(w) arbitrary fixed whole spellings, with
free occurrence-by-occurrence selection and disjoint labels across words.
They need not look like the source or obey actual following-word and record-
final constraints. This is more freedom than the literal shared-run writer.
It also avoids treating the literal internal-run obstruction as a new finding.

For frequency f, the maximum number of used labels is min(f,a). Summing gives
the optimistic maximum diversity. Splitting each f as evenly as possible among
a integer cells minimizes every largest-k count sum. Taking the ten largest
cells yields the optimistic Top10minimum. Merging spellings across source words
cannot increase diversity or lower concentration. Both optima are attained by
the same disjoint balanced allocation in this abstract relaxation; attainment
is not claimed for the actual contextual writing rule or a human alphabet.

The complete1035literal writer already inherits1240's fixed five-source
internal-fourfold obstruction. That old conclusion is retained, not rerun or
credited as new. Today's larger arbitrary-label family does not inherit literal
letter-run obligations, so its variable-budget frequency result is a separate
necessary check. No alphabet, extra exception or full source encoder was fitted.

## The reader is formally sound, but ambiguous

The separate source-free audit verifies the exact right-to-left set reader.
For a written left word Y and a reconstructed right word beginning with a run
of Rcopies of c: if length(Y)>=2and Yends c, its unique local preimage is Y+c^R.
Otherwise all R+1words Y+c^j for j=0..R are genuine local preimages.

For fixed key and record boundaries, if Bboundaries are of the latter kind,
the full message has at least2^Bpreimages, and is unique exactly when B=0.
This is a cardinality statement without a source prior, not Shannon entropy,
a failure solely because writing is ambiguous, or a count measured in Voynich.
No native record boundaries or language-filtered readings were selected.
A source grammar could restrict this set, but none has been established here.
The900local and258small record controls supplement the general proof only.

## Decision and limits

Do not construct this bounded-variant writer on the unchanged four comparison
profiles. The source-unspecified1035proposal remains inconclusive as a manuscript
hypothesis. Its formal reader works, but native-only successful enumeration is
not evidence because every written record has source preimages.

These profiles are the same fixed first8000stored source tokens used in1202.
They are not actual Voynich plaintext, all passages of their books, or universal
language samples. Target/source eligibility and editorial tokenization are not
independently matched. The operational failure does not automatically exclude
full-source generation followed by a different selection filter. Source identity,
word/group correspondence and the old screen's qualifications remain binding.
