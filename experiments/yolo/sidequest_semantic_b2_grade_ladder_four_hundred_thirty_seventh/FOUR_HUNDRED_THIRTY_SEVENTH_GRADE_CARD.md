# Kurzkarte: E / EE / EEE

```text
E    = kurz
EE   = länger
EEE  = vollständig
Y    = dies / aktueller Posten, offen
DY   = nur in gelernter Endkarte: Schluss
```

Beispiele:

```text
OK + E   + Y  = kurz ansetzen
OK + EE  + Y  = länger ansetzen
OK + EE  + DY = länger ansetzen; Schluss
OK + EEE + DY = vollständig ansetzen; Schluss
```
