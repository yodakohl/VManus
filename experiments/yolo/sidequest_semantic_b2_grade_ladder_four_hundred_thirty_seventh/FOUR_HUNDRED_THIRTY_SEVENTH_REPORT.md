# Pass 437 — B2 hat eine vollständige Kurz/Lang/Voll-Leiter

Acht Karten und fünfzehn Ereignisse bilden dasselbe Gradsystem wie B1:

- `E` — KURZ;
- `EE` — LÄNGER;
- `EEE` — VOLLSTÄNDIG;
- `Y` — aktueller Posten bleibt offen;
- lizenzierte `DY`-Karte — Schritt schließen.

## Paradigmen

| Konstruktion | Lesung |
|---|---|
| OK+E+Y | kurz ansetzen |
| OK+EE+Y | länger ansetzen |
| OK+EE+DY | länger ansetzen; Schluss |
| OK+EEE+DY | vollständig ansetzen; Schluss |
| OT+EE+Y | nächsten Posten länger halten |
| OT+EE+DY | nächsten Schritt länger halten; Schluss |
| CHK+EE+Y | dies länger wärmen |
| CTH+E+Y | dies kurz bereithalten |

Sechs dieser acht Karten waren bisher B2-Ganzkarten. Sie werden jetzt
produktive Zusammensetzungen. Damit steigt B2 von acht auf vierzehn neue
produktive Kartentypen; das lokale Ganzkartendeck sinkt von 24 auf 18.

Die wichtigste semantische Reparatur ist OTEEY/QOTEEDY. „Längerer Folgeposten“
war nur ein Nomen und erklärte die Stelle im Arbeitsgang schlecht. OT+EE+Y
liefert die ausführbare Anweisung **DEN NÄCHSTEN POSTEN LÄNGER HALTEN**; mit
der Schlusskarte wird daraus **DEN NÄCHSTEN SCHRITT LÄNGER HALTEN; SCHLUSS**.

Der Lehrling braucht damit kein neues Wort für jede Dauer: Er kombiniert
Operation, Grad, aktuellen Posten und Abschluss.
