## Prospective clarifications received before fitting

Global ordinary-character mapping is many-to-one. LITERAL decodes every atom, including any class omitted during heuristic search. CONSTANT/VARIABLE select a mark class afresh from fit-supported classes plus no mark; all occurrences of that class are removed. At least two ordinary carriers remain and at most four inserted letters are permitted in the entire word, including zero. CONSTANT requires the same globally learned residual string repeated once per mark; VARIABLE permits any residual. Distinct alignments never multiply a candidate's weight. Ranking is reference prior times 2 to the negative inserted-letter count, with exact Unicode lexical tie ordering and no extra tied candidates in top five.

Every arm rescans all32 snapshots: four forced-no-omission and four latent-omission anneals, each with four fixed checkpoints. This panel balance is prospective. Words containing atoms unsupported in the actual512-type fit panel receive no predictions, irrespective of random key assignments. Primary novelty is measured against all training records, not just512 fitted types. These choices must appear in the final public contract before real fitting; messages alone are not a substitute for that frozen contract.
