# Artifacts

RESULT.json contains exact offered/used table sizes, used entries, activity, initial-run counts, examples and conditional singleton classification. EVENTS files retain each original source row and its parse. VALIDATION.json records independent DP/UD checks; PRETARGET_CONTROLS and PROSPECTIVE_REVIEW concern pre-execution controls. RESULT_REVIEW checks reporting scope. Source/code hashes are in src/REGISTRATION_LOCK.json. No native meaning or source value is assigned.
