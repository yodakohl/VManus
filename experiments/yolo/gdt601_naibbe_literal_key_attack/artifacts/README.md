# GDT601 artifacts

- `gdt601_result.json`: source hashes, guarded target census, strict table
  coverage, all observed/null scores, and decision.
- `gdt601_top_chance_readings.tsv`: the twelve highest-scoring target lines per
  language, retained to show what tempting local coincidences look like when
  the corpus-wide signal fails.
- `gdt601_validation.json`: compact invariant and artifact-hash audit.
