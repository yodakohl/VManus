# Reproduction artifacts

SOURCE_UNITS contains every source paragraph ID/hash/wordcount, without its
full text. INITIAL_SOURCE_UNITS and EXTRACTION_CORRECTION retain the isolated
editorial-marker correction. ANNOTATIONS files and ANNOTATION_FREEZE retain
all first judgements; SECOND_REVIEW and CORRECTIONS keep review separate.
RESULT is arithmetic over those disclosed judgements. VALIDATION checks source
extraction/coverage/arithmetic mechanically; it cannot validate meanings.
