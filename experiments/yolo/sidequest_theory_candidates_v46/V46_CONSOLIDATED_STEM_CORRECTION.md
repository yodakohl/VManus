# V46 — Konsolidierung nach der Stammüberinterpretation

## Korrektur

V45 hat lokale kreative Übersetzungen rückwärts als Belege für gemeinsame
Stammbedeutungen benutzt. Bei `ch`, `chy`, `che` und `olk` waren jeweils nur
zwei Karten oder Ereignisse vorhanden. Die scheinbar gemeinsamen Bedeutungen
„Flüssigkeit trennen“, „warmes Medium anwenden“ oder „Transferstation“ waren
daher keine unabhängigen Befunde, sondern aus den bereits erzwungenen
Übersetzungen zurückprojizierte Gemeinsamkeiten.

Diese Zirkularität wird vollständig entfernt.

## Konsolidiertes Inventar

### Als Arbeitshypothese behalten

| Einheit | korrigierter Minimalwert | Status |
|---|---|---|
| `ok` | spezifizierten Arbeitsposten einsetzen/aktivieren | beste formale Kombinationsachse; 5 Karten/24 Ereignisse |
| `or` | bereitetes Ergebnis oder Arbeitsmedium | bester vorläufiger Inhaltskern; 2 Karten/8 Ereignisse |
| `al` | Ziel- oder Parallelstation | schwache Relationsfamilie |
| `e` | Vorgang bis zu einer Zustandsgrenze führen | schwache Zustandsfamilie |
| `ot` | markierten Bezug, Parameter oder Weg wählen | abstrakte formale Achse |
| `l` | angeschlossene Station oder Fortsetzung | abstrakte formale Achse, kein Gegenstandswort |

Nur `ok` besitzt derzeit eine nennenswerte produktive Kartenserie. Auch seine
deutsche Funktion bleibt Sidequest-Arbeitshypothese, nicht Entzifferung.

### Wiederkehrende Karten, aber keine Wortstämme

| Host | lokale Kartenhypothese | Warum kein Stamm? |
|---|---|---|
| `aiin` | Maß-/Standardkarte | 20 Ereignisse, aber nur eine exakte Kartenart |
| `ey` | Sollzustandskarte | 4 Ereignisse, eine exakte Karte; kein freies `-ey` |
| `oky` | Verwendungskarte | eine Karte |
| `lche` | Ablaufkarte | eine Karte |
| `oke` | Spülkarte | eine Karte |
| `cthy` | Bereitschaftskarte | eine Karte |
| `okeey` | Temperierkarte | eine Karte |
| `ckhy` | Verbindungswegkarte | eine Karte |
| `olor` | Voransatz-Produktkarte | eine Karte |

Rekurrenz kann den Wert einer Ganzkarte interessant machen, demonstriert aber
keine produktive Stammvariation.

### Nur explorativ, nicht als Defaultstämme

- `chor`: möglicherweise Sammel-/Beschaffungszeit; 2 Karten/3 Ereignisse im
  selben Herbal-Deutungsraum.
- `chey`: möglicherweise Auswahl eines Materialteils; 2 Karten/3 Ereignisse,
  aber die Gemeinsamkeit stammt aus der Bildinterpretation.

### Zurückgezogen

| Host | zurückgezogene V45-Glosse | korrigierter Status |
|---|---|---|
| `ch` | Flüssigkeit trennen/abziehen | `UNBEKANNT` |
| `chy` | warmes Medium anwenden | `UNBEKANNT` |
| `che` | Flüssigkeitsschritt | `UNBEKANNT` |
| `olk` | Transferstation | `UNBEKANNT` |
| `y` | gegenwärtiger Träger | `UNBEKANNT`; Stoff, Mischhandlung und Habitat widersprechen sich |

Alle übrigen Hosts sind auf Hostebene `UNBEKANNT`. Ihre konkreten deutschen
Ganzkartenlesungen bleiben im kreativen Interlinear erhalten, zählen aber
ausdrücklich **nicht** als Stammbelege.

## DY

`DY` bleibt eine beobachtete formale Koordinate, kein Wortstamm. In der
kreativen Werkstattlektüre darf es weiterhin einen lokalen Zellschluss
anzeigen. Eine Bedeutung wie „vollziehen“, „fertig“ oder „danach“ ist dadurch
nicht nachgewiesen.

## Was mit der Übersetzung geschieht

Die vollständige Zehnseitenlesung wird nicht gelöscht. Sie wird neu etikettiert:

```text
lokale kreative Expansion != Bedeutung des PAGE_HOSTs
```

Damit können wir weiterhin fragen, ob eine Passage als medizinischer oder
technischer Ablauf Sinn ergibt. Wir dürfen diese Lesung aber nicht anschließend
als Beweis dafür verwenden, dass ein kurzer Host genau die darin vorkommende
deutsche Teilbedeutung trägt.

Die korrigierten vollständigen Artefakte sind:

- `V46_CORRECTED_CORE_INVENTORY.tsv`;
- `V46_CORRECTED_173_CARD_LEXICON.tsv`;
- `V46_CORRECTED_381_EVENT_INTERLINEAR.tsv`;
- `V46_VALIDATION.json`.

## Neue Arbeitsbasis

```text
produktive Hauptachse:       OK
vorläufiger Inhaltskern:     OR
schwache formale Achsen:     AL, E, OT, L
wiederkehrende Ganzkarten:   AIIN, EY, OKY, LCHE, OKE, CTHY, OKEEY, CKHY, OLOR
explorative lokale Familien: CHOR, CHEY
unbekannt/zurückgezogen:     CH, CHY, CHE, OLK, Y und alle übrigen Hosts
```

Das ist deutlich kleiner, aber belastbarer und als Ausgangspunkt für weitere
kreative Arbeit brauchbarer. Es bleibt eine Sidequest-Arbeitstheorie ohne
Nachweis von Sprache, Morphemen, Wörtern oder Bedeutungen. `f84` und `f84r`
blieben versiegelt.
