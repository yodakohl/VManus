# GDT607 — boundary/word-bucket disentanglement

Status: `W_BUCKET_CONFUND_CORRECTED__FIVE_DISTINCT_OUTPUT_BEARING_FORMAL_ROLES`.

GDT606's recurring `W` assignments do not identify whole words. The fixed
bucket preferentially absorbs frequent, mobile units, while nearly literal
one-unit chunks can receive no `W` assignment at all. A separate 90-key grid
adds an outputless boundary category. `o`, `y`, and `ol` never move into it;
`C` and `d` do so only four times each in 72 eligible runs. When `W` capacity
is removed, all five predominantly become output-bearing multi-character
macros.

The retained result is a five-way formal-role table: `C` is a strict local
opener, `d` a chunk/line head carrier, `y` a closure carrier, `ol` a boundary
and occasional standalone carrier, and `o` a flexible connector. These tags
are not translations. The next experiment decomposes the 98 BPE units into
shared collapsed-glyph stems so that compounds such as `ol`, `or`, `ok`, `ot`,
`dy`, and `aN` need not be learned as unrelated signs.
