# GDT1271 — a fixed signature, and why a fitted chart is not yet a reading

**ZERO_MASK_INVARIANT_AND_DIFFERENT_CHART_AMBIGUITY.** For the unchanged977core,
an output repeats the previous visible label exactly when its selected local
rank is0. This signature is independent of the circular chart. A constructive

Each chart's own inverse remains unique. No manuscript text was used or translated.

## A constraint no chart can change
The local candidate list begins ATthe current pointer. Its first entry is the
current visible label; all other entries have different labels. Hence a zero
rank prints the same label and stays put, while a positive rank prints a different
label. Zero movement still transmits a digit; it is not a deleted or meaningless
filler sign. The first output must be compared to the known initial label.
For an unanchored fragment that first comparison and the two-step phase are unknown.

A source index v=4a+b has two ranks (a,b), with6and4choices. Their zero pattern
therefore separates24source values into four classes:

| First rank | Second rank | Source indices | Count |
|---|---|---|---:|
|zero|zero|0|1|
|zero|nonzero|1,2,3|3|
|nonzero|zero|4,8,12,16,20|5|
|nonzero|nonzero|all remaining indices|15|

These are conditional INDEXclasses in the proposed model, not four native word
meanings, sound classes or a partial confirmed translation. A glyph such as e
has no fixed source value: its role depends on the entering pointer and phase.
Without the chart, the nonzero rank within a class is not determined. Additional
unencoded pointer resets/nulls would change the contract rather than repair it
for free. None is inserted in this demonstration.

This supplies a prospective way to check a future fixed source/alphabet contract
before expensive chart fitting: a proposed input's zero-rank pattern must match
its output's equality pattern. No such native/source comparison was selected here.

## General construction and its cost
Given a finite desired output and an input rank stream with the same equality/
zero mask, start a chart with the public initial label. For a positive rank d,
append d−1different filler labels (excluding current and requested labels), then
the requested label. It is the d-th first-occurring distinct label from the
current pointer. A zero rank emits the current label without appending a position.
The pointer always reaches the end of the constructed prefix. After all requested
outputs, append missing alphabet labels so all future candidate lists exist.
No demonstrated step wraps; later chart completion cannot alter the earlier ranks.
The filler labels occupy the CHART, not the emitted ciphertext.

With22available labels and d≤5, sufficient fillers always exist. The construction
uses at most1+sum(digits)+22positions; this is a generous upper bound, not an
optimum. Its chart depends on BOTHthe selected input and desired output and grows
with message length. It can hide the chosen path in the key. Thus for fixed equal-length input/output, public initial label and phase, the
mask condition is necessary AND sufficient when chart size is unrestricted.
This does not show arbitrary texts fit a previously fixed small chart or fixed
chart-size budget.

## Two equal-cost artificial charts
The source alphabet is explicitly A..V, SPACE, #; # is the end-of-message symbol.
It is a finite toy alphabet, not a proposal about English, Hebrew or Voynich.
The complete messages are exactly:

    HEAT GIN#

O(index14)andG(index6) both have two nonzero ranks; I(index8)has nonzero/zero;
L(index11)andN(index13)again both have two nonzero ranks. All other source
positions are equal, so both messages have the same required zero mask.

Their shared ARTIFICIALoutput, written as working-unit labels, is:

    e d y y y y a l ch i n e d d y a l ch

Spaces on this display separate individual units; this is not an extracted
manuscript line or a claimed native word segmentation. ch is one demonstration
unit. Both charts begin at position0with labelo. Deterministic fillers produce
unpadded charts; the shorter is padded only at its unvisited tail to equalize
both final charts at53positions. Each chart contains all22working-label drawings.
Full charts, exact pointer/rank traces, padding and both inverses are in RESULT.json.

The different readings arise from DIFFERENTcharts, not ambiguity of a fixed
chart. This is an explicit instance of ordinary key nonidentifiability, not a
new theorem that all decipherment is impossible. Nor are these53-position toy
charts candidates for the native corpus: they were not asked to satisfy1270's
stronger66–69full-panel lower bounds. The datasets and tasks are different.
A fixed small budget, independent source information and genuine predictions may
still distinguish candidates; this example does not settle the whole manuscript.
