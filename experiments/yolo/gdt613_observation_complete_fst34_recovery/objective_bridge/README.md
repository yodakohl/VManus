# GDT613 post-run objective bridge

This labelled bridge uses only GDT612 synthetic artifacts.  It compares the
planted truth with six archived pseudokeys and all 1,888 declared fixed-length
one-primitive output mutations under both the legacy continuous-fit/chunk-reset
language model and the corrected reset-matched model.

The coarse ordering is repaired: truth ranks first of seven against every old
pseudokey in every panel.  Exact local identification still fails.  The exposed
mutation `P28 que→qua` beats truth in all eight primary reference/model panels,
and 232 exact ties are exhausted by four zero-train-exposure primitives.

`compact/` retains the validated summaries, mutation catalog and key scores.
The exhaustive `local_mutation_scores.tsv` is intentionally not committed; it
is about 15 MB and is regenerated by the source:

```text
bridge_work=$(mktemp -d)
mkdir -p "$bridge_work/results"
cp objective_bridge/{gdt613_bridge_audit.py,validate_bridge.py,PREREGISTRATION.md,REPORT.md} "$bridge_work/"
python3 "$bridge_work/gdt613_bridge_audit.py" \
  --gdt612 experiments/yolo/gdt612_historical_fst34_target_attack \
  --out "$bridge_work/results"
python3 "$bridge_work/validate_bridge.py" \
  --bundle "$bridge_work" \
  --out "$bridge_work/results/INDEPENDENT_VALIDATION.json"
```

This is a post-run diagnostic, not a GDT613 recovery world and not a Voynich
target result.
