# GDT605 — a stable 98-unit alphabet below Voynich spaces

Status: `STABLE_98_UNIT_ALPHABET__ONE_LETTER_READING_REJECTED`.

GDT604 showed that whitespace-delimited U/P/S surfaces manufacture unstable
pseudotext. GDT605 moves the unit boundary down to recurrent collapsed-glyph
sequences. A 64-merge inventory learned on 68 physical folios contains 98
units; the 23 held folios use 97 of them and introduce zero unseen unit types.

The source-space result localizes the error. On held folios, learned units
independently cross 185/749 uncertain separators (24.70%), but only 575/8,570
certain spaces (6.71%) and 5/97 drawing interruptions (5.15%). The uncertain
rate is higher than the certain rate on 22/23 held folios. A second fit therefore
joins uncertain separators while treating certain spaces and drawing
interruptions as hard boundaries.

Ordinary one-unit-to-one-letter substitution still fails in Latin and Old
Italian. The next decoder must test a historical mixed inventory of homophonic
letters, syllables, nulls and a small whole-word nomenclator. No GDT605 unit is
yet assigned a sound, word or meaning.
