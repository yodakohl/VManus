# GDT541 method

## Question

When each of the 145 final GDT540 recipes is looked up unchanged in GDT407's
old 26-page running deck, which exact carriers exist and do their actual
same-statement action/argument modes reproduce the new target profile?

## Inputs

- GDT407's 4,576 old running events and 715 fixed statements;
- GDT516's original ten exact old-recipe contacts;
- GDT539's 546 selected-page contextual prose events;
- GDT540's 145 surface contracts and 149 occurrence contracts.

No unadmitted page or alternate segmentation is used.

## Method

1. Index the 145 final target recipes without changing atom order.
2. Replay each GDT407 statement from empty action and argument state. Visible
   roots update the two slots; a missing action/argument uses only the current
   same-statement slot under the GDT540 rule.
3. Select every old event whose complete recipe equals a target recipe.
   Preserve its old surface, page, register, statement, owner, context source,
   distance, and resolved roots.
4. Compare the set of old observed modes with the target's GDT540 mode set.
   Frequencies need not be equal.
5. Build a seven-event `OK+EE+S` casebook from the four old carriers and all
   three contextualized occurrences on the selected pages, including the old
   `okees` occurrence not itself among the 145 target surfaces.
6. Compare the final contacts with GDT516's ten-card inventory to isolate
   consequences of later recipe revisions.

## Result conditions

- every GDT407 statement, surface sequence, and recipe sequence replays;
- all exact matches are selected and no nonmatch enters;
- each inherited source is earlier in the same statement;
- all eleven old/target mode sets are identical;
- the four old `OK+EE+S` carriers exhibit both modes independently of the two
  target occurrences;
- the original ten GDT516 contacts remain and later `chekchy=CH+K+Y` is the
  sole new exact contact.

## Decision rule and claim ceiling

This compares exact recipes and their observed working context modes. The
state resolver is shared with GDT540; the new information is the independently
existing sequence environment on the old pages. Profile-set equality is not
frequency equality, plaintext, a confirmed lexeme, or proof that different
surface spellings are phonetic allographs. No page, recipe, root value, or
segmentation changes.
