# GDT776 — ol h4 h3 medial register bridge

Status: `PASS__H4_LEANING_HEURISTIC__INTERNAL_LATE_FIELD_BRIDGE__149_CONTEXTUAL__NO_PLAINTEXT`

GDT776 compares the fixed medial GDT775 `ol` remainder with complete H3/H4
record-field forms and compiles a more concrete exact-whole renderer. See
`PREREGISTRATION.md`, `METHOD.md`, and `experiment.json`.

The fixed run contains 183 targets, 102 H3 controls, and 350 H4 controls. H4
leads the broad and register-plus-ordinal views, while equal weighting of the
18 active shared bodies reverses to H3. The selected interpretation is therefore
an H4-leaning internal/late-field bridge, not an H4 identity.

Twenty-five recurrent complete right words now have explicit candidate
meanings, confidence, positive evidence, and counterevidence. Ten newly used
surfaces replace 26 generic target renderings: seven safe non-consuming
`ol ol` chain links and nineteen new consuming spans. Contextual coverage rises
from 123 to 149 of the fixed 376 `ol` positions.

Those 26 additions are C0/C1 span hypotheses, mostly field structure, not 26
newly decoded lexemes. The immediate next gain is to compose `ol r/s` with the
following value or state whole instead of ending the meaning after one glyph.

Reproduce with:

```bash
python3 experiments/yolo/gdt776_ol_h4_h3_medial_register_bridge/src/run.py
python3 experiments/yolo/gdt776_ol_h4_h3_medial_register_bridge/src/validate.py
```
