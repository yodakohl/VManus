1. `oldy` = weiter+Schluss — B4|H4 (NARROW_CROSS_SECTION_EXEMPLAR)
2. `choky` = ansetzen+Posten — B1|B2|B3|B4|H1|H5 (BROAD_CROSS_SECTION)
3. `cheeky` = wärmen+länger+Posten — B4|H4 (NARROW_CROSS_SECTION_EXEMPLAR)
4. `aiin` = Sollmaß — B1|B2|B3|B4|B5|B6|H1|H2|H3|H4|H5 (UNIVERSAL_ALL_PROSE_RECORDS)
5. `okal` = ansetzen+Ziel — B1|B2|B3|H4 (BROAD_CROSS_SECTION)
6. `char` = Quelle — B1|B2|B3|H1|H2 (BROAD_CROSS_SECTION)
7. `chdy` = umsetzen+Posten — B1|B3|B4|B5|H4 (BROAD_CROSS_SECTION)
8. `chor` = Ansatz — B3|B4|H2|H4 (BROAD_CROSS_SECTION)
9. `chety` = teilen+Teil — B3|H1 (NARROW_CROSS_SECTION_EXEMPLAR)
10. `cheey` = Ergebnis — B2|B4|H3 (NARROW_CROSS_SECTION_EXEMPLAR)
11. `okaiin` = ansetzen+Sollmaß — B1|B2|B3|H4 (BROAD_CROSS_SECTION)
12. `chey` = Posten — B1|B2|B3|B4|B6|H2|H3|H4 (BROAD_CROSS_SECTION)
13. `cheol` = weiter — B1|B3|B4|B5|B6|H1|H2 (BROAD_CROSS_SECTION)
14. `al` = Ziel — B1|B2|B3|B4|B5|H5 (BROAD_CROSS_SECTION)
15. `cholor` = weiter+Ansatz — B1|H2 (NARROW_CROSS_SECTION_EXEMPLAR)
16. `checthy` = bereit+Posten — B3|H1|H2|H3 (BROAD_CROSS_SECTION)
17. `otchey` = danach+Posten — B4|H5 (NARROW_CROSS_SECTION_EXEMPLAR)
