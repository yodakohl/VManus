# Taschenkarte der zweiten Atomschicht

## Vierzehn neue Kerne

- `SHED` = **ABSETZEN** — cheedy / shedal / sheedy
- `L` = **ABFÜHREN** — lchedy / ldy / lar
- `CTH` = **BEREIT** — checthy / cthaiin / cthoor
- `CKH` = **DURCHLEITEN** — chckhy / sheckhy / qockhey
- `CKHE` = **SEIHEN** — shckhedy / lcheckhedy
- `CHK` = **WÄRMEN** — cheky / cheeky / chkeedy
- `SOLK` = **SAMMELN** — solkey / solkeey / olkeedy
- `WASH` = **WASCHEN** — lsho / lshedy / rshedy
- `IIN` = **STUFE** — oiiin / daiiin / kaiiin
- `TY` = **TEIL** — cheeety / etyd / otytchol
- `AIR` = **WASSERLAUF** — chair / kair / okair / schedair
- `CHEO` = **AUSZUG** — cheoar / chokcheo / ycheor
- `P` = **EINFÜHREN** — pchedal / pchedy
- `PARTITION` = **TRENNEN** — ches / chety

## Neue produktive Reihen

- `SHED + E/EE + CLOSE` → kurz/länger absetzen und schließen
- `CKH + E + Y/AL` → kurz durchleiten / kurz zum Ziel durchleiten
- `CHK + E/EE + Y/CLOSE` → kurz/länger wärmen, offen oder geschlossen
- `SOLK + E/EE + Y/CLOSE` → kurz/länger sammeln, offen oder geschlossen
- `L + CHD + AR/AL/CLOSE` → vom Ausgang / zum Ziel / abschließend abführen
- `AIR`, `OK+AIR`, `AIR+Y+CLOSE` → Wasserlauf lesen, setzen, schließen
