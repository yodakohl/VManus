# Vier Passagen der zweiten Atomschicht

Die neuen Kerne benennen konkrete Werkstatthandlungen. Bereits bekannte Atome liefern Richtung, Wert, Grad, Posten und Schluss.

## H1-S001 · f10r · f10r.2

**Sichtbar:** `dchey cthoor char chty os chair otytchol oky daiin etyd`

**Kartenweise:**

- `dchey` → `LOCAL_WHOLE` → **WURZEL** (LEARNED_LOCAL_WHOLE)
- `cthoor` → `CTH+OR` → **BEREITER ANSATZ** (SECOND_RING_COMPOSED)
- `char` → `AR` → **VOM AUSGANG** (FIRST_RING_SHARED_SEED)
- `chty` → `PARTITION+TY` → **TEIL ABTRENNEN** (SECOND_RING_COMPOSED)
- `os` → `OS` → **UMSCHLIESSENDER TRÄGER** (FIRST_RING_SHARED_SEED)
- `chair` → `AIR` → **WASSERLAUF** (SECOND_RING_COMPOSED)
- `otytchol` → `OT+TY+OL` → **NÄCHSTEN TEIL FORTSETZEN** (SECOND_RING_COMPOSED)
- `oky` → `OK+Y` → **AKTUELLEN POSTEN SETZEN** (FIRST_RING_SHARED_SEED)
- `daiin` → `AIIN` → **VORGABEWERT** (FIRST_RING_SHARED_SEED)
- `etyd` → `E+TY` → **KURZER TEIL** (SECOND_RING_COMPOSED)

**Neue flüssige Lesung:** Nimm die Wurzel, halte den Ansatz bereit, nimm vom Ausgang, trenne einen Teil, gib ihn in den Träger, öffne den Wasserlauf, führe den nächsten Teil weiter und setze den aktuellen Posten auf den Vorgabewert.

**Bisherige Lesung:** Nimm die Wurzel, bereite den Ansatz, trenne daraus einen Teil ab, gib ihn in das Gefaess, gib den Wasserzulauf zu, fuehre den naechsten Teilposten weiter, setze ihn nach Sollmass an und behalte einen kleinen Restteil.

## B2-S005 · f82r · f82r.3|f82r.4

**Sichtbar:** `qokaly solkaiin chckhy qokaiin qokaiin octheol chkeey ldy`

**Kartenweise:**

- `qokaly` → `OK+AL+Y` → **AKTUELLEN POSTEN AM ZIEL SETZEN** (FIRST_RING_PREDICTED)
- `solkaiin` → `SOLK+AIIN` → **BIS VORGABEWERT SAMMELN** (SECOND_RING_COMPOSED)
- `chckhy` → `CKH+Y` → **AKTUELLEN POSTEN DURCHLEITEN** (SECOND_RING_COMPOSED)
- `qokaiin` → `OK+AIIN` → **AUF VORGABEWERT SETZEN** (FIRST_RING_PREDICTED)
- `qokaiin` → `OK+AIIN` → **AUF VORGABEWERT SETZEN** (FIRST_RING_PREDICTED)
- `octheol` → `CTH+OL` → **BEREIT FORTSETZEN** (SECOND_RING_COMPOSED)
- `chkeey` → `CHK+EE+Y` → **LÄNGER WÄRMEN** (SECOND_RING_COMPOSED)
- `ldy` → `L+CLOSE` → **ABFÜHREN; SCHLUSS** (SECOND_RING_COMPOSED)

**Neue flüssige Lesung:** Setze den aktuellen Posten am Ziel, sammle bis zum Vorgabewert, leite durch, setze zweimal auf Vorgabewert, führe bereit fort, wärme länger, führe ab und schließe.

**Bisherige Lesung:** Setze diesen Posten dort an, sammle bis zum Sollmass, leite durch, stelle das Sollmass ein, fuehre bereit weiter, waerme laenger, ziehe ab und schliesse.

## B2-S016 · f82r · f82r.26|f82r.27

**Sichtbar:** `cheal lchedar ches aiin oteey qokaiin okey pchedy`

**Kartenweise:**

- `cheal` → `AL` → **ZUM ZIEL** (FIRST_RING_SHARED_SEED)
- `lchedar` → `L+CHD+AR` → **VOM AUSGANG ABFÜHREN** (SECOND_RING_COMPOSED)
- `ches` → `PARTITION` → **TRENNEN** (SECOND_RING_COMPOSED)
- `aiin` → `AIIN` → **VORGABEWERT** (FIRST_RING_SHARED_SEED)
- `oteey` → `OT+EE+Y` → **NÄCHSTER POSTEN; LANGE STUFE** (FIRST_RING_SHARED_SEED)
- `qokaiin` → `OK+AIIN` → **AUF VORGABEWERT SETZEN** (FIRST_RING_PREDICTED)
- `okey` → `OK+E+Y` → **KURZE STUFE SETZEN** (FIRST_RING_SHARED_SEED)
- `pchedy` → `P+CHD+CLOSE` → **EINFÜHREN; SCHLUSS** (SECOND_RING_COMPOSED)

**Neue flüssige Lesung:** Führe zum Ziel und vom Ausgang ab, trenne, setze den Vorgabewert, nimm den langen Folgeposten, setze kurz, führe ein und schließe.

**Bisherige Lesung:** Führe ihn dorthin und von dort ab, teile gleich, stelle das Sollmaß ein, nimm den langen Folgeposten, setze kurz an, führe ein und schließe

## B3-S034 · f83r · f83r.24

**Sichtbar:** `soiiin checthy chety otaiin olsaly shedy`

**Kartenweise:**

- `soiiin` → `IIN` → **STUFE** (SECOND_RING_COMPOSED)
- `checthy` → `CTH+Y` → **BEREITER POSTEN** (SECOND_RING_COMPOSED)
- `chety` → `PARTITION+TY` → **TEIL ABTRENNEN** (SECOND_RING_COMPOSED)
- `otaiin` → `OT+AIIN` → **FOLGEWERT** (FIRST_RING_PREDICTED)
- `olsaly` → `AL+Y` → **POSTEN ZUR UNTEREN ZIELSTELLE** (SECOND_RING_COMPOSED)
- `shedy` → `SHED+E+CLOSE` → **KURZ ABSETZEN; SCHLUSS** (SECOND_RING_COMPOSED)

**Neue flüssige Lesung:** Setze die Stufe, halte bereit, trenne einen Teil, setze den Folgewert, führe zur unteren Zielstelle, setze kurz ab und schließe.

**Bisherige Lesung:** Bringe auf Sollstufe, halte bereit, trenne einen Teil ab, stelle das Folgemass ein, fuehre zur unteren Zielstelle, lass absetzen und schliesse.
