# Method

Read only the hash-fixed1042 projection, already limited to f85r2. Preserve all473 rows,24loci and three alternative readers. Assign spatial blocks by the fixed locus ranges, keeping .1 and .24 separate. Select every raw string beginning qod, including unmatched/uncertain remainders. For each candidate apply only the SPEC type table to the literal suffix after those three letters. The LOC_OWNER output is conditional on a tagged unique-owner representation.

For each occurrence retain exact group identity and full block context. Report availability of the five exact tokens in S's previously authored attraction frame. Token presence is not a newly inferred syntax: this check merely verifies the written constituents of that one fixed frame. Other blocks lack a reference grammar and receive NO_LICENSED_TRANSFER_FRAME. Also report every baseline whole-sense assignment and every other unassigned context token, without silently extending the24-value dictionary.

The runner emits occurrence and complete-context tables plus a compact result. An independent validator reconstructs selection, preservation, two type outcomes, frame gaps and counts without importing the runner. No statistic, fitted parameter, segmentation search or meaning promotion is computed. The full glyph strings and source separators remain in the context table.
