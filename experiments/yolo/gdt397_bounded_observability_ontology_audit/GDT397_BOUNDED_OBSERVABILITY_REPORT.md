# GDT397 bounded observability-ceiling and ontology-correction audit

Date: 2026-08-21

Status: `ONE_CONDITIONAL_FORMAL_EDGE_CEILING_PASSES`

## Outcome

GDT397 corrects the ontology used to interpret GDT396 and isolates one narrow
recoverable structural endpoint. Exact visible identity is observable. A
backward target can also be ranked from observation-only context when the
source pivot is supplied, across W02 and W09 and all five held-seed folds. This
supports future work on an anonymous conditional relation-edge ranker, not a
`REF` word, pronoun, semantic reference class, or meaning.

The other operator-relevant routes do not pass:

- control-like roles are already almost completely predicted by the simple
  position/frequency/boundary baseline, leaving no registered incremental
  gain;
- the alternative/branch endpoint has positives in only W09;
- scope ends are largely physical record ends, and the learned model does not
  beat that stronger baseline.

No Voynich text was scored. No new corpus, seed, world, decoder, or LLM output
was generated. Confirmation seeds `3962000..3962004` were not opened or
generated. Neither `f84` nor `f84r` was accessed.

## Corrected ontology

| level | internally observable? | licensed conclusion |
|---|---|---|
| `FORMAL_IDENTITY` | yes, where equality/recurrence transfers | the same opaque visible or renderer-invariant unit recurs |
| `ANONYMOUS_STRUCTURAL_ROLE` | sometimes | an unlabeled slot, edge, state, or scope pattern recurs |
| `REFERENTIAL_SEMANTICS` | not from distribution alone | requires external grounding; no denotation, gloss, or named operator follows |

A branch/rejoin topology can be real while its interpretation as OR remains
underdetermined. Likewise, a backward edge can be real without licensing REF,
anaphora, pronoun, or any readable semantic category.

### Conditional-edge limitation

The backward-edge ceiling conditions on source rows selected by the exposed
oracle, then ranks every earlier visible event. It proves that antecedent/target
choice is encoded once a query pivot is supplied. It does **not** show that a
blind method can identify which events are query pivots. That source-detection
problem remains uncalibrated and must be part of any future targeted test.

## Surface-channel correction

The constrained channel is fixed-width and bijective. Grouping consecutive
atom pairs restores the FREE token algebra exactly; the runner requires all
FREE and atom-decoded fold results to be byte-identical.

Raw-atom segmentation changes some scores but does not consistently harm them.
For example, W02 backward-target MRR is .5044 raw versus .4844 decoded, while
W09 is .9678 raw versus .9793 decoded. Thus the GDT396 channel did not destroy
the tested information. Differences are decoder/segmentation effects.

## Observational-equivalence witness

W09 qualification seed 3961000 has two interpretation records sharing the
same unchanged observation SHA-256:

`b859fe8a440f092e06ea58611d9d4f15596eff6e92e8f4a083e2538b5d12ae65`

Interpretation A retains the original semantic oracle. Interpretation B keeps
only anonymous formal edges, construction, record schema, state transitions,
scope, and register realization while deleting external entities, domain and
activity, semantic categories, component meanings, and readable
function/relation labels.

Because the observation bytes are identical, any observation-only decoder must
emit the same output for A and B. Consequently internal distribution cannot
identify:

- whether the system denotes anything outside itself;
- actual lexical meanings or English glosses;
- whether an isomorphic control symbol is meaningful or semantically inert.

This is a logical identifiability ceiling, not evidence that a manuscript is
meaningless.

## What the W10 audit changes

W10 genuinely contains construction classes, record schemas, state
transitions, and scope boundaries. Those formal objects must not be called
semantic false positives merely because W10 lacks external denotation.

The frozen GDT396 outputs separate into three cases:

1. **Invented formal edges.** W10 has no oracle relation edge. Across the
   frozen decoder/representation claim rows, all 165,661 resolved reference
   assertions per surface and all 169,104 resolved alternative assertions per
   surface predicted a target. Their invented-edge rate is 1.000. Counts are
   route-level claim rows, not unique manuscript-like events.
2. **Unvalidated role clustering.** The best former
   `FUNCTION_OPERATOR_CLASS` partition has formal NMI .1376 and ARI .0071,
   with 0/5 seeds meeting the formal-alignment gate. It is neither a validated
   semantic class nor a stable recovered formal role.
3. **A modest real formal signal mislabeled semantically.** The best former
   temporal/gate output predicts actual W10 formal scope-end events with AUROC
   .7153 and AP .1319 against prevalence .0811. This is evidence of some formal
   closure sensitivity. It cannot identify TIME, UNTIL, a state-gate meaning,
   or any semantic label.

The former blanket W10 semantic-false-positive summary was therefore partly
correct for invented relations but too coarse for scope/closure structure.

## Concrete answers

1. **Which GDT396 failures were caused by the unrelated suite?** All 18 routes
   that passed their endpoint/world/W10 gates were suppressed because every
   decoder failed the global recurrent-relation suite: eight lexical-identity
   routes, three record-schema routes, two entity-reuse routes, two ancestry
   routes, two state-after routes, and one productive-component route. GDT397
   directly validates the lexical case as gate contamination. It does not
   retroactively validate the other ten route-level diagnostics.
2. **Which W10 positives invented structure?** Positive reference and
   alternative target edges: their corresponding formal relations are absent.
3. **Which were formal detections mislabeled as semantic?** The scope-end
   signal has modest real formal alignment. No stable anonymous role alignment
   was found for the function-class partitions.
4. **Can the three operator topologies be predicted?** Conditional backward
   target ranking: yes in both worlds and 5/5 folds. Alternative topology:
   insufficient two-world capacity. Scope endpoint: no gain over record-end
   controls.
5. **Is decoder improvement justified?** Yes, but only for one bounded target:
   anonymous backward-edge target ranking jointly with blind pivot detection.
   Semantic names remain forbidden.

## Hard-stop disposition

The sole future nominee is `REFERENCE_OR_REUSE_EDGE`, understood strictly as a
conditional anonymous backward-edge target. GDT397 stops here. It does not
build a decoder, generate another seed, start GDT398, or authorize Voynich
scoring. Any future test must use entirely new seeds outside
`3961000..3962004`, freeze blind pivot detection as well as target ranking, and
retain:

`anonymous formal relation != REF / anaphora / meaning`.

Full fold details and the two-row proof witness are in
`artifacts/gdt397_observability_results.tsv`; independent validation passes
25/25.
