## Selected historical object

The selected object is the separately headed, unnumbered `[Anonym.]` nomenclator placed after no. 28 in Aloys Meister's documentary edition of Gabriel de Lavinde's 1379 cipher manual. It is not Lavinde key 13 or key 26. Meister's section heading dates the manual to 1379 and identifies its archival object as `Vat. Arch. Collect. 393, f. 166-181`; the section's opening declaration identifies Gabriel as a *familiaris et officialis domini nostri pape* and names Clement VII. This gives the table papal-curial provenance within the requested 1370-1450 window, although the anonymous table itself has neither a separately stated correspondent nor a separate date.

The edition prints the table on pp. 175-176. The table begins below no. 28 with its own bracketed editorial heading `[Anonym.]`, then continues at the top of p. 176 before Meister begins section II. Stable page objects are:

- printed p. 175 / scan leaf n191: <https://archive.org/details/diegeheimschrift00meis/page/n191/mode/1up>
- printed p. 176 / scan leaf n192: <https://archive.org/details/diegeheimschrift00meis/page/n192/mode/1up>
- full documentary-edition PDF: <https://archive.org/download/diegeheimschrift00meis/diegeheimschrift00meis.pdf>

Documentary edition: Aloys Meister, *Die Geheimschrift im Dienste der päpstlichen Kurie von ihren Anfängen bis zum Ende des XVI. Jahrhunderts*, Quellen und Forschungen aus dem Gebiete der Geschichte 11 (Paderborn: Ferdinand Schöningh, 1906), pp. 171, 175-176.

Original shelfmark as cited by Meister: Archivio Apostolico Vaticano (Meister's `Vat. Arch.`), Collect. 393, ff. 166-181. The edition does not assign this unnumbered table to a narrower manuscript folio, so the frozen locators use the exact printed page, column, and line rather than inventing a folio.

## Prior-use screen and independence limit

The historical-source-only V77 inventories were consulted only to prevent reuse. They contain Lavinde keys 13 and 26, the post-1412 Pisan papal key, and secular comparison/control keys, but not this separately headed post-no.-28 table.

This is a previously unused table identity, but it is not strong independent evidence from key 13. Meister attaches the footnote `Sehr ähnlich Nr. 13` ("very similar to no. 13") to it. Many entries and codes overlap key 13, sometimes with spelling or abbreviation differences. Phase 2 must therefore treat the rows as one additional documentary table, not as 37 independent confirmations and not as cumulative weight against key 13. The source can license only source-vocabulary/category granularity; it cannot by itself license any manuscript-word identity.

## Frozen row rule

The inventory freezes 37 exact entry-code pairs, below the 60-row cap, in documentary-page order: each column top-to-bottom, then the next column. Admission was source-first and mechanical:

1. the source-language entry is fully printed;
2. the corresponding code consists only of unambiguous Roman letters and/or Arabic digit `3`;
3. capitalization, abbreviations, editorial brackets, and mixed-case `pR` are preserved;
4. line-wrapped `vice-comitibus` entries are joined only across the documented print line break; and
5. no missing, graphic, supraline, or uncertain sign is reconstructed.

Excluded controls are the graphic substitution alphabet, `papa` (graphic code), `Karolus de la pace` (supraline/overbarred b-like code), `Comes fundorum` (letter plus graphic stroke), and `Matrimonium` (printed first code character is typographically l/I-like). These exclusions cannot license a word or code in Phase 2. The full-document PDF is hash-bound so every exclusion and admitted row can be checked against the same immutable source object.

## Historical structure and evidential ceiling

The nomenclator is diplomatic rather than herbal or medical. Its source-side vocabulary is dominated by rulers and offices, named persons, territorial or civic referents, adherents and armed people, and political states/actions such as *pax* and *guerra*. This is a description of the historical table only, not a translation proposal. No mapping by sound, spelling resemblance, or modern semantic expectation is permitted.

The strict Phase-1 evidential ceiling for every admitted row is `SOURCE_VOCABULARY_ONLY_NO_TARGET_IDENTITY`.
