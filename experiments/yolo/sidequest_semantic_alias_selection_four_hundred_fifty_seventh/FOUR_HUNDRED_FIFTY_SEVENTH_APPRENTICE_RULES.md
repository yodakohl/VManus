# Nine rules for choosing among same-value cards

1. Write short `QOKCHDY` for ANSATZ UMSETZEN; SCHLUSS at statement entry;
   write expanded `OKCHEDY` after an earlier action.
2. B5 contracts DANACH UMSETZEN; SCHLUSS to `OTCHDY`; B3 uses expanded
   `OTCHEDY`.
3. H1 orders DIES KURZ FUELLEN as `ETYD`; B1 writes `YTEY`.
4. B2 writes `CHKEEY` for DIES LAENGER WAERMEN; H4/B4 write `CHEEKY`.
5. Write `CHEDCHY` only directly before AN DIE STELLE SETZEN; elsewhere use
   the ordinary `CHDY/CHEDY` card.
6. Write `YKAIN` for the first supplied portion and contracted `YKAN` when the
   same portion instruction repeats immediately.
7. At Herbal statement entry use `DCHOL/SCHOL` to resume; inside a running
   statement use the ordinary `OL` card.
8. H3 writes `QOTCHY` for NAECHSTER POSTEN; H5/B4 use `OTCHEY`.
9. Contract UMSETZEN; SCHLUSS to `DCHDY` only after KURZ FORTSETZEN; otherwise
   write expanded `DCHEDY/SCHEDY/TCHEDY`.

The context rules are productive. The four record-renderer rules are learned
allographs: they predict the exact card but do not add a second meaning.
