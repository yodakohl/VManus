# GDT338 — renderer invariant equivalence

Status: `REGISTERED_UNSCORED`

GDT338 tests whether distinct wrapper-rendered field observations on held
folios collapse to the same exact opaque joint-tuple sequence under only the
supported GDT322 renderer and GDT335 placement effects.

It does not mine glyphs, PAGE_HOST, substrings, phase, semantics, or external
content. Different exact joint tuple sequences remain different.

See `METHOD.md`, `artifacts/gdt338_design.json`, and `experiment.json`.
