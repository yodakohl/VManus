# De balneis: complete-record joint content preflight

Source-only independent review, 2026-09-15. Budget: 20 minutes from 09:39:30 UTC.
No target paragraph bodies, new admissions, decoder, registry changes or image
inferences enter this review. This is a proposed conditional model, not a source
identification or a clinical endorsement of the medieval claims.

**Decision:** the complete source supplies nontrivial joint constraints. A bounded
source-compilation and metadata-capacity preflight is justified. A name/keyword
incidence fit alone would remain a partial-content hypothesis like GDT888; it
would not deliver the requested complete paragraph reading. Do not start a large
solver until the complete serialization and target-record capacity are fixed.
No previously confirmed name or body-part translation is logically required to
test such an explicitly conditional model.

## Concrete contrasts and source-owned links

The full source, rather than pictures or selected snippets, supplies:

- XVI: Raynerius users are advised to proceed to another bath to avoid recurrence
  (lines 189–190). The downloaded text prints `tribuli`; identifying this with
  Trituli requires an explicit source alias, not silent spelling repair. Under

- XXI: Arculus is compared with Trituli and Culma; the comparison is qualified
  rather than universal identity (lines 253–256).
- XXV: Petroleo/Olivum is near Culma (line 293). Spatial proximity is a different
  relation from supply, sequential use or comparable effects.

Under that stated identity resolution these involve seven bath identities; the
off-diagonal name network alone leaves 25 records isolated. It is still useful
because the mention of a bath must share
its global identity code with that bath's own record. Names can be hypothesized
jointly; none needs a confirmed Voynich anchor first. Etymological resemblance
such as Bulla/bullit or Arcus/Arculus does not itself specify a phonetic code or
authorize a new spelling transformation.

HYDROPS has five explicit occurrences, once per body: VII harms hydropic
patients; XX and XXIII claim relief; XXX claims relief in a passage containing
a dose/repetition prescription; XXXIII helps a specified gross-phlegm subtype.
Keep the latter qualification and the exact scope of XXX's dose in the source

## Smallest adequate model and exact consequence

The smallest useful **joint preflight** is a fixed complete incidence contract:
all 32 source records, an injective assignment to 32 whole eligible target
records within one transcription, and one shared code for every declared
concept and named entity. Preserve all source multiplicities and zeros, typed
references, polarity and conditions. Freeze the target units and how source
roles are expressed before fitting. An arbitrary substring occurrence cannot
stand in for a decoded concept if it crosses codeword boundaries.

Let S be the full source record-by-concept count matrix. Under record assignment
pi and common concept code c, the corresponding target matrix must satisfy
T[pi(r),c(k)] = S[r,k] simultaneously for every row and column. Consequently all
column totals, all row vectors and every column co-incidence count must agree
under **the same** assignment. Typed relation and condition tensors add their
corresponding equalities. Choosing a fresh assignment for each organ or each
comparison is prohibited. An incompatible overlap, missing required mention,
extra forbidden mention, reversed typed relation or lost condition is an exact
contradiction of that fixed model. No prior translation is needed to state it.

This alone is an informative incidence experiment, not a complete reading.
To meet the stronger goal, freeze **one complete source-to-atom serialization**
and **one global compositional encoding** covering every position of each
assigned paragraph. Every source clause must have a traceable disposition:
predicate, arguments, modifiers, negation, dose/sequence and narrative content.
Canonicalizing prose is permissible as a declared hypothesis, but clause order,
omissions and grammatical realization cannot be chosen per target. No fresh
row-specific residual atom, ignored target group or arbitrary source window may
fill a mismatch. Any literal lexical fallback must itself use a declared shared
representation, rather than a new unconstrained whole-string key per singleton.

A fixed complete Latin source transduction is a smaller mechanical implementation
than a new semantic grammar, but it tests copying/transduction of this edition.
A complete canonical proposition language would test translated/reorganized
content; it requires source-only compilation of all 32 bodies first. These are
different contracts. A few labeled nouns with anonymous rest-of-paragraph material
do not become a complete proposition language merely by sharing five codes.

Under either complete contract, a saved full key and all 32 exact paragraph
readings are a plausible **conditional witness**. Rejecting every assignment
falsifies that source/serialization/code/scope combination. Several solutions
leave the differences unidentified; report the projection common to all
solutions if any. A single solution can conditionally identify code values
without pre-existing anchors, but only within the frozen hypothesis space.
Graph asymmetry or a best-scoring fit does not remove rival source/encoding
families, create independent confirmation, or establish historical translation.

## Decision-changing next step and stop

First check capacity from existing frame metadata, without paragraph payloads.
GDT211's exact section-B primary has only 17 editorial paragraph starts on nine
folios. It cannot host 32 distinct complete entries under a one-entry/one-paragraph
contract. This is not the current capacity result. Root's subsequent
`BALNEIS_CAPACITY.json`, whose metadata I inspected, reports 78 ZL and 79 IT
complete frames on 18 admitted f75r–f83v selectors (nine physical leaves), and
zero RF complete-boundary capacity under GDT928's fixed frame convention.
After the unchanged parent-line literal eligibility rule, ZL has **3** literal
frames and IT **71**. I have not read or fitted their payloads or independently
reconstructed raw-frame eligibility. IT has 32-record capacity; ZL's 75 nonliteral
frames remain unknown and RF's missing complete boundaries are missing capacity,
not general source refutations.
Do not obtain capacity by clipping entries, silently treating lines as records,
merging alternate transcriptions, or admitting pages. A different unit convention
would need its own source and manuscript rationale before scoring.

If capacity exists, compile the full source and run cheap exact necessary
conditions first: counts, complete-record length where the encoding licenses
it, repeated-unit equality, code-boundary constraints and joint incidence.
If capacity fails, stop this exact 32-distinct-record model. If necessary
conditions fail, publish that finite failure. Only a surviving completely
specified model justifies a separately budgeted exact joint search; a timeout
must remain unknown. This review authorizes neither a decoder nor serial repairs.

The real unknown is whether a complete fixed source-content code has a joint
embedding, not whether bath imagery suggests medicine. That question is
testable. A source graph with free labels and unexplained paragraph bodies
would answer a materially weaker question.

## Narrowed 13-family proposal received during review

Root subsequently proposed an explicitly **partial necessary-condition test**:
WATER, clinical HEAD, STOMACH, OCULUS, LIVER, SPLEEN, SKIN, LUNG, KIDNEY,
BLADDER, WOMB, NERU and HYDROPS, all 32 complete source records, every zero and
multiplicity, one shared finite carrier lexicon and an injective whole-paragraph
assignment. **HEAD replaces EAR** in the earlier 11-family diagnostic; that
diagnostic is not the final 13-column source matrix. Other target groups remain unknown;
no full-translation claim would be made. That distinction resolves the strongest
objection to calling an incidence fit a complete reading. The complete source
family allocation, not a complete new Latin grammar, is the source work required
for this narrower preflight.

This is worth a small, fixed-budget feasibility test if literal capacity exists.
It has an exact, new all-record incidence consequence, not just an attempt to
pick a better member of GDT888's failed 18-lexicon family. The following terms
are essential before registration:

1. Use lexical-family identifiers. The seven-record OCULUS column excludes
   several other explicit eye/vision expressions; it is not the full semantic
   concept EYE. Likewise the NERU family does not purport to exhaust every nerve,
   sinew, limb or modern neurological reference. Glosses are hypotheses about
   the declared family, not a claim of exhaustive clinical coding.
2. State the no-homography assumption: an unmodelled word cannot coincidentally
   contain the selected family carrier under the tested occurrence definition.
   Otherwise extra matching groups cannot be counted as contradictions. The
   decision note now states distinct carriers and two separate fixed models:
   a whole literal group, or a nonempty literal piece within a group. The latter
   counts presence once per group, allows different pieces to co-occur, and
   never crosses groups. It does not assert discovered morpheme or codeword
   boundaries; the stronger complete-code discussion above is not its parser.
3. Count every source occurrence under the declared namespace and freeze any
   source sense distinction. Root deliberately defines clinical HEAD, excluding
   I's civic caput: this is a permitted sense-specific semantic-code hypothesis,
   under which the other sense may receive another carrier despite identical
   Latin spelling. Every occurrence of the chosen target carrier must still
   count; an inconvenient extra occurrence cannot later be declared nonclinical.
   Do not alternate lexical and clinical scope after seeing a match.
4. Preserve literal annotation unknowns. An unusable whole paragraph is not a
   negative result; fewer than 32 eligible paragraphs is a capacity failure of
   this exact assignment model. Nine physical leaves are not 32 independent
   observations, and alternate readings are not replications.
5. Positive incidence compatibility is a candidate lexical-family assignment.
   It neither supplies effect polarity or condition attachment automatically,
   nor constitutes a complete hypothetical paragraph. A signed-condition model
   would need its own source allocation and fixed encoding. Any later complete
   reading must account for the residual rather than reusing its freedom to
   repair the fitted family values.

The inexpensive necessary screen can decide whether that finite partial model
has capacity or immediate contradictions. A surviving assignment justifies
reporting the conditional candidate and remaining ambiguities; it does not
justify automatic decoder expansion, a source claim or a semantic score.
