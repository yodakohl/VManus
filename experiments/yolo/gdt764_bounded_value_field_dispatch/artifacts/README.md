# GDT764 artifacts

- `X_254_EXACT_OCCURRENCE_ATLAS.tsv`: all reader-exact occurrences of the six
  X wholes, with L2-R2 roles and provenance.
- `X_6_GLOBAL_ROLE_PROFILE.tsv`: frequency, geometry, GDT686 recurrence, role,
  confidence, evidence, and counterevidence for each X whole.
- `X_DAIIN_9_EXACT_BIGRAM_ATLAS.tsv`: every current reader-exact `X daiin`
  pair and its selected or explicitly open local-axis decision.
- `H1_X_DAIIN_5_BOUNDED_FIELD_ATLAS.tsv`: the five bounded target fields and both
  portable and aggressive C1 renderings.
- `DAIIN_LOCAL_AXIS_DISPATCH_SUMMARY.tsv` and `FIELD_GRAMMAR.tsv`: compact
  grammar and axis summary.
- `OL_RAW_EXACT_RECURRENCE_AUDIT.tsv`: all fifteen raw strings, twelve admitted
  exact strings, and the three excluded reader-flag patterns.
- `OL_ORDER_ASSOCIATION_PROFILE.tsv`: four construction-specific neighbor
  comparisons; only `ol s aiin` is independently distinctive.
- `OL_12_REPEAT_ORDER_ATLAS.tsv` and `OL_REPEAT_ORDER_PROFILE.tsv`: all four
  recurrent `ol` orders and their positional dispatch.
- `OL_HYPOTHESIS_SCORECARD.tsv`: ranked preparation, oil, context, unit, and
  source alternatives.
- `HISTORICAL_REGISTER_TEMPLATE_MAP.tsv`: attested grade, amount, equal-parts,
  and oil architectures with zero spelling credit.
- `BOUNDED_RENDERER_REVISION.tsv`: seventeen directly usable span renderers.
- `RESULT.json` and `VALIDATION.json`: compact outcome and replay checks.

The 254-row context atlas is retained because it is the complete evidence
base for the six X-role decisions and is well below the five-megabyte limit.
