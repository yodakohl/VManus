# Sidequest Pass 807: three material roots

The material-looking strip values are not variants of one visible `o` stem.
They are three distinct reusable roles:

- `AIR = WASSER` — working liquid (5 cards / 5 events);
- `OR = ANSATZ` — the current preparation or batch (10 cards / 18 events);
- `HO = ZUTAT` — an input ingredient (5 cards / 8 events).

Each value survives several independent compositions. Water can be taken,
added, started, transferred, kept current, and closed. The batch combines with
next/continue, taking, portion, target, cooling, and guiding. The ingredient can
stand alone, remain current, be sent to a target, be added from a source, or be
taken for the batch.

The decisive card is `chochor = HO+CH+OR`:

> **Zutat entnehmen; zum Ansatz.**

Because `HO` and `OR` coexist as different arguments, they cannot be two
spellings of the same material. Likewise `AIR` has its own operation frames.
No meaning is assigned to every visible letter `o`; only the registered card
recipes license these roots.

`O=VORGANG`, `IIN=ARBEITSSTUFE`, and `SOLK=SAMMELSTELLE`. SOLK already suggests
a grade/endpoint grid; O and IIN must show independent portability rather than
being promoted merely because they recur.
