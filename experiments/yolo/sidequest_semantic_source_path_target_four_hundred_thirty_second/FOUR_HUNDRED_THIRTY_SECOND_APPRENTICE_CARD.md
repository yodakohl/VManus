# Werkstattkarte: WOher — WOdurch — WOhin

| Frage | Karte | Lesung |
|---|---|---|
| WOher? | AR | von dort / Quellseite |
| WOdurch? | CKH | durch den Durchlass |
| WOhin? | AL | an die Zielstelle |
| In welcher Folge? | OT / OL | danach / fortsetzen |
| Welche Bewegung? | CHED | überführen |
| Welche Sonderbewegung? | L+CHED / SH+CKHE | hinausführen / seihen |

Kurzform für den Lehrling:

> AR nehmen — durch CKH führen — an AL setzen. OL setzt denselben Gang fort;
> OT beginnt danach vom erreichten Punkt. DY schließt nur die gelernte
> Schlusskarte.
