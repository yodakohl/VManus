# Method

The proposed carrier is a bijection from22Hebrew base letters to22working
signs, one group per source word. A bijection preserves length moments and
within-word bigram probabilities up to renaming, hence conditional entropy.
Both declared letter directions are covered. No decoder is built.

All source chapters are projected before comparison, including citations and
editorial parenthetical text; the projection is explicitly lossy before the
letter channel. The fixed complete word count defines the native sample size.
All pooled and single-field metadata categories are considered separately for
each reader; only cells with enough words are scoreable. Use all128old page
seeds and three unchanged1174tolerances. ANYjoint sample match prevents exclusion.
All details, stops, outcomes and limitations are frozen in src/SPEC.json.
