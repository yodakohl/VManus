## The hand-checkable cost argument
At a chart position bearing g, the first-six distinct clockwise labels include
g itself. Thus at most five OTHER labels can follow. The first-four list for
the other phase is a subset from the SAME position and adds no new alternatives.
If the chart contains m_g occurrences of g, at most5m_g distinct nonself
successors are available across them. Therefore

    m_g >= max(1, ceil(nonself_degree(g)/5)).

An observed sign still needs a position when it has no observed successor.
Self repetitions are excluded from the degree because the current label already
occupies one of the six choices. Summing the22requirements is necessary.
Shared circle order, reachable states, compatible paths through full messages
and source statistics can require more or prevent a proposed chart altogether.
No optimizer has shown that these bounds can be attained simultaneously.

## Post-result consequence: incoming and outgoing positions together
After the registered calculation, a second source-free argument was checked.
For one landing position labeledh, any eligible non-h predecessor label must
belong to the lastfive distinct non-h labels before it. Otherwise the arc from
that predecessor to the landing already contains at leastsix non-h labels, so
h cannot be among the firstsix choices. An earlier h occurrence only restricts
which landing is reachable. This requires the specified FIRST encountered
occurrence, not a free jump to another identically labeled chart position.

Consequently the same position budget bounds both incoming and outgoing diversity:

    m_g >= max(1, ceil(d_out(g)/5), ceil(d_in(g)/5)).

Take the maximum perlabel, NOT the sum of incoming and outgoing requirements;
one position may serve both. Then sum across the22labels. Shared circle-order
and full-path constraints still remain, so this is again only a necessary bound.
