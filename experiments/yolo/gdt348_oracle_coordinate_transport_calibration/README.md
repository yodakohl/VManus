# GDT348 oracle-coordinate transport calibration

This experiment tests the frozen GDT347 graph against the sealed, authored
coordinate fields of lexical System A, factorial System B, and human-grown B2.
It is an oracle-ceiling calibration of control comparability, not a new
Voynich model. See `METHOD.md`.

Status: **ORACLE_MANUSCRIPT_SPECIFIC_RETAINED**. All three comparable oracle
controls worsen held codelength under the unchanged graph: lexical A -82.19
bits, factorial B -1,403.70, and human-grown B2 -788.29; every system is
negative on all five held source units. This retains the GDT347 convention as
manuscript-specific within the mapped coordinate layer, not as a unique
compiler or language.
