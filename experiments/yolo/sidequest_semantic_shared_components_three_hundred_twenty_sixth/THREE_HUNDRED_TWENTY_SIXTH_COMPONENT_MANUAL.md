# Der kleine Kompositionskasten

## Dreizehn Bedeutungsbausteine

| Kern | Werkstattwert |
|---|---|
| AIIN | Sollmaß |
| OL | Fortsetzung |
| Y | aktueller Posten / dies |
| CHD | umsetzen |
| AL | Stelle |
| OK | einsetzen |
| OR | Ansatz |
| CTH | bereit |
| AR | Quelle / Vorrat |
| CHK | Wärme |
| EE | Langgrad |
| OT | Folge |
| DY | lokaler Schluss |

Nur zwei der siebzehn portablen Karten bleiben als ungeteilte Ganzkarten:

- `cheey/shey` = **Klarauszug**
- `chety/chty` = **Zerkleinern**

## Die siebzehn Karten

```text
AIIN       Sollmaß
OL         Fortsetzung
Y          Diesposten
CHD+Y      Umsetzen
AL         Stelle
OK+Y       Einsetzen
OK+AIIN    Sollstellung
OR         Ansatz
CTH+Y      Bereit
OK+AL      Zieleinsatz
AR         Quelle
WHOLE      Klarauszug
WHOLE      Zerkleinern
OL+DY      Fortschluss
CHK+EE+Y   Langwärme
OT+Y       Folgeposten
OL+OR      Fortsetzungsansatz
```

`char/dar/sar` wird dabei von der zu langen alten Glosse „aus demselben
Vorrat“ auf den Kern **Quelle** reduziert. „Derselbe“ stammt aus dem bereits
aktiven Recordbezug, nicht aus einem zusätzlichen Wortteil.

## Vorhersagen, die im restlichen Zehnseiten-Deck schon auftauchen

Der Kasten erklärt nicht nur seine eigenen siebzehn Karten. Zehn weitere
Kartenfamilien passen sofort:

- `OK+AIN` → Portionszugabe (`okain/qokain`)
- `OL+AIN` → Folgeportion (`olkain/qolkain`)
- `OT+OR` → Folgeansatz (`otchor/qotchor`)
- `OT+EE+Y` → Langfolgeposten (`oteey`)
- `OT+E+DY` → Kurzfolgeschluss (`otedy`)
- `OT+EE+DY` → Langfolgeschluss (`qoteedy`)
- `CHK+E+Y` → Kurzwärme (`cheky`)
- `CHK+EE+Y` → Langwärme (`chkeey`)
- `CHK+EE+DY` → Langwärmeschluss (`chkeedy`)
- `OK+AL+Y` → Zielposteneinsatz (`qokaly`)

Das ist genau die gesuchte Mischung aus Fachkürzeln und Ganzwörtern: ein
kleiner produktiver Satz bildet häufige Arbeitsbegriffe; zwei fachliche
Produkte werden als Ganzkarten gelernt; q/s/ch/d/t-Varianten rendern die Karte,
ohne eine neue Bedeutung beizusteuern.

## Lehrregel für 1420

> Lerne zuerst die dreizehn Kerne. Setze sie wie Werkstattzeichen zusammen.
> Wenn eine Karte `Klarauszug` oder `Zerkleinern` heißt, kopiere sie als Ganzes.
> Wähle danach die Schriftform deiner Hand aus der Musterpalette. Lies beim
> Rückweg zuerst die ganze Kartenidentität, dann ihre Kernformel – niemals jeden
> sichtbaren Strich als eigenes Wort.
