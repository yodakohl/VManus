# Local fixed decoding function

A medieval writer can use more than one sign for the same source letter. This test drops GDT1404's global injection and changes nothing else about that local lexical question. One fixed function maps every22working unit to one source codepoint; different units may share a value. No null, variable-length code, new dictionary, normalization, gap change or contextual source-letter value. The hypothetical e/i-run inverse is supplied, not confirmed. FWD and wordwise BIDIR remain separate fixed modes; BIDIR is a capacity relaxation, not a historical writing rule.

The original77 IT2a f75v.43–49 groups all stay. Existing eight W supply local candidate words only; the rest of the manuscript is not required to use these vocabularies. In particular GDT1406's global closed-W cube failures and GDT1404's injective failures stay unchanged. This is no rescue of either writer. Source Unicode spelling, case, accents, punctuation and tokenization stay unchanged.

An exact finite word-table function join runs after a generated77-token positive gate. The control uses actual source words from Deot but is NOT a coherent77-word passage; first77 individually alphabet-filtered original tokens, not a contiguous window. It actually exercises two active homophone pairs and e/i expansion. Independent Z3 encoding has no Distinct and only equal-native-implies-equal-source filtering. SAT certificates require every source word in the fixed local W; UNSAT requires independent confirmation. Caps are UNKNOWN, no exclusion or automatic repair. Read SPEC.json for the complete frozen generator and limits.

SAT only supplies a possible written letter key and full77-word output for subsequent manual coherence/profile review. Dictionary membership alone is not grammar, meaning, source identification or decipherment. Unassigned word meanings may not be adopted from a solver certificate. A decoder is not a complete human writer: the rule selecting among source-letter homophones remains absent and cannot be silently fitted afterward. No native reader pooling, image, reserved material or new source access.
