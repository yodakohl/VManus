# GDT538 method

## Question

Can all 159 final GDT537 surface locks receive one short, consistent German
working phrase without changing a recipe, a fixed atom value, or the special
route by which seven surfaces were resolved?

## Inputs

- GDT537's final 159-surface dictionary;
- GDT413's 46-component dictionary, used only to verify the nineteen portable
  values and the formal/local classification.

No manuscript page or transcription table is read.

## Method

1. Split every final recipe into its ordered atoms. The 159 recipes contain 640
   slots drawn from 34 atom types.
2. Give each portable atom one unique unbracketed realization of its fixed
   value. Give every formal, address, sign, or learned local atom a unique
   bracketed realization. This produces an exactly reversible order channel.
3. Render a second neutral workshop phrase with eight small templates. Visible
   actions, arguments, relations, repeats, grades, controls, addresses, and
   local cores are spoken; an absent object or action is never supplied.
4. Retain the old phrase in a comparison column. Fill all 152 `INHERITED`
   placeholders and normalize the seven previously handwritten phrases through
   the same renderer.
5. Audit every pair of current recipes separated by one atom edit. The
   unchanged ordered slots must remain byte-identical and the edited slot must
   have one explicit phrase effect.
6. Put the phrase layer ahead of GDT537 only for an exact prose-surface match.
   Local-record and unknown requests still delegate.

## Pass conditions

- 159/159 surfaces have non-placeholder phrases and exact recipe roundtrips;
- 640/640 slots appear in the controlled order channel;
- all nineteen portable values remain byte-locked and all fifteen
  structural/local types remain bracketed;
- all one-atom neighbour pairs have exactly one visible slot delta;
- exact prose lookup, local delegation, old-surface delegation, deterministic
  regeneration, and independent validation pass.

## Claim ceiling

This is a complete editorial phrase layer for the existing working theory. It
adds no recipe, root meaning, plaintext claim, language identification, object
identity, page, surface, or occurrence prediction.
