# GDT801 — terminal `l/m` boundary-hierarchy discriminator

GDT801 joins the final nonempty GDT800 terminal population to the released
GDT791 visual-owner spine. It asks whether the physical-line effect survives
away from paragraph, legacy-statement, record and panel boundaries, and whether
those higher boundaries have enough independent `l/m` support to estimate an
additional closing field.

No new page, image or transcription is opened. Structural endings are not
translated. The expected useful outcome is a sharper renderer scope and an
honest capacity decision for higher-level closure.

Run:

```bash
./vmanus-exp run experiments/yolo/gdt801_terminal_lm_boundary_hierarchy_discriminator
./vmanus-exp validate experiments/yolo/gdt801_terminal_lm_boundary_hierarchy_discriminator
```
