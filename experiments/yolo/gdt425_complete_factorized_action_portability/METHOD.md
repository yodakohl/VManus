# Method

## Inputs

- GDT416's complete 4,576-event running edition;
- GDT407's 5,051 fixed focus-to-action attachments;
- GDT424's seven-card provisional local appendix.

No new page, image, transcription, root, or meaning is used.

## Complete factor replay

For every event:

1. replay each exact `action<-focus` edge against other pages;
2. learn an ordered pair only when two action atoms are immediately adjacent;
3. reduce a page-private adjacent pair only by an already visible R topology or
   exact repeated-action scope;
4. bind every DY close to the final explicit action, or to the already carried
   action when the closing card has no explicit head;
5. retain every remaining local action edge as a separate appendix card.

Owner-only focus edges remain in the existing local-address channel and never
become action words.

## Decision rule and claim ceiling

An action factor is cross-page only if the exact role occurs outside its own
page. Local rules may be promoted only after a second-page occurrence with the
same factor role. This is a complete working-grammar replay, not confirmation
of the German values, plaintext, language, or source.
