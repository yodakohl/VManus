# GDT551 method

## Question

Are the twelve GDT543 target/anchor mode-set disjoints, and especially the four
context rests surviving GDT550, different compositional context contracts or
merely different incoming states observed at individual occurrences?

## Frozen inputs

- GDT540's 145-surface context contract;
- GDT546's 81 consolidated fragment cards and their selected old anchors;
- GDT548's unified 145-card reader;
- GDT549's nine target/anchor context warnings and 23 exact visible default
  routes;
- GDT550's nine-card residual support queue.

No new manuscript page, transcription, image, surface, recipe, segmentation or
root meaning is admitted.

## Method

Use the already compiled GDT539/GDT540 root classes without alteration:

```text
action roots   = OK CH SH K S CHD T R P
argument roots = Y AIIN AIN OR
```

For each full target recipe and its selected old anchor, derive a two-slot
contract:

1. action is either visibly supplied or open;
2. argument is either visibly supplied or open.

An open slot can inherit a same-statement state. An unfilled action slot yields
the existing nonverbal fragment fallback; an unfilled argument slot yields the
existing objectless reading. Consequently the four contracts permit these
instance modes:

```text
visible action + visible argument -> SELF_CONTAINED
visible action + open argument    -> SELF_CONTAINED or ACTIVE_ARGUMENT
open action + visible argument    -> SELF_CONTAINED or ACTIVE_ACTION
open action + open argument       -> all four state combinations
```

Recompute the contract and allowed mode set independently of the mode actually
seen at a historical occurrence. Audit all 81 fragment anchors, then isolate
the twelve whose observed anchor and target mode sets had been disjoint. Also
replay the nine GDT549 warnings and the four context rests still active after
GDT550. Preserve exact visible routes and both complete German working readings.

## Decision rule

- Normalize an observed-mode disjoint when both observed mode sets are legal
  under their own slot contracts and the target contract is either identical
  to the anchor contract or is narrowed exactly because the visible extension
  fills an open slot.
- Keep a context rest open if an observed mode is impossible under its recipe,
  if the contracts are incompatible, or if its recipe/visible route/reading
  drifts.
- Carry every non-context residual forward unchanged.

## Claim ceiling

This is a consistency repair inside the adopted working reader. It may show
that equality of two occurrence-specific incoming states was an unnecessary
support demand. It does not prove that the root classes are plaintext parts,
that an observed mode is a lexical property, or that any German working value
is a historical word meaning. No language, cipher, phonetic value, object,
codebook identity, new page, recipe or root meaning follows.
