# GDT615 artifacts

At registration this directory contained `REGISTERED_SEARCH.json`, the exact
role/output pools, search hierarchy, deterministic tie-breaks, stop outcomes,
inherited downstream gates, and the 28,101-entry train-only substring table
`REGISTERED_TRAIN_SUBSTRINGS.txt`. The latter is generated byte-for-byte by
`src/prepare.py`; no held or LM-confirm input is read.

`stage0/` is the compact scored release. Its entry points are:

- `STAGE0_MAPPING_COMMIT.json`: immutable 34-card mapping, 55/4 objective,
  unsupported renders, claim ceiling, and next-stage lock;
- `STAGE0_BUNDLE.json`: stable hashes for the primary/independent evidence,
  tables, certificates, and solver sources;
- `STAGE0_VALIDATION.json`: independent direct replay and bundle audit;
- `DECISIVE_QUERY_MANIFEST.json`: full accumulated contexts for the nine
  decisive SAT/UNSAT boundaries;
- `PRIMARY_RESULT.json`, `INDEPENDENT_RESULT.json`, and
  `STAGE0_REPLAY_CERTIFICATE.json`: two exact backends and deterministic replay;
- `mapping.tsv`, `raw_merges.tsv`, and `minimum_cover.tsv`: compact scored
  tables;
- `SCOUT_*`: explicitly noncertifying heuristic search history.

Transient work directories, timing diagnostics, PIDs, and compiler binaries
are not public scored artifacts.
