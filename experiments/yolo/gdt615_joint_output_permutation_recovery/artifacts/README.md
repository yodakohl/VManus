# GDT615 artifacts

At registration this directory contains `REGISTERED_SEARCH.json`, the exact
role/output pools, search hierarchy, deterministic tie-breaks, stop outcomes,
inherited downstream gates, and the 28,101-entry train-only substring table
`REGISTERED_TRAIN_SUBSTRINGS.txt`. The latter is generated byte-for-byte by
`src/prepare.py`; no held or LM-confirm input is read. Scored artifacts are
added only after the registration is public.
