# Herbal-Operationslektion

## Vollständig baubare Karten

- `chokcheo` = `OK + CHEO` → Auszug einsetzen
- `qokokchy` = `OK + OK + Y` → denselben Posten erneut einsetzen
- `okchol` = `OK + OL` → die Fortsetzung einsetzen
- `kaiiin` = `K + IIN` → die Arbeitsstufe setzen
- `otol` = `OT + OL` → anschließend fortsetzen
- `kchal` = `K + AL` → an der Zielstelle bearbeiten
- `kchol` = `K + OL` → weiter bearbeiten
- `qokchy` = `OK + Y` → den laufenden Posten einsetzen und weiterbearbeiten
- `keol` = `K + E + OL` → kurz weiterbearbeiten
- `qotchy` = `OT + Y` → zum nächsten Posten wechseln
- `qoctholy` = `OT + OL + Y` → den bereiten Folgeposten wählen
- `kchy` = `K + Y` → den laufenden Posten bearbeiten
- `kchey` = `K + E + Y` → den laufenden Posten kurz bearbeiten
- `cthoor` = `CTH + OR` → den Ansatz bereitstellen
- `qotchol` = `OT + OL` → den Folgegang fortsetzen
- `cthaiin` = `CTH + AIIN` → die Sollvorbereitung setzen

## Teilweise baubare Karten

- `oltchy` = `OL + TCH + Y` → die laufende Bereitung fortsetzen; neu zu lernen: TCH preparation core
- `shfydaiin` = `SHFY + AIIN` → eine vorgeschriebene Stehzeit einhalten; neu zu lernen: SHFY standing core
- `dchol` = `D + OL` → vom vorigen Arbeitsgang nehmen; neu zu lernen: D previous-source core

## Sechs echte neue Ganzhandlungen

- `tchody` → kalt stellen; Schluss
- `sotodan` → als Folgeanwendung führen
- `cheeckhody` → auftragen; Schluss
- `ody` → abkühlen; Schluss
- `cfhy` → auswringen
- `cphy` → nachseihen

Der Herbal-Lehrling muss also nicht 25 neue Operationswörter auswendig lernen. Sechzehn baut er vollständig, drei mit einem kleinen Restkern, sechs als ganze Fachzeichen.
