# GDT659 — naked `y` as a mobile entry boundary

Status: `PASS_270_NAKED_Y_CONTEXT_CARDS__V36`

GDT659 replaces the single false question “what word does `y` mean?” with a
contextual one: what does the separated sign do at the beginning, middle, end
or on a label line? The working model treats it as a mobile entry/boundary
carrier and renders each occurrence through an explicit scoped card.

The main practical target is f80v.21, where IT2a joins `y+rchey` and ZL3b/RF1b
separate it. Its working reading is `hierzu: trocken gebundene
Wurzeldroge, Form I`, not a manuscript-wide `y = dieser` equation.

See [METHOD.md](METHOD.md), [REPORT.md](REPORT.md) and the generated artifact
deck.
