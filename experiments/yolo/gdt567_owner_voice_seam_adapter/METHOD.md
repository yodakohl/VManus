# GDT567 method

## Question

Can the abrupt vocabulary seam between GDT565's generic state phrases and the
owner-bound nonstate clauses be removed with a small, reusable rendering layer,
without changing any root value, recipe, event or statement boundary?

## Inputs

- GDT566's complete 5,122-event, 793-statement and 30-page editions;
- GDT565's 1,656 state-card replay, including effective argument roots, recipes,
  templates and written atom alignments.

No new page or transcription source is opened.

## Method

1. Enumerate all 4,329 adjacent event pairs inside the 793 statements. Keep the
   four directions—nonstate→nonstate, nonstate→state, state→nonstate and
   state→state—distinct.
2. For every register×argument-root and register×relation-root cell actually
   used by a state card, recover the existing owner-voice phrase from its
   GDT566 control clause. Missing register×root combinations remain absent;
   they are not invented as defaults.
3. Admit a card only when its target phrase or whole-word head occurs in every
   applicable owner-bound state clause. This yields 19 argument and 18 relation
   cards. Add two all-register wording cards only because `hier`→`an der
   bezeichneten Stelle` holds 123/123 and `abschließen`→`schließe den Schritt`
   holds 705/705.
4. Apply a card only to a GDT565 state event whose effective argument root or
   written relation root calls for it. Use whole-word substitution; substrings
   such as `Eintrag` inside `Eintragseinheit` do not count.
5. Leave all 3,466 nonstate clauses byte-identical. Reassemble all 793 statements
   and all 4,329 seams, while retaining the original GDT566 phrase and the
   owner-bound control phrase beside the new owner-voice phrase.

## Decision rule and claim ceiling

Pass only if all 39 cards have complete observed support, all 5,122 events and
793 statements replay in the original order, every nonstate clause is
byte-identical, all 4,329 adjacencies are retained, and deterministic replay is
exact. The adapter may alter only German rendering terms already present in the
owner-bound channel. It supplies no new Voynich root meaning, historical
lexeme, plaintext, surface, recipe or occurrence.
