# Prefix-code expansion consequence

For prefix-free C, u and ur in C* imply r in C*: decoding ur must finish
u at exactly its endpoint. Repeated left quotients are finite, being suffixes
of the original words. A one-unit member of C* must itself be in C. The
existing1236proof events provide explicit acyclic equations for k,e,s.
A prefix code with these singleton entries must parse keeees into six such
entries, regardless of any other entries. For a fixed homomorphism
phi:C*->Sigma* with phi(c)nonempty, this gives phi(k)phi(e)^4phi(s).
Equal expansions of different codes are allowed; source symbol identity and
meanings are irrelevant. Both surrounding images remain nonempty.

Enumerate each source token position p>=1 and period m>=1 with p+4m<len(w).
A witness exists exactly when w[p:p+4m] is four equal blocks. Record X,U,Y,
token identity, p,m and both old source coordinates. Duplicate spellings keep
all occurrence coordinates. A second implementation checks equality between
the three m-offset character bands; no maximal-run or primitive-root filter.
Whole-word reversal exchanges the two nonempty flanks and reverses U, so it
preserves existence. This is not a statement about suffix-free glyph parsing.

No source corpus output frequency, table fit or native population resampling
is used. The source pool is an optimistic envelope: every native occurrence
could choose any source word arbitrarily often. Failure of this relaxation
still excludes a common complete table for that pool; survival does not
construct one. The singular native witness remains a material limitation.
