# GDT571 method

## Question

Can the nine observed OT/OL/DY state sequences be generated by the three
unchanged operator roots and only two sentence slots, while replacing the
remaining sequence-specific German infinitives with finite, compositional
forms?

## Inputs

- GDT570's complete state, event, statement and page editions;
- GDT565's complete state-template replay and old nine state-frame cards;
- GDT557's exhaustive nine-sequence profile.

No new page, transcription, state sequence, atom or root value is introduced.

## Method

1. Project OT, OL and DY from every state recipe and verify exact agreement
   with the GDT565 sequence field and the nine GDT557 profile counts.
2. Give the first OT or OL the entry-prefix slot. Give every DY and every
   operator after that first prefix the follower-suffix slot. This yields five
   occupied operator×slot cells: OT entry/follower, OL entry/follower and DY
   follower.
3. Retain `Danach`, `Weiter` and `schließe den Schritt`. Render follower OL as
   `führe den Gang weiter` and the single follower OT as `eröffne danach den
   nächsten Gang`. Assemble multiple followers in written marker order.
4. Assign every one of the 1,870 marker occurrences once, then rebuild all
   1,656 state clauses, 5,122 events, 793 statements and 30 pages. Leave all
   nonstate text byte-identical.

## Decision rule and claim ceiling

Pass only if all nine sequences, all 1,870 marker occurrences and all 1,656
state cards receive an exact two-slot derivation; the old nine sequence frames
must reduce to three root cards, five occupied position realizations and two
slot rules; all source order and boundaries must replay; and deterministic
generation must be exact. The result is a German workshop-voice factorization.
It changes no Voynich root value, recipe, surface, event, statement, page,
historical lexeme, plaintext, language, genre or object identification.
