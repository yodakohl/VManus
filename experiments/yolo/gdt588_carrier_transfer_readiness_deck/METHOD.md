# GDT588 method

## Question

How much of GDT587's concrete action-conditioned carrier vocabulary already
recurs away from its own physical page, and what fixed fallback ladder can
carry the model onto a later user-released page without inventing a new action
rule, silently reusing an old occurrence-only override, or collapsing repeated
written carrier roots?

## Fixed inputs

- the complete 1,243-row GDT587 carrier assignment table;
- GDT587's complete statement/local readers and running host phrases;
- the fixed GDT583 rule model;
- GDT584's occurrence revisions, used only to separate automatic rules from
  source-bound and manual refinements.

No new page, image, surface, segmentation, OCR result, root, name, or action
sense is admitted.

## Selection mobility

For every GDT587 assignment, remove its own physical page from the support
pool and apply the first available level:

1. `EXACT_SELECTION_OTHER_PAGE`: another page has the same register, GDT584
   action rule, root, context family, lemma, packet rule, and presence-only
   carrier-root signature.
2. `SAME_ACTION_ROOT_LEMMA_OTHER_PAGE`: no strict match, but the same
   register×action-rule×root cell occurs elsewhere. Validation separately
   requires the contextual lemma to agree.
3. `SAME_REGISTER_ROOT_OTHER_PAGE`: no same action cell, but the same
   register×root occurs elsewhere.
4. `PAGE_PRIVATE_REGISTER_ROOT`: none of the preceding channels crosses the
   page boundary.

The census is also recomputed with `layer` added to every key so running text
and local cards cannot support each other. These are provenance and practical
portability labels, not independent semantic confirmation.

## Future action and noun gate

The 29 fixed GDT583 rules divide mechanically into 27 automatic context rules
and two rules carrying explicit old `source_ids`. Nine additional GDT584 rule
IDs are retained as manual overrides because they touch at least one GDT587
carrier; they are never selected automatically on a new page.

The 27 automatic rules expand to 55 rule×register contexts. Crossing these
with `Y/AIIN/AIN/OR` creates the complete 220-row declared intake matrix:

- use `OBSERVED_CELL` when that exact automatic action×root cell exists;
- otherwise use `REGISTER_INVARIANT` only when all old actions agree on the
  register×root noun;
- otherwise keep the broad register default.

At runtime the full GDT583 host selector still runs first. The matrix is a
contract, not a free lookup. A new noun variant inside an observed cell is
demoted to its registered fallback. The eight complete packet conditions run
before that demotion. Names and address cores remain on the GDT470/GDT586 path.

## Multiplicity-safe packets

Group all 121 non-default packet assignments by their exact
`primary_governor_key`, producing 74 hosts. Reconstruct the ordered root
sequence from assignment order and a separate root `Counter`; never use the
old set-like `carrier_root_signature` as a count.

Packet transfer support uses `(packet rule, root multiset)` after removing the
host's page. The register-specific inventory contains 34 multiset shapes.
Thirteen hosts repeat at least one written root. GDT587 retained every slot in
its exact trace but its fluent clause collapsed the repeat, so GDT588 installs
thirteen explicit `×2` clauses. `×2` counts written carriers only; it does not
claim two real objects.

## Complete reader and validation

The thirteen substitutions affect eleven of 793 running statements and two of
744 local cards. Every other GDT587 reader value remains byte-identical. The
validator recomputes all page-removal tiers, gates, matrix cells, ordered root
sequences, multisets, repairs, complete-reader projections, executable body
blockers, and a byte-identical rebuild.

## Claim ceiling

GDT588 may claim a fixed, executable transfer contract and correct a fluent
count-loss bug in the exploratory German reader. It does not confirm a Voynich
lexeme, stem, plaintext, language, patient, body part, substance, procedure,
astronomical value, historical codebook, new-page prediction, or surface
parser.
