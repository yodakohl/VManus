# Method

## Question

Can the 11/29/81/24 support ladder be compiled into one exact-key practical
reader in which every one of the 145 prose surfaces retains its complete
working meaning, context contract, structural trace and named caution?

## Inputs

- GDT540 supplies the exact 145-surface inventory, final recipes, German
  neutral/context readings and action/argument state contract.
- GDT541 supplies the eleven complete old-recipe profiles.
- GDT542 supplies the final tier assignment and 29 full-tile bridges.
- GDT546 supplies the consolidated 81-card fragment reader.
- GDT547 supplies the 24-card atom/factor reader.

All six inputs are already bounded derivatives over admitted material. No
transcription or image source is opened.

## Compilation

Join all sources by exact surface key. GDT540 and GDT542 must have the same 145
keys and recipe for every key. Each GDT542 tier must equal exactly the relevant
GDT541, GDT542-bridge, GDT546 or GDT547 deck.

The common output retains recipe, readings, context roots and future-state
rules. It then adds tier-specific route, trace, evidence, context relation and
caution fields. These tier fields are deliberately not collapsed into one
fabricated confidence score.

The named improvement queue is mechanical:

- GDT542 class `COMPLETE_TILES_AND_OLD_SEAMS_ONLY` (10 cards);
- GDT546 `EXPLICIT_WORKING_DEFAULT*` (12 cards);
- GDT547's raw new direct action-pair default `shso` (1 card).

Every queued card keeps its current complete working reading.

## Executable contract

`read_prose.py` accepts exact keys only. Visible roots take precedence; absent
roots may be supplied only from same-statement state, following GDT540. If no
action is available, the neutral default remains available but the reader marks
the contextual verbal clause unresolved. Unknown surfaces stop.

## Validation

The validator independently replays all four source inventories, recipes,
meanings, context fields, tier traces and the 10/12/1 queue partition. It probes
one CLI card from every tier, both sides of the context switch, the unknown-key
stop, all 145 listed keys and deterministic regeneration.
