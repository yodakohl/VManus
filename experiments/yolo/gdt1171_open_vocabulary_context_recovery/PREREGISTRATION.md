# GDT1171 preregistration

The complete contract is METHOD.md. It is fixed before any real language-model
count fit, decoding or prediction evaluation. The six sources and aggregate
capacity results were previously exposed; this is not analyst-blind research.

One order5 alpha0.1 character architecture, U/C/S arms, six whole-book folds,
all finite declaration outputs, exact Viterbi, no word-list veto, no tuning.
Primary: equal types within each book, then equal books, on novel written forms.
Success requires C>=70%, C-U>=3points and4positive books, C-S>=2points and
4positive books, and novel-OOV C>=50%. All errors and unknowns remain.

PREREG_LOCK.json binds method, this contract, all executable code, prepared
inputs/answers and synthetic validation. The runner verifies these against a
published commit before fitting and locks all predictions before score.py reads
the answer file. Result-dependent modifications are prohibited. Source values
and language/alphabet information are supplied; this is no unknown-key test.
