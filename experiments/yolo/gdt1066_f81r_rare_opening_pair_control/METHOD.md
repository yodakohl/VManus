# Method

Run `python3 experiments/yolo/gdt1066_f81r_rare_opening_pair_control/src/run.py`, then the sibling `validate.py`. Both scripts read only GDT791's already admitted ZL3b occurrence spine. The runner groups source-order running events by fixed physical-page and major record ID, counts each complete form over all thirty GDT791 pages, and writes all nine pair rows. The validator independently rereads the source and recomputes every source hash, record length, opening, overlap and frequency. No image/OCR step, new transcription, token normalization, decoder or word glossary is used.

The chosen first-five window and frequency cutoff are retrospective. GDT675 already tabulated f81r/external `olpchedy`; GDT791 supplied all fixed owners. This packet checks a narrower positional comparison absent from those reports. Treat all values as exploratory descriptions of ZL3b, not a p-value or cross-reader result. The original IDEA647 dossier records ZL3b/IT2a identity and RF1b's lower split.
