# GDT637 — vier Leitern weiterziehen, konkrete Ein-Loch-Zeilen finden

Status: `EIGHT_ATTESTED_LADDER_CELLS_ADDED__ONE_UNKNOWN_PASSAGES_RANKED`

Vier bereits sichtbare Reihen werden unter den GDT635-Stoffköpfen fortgesetzt:
`aiir=Teil-/Sortierklasse III`, `oiiin=Formklasse IV` und
`aim/aiim=Mengenklasse II/III`. Acht der sechzehn möglichen Kopfzellen sind
belegt; nur diese acht kommen ins Wörterbuch V14. Die anderen acht bleiben
sichtbare Vorhersagen.

Der scope- und lesersensitive V14-Leser deckt alle 4.128 physischen Zeilen der
unveränderten 179-Seiten-Auswahl ab. Er findet 16 vollständig belegte
Mehrwortzeilen und 65 Zeilen mit genau einem unbekannten Token; 30 der
Ein-Loch-Zeilen sind vollständig dreileser-exakt und frei von aktiver
Trägermehrdeutigkeit.

Ausführen:

```bash
python3 experiments/yolo/gdt637_ladder_completion_one_unknown_passages/src/run.py
python3 experiments/yolo/gdt637_ladder_completion_one_unknown_passages/src/validate.py
```
