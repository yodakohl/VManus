# Compact exact-card writer

1. Expand the intended workshop step with the 35-component manual and the six
   whole cards.
2. If its small value has one card, write that card. This handles 320 events.
3. For the eleven alias values apply, in order: immediate neighbor, statement
   entry, then record renderer. This handles the remaining 61 events.
4. `YKAIN -> YKAN` marks immediate repetition of the portion instruction.
5. `DCHOL/SCHOL` resumes at Herbal statement entry; ordinary `OL` continues
   inside the statement.
6. `CHEDCHY` is reserved for DIES UMSETZEN directly before target setting.
7. `DCHDY` is reserved for UMSETZEN; SCHLUSS after KURZ FORTSETZEN.
8. B5 uses `LOL` for WEITERFUEHREN; B1 uses `DL`.
9. B6 uses `QEKY` for DIES KURZ ZUFUEHREN; H5 uses `KCHEY`.
10. The remaining record renderer pairs are memorized allographs, not second
    meanings.

These rules regenerate all 381 expected exact card IDs from the selected small
workshop reading plus record and immediate context.
