# GDT478 method

## Question

Does the GDT477 directional audit leave `OT=DANACH` as a pure next-unit
operator, and can all 41 OT plus 28 OL slots be compiled into one paired order
grammar with a default for every occurrence?

## Inputs

- GDT474's 183 literal event traces and three grammatical readings;
- GDT475's 69 order-root occurrences and 146 bundle boundaries;
- GDT476's active contextual model selections;
- GDT477's complete 28-slot OL scope edition and three OL rules;
- GDT460's calibrated prefix `ot-` channel and GDT461's calibrated strict-
  internal `ot` channel.

Only the already admitted six local-address pages are used. No new page or
source transcription is opened.

## Method

1. Select the 41 OT rows from GDT475 and align each `OT` recipe atom to the
   corresponding `DANACH` token in its unchanged GDT474 function/name trace.
2. Apply the same positional shapes used by GDT477:
   - `OT · X`: next carrier is X;
   - `X · OT · Y`: after X follows Y;
   - `X · OT`: backward form, if any.
3. Preserve learned-name position, immediate left/right carrier, boundary
   role, active GDT476 model and complete event reading.
4. Reuse the 28 GDT477 OL rows byte-for-field in a common 69-slot schema.
5. Assign one state operation per root:
   - OT: `START_FRESH_SIBLING`;
   - OL: `KEEP_ACTIVE_UNIT`.
6. Collapse the 69 slots to sixty events, five observed root×direction rules,
   seven joint OT+OL events and six page summaries.

The positional tokens belong to the complete function/name working trace, not
to a claim that every raw character is semantic. Prefix and strict-internal OT
surface channels stay separate and retain their old provenance.

## Decision rule and claim ceiling

The grammar succeeds if every OT has a right-hand successor, no OT is a
backward hold, all seven joint events put OT before every OL, all 69 slots have
a directional phrase and no source meaning, learned name, surface, recipe,
selected model, event or page changes.

This is a compact working state grammar, not confirmed syntax, plaintext, a
historical codebook identification, language identification or decipherment.
