# GDT386 method — independent relation-edge capacity

## Question

Does the already permitted, f84-free human/layout evidence contain a Voynich
relation edge that is independently authored or externally supplied, has an
exact pivot and target, and can support held-folio transfer of the one relation
instrument calibrated in GDT385?

## Score-blind boundary

The audit reads only compact, previously published f84-free source/capacity
artifacts. It may count pages, physical folios, source-bound relations, local
ownership and schema fields. It may not read or join Voynich surface tokens,
families, members, PAGE_HOST, GDT327 tuple identities, renderer states, or any
f84 row. It performs no model fit, association test, or semantic score.

## Frozen eligibility gates

A viable endpoint must satisfy every condition:

1. an author/editor/external source supplies the relation rather than the
   Voynich grammar or text;
2. every observation has an exact observable pivot and exact observable target;
3. the relation is directional/ordered in a way homologous to a parent,
   antecedent, pointer, or fixed relation target;
4. if formal data would later be attached, both endpoints have singular,
   source-bound ownership rather than mere proximity or a whole-page bag;
5. at least 50 eligible edges span at least five physical folios;
6. the relation and target remain unknown from the future predictor variables;
7. the endpoint is not a re-expression of a closed resume/repeat/scope,
   exact-tuple, PAGE_HOST, visual-proximity, or GDT345–347 route; and
8. no f84 source or payload is required.

These thresholds are inherited from GDT385's minimum relation capacity and
are not adjusted to the census outcome.

## Candidate families

The complete predeclared source set is:

* GDT169's 40 human-nominated cross-page referent pairs;
* GDT351's four remaining referent-ownership upgrades;
* GDT360's f84-free existing human/layout annotation inventory;
* GDT337's 11 external exact/topological homologue candidates;
* the f84-free Q20 star-defined 170-record panel; and
* internal recurrence/resume/field relations as an explicitly ineligible
  source-defined control, without opening their formal identities.

No candidate is added because a Voynich string or tuple looks promising.

## Decision

If one or more families pass all gates, publish exact endpoint rows in
`gdt386_viable_endpoint_freeze.tsv` for a separately frozen experiment. If
none pass, return `NO_INDEPENDENT_TARGET_RELATION_EDGE_AVAILABLE` and do not
create a target score.

## Claim ceiling

The result is relation-edge capacity only. It assigns no Voynich role,
reference, time, alternative, exclusion, parent, meaning, POS, language,
plaintext, or translation. f84 is forbidden.
