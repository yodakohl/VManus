# GDT461 method

## Question

Can a direction-calibrated functional stem also be read strictly inside the
learned name core? Can any of GDT460's nineteen wholly learned residual labels
join a repeated owner-class family in the complete 183-address deck?

## Inputs

- GDT407's invariant running surface→recipe inventory.
- GDT413's unchanged component working dictionary.
- GDT459's complete 183-address interlinear.
- GDT460's 107 hybrid labels and seventeen owner-family stems.

## Method

### Internal function channels

1. For every invariant running surface of length at least two, collect other
   running surface types in which it occurs strictly inside the written form.
2. Retain a channel only when it has at least four such extension types and the
   stem's complete component recipe occurs contiguously in at least 90% of
   their recipes.
3. Require at least one occurrence strictly inside a GDT460 learned center—not
   inside an already assigned prefix or suffix.
4. Within each label choose the longest stem first, then the leftmost, and keep
   only nonoverlapping occurrences.

This yields nine channels: `AIR`, `CH+T`, `D_ADDR+AR`, `AL`, `AR`, `OK`, `OL`,
`OT`, and `SH` under their attested surfaces.

### Residual owner-family bridge

1. Deduplicate the complete GDT459 address deck by surface and content class.
2. Enumerate exact substrings of length two through five.
3. Require at least three unique surfaces, one content class, both current
   pages of that class, and a hit on one of the nineteen GDT460 whole labels.
4. Do not alter GDT460's old families; add only a new maximal family that
   reaches the residual tail.

Exactly one bridge survives: `cheo`, shared by four pharmaceutical address
surfaces on `f88v` and `f89r`.

### Revised label status

- full function formula if prefix + internal stems + suffix cover every
  character;
- function shell + learned core if any character remains learned;
- owner-family only if no function channel exists but a family marker does;
- whole learned label otherwise.

## Decision rule and claim ceiling

Internal values come only from running-text calibration, never from the target
picture. The assigned intervals must be strict-internal, remain inside the old
learned center, and never overlap. `cheo` receives only `DROGENFAMILIE`, not a
drug identity or operation.

No existing core value, page, surface prediction or individual name changes.
This is a compositional working dictionary, not confirmed plaintext.
