# GDT460 — learned label edge stem atlas

Status: `HYBRID_FUNCTION_EDGES_AND_LEARNED_NAME_CORES`

GDT460 reopens only GDT459's 107 learned singleton labels. It finds 24 unique
surface stems in 27 direction-specific edge channels whose prefix/suffix value
is calibrated on at least four running-text extension types with at least 90%
precision. Eighty-three labels carry one of those known functional edges; five
become completely edge-readable. Seventeen additional owner-family substrings
recur on both pages of one content class.

The resulting dictionary contains known functional edges plus retained learned
name cores, not forced whole-string translations. See `METHOD.md`, `REPORT.md`,
and `artifacts/README.md`.
