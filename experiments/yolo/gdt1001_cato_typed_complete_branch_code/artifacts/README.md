# Complete reproduction artifacts

CANDIDATES.tsv and CASES.json retain every paragraph/writer prediction,
complete raw target/provenance, code witnesses, contradictions and limits.
READINGS.md lists every saved complete code and its whole-word component map.
RESULT.json and EXECUTION_RECEIPT.json report actual search outcomes and times.
VALIDATION.json and INDEPENDENT_REPLAYS.json preserve independent checks,
including uncompleted reverse searches. Preflight results are software checks,
not search significance or independent source meaning.
