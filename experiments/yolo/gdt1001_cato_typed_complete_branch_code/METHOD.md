content is a hypothesis for the manuscript; its historical efficacy is not
being tested. All of chapter133 is owned, including the title, species list,

PREFIX writes each operator then its children; POSTFIX writes children then
operator. Child order is unchanged. Both serialize the entire same tree. Each
source atom has one shared nonempty character string. The five declared code
classes are OP, ENTITY, PROPERTY, REFERENCE and NUMBER. Within each class the

classes are not a proof that unknown text admits a unique grammatical parse.
The present fit is conditional on the complete source tree and declared types.

Any consecutive atoms may fuse into one original word, but no atom may cross

The change from a globally prefix-free code is deliberate: different semantic

boundary. Known productive parts and entry/whole-form effects motivate testing

## Finite search and limits

Every atom must fit inside an existing word, so every possible code is a
nonempty substring of some whole word. For an atom with k source occurrences,
its possible code must have at least k nonoverlapping occurrences across the
target words. Its maximum length is the lesser of the longest word and
floor((target_characters - source_atoms + k)/k). These are necessary conditions,
not a meaning score. Repeated codes cannot consume overlapping target positions.

The primary left-to-right enumerator covers every possible prefix at an atom's
first occurrence, using only nonempty lengths, exact word boundaries, remaining
length, per-atom nonoverlapping substring capacity and type-local prefix checks.
Later occurrences use that same code. At most two complete distinct code maps
are retained per case. Two witnesses establish non-uniqueness; a single witness
is unique only within this exact model if the complete enumeration exhausts.
If search ends at a limit after one witness, alternatives remain unresolved.
No restart agreement or numerical similarity establishes a word meaning.

Limits per whole paragraph/writer case:5seconds,500000nodes,20seconds external
process ceiling;32workers. Domain construction is included in the wall budget.
There is no new search-order selection of favored targets; every literal case
is submitted. A limit without a witness is UNKNOWN_FINITE_LIMIT or
UNKNOWN_WALL_LIMIT, never UNSAT. Errors remain explicit unknown work. Reaching
the19:15UTC inclusive checkpoint stops expansion; no automatic longer replay
or decoder change follows. All uncompleted cases remain accounted for.

## Independent checks and decisions

Before target execution, a complete Cartesian small-code oracle checks2520
cases, including924 cases with different atom classes. The algorithms accept
A:OP=a and B:ENTITY=a in an A/B/A stream while rejecting that collision if both
atoms are OP. Pinned complete-source positive equations and broken seams check
both traversal writers after compilation. These tests validate implementation,
not historical semantics or the entire research search.

The independent validator uses an explicit stack to reconstruct source streams,
rechecks every target case and consumes every saved code word by word. Every
primary UNSAT and every claimed exhaustive unique-code result gets a separately
implemented right-to-left search:10seconds,1000000nodes,32workers. Prefix
checks remain on the original strings, only inside equal classes. Independent
limits are disclosed. A contrary SAT/UNSAT or different code against a claimed
unique result is an error, not grounds to change the frozen source.

A full code supplies a complete conditional whole-chapter reading, with all
words, components, repeated meanings and alternatives displayed. It can be
retained for a new exposed-content consequence test. A complete literal failure
closes only this source/type/writer conjunction; source or computation unknowns
prevent a universal exclusion. Arbitrary renaming of singleton species, other
sources with the same typed repetition pattern and entirely different semantic
systems may preserve a fit. No suitable control of the whole historical search
exists, so there is no significance claim. No source, plant name, numeral,
translated word or independent confirmation is established by a code fit.
