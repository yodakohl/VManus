# GDT819 method

## Question

Which GDT818 predicate/connective conflicts are written in the manuscript,
which are uncertain readings, and which arose from legacy text normalization?

## Inputs

Three admitted pages f76r/f77r/f81r; five loci specified in `src/SPEC.json`.
Cached ZL/cross TSVs, existing source-group atlas and its producer/specification;
authenticated public Yale canvas metadata and13 rendition records on those
same three pages. GDT818 hypotheses remain C0. No new admission.

## Method

1. Selector-first guarded queries project only permitted page payloads. Join
   137 source loci; preserve P/L and paragraph flags. Retain four complete
   P streams containing74 P loci and nine separately tagged L records.
2. Extract all three editions' source groups at the five targets:129 groups,
   15 comparisons. Preserve definite/uncertain/drawing separators and extended
   entities. Compare atlas flattening with current clean rows, not by assumption.
3. Inspect full-page placement and native source regions manually. Register
   entire target sequences and neighboring prose; locus numbers include labels.
   Two parallel visual readers and coordinator cross-checks use the same images.
4. Independent validator imports neither runner nor decoder. It re-queries guarded
   sources, reconstructs groups/separators/fragments and all five ZL raw lines,
   checks exact output reproduction and public image metadata. Six mutations
   exercise preservation of entities, alternate readings, doublets and claim ceiling.
5. Publish decisions separately from raw readings. No automatic entity expansion,
   source editing, lexical backoff, token deletion or new semantic relation edge.

## Decision rule and claim ceiling

The source atlas was already corrected/documented on2026-08-09; this is a bounded
integration into the current semantic route, not its original discovery. Source
groups are transcription units, not established linguistic words. Image inspection
can favor an uncertain reading without proving its EVA identity or semantics.
Software reproduction cannot validate manual ink observations or translation.
No new relation packet is offered for scoring; inherited GDT818 alternatives
remain ineligible. Historical artifacts are preserved, not silently regenerated.
