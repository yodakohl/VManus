# GDT580 method

## Question

Can the three remaining raw-adjacent identical relation/modifier pairs receive
one concise but meaningful resumption grammar without counting an action,
changing either root value or losing either written slot?

## Inputs

GDT579 supplies the complete current 5,122-event, 793-statement, thirty-page
edition. GDT575 supplies the complete duplicate-phrase inventory and its three
`SAME_ROOT_RAW_ADJACENT` plain pairs. GDT515 supplies the fixed attachment rows
for the two AL slots in G515-E0379. The embedded GDT574 backchannels are used
only to recompute cumulative edition changes.

No new page, image, transcription, event, statement, surface, recipe, atom,
root value or scope is admitted. Sealed f84 and f84r remain forbidden.

## Method

Selection is mechanical at the already interpreted atom layer: both slots must
have the same root, be adjacent in the raw recipe, carry the same unscoped base
phrase and be PLAIN rather than OUTER/INNER. The GDT575 inventory must yield
exactly O+O at G407-E0152, D_ADDR+D_ADDR at G407-E1846 and AL+AL at
G515-E0379. Interrupted pairs, different-root surface collisions and scoped
twins remain untouched.

The common rule is a two-slot modifier-resumption operator rather than an
action count:

```text
MODIFIER_REPRISE(BASE, label class)
    = BASE; dieselbe LABEL-Angabe nochmals
```

The inherited class chooses only the German label head: O uses
`Ausführungsangabe`, D_ADDR `Stellenangabe`, and AL `Zielangabe`. Thus the three
surfaces are `als Ausführung; dieselbe Ausführungsangabe nochmals`, `an der
D-Stelle; dieselbe Stellenangabe nochmals` and `zur Zielspalte; dieselbe
Zielangabe nochmals`. This deliberately explicit grammar voice prevents
`nochmals` from sounding like a repetition of the visible action. Slot one owns
the full base span; slot two owns the complete resumption-label span. Every card
stores the exact two-base expansion, both atom positions and the complete
GDT579 source clause.

G515-E0379 is not allowed to inherit the visible SH head. Both fixed GDT515 AL
rows are `PREVIOUS_CARD_ACTION`, point to the T action in G515-E0378 and carry
the paired `FREE_PEER_1/2` roles. Its target therefore says `Beim vorangehenden
Festlegen: zur Zielspalte; dieselbe Zielangabe nochmals` before the new
`Halte ...` sentence. This names the previous T head, matches the raw AL+AL+SH
order and blocks an audible forward AL-to-SH attachment. The other two clauses
replace only their exact adjacent source fragment.

Statements are rebuilt solely from fixed event-ID sequences. A complete event
and statement backchannel must reproduce GDT579 byte-for-byte; all 5,119
nontarget events must remain byte-identical.

## Decision rule and claim ceiling

Pass only if the source inventory independently yields exactly the three
eligible pairs and six written slots; all three target clauses use one
modifier-resumption operator and the correct explicit label realization; no
resumption can be read as a new action count; both AL slots retain and audibly
name their prior-T attachment; and all 5,122 events plus 793 statements
reconstruct the GDT579 source exactly.

This is an exploratory German repetition voice over already assigned relation
and modifier values. `Ausführungsangabe`, `Stellenangabe`, `Zielangabe` and
`nochmals` are editorial grammar labels, not claimed Voynich lexemes. The pass
confirms no numeral, conjunction, pronunciation, plaintext, language, syntax,
genre, historical codebook, chronology or object identity.
