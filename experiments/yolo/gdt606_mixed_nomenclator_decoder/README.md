Status: `MIXED_CODEBOOK_UNSTABLE_PSEUDOTEXT__STRUCTURAL_WHOLE_WORD_CATEGORY_LEAD`.

whole-word category in every language, restart and capacity grid; `C` and `d`
do so in at least 11/12 real starts per language. This is a role hypothesis,
not a word meaning. See `REPORT.md` for the concrete outputs and next route.
