# Matched and cross-reading selection sensitivity

The runner reconstructs1174's exact contiguous eligible segments after the
selector-first guard, reuses its frozen metric implementation and keeps all
original reference metrics. Caching the pure glyph parser changes no values.
Each seed shuffles the same sorted prose-page universe, never rows within a
page. The first8000eligible tokens are retained with physical-line breaks,
uncertain boundaries and ineligible holes preventing adjacency.

The validator uses a separate regex parser, ordered eligible row traversal,
explicit original-neighbor edges and independent weighted count/entropy/
length/distance formulas. It never imports the runner or1174metrics. All128
sample-ID digests and frequency counts must equal1213, and the1174anchor
must equal the saved24,000IDs and full metrics. Metric agreement tolerance
is1e-10; scientific thresholds and Boolean gates are unchanged.

Primary all-nine-reading-pair conjunction and secondary own-reading result
are separate. Per-metric failures explain observed sensitivity but do not
select a better sample, metric subset or comparison reading. Counterexamples
of concrete word grammar remain separate from these engineering bands.
