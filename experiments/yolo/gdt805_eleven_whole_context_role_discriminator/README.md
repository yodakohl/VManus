# GDT805 — eleven-whole context-role discriminator

GDT805 subtracts the twelve GDT803 discovery occurrences and compares complete
L1/R1 context profiles for all eleven bracket-middle wholes against their fixed
K12 controls.

The corrected result contains 1,086 external occurrences, 916 all-reader-stable
target tokens, 21 projected-axis profile leads and seven repeated real
two-sided frames. Only two profiles exceed all twelve controls in both raw and
pair-stable views (`okal`–L1–HOT and `otal`–R1–CLOSE), but the underlying axes
are mostly surface projections rather than exact licensed cells. Consequently
GDT805 installs zero new roles and retains only the prior `okal` opaque-entry
and `ol` general-carrier readings.
