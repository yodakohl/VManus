# GDT1092 result: f25v/Sloane dragon motif

**Decision: `NO_RARE_COPY_ANOMALY_MATCH`.** The source page is [Sloane MS
4016 f38r](https://bl.digirati.io/images/ark:/81055/vdc_100165751215.0x00004d/full/1500,/0/default.jpg),
whose visible heading begins `Dragontea .i. serpentaria .i. asclepius` and
whose drawing includes a winged dragon and separate serpent at a spotted-stem
plant. The target is the newly admitted [Yale f25v](https://collections.library.yale.edu/iiif/2/1006123/full/1500,/0/default.jpg).

The f25v creature abuts a green pointed element, so this is a motif-level
similarity. It cannot own the source entry when all plant-organ features and the
second animal disagree. Sloane f38r is circa 1440 and cannot by itself establish
direction of copying. The British Library public caption's snakebite reading
is secondary context, not a literal Voynich gloss or evidence that f25v's text
mentions snakes, dragons or a medicinal use. No f25v transcript was opened.

Prior project discussion had already exposed the dragon observation. This is
therefore an informed, single-page exploratory comparison, with no independent
holdout and no word confirmation. Historical herbal image matching already had
broad false parallels; this fixed comparison closes this source-owner proposal.
Reopen only on a different named source sharing a prospective multi-part
attached anomaly and written relation, then seek a second witness before a
Voynich word test. Another dragon picture alone does not reopen it. f84/f84r
and reserves remained closed. Validation replays judgments and decision, but
does not automate visual interpretation. Source URLs, sizes and hashes are in
`src/SOURCE.tsv`.
