# Sidequest Pass 803: what does SHED actually ask the scribe to say?

The old dictionary used `SHED = ABSETZEN`. That was too narrow: it silently
assumed sediment separation wherever the form occurred. A pure result reading
`ABGESETZT` is worse because the rest of the workshop grammar is imperative and
the two target-addressed forms become awkward.

The portable reading across all fifteen events is:

> `SHED = STEHENLASSEN`

It gives three simple constructions:

- `SHED + DY`: **stehen lassen; Schritt schließen** (12 events);
- `R + SHED + DY`: **abkühlen und stehen lassen; schließen** (1 event);
- `SHED + AL`: **an der Zielstelle stehen lassen** (2 events).

This fits a decoction, bath, vessel, application, or apparatus equally well.
Local context may still expand it to settling, resting, soaking, or waiting,
but none of those narrower nouns belongs in the core dictionary.

The revised reading also explains the endpoint-heavy distribution: thirteen
of fifteen uses close a cell because “leave it standing” naturally ends a
workshop step. The two open `AL` uses keep the placed item available for the
next instruction.

`SHED` therefore joins the productive core20. This is a semantic improvement,
not merely a promotion: the new value removes an invented material mechanism
and gives one unchanged imperative across all fifteen affected statements.

`P+CHD+AL`.
