# Compact reproducibility artifacts

EVENTS contains only eligible admitted raw groups, exact source IDs and fixed
analytical halves/strata. STRATA retains full marginal inventories and exact
rational moments. LEAF_DELETIONS contains the fixed sensitivity calculations.
RESULT is the predeclared decision; VALIDATION verifies source and arithmetic.
SOURCE_RECEIPT and REGISTRATION_LOCK bind the guarded scope and pre-run code.
No independent readers, native meanings, significance or public registration.
