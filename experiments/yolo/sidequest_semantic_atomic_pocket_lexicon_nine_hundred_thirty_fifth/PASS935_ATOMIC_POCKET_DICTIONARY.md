# Pass 935 — Einwort-Wörterbuch für den Lehrling

Jede Stammkarte erhält genau einen kurzen deutschen Merkwert. Dieser Merkwert ist nicht die fertige Übersetzung; die fertige Formulierung entsteht erst aus Kartenfolge, Register und Bildbesitzer.

## Die 56 Merkwörter

- `Y` = **DIES** — Werkstatt: dieser Arbeitsgegenstand; Bild: dieser Bildplatz
- `OK` = **START** — Werkstatt: Arbeitsgang ansetzen; Bild: Bildplatz aktivieren
- `E` = **KURZ** — Werkstatt: kurz oder direkt; Bild: erster Grad
- `DY` = **ENDE** — Werkstatt: Arbeitsschritt schließen; Bild: Bildeintrag schließen
- `O` = **GANG** — Werkstatt: Arbeitsgang ausführen; Bild: Reihe aufrufen
- `OL` = **WEITER** — Werkstatt: im selben Arbeitsgang fortfahren; Bild: dieselbe Reihe fortführen
- `EE` = **LANG** — Werkstatt: länger oder gehalten; Bild: zweiter Grad
- `OT` = **NAECHST** — Werkstatt: danach oder nächster Posten; Bild: nächster Bildplatz
- `AL` = **ZIEL** — Werkstatt: Ziel- oder Anschlussstelle; Bild: Zielplatz
- `CH` = **AUSWAHL** — Werkstatt: bezeichneten Anteil entnehmen; Bild: Klasse oder Figur kennzeichnen
- `D_ADDR` = **UNTER** — Werkstatt: bezeichneter Teil; Bild: Unterplatz
- `SH` = **HALT** — Werkstatt: Arbeitsgegenstand halten; Bild: Bezug festhalten
- `AR` = **QUELLE** — Werkstatt: Entnahmestelle; Bild: Quell- oder Bezugsstelle
- `K` = **ZUORDNUNG** — Werkstatt: Material zugeben; Bild: Wert zuordnen
- `AIIN` = **SOLLWERT** — Werkstatt: Sollmaß; Bild: verzeichneter Sollwert
- `S` = **WAHL** — Werkstatt: Arbeitsvariante auswählen; Bild: Bildklasse auswählen
- `CHD` = **WECHSEL** — Werkstatt: Arbeitsgut umsetzen; Bild: zu Gegen- oder Folgeplatz wechseln
- `OR` = **EINTRAG** — Werkstatt: Ansatz oder Zubereitung; Bild: Eintragsklasse
- `L` = **VERBINDUNG** — Werkstatt: entlang des Arbeitswegs führen; Bild: Bildverbindung
- `T` = **EINSTELLUNG** — Werkstatt: Arbeitsgang einstellen; Bild: Platz oder Wert einstellen
- `AIN` = **EINHEIT** — Werkstatt: Portion; Bild: Einheit oder Index
- `R` = **MARKE** — Werkstatt: Zustand kennzeichnen; Bild: Zustandsmarke
- `P` = **EINSATZ** — Werkstatt: Material einsetzen; Bild: Platz besetzen
- `CTH` = **BEREIT** — Werkstatt: bis bereit führen; Bild: Bereitschaftsklasse
- `SHED` = **ABSETZEN** — Werkstatt: absetzen lassen; Bild: Absetzklasse
- `CKH` = **DURCHLASS** — Werkstatt: durch einen Durchlass führen; Bild: Verbindung oder Durchlass
- `AM_ADDR` = **INNEN** — Werkstatt: Innenstelle; Bild: Innenplatz
- `CHEO` = **AUSZUG** — Werkstatt: Auszug; Bild: lokaler Eintrag
- `DA` = **ZWEIT** — Werkstatt: zweite Arbeitsstufe; Bild: zweite Bildstufe
- `CARRIER_Q` = **EINTRITT** — Werkstatt: neuen Kartenblock beginnen; Bild: Eintrittsform einer Bildkarte
- `A_ADDR` = **ADRESSE** — Werkstatt: lokale Arbeitsstelle; Bild: lokale Bildadresse
- `AIR` = **LAUFWEG** — Werkstatt: Flüssigkeits- oder Stationslauf; Bild: Ringlauf
- `CHK` = **BEHANDLUNG** — Werkstatt: Arbeitsgegenstand behandeln; Bild: Behandlungsklasse
- `IIN` = **STUFE** — Werkstatt: Arbeitsstufe; Bild: Wertstufe
- `S_ADDR` = **STERNORT** — Werkstatt: bezeichnete s-Stelle; Bild: Stern- oder s-Stelle
- `SOLK` = **SAMMELN** — Werkstatt: auffangen; Bild: Sammelstelle
- `EEE` = **VOLL** — Werkstatt: vollständig; Bild: dritter oder voller Grad
- `LSH` = **SPUELEN** — Werkstatt: spülen; Bild: Spülklasse
- `LOCAL_CHAR_F` = **F** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `CPH` = **GEGENLAUF** — Werkstatt: umleiten; Bild: Gegenplatz
- `HO` = **TEIL** — Werkstatt: Teil des sichtbaren Gegenstands; Bild: Teil oder Mitglied der Bildklasse
- `AN` = **ZUSATZ** — Werkstatt: weiteren Posten zugeben; Bild: zusätzlicher Eintrag
- `G_LABEL` = **G** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `CFH` = **TRENNEN** — Werkstatt: trennen; Bild: Trennklasse
- `LOCAL_CHAR_G` = **GLOKAL** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `LOCAL_CHAR_I` = **I** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `OS` = **DAZU** — Werkstatt: dazu oder außerdem; Bild: zusätzlicher Bildposten
- `D_LABEL` = **D** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `S_LABEL` = **S** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `LOCAL_CHAR_B` = **B** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `M_LOCAL` = **M** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `Z_ADDR` = **ZORT** — Werkstatt: z-stelle; Bild: z-stelle
- `LD` = **BEFESTIGEN** — Werkstatt: befestigen; Bild: Befestigungsstelle
- `LOCAL_CHAR_J` = **J** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `LOCAL_CHAR_Z` = **ZLOKAL** — Werkstatt: lokales Schreibzeichen; Bild: lokales Bildzeichen
- `RESUME_CARD` = **WIEDER** — Werkstatt: vorigen Posten wieder aufnehmen; Bild: vorigen Bildbezug wieder aufnehmen

## Kompositionsbeispiele

- `OK+E+DY = START + KURZ + ENDE` → kurz ansetzen und schließen.
- `SH+EE+Y = HALT + LANG + DIES` → diesen Posten länger halten.
- `CHD+Y = WECHSEL + DIES` → diesen Posten umsetzen.
- `S+AIIN = WAHL + SOLLWERT` → Variante nach Sollwert wählen / Bildklasse mit Sollwert.
