# GDT539 method

## Question

Can the final GDT538 meanings be returned to all four admitted pages as
complete contextual statements while keeping local margin/sign cards outside
the prose reader and changing no recipe or root value?

## Inputs

- GDT516's 597 selected-page contextual event rows;
- GDT515's 78 prose statements;
- GDT538's final 159-surface phrase dictionary and 34-atom realization deck.

All inputs concern the already admitted pages f4r, f20v, f31r, and f66r.

## Method

1. Split the 597 events by GDT515 role: 546 statement events and 51 local
   margin/sign events.
2. Recount the 159 GDT538 surfaces within those roles. Assign each exact
   surface its observed role scope rather than GDT538's blanket prose scope.
3. For prose events, use the final GDT538 recipe when the surface belongs to
   the 159 and otherwise replay GDT516. Reset active action and argument at
   every statement boundary.
4. Render each event with the fixed register vocabulary. A missing action or
   argument may be carried only from an earlier card in the same statement;
   the source event remains explicit. Pure opening fragments receive a nominal
   or structural reading instead of an invented verb.
5. Join all event clauses into 78 statement readings while preserving event
   IDs, surface order, recipes, and exact controlled-order backprojection.
6. Keep all 51 local cards in a separate role-labeled edition. Compile a
   159-surface role-aware lookup above GDT538 and bypass the old prose overlay
   whenever a local-only surface is requested as prose.

## Pass conditions

- 546 prose plus 51 local events cover all 597 inputs exactly;
- 78/78 statements have complete readings and event backprojections;
- the 159 surfaces partition without collision into 145 prose-only and 14
  local-only forms, with 149 and 19 occurrences respectively;
- every inherited action/argument comes from an earlier event in the same
  statement and no cross-statement carry occurs;
- all final recipe changes replay, both role-matched lookups work, mismatched
  roles delegate below the old overlay, and deterministic validation passes.

## Claim ceiling

This is a contextual editorial reading and observed-role correction for four
already admitted pages. It identifies no plaintext, language, syntax, object,
historical codebook, new recipe, new root value, future role, or unseen page.
