## Method

The old inventory contains sixteen exact equal-recipe pairs in which an inner
visible `d` is the only surface difference. Nine have the narrower terminal
frame `...y→...dy`.

A candidate receives the selected feature only if all of the following hold:

1. the target ends in `dy` and deleting that penultimate `d` yields an exact
   old base ending in `y`;
2. the candidate recipe equals that base recipe exactly;
3. an old exact equal-recipe `...y/...dy` pair has a base differing from the
   target base by exactly one visible substitution;
4. after removing only `CARRIER_Q`, the two base recipes have equal length and
   differ in exactly one slot, with both slot values drawn from the established
   action set `OK CH SH K S CHD T R P`;
5. an exact old target with another recipe overrides the variant rule.

For `qocthedy`, the base is `qocthey=CARRIER_Q+O+CH+T+E+Y`; the certificate is
`qockhey/qockhedy=O+CH+K+E+Y`. The surface substitution is `t↔k` and the one
normalized recipe substitution is `T↔K`.

The selected feature is `log(1+9)=2.302585093` with weight `1.15`, applied
after GDT527. The model ladder also retains the tempting rule that asks only
for one visible substitution. At the same weight it gains the current target
but lowers old top-two recovery `1328→1327` and worsens rank sum `2109→2110`.
Requiring the matching action-root slot removes that cost.

## Decision rule and claim ceiling

The selected rule must improve current top one, lose no current correct case,
and preserve the complete old aggregate scorecard. GDT528 passes: inherited
current top one rises `148→149`, the working-revised score rises `150→151`,
and the old four-fold scorecard is unchanged.
