# GDT631 — prefixed cth quality parts

Status: `CH_SH_PRODUCTIVE_CTH_PREFIX_OPPOSITION__DRY_MOIST_DEFAULT_PROVISIONAL`

Das Experiment ersetzt das isolierte Ganzwort `chcthy` durch eine produktive
Arbeitskomposition. Streng gegen GDT625 stehen 115 `ch+cth+R`- und 36
`sh+cth+R`-Token; einfache k/t-Gegenstücke fehlen. Eine Leserbrücke zeigt
`sh cthey ↔ shcthey` am selben Span.

Arbeitsdefault: global trockene beziehungsweise feuchte CTH-Materialform, im
Herbal trockenes beziehungsweise feuchtes Blatt-/Krautgut. Die genaue
Feuchtesemantik bleibt wegen sichtbarer Gegenkontakte vorläufig.

Siehe `REPORT.md`, `METHOD.md` und `experiment.json`.
