# GDT462 method

## Question

Can a direction-calibrated running-text edge just below GDT460's 0.90 gate be
used on any of GDT461's thirteen remaining whole labels when every mismatch is
explained by an independently established exact package?

## Inputs

- GDT407's 4,576-event running edition and 5,051 attachment edition;
- GDT413's unchanged component working values;
- GDT461's 107-label hybrid dictionary and thirteen whole-label tail.

## Method

1. Enumerate every running-text surface of length at least two that occurs as a
   prefix or suffix of a residual label and has at least one longer running
   extension.
2. Recompute direction-specific atom alignment over all extension types.
3. Review only channels with at least four extensions and precision from 0.75
   up to but excluding 0.90.
4. Enumerate every mismatch. Promote a channel only if every mismatch is an
   independently replicated exact package whose attachment structure explains
   why ordinary edge order is unavailable.
5. Apply an accepted channel only to residual labels at that same edge; retain
   the remainder as a learned name core.

## Decision rule and claim ceiling

Only `PREFIX ar=AR` qualifies: 6/7 ordinary extensions align, while `arary` is
one of two exact `P+AR+AR` surfaces on two pages. Both cards contain two `AR`
peers attached to one `P` head under the old repeated-relation package rule.
No lower-support channel is promoted.

This licenses a working functional edge, not a plaintext word or object name.
It changes no core meaning, page, surface, owner, image binding, or prediction.
