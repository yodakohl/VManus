# Hundred-ninety-fourth pass: forward-writing all five field modes

## Outcome

A fresh 25-token, five-field instruction was written deliberately in CH, D, O,
Q and S modes. It uses twenty exact cards. Every selected surface is already
registered for its intended card, every surface uniquely reads back to that
card, and all 25 prefixes recover the intended field mode.

The sequence is:

`chor chaiin cheky cheol chey | dchol dchey daiin dal dar | or okain okeey ol
olchedy | qokaiin qokal qokeey qoky qokedy | saiin shedal shecthy shcthy
schedy`

CH and D remain open; O, Q and S carry a learned terminal card. This follows the
closure tendencies found in the observed fields without copying any one source
sentence.

## The important compositional test

Four exact cards recur under more than one field frame while retaining one
value:

- MC080 `chor/or` = Ansatz;
- MC039 `chaiin/daiin/saiin` = Sollmaß;
- MC153 `cheol/ol` = weiter;
- MC002 `okeey/qokeey` = lange einwirken.

This is the concrete mixed system we were looking for: a learned whole-card
body remains readable while a short frame marks how the field is being used.
The written object is neither ordinary word morphology nor a flat
nomenclator. It is closer to `mode frame + taught card + close convention`.

## What this teaches an apprentice

- Keep the card value fixed.
- Choose one field mode from the source intention.
- Use a registered surface of that card in the selected mode.
- Keep CH/D construction clauses open unless the instruction truly ends.
- Give O/Q/S a terminal card when the cell is complete.

The next improvement is to hand this same source instruction to a second
renderer who may use mixed rather than perfectly harmonized fields. If value
and closure survive while surfaces diverge, the system can plausibly support a
small multi-scribe workshop.
