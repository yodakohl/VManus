# Sidequest Pass 821: T means “bearbeiten”

The ten T-bearing events expose a weakness in the old value ANWENDEN. It works
for the plant passages, but it is too target-specific for the basin records.
More importantly, two f11r sentences silently omitted T because “apply” could
not be fitted without inventing an application target.

The simpler portable value is:

> `T = BEARBEITEN`

It survives all nine exact cards:

- `T+Y`: den laufenden Posten bearbeiten;
- `E+T+Y`: kurz bearbeiten;
- `EEE+T+Y`: vollständig bearbeiten;
- `T+SH+OL`: bearbeiten und weiter halten;
- `T+CH+O+DY`: im Vorgang bearbeiten, entnehmen und schließen.

This also sharpens the action triad:

- OK=ANSETZEN activates a work step;
- T=BEARBEITEN performs work on the current item;
- CHD=UMSETZEN moves or converts it inside the chain.

All seven affected statements have been rewritten so T is spoken explicitly.
The result is slightly more repetitive, but that is preferable to hiding a
component whenever its former gloss becomes awkward.

Next, pressure-test K=ZUGEBEN, P=EINFUELLEN, and L=LEITEN across every event.
The critical question is whether P truly marks a receiver or is merely a rare
renderer of K or L.
