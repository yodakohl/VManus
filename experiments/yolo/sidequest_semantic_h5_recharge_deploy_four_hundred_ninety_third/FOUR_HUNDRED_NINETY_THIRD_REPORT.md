# Pass 493 — H5-S001 beschickt einen Pflanzenzusatz zweimal

Die neun Karten von H5-S001 bilden einen eigenen Herbal-Makrotyp:
**PFLANZENZUSATZ DOSIEREN, NACHBESCHICKEN UND EINSETZEN**.

Zuerst wird aus dem Bildbesitzer ein Zusatzansatz aktiviert. Eine erste Zutat
wird zur gelernten Arbeitsstelle gebracht und auf Sollmaß gesetzt. Danach folgt
dieselbe HO-Karte erneut — sichtbar einmal als `cho`, einmal als `sho` — und
markiert eine weitere Beschickung desselben Arbeitsgangs. Erst dann wird der
Folgeansatz bereitgestellt, eingesetzt und an die lokale Zielstelle gebracht.

Das ist weder H1s zweifaches Abziehen noch H2s Sollwertprüfung eines bereits
fertigen Ansatzes. Die drei Herbal-Makros unterscheiden sich jetzt sauber:

- H1 erzeugt zwei Auszugsfraktionen;
- H2 standardisiert und übergibt einen fertigen Ansatz;
- H5 beschickt einen Ansatz zweimal und setzt den Folgeansatz ein.

Die Bildpflanze besitzt die Folge, aber sie identifiziert keine zwei bestimmten
Pflanzenteile. `cho/sho` bedeutet daher hier zweimal die gelernte Zutatenklasse,
nicht etwa Blatt versus Blüte. Eine medizinische Auflage bleibt ein möglicher
lokaler Gebrauch, ist aber nicht nötig, um die Kartenfolge zu lesen.

Als Nächstes folgt die siebenkartige H3-S001-Form. Sie ist wegen der bereits
erkannten Auswring–Absetz–Nachseih-Kette der beste Test, ob sich eine lange
Herbal-Form vollständig aus einem wiederverwendbaren Filtrationsmakro statt aus
einer lokalen Ganzphrase lesen lässt.
