## The hand-writing hypothesis and its precise limit

A record contains a list of distinct fields, each written with its own disjoint
sign inventory. The fields may appear in any order. Once the writer leaves one
field, it does not return within that complete written group. Because every sign
identifies its field class, maximal class runs give an exact inverse for this
abstract record language. No native field names or word meanings were stipulated.
