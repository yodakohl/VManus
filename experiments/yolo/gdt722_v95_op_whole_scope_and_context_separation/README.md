# GDT722 — fünf konkrete gebundene OP-Renderer ohne erfundene p-Zerlegung

Status: `PASS_V95_5_OP_HOLDS_RESOLVED_AS_BOUND_WHOLE_RENDERERS__QOPAIIN_ACTION_REMOVED_FROM_LEXICAL_CORE__OPCHEY_26_PLUS_4_FORMAL_FAMILY__NO_INTERNAL_P_EXPORT__47_WEAK_READINGS_REMAIN__NO_SCORE_CREDIT__ALL_H0_NONE`

V95 schließt die fünf schwachen Lesarten `op`, `chopo`, `qopaiin`,
`opchedaiin` und `opchey` als konkrete, unzerlegte gebundene Renderer. Ob ihre
formale Herkunft gelernter Ganzwert oder unexportierte Komposition ist, bleibt
offen. Die Zerlegung über ein inneres `p=Pulver` bleibt als Rivale sichtbar, erhält aber
keinen Komponentenexport. Bei `qopaiin` wird die lokal lizenzierte Handlung
erstmals vom portablen nominalen Wortkern getrennt.

Siehe `REPORT.md`, `METHOD.md` und `experiment.json`.
