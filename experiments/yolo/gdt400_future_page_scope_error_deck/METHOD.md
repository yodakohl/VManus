# GDT400 method — hierarchical future-page error deck

## Question

Can every one of the 4,374 current scope attachments be taught from another
page and another register at some already selected level—exact typed head,
typed microform, untyped microform, coarse rule combination, or independently
portable rule components—and can the dangerous forward/owner cases be reduced
to a compact admission sheet?

## Inputs

- GDT399 complete 4,374-attachment scope edition;
- GDT399 3,888-event replay, 627 statements, 22-page replay, and nine-rule
  support table.

## Method

For every attachment, search outside its own page and register in decreasing
specificity:

1. same focus, attachment class, action head, R mode, duplicate mode, and rule;
2. same focus and microform;
3. same untyped microform;
4. same complete coarse-rule combination;
5. independently attested components of that rule combination.

The fifth level is explicitly amber: four Biological forward-to-R cases use a
compound combination not seen as a unit outside that register, although both
components are separately present in all other registers.

Audit all forward bindings for a visible action exactly one card later and all
owner bindings for a named fallback reason. Rehearse every admitted page, then
emit a fourteen-rule green/amber/red error deck.

## Decision rule and claim ceiling

Pass requires 4,374/4,374 attachments to have outside-page and
outside-register support somewhere in the hierarchy, all 127 forward heads to
be visible exactly one card later in the same statement, all 126 owner cases
to be accounted for, all twenty running pages to replay, and no private
attachment after component fallback.

This remains a creative consistency tool, not a confirmed translation.
