# One compound entry among21singletons

Let A be the22working units and g,h in A. C=(A\{g}) union {gh} or {hg}.
Entries are nonempty and distinct. There are22*21*2+22=946distinct tables.
For gh, only the long entry starts g, so C is prefix-free. For hg, only the
long entry ends g, so C is suffix-free. Both properties imply free unique
decodability. When g=h, every maximal g-run must have even length.

When g differs from h, gh accepts exactly strings where every g is followed
immediately by h; hg accepts exactly strings where every g is immediately
preceded by h. These pairs cannot overlap because g differs from h. Other
signs are singletons. The runner uses this direct criterion; validation uses
full-word codeword dynamic programming and counts distinct parses explicitly.
The number of compound uses is count(g), or half that count for gg. A failed
word contributes its complete occurrence count, not just a problematic glyph.

For each fixed activity threshold the minimum is an empirical optimization
within a declared finite family, NOT independent model selection evidence.
Every tie remains. The Pareto frontier retains a model iff no other has no
more failures and no less activity with at least one strict improvement.
Zero-activity tables are outside the nontrivial class and cannot win its minima.
All sourceword equality frequencies remain unchanged among decoded groups.

Example with abstract source letters A,B and B written ab: source ABBA writes
[a,ab,ab,a], namely aababa. End-first reading recovers A,B,B,A in reverse order
and restores ABBA. No native word or actual language is assigned these labels.
