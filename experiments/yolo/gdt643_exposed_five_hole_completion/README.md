GDT643 turns all five one-hole lines exposed by GDT642 into complete practical
working readings. V20 adds these exact-surface cards:

- `cheodain = Trockenansatz, Dosis II`;
- `oiin = Zubereitungsform III`;
- `choky = heiß-trockene Zubereitung, Grundform`;
- `soysar = soy|sar = Samenzubereitung, Grundform; Samenfraktion I`;
- `kcheedy = heiß-trockene gebundene Abschlussform, Bindungsstufe II`, with
  the RF1b cold-form rival `tcheedy` retained.

All 68 target occurrences are rendered. The five cards add 68 known token
positions and five complete multi-token lines while exposing five next holes.

Run:

```bash
python3 experiments/yolo/gdt643_exposed_five_hole_completion/src/run.py
python3 experiments/yolo/gdt643_exposed_five_hole_completion/src/validate.py
```
