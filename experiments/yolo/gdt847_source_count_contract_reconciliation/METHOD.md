# GDT847 method

Retrospective source-count audit; all results were known before this package.
No manuscript hypothesis or significance test is proposed. Decision: replace
an unexplained old/new count difference with its explicit source contract.
Budget: ten minutes for packaging, validation and handoff; root publication separate.

GDT624 counts ZL3b cleaned eva tokens, with alternate-reader counts separate.
GDT845 counts exact whole raw groups. Compare the identical179selector sets.
Compare occurrence multiplicities by page/locus/whole form, avoiding index
assumptions after cleaning. Retain all old-only and raw-only differences.
For each difference, inspect its guarded raw ZL3b group, clean fragment count
and mapping. Classify bracket alternatives, brace removals and inline metadata
separately. These classes describe source notation, not true manuscript words.

Default runner verifies bound cached witnesses and independently recounts the
GDT845 JSON hits. Optional --reacquire repeats both original guarded TSV
queries and verifies the complete occurrence difference and every witness.
Explicit page allow-values and columns precede payload materialization;
f84 and f84r are excluded. No images, web access or extra selectors.
Default validation does not claim a fresh source query; recorded query
statistics belong to the original audit. All source hashes remain checked.
