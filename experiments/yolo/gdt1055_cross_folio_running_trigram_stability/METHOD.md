# GDT1055 method — complete running-to-running raw phrase census

## Question and disclosure

Do any exact contiguous raw three-or-more-group sequences recur in running text on different physical leaves of the fixed GDT791 thirty-page roster, with the same locus pair and offsets in all three alternate readings? GDT874 asked a different question: complete local-label records as windows in running text. GDT829 required much longer masked l/m contexts. Root already made an exploratory GDT791 clean-token scan, then viewed the raw GDT874 cache and learned that two cross-page triples survive all three readings. This is a **post-discovery documentation/verification experiment**, not a blind search, significance test or word-meaning test.

## Frozen inputs and scope

Use only GDT874's selector-guarded `runtime/ATLAS.tsv`, SHA256 `3b303196be0f3411de7b26d348f858cdda27c847a13c73d058292b3bce306bea`, generated by its published `src/run.py` and `src/SPEC.json`; those tracked recipes are manifest inputs, while the ignored runtime projection is a hash-checked derived cache. If absent, GDT1055 regenerates it through the GDT874 guarded command and stops if its hash differs. Its thirty-page roster comes from GDT791. Require `kind=P`; within each exact `edition,locus,page` line, order by source group index and create windows of 3–6 groups only when every internal boundary is `DEFINITE_SPACE`. Match raw `ivtff_group_raw` exactly, without entity expansion, cleanup, approximate spelling, cross-line concatenation or reader pooling. Require two different physical leaves by `fNN` identity, so recto/verso and multiple sections of one leaf cannot count as cross-leaf evidence. Preserve all hits, including reader-specific hits; do not choose only the two stable pairs. No new manuscript data or pixels are opened.

## Outputs and decision

Report every cross-page 3–6-group window per reader with locus and within-line index; report the intersection requiring identical raw sequence and the same occurrence-locus/start-index pair in all three readers. If a stable pair exists, it is only an inspectable **text-identity lead** for a later owner/content audit. It cannot assert phrase meaning, image correspondence or independent replication. The two known triples make the capacity outcome anticipated; the value here is complete raw validation, full negative 4–6 range, and separating strict from reader-specific recurrence. The validator must reconstruct every window independently and check coverage. Wall-time ceiling 35 minutes including preparation, implementation, validation and publication; stop on input hash mismatch rather than rewriting old caches.
