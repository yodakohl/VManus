# GDT788 — DAL remainder cross-family transfer

GDT788 exhausts the admitted `*dal` surface family and asks whether the
visible `dal` remainder predicts the outside behaviour of longer complete
wholes. The formal family is strong; the semantic remainder is not portable.

Key result:

```text
raw *dal forms/tokens             107 / 415
reader-exact forms/tokens          80 / 304
complete primary lattice cells     40 / 40
SHIFT defeats both controls         2 / 10
CORE defeats both controls          4 / 10
portable dal remainder          WHOLE_ONLY
nonempty working cards             107 / 107
component exports                        0
```

Run and validate:

```bash
python3 -B experiments/yolo/gdt788_dal_remainder_cross_family_transfer/src/run.py
python3 -B experiments/yolo/gdt788_dal_remainder_cross_family_transfer/src/validate.py
```

The German defaults are replaceable complete-whole displays. They are not
plaintext, and EVA strings are not interpreted as Latin letters or sounds.
The 179-page corpus is the already admitted guarded cache; no new page or
sealed `f84/f84r` material is opened here.
