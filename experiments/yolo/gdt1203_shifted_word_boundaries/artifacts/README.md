# Reproduction artifacts

REGISTRATION_LOCK binds the contract, code and existing inputs before counting.
ENCODED is every complete emitted recipe as groups of Unicode units plus END=-1.
FREQUENCIES counts complete ordered groups; no hidden source labels define types.
SOURCE_RECEIPT binds source/summaries, sample ranges and emitted content hashes.
RESULT stores every fixed condition; VALIDATION checks source and inverse fidelity.
These are exposed source-control outputs, not a native interpretation.
