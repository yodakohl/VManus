# GDT486 — Kontraststapel der flüssigen Komponentenrahmen

Status: `TWENTY_NINE_FLUENT_COMPONENT_CONTRASTS__ONE_CONTEXTUAL_VARIANT__ZERO_DICTIONARY_PRESSURE`

GDT486 vergleicht GDT485-Records nur innerhalb desselben Registers, aktiven
Modells, lesbaren Satzrahmens und derselben Eventform. 48 Recordpaare ändern
genau eine funktionale Komponente; daraus entstehen 29 modellgebundene
deutsche Kontrastregeln.

Die vollständige Ausgabe steht in
`artifacts/GDT486_FLUENT_COMPONENT_CONTRAST_DECK.md`; Methode und Ergebnis sind
in `METHOD.md` und `REPORT.md` zusammengefasst.
