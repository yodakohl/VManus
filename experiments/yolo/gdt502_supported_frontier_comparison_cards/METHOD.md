# GDT502 method

## Question

Can every one of the 46 structurally supported GDT501 cells be paired with one
concrete old clause for direct semantic comparison while the four unsupported
assumptions remain visible and unchanged?

## Inputs

- all 4,576 exact GDT416 imperative clauses;
- the complete GDT501 fifty-cell rank, 167 partial candidates, 285 exact
  candidate×register witnesses and thirty ordered-pair joins.

No new page, image or transcription is opened.

## Method

1. Retain GDT501 order and split 46 supported cards from four atomic-only open
   cards.
2. Build support options in fixed order: local action-retaining N−1 recipe;
   other local action partial; attested pair in the target register;
   cross-register action-retaining N−1 recipe; attested pair in another
   register; other cross-register action partial; local action-neutral
   backbone.
3. Within a partial-recipe channel, prefer the longest candidate, then more
   old events, contiguity, candidate ID and register. Within an ordered-pair
   channel, choose a concrete GDT416 carrier group, preferring the target
   register, fewer components, more events and deterministic lexical ties.
4. Select the modal old clause in the chosen exact recipe×register group and
   publish every form, event ID, page and surface. Record which target
   components are absent from a partial carrier; pair cards instead retain the
   exact ordered pair and target nonaction slots.
5. Copy the current target phrase and `COMPOSED_WORKING` label unchanged. Keep
   the four no-support cells as explicit open cards.

## Decision rule and claim ceiling

A comparison card is usable only when its source is an exact GDT416 clause and
roundtrips through the old compiler. A pair-only card asserts only that its
ordered action pair is old; extra slots in the carrier remain visible and are
not transferred silently. A card does not make the target observed. No target
phrase, root value, evidence class, manuscript surface or occurrence changes.
