# GDT344 — grammar transition paths

This experiment moves the grammar one level above exact atomic GDT327 tuples.
It tests whether coordinate-change paths transfer across distinct tuple
sequences and held Recipe/Pharma folios, then separately calibrates a readable-
recipe event-path instrument before any semantic alignment.

Final status: `NO_TRANSFERABLE_GRAMMAR_TRANSITION_PATH` with
`COMPARATOR_EVENT_PATH_NOT_CALIBRATED`.

Both abstract path resolutions beat placement alone, and `PATH_VALUE` saves
4.39 bits relative to exact predecessor identity on 1,604 held edges whose
exact tuple pair was absent from training. Across all 2,002 scored edges,
however, exact predecessor identity remains better by 1.68 bits; path models
are positive on only 6/12 Recipe/Stars and 3/5 Pharma folios, with max-two
diagnostic p=.78887.

On 1,133 readable CoReMA records, anonymous identity-flow topology loses 1.84
held bits to record shape and is positive in only 2/6 collections. The two
required gates therefore stop the event-path alignment before any Voynich
record receives a comparator class.

No PAGE_HOST factorization, tuple merging, token gloss, cross-section pooling,
or f84 access is permitted.
