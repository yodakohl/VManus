# GDT497 method

## Question

Can the complete 110-cell GDT493 T/R deck be given one current, readable
default policy that preserves all observations, keeps explicit arguments
concrete and no longer invents a fixed POSTEN noun for unobserved ellipses?

## Inputs

- all 110 GDT493 owner-dependent T/R realization cells;
- the four GDT493 active-argument frame summaries;
- the nine GDT496 context-safe Tier-A defaults.

## Method

1. Preserve every `OBSERVED_CLAUSE` display phrase, provenance, carrier, page,
   argument-root inventory and evidence status exactly.
2. Preserve each self-contained `COMPOSED_WORKING` phrase exactly.
3. In each active-argument `COMPOSED_WORKING` phrase, replace the inherited
   owner-Y noun plus `[wie zuvor]` with `das zuvor Genannte`. In
   `CH+@ACTION`, replace the second repeated noun with `es`.
4. Render composed `@ACTION+OL` forms as natural German: `Fahre fort, ...
   einzustellen/zu kennzeichnen/zu markieren`.
5. Link each of the 23 generalized cells to all seventeen observed state cells
   in its frame, and separately list same-register and same-action examples.
6. Rebuild all 55 direct T/R pairs and the eleven-frame/five-register coverage
   tables.

## Decision rule and claim ceiling

The current deck is complete only if it contains 37 byte-retained observed
phrases, 50 byte-retained self-contained compositions and 23 generalized
ellipses; all 55 T/R pairs must remain distinct. Every generalized cell must
have observed same-frame and same-action state examples. Meanings, frames,
evidence labels, events and pages remain unchanged. This is an editorial
working translation layer and predicts neither a surface nor an occurrence.
