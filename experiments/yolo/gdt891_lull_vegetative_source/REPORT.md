# GDT891 — Llull original recovered; four owned captions, incomplete action key

**SOURCE_LABELS_CONFIRMED_ATTRIBUTES_PARTIAL.** The official original is
[Vat.lat.3468.pt.1 f38r](https://digi.vatlib.it/view/MSS_Vat.lat.3468.pt.1),
IIIF canvas p0089. The manuscript is split into two catalogue objects: the old
unsplit 404 was an incorrect locator, not absent digitization.

Two native observations agree on the four spatial caption owners and horizontal
order: **Expulsiua — digestiua — Retentiua — Appetitiua** (B's readings; root
normalizes consonantal u to v). This is pictorial order, not a certified temporal
sequence. One branching tree carries the figures; no directed inter-figure
process is drawn. Both see differing props/gestures, including the right-hand
figure's stemmed cup and fruit-like form, the second figure's concentric object
with a central rod, and the third figure's chest-near raised hand.

The stronger functional conjunction from Bonner/Soler, *Imago* 8 (2016), p.135,
[DOI 10.7203/imago.8.9153](https://doi.org/10.7203/imago.8.9153), is **not fully
independently recovered**: B does not identify the left figure as defecating and
allows a vessel/stirring or pounding interpretation for the supposed small
mill. Root had already read the scholarly description; root's agreement cannot
resolve those uncertainties. These are missing functional measurements, not
evidence against the historical caption readings or the scholarly interpretation.

This supplies a source-bound four-role diagram, but not the complete fixed
attribute key required by IDEA000119. No Voynich target was nominated, image
opened, relation scored or word translated. Park the strict functional homolog
test; do not replace the missing actions with four-figure or isolated-cup
resemblance. A later source clarification and separately frozen target contract
would be needed. The external scan stays local; source URL/hash and both original
observations are published.

Validation checks exact source binding, caption normalization and artifact
consistency, not the truth of visual interpretations. Discovery scope and
15-minute budget preceded native access in the published proposal; this directory
was created after root's first observation. This is disclosed source discovery.
