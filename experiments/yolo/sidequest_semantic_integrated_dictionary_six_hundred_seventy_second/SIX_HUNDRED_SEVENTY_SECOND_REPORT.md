# Sidequest pass 672: integrated workshop dictionary

The fixed prose pages now have one consolidated creative edition:

- 39 short root/control entries;
- 173 exact cards;
- 381 visible events;
- 116 complete workshop statements;
- 11 continuous records;
- exactly three memorized whole commands.

Every card has one component recipe, one atomic expansion, and one short default
reading. Every occurrence inherits that same card reading. No word or sequence
is left without a working meaning.

## The architecture in one line

> source/material + quantity + current item + process verb + duration/state +
> path/target/sequence + active endpoint or licensed close.

The most useful distinctions survive intact: AIN portion versus AIIN prescribed
measure versus IIN work stage; AR source versus AL target versus AIR moving
liquid; L forwarding versus OL continuation versus OT next step; Y active item
versus a licensed DY close.

## What became simpler

- `shey/cheey` is SH+EE+Y: hold the item longer, not “clear liquid runs out”.
- `cphy` is P+Y: fill the active item into a receiver, not “strain again”.
- `schedair` is CHD+AIR: transfer the running liquid, not a whole hydraulic
  sentence.
- `qokaiin` is OK+AIIN: set according to the prescribed measure.
- `qokain` is OK+AIN: set one portion.
- `lchedar` is L+CHD+AR: forward and transfer from the source stock.

## The three true whole commands

Only `os` (work compartment), `dchol/schol` (resume), and `talam` (store/put
away) remain learned as indivisible commands. All other exact cards receive at
least one shared contribution from the 39-entry tablet.

This is a complete **working translation system for the sidequest**, not a
claim that these German values are the historical plaintext. Its value is that
one compact, teachable mechanism now rereads all selected prose consistently
and makes new compositions predictable.
