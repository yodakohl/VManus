# GDT568 method

## Question

Can the complete five-register action vocabulary already exposed by GDT415 and
GDT498 be compressed into a small set of reusable owner-voice verb frames and
applied to every GDT567 state clause without changing any of the nine portable
action-root values?

## Inputs

- GDT567's complete 5,122-event and 793-statement owner-voice editions;
- GDT566's ordered 30-page profile;
- GDT565's 1,656 state-card replay with action topology and effective roots;
- GDT415's 95 register-local expansions, of which 45 are action cells;
- the GDT416 and GDT539 owner-bound control clauses used by the current
  30-page edition.

No new page, transcription or root value is introduced.

## Method

1. Retain the nine portable action values and all five register labels exactly.
   Read the 45 old register×action cells from GDT415.
2. Express every cell as a short verb frame with one explicit argument slot.
   Cells with the same frame are grouped. The 45 cells collapse to 20 distinct
   cards; no unavailable cell is filled by analogy.
3. For every state card, reconstruct its generic action chain from the GDT565
   action topology, including separated and repeated action units. Substitute
   only that generated chain with the applicable owner frame; keep arguments,
   modifiers, relations, closure, written atoms and event boundaries fixed.
4. Require the target verb head of every applied register×root cell to occur
   in every applicable owner-bound control clause. Keep all 3,466 nonstate
   clauses byte-identical.
5. Reassemble all 793 statements and enumerate all 4,329 within-statement
   seams. At each mixed state/nonstate seam, count an action contact only when
   both events carry the same fixed root and the nonstate endpoint contains the
   applicable owner-frame head as a whole word. Score both exact full frames
   and exact verb heads before and after the adapter.

## Decision rule and claim ceiling

Pass only if all 45 old register cells are represented by the 20 cards, every
one of the 1,834 state-event root uses has an owner-control witness, all 5,122
events, 793 statements and 4,329 adjacencies replay in their original order,
all nonstate clauses remain byte-identical, and deterministic regeneration is
exact. The cards are German working-realization frames for the existing
exploratory dictionary. They do not alter or confirm a Voynich root meaning,
historical lexeme, plaintext, language, surface, recipe or occurrence.
