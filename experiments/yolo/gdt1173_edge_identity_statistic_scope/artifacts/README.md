# Compact reproducibility artifacts

SPEC.json is in src/. PREREG_LOCK.json binds the fixed method and runner.
RESULT.json gives the exact enumeration result; EDGE_TABLE_HISTOGRAM.json gives
all joint tables with multiplicities. VALIDATION.json records the independent
joint-table reconstruction. SOURCE_METADATA.json pins inspected external code
without reproducing or executing it. WORK_RECORD.json discloses timing and scope.
