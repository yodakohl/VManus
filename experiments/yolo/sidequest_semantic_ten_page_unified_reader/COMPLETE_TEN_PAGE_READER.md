# Vollständiges Zehnseiten-Lesebuch

Die sieben Prosaseiten werden über die gemeinsame Meisterkarte gelesen; die drei Diagrammseiten über sichtbaren Besitzer plus lokale Oberfläche.

## PROSE_STATEMENT · H1 · f10r

### H1-S001

- Oberfläche: `dchey cthoor char chty os chair otytchol oky daiin etyd`
- Wörtlich: Wurzel -> Ansatz bereit -> aus dem Ansatz -> Teil abtrennen -> Mischgefäß -> Wasserzulauf -> naechsten Teilposten weiterfuehren -> aktuellen Posten ansetzen -> Sollmaß -> kleiner Restteil
- Werkstattlektüre: Nimm die Wurzel, bereite den Ansatz, trenne daraus einen Teil ab, gib ihn in das Gefaess, gib den Wasserzulauf zu, fuehre den naechsten Teilposten weiter, setze ihn nach Sollmass an und behalte einen kleinen Restteil.

### H1-S002

- Oberfläche: `qokchy qotchol chol cthy`
- Wörtlich: Posten zur Weiterbearbeitung ansetzen -> danach weiterfuehren -> fortsetzen -> bereit
- Werkstattlektüre: Setze den Posten an, fuehre ihn danach weiter und halte ihn bereit.

## PROSE_STATEMENT · H2 · f10r

### H2-S001

- Oberfläche: `ycheor cthy chor cthaiin qoctholy dy chy taiin shy`
- Wörtlich: Auszugsansatz -> bereit -> Ansatz -> Fertigmaß -> bereiten Posten weiterfuehren -> dieser Posten -> dieser Posten -> Sollmaß -> dieser Posten
- Werkstattlektüre: Nimm den bereiten Auszugsansatz, bringe den Ansatz auf Fertigmass, fuehre den bereiten Posten weiter und stelle sein Sollmass ein.

### H2-S002

- Oberfläche: `qotchor chor otol chol cholor chol daiin dar`
- Wörtlich: Folgeansatz -> Ansatz -> danach fortsetzen -> fortsetzen -> Fortsetzungsansatz -> fortsetzen -> Sollmaß -> aus dem Ansatz
- Werkstattlektüre: Führe den bemessenen Pflanzenansatz als Folgeansatz samt seinem Fortsetzungsposten weiter und nimm daraus das Sollmaß

### H2-S003

- Oberfläche: `oykchor shor chor chy kaiiin dy chodaiin`
- Wörtlich: Ansatzgefäß -> Ansatz -> Ansatz -> dieser Posten -> Weichstufe -> dieser Posten -> Zutatenmaß
- Werkstattlektüre: Gib den weitergefuehrten Folgeansatz in das Gefaess, bearbeite diesen Posten bis zur Weichstufe und stelle das Zutatenmass ein.

## PROSE_STATEMENT · H3 · f11r

- Werkstattlektüre: Entnimm eine Zutat, gib sie dorthin, wringe aus, lass bis zum Standmass stehen, seih nach, nimm den Klarlauf und stelle ihn kalt.

### H3-S002
