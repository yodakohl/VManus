# Artifact roles

`WITNESS.json` retains both complete source groups separately for each reader.
`TRANSITIONS.json` contains every concrete inventory/rank case.
`CONTROLS.json` and `VALIDATOR_CONTROLS.json` retain finite theorem checks and
countermodels outside the excluded conjunction. `RESULT.json` records the
new conditional consequence and labels the old endpoint counts as inherited.
`VALIDATION.json` independently checks the source and computations.

No output assigns a word meaning or a native action. Original IDEA1054 is
outside the mandatory stopping contract; its newer variant is IDEA1065.
