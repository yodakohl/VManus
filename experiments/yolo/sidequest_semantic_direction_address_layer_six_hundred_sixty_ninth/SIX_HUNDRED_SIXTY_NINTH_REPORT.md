# Sidequest pass 669: one direction and address layer

Six recurring pieces now form one compact source–path–target and sequence
grammar:

| Root | Short value | Workshop question |
|---|---|---|
| AR | VORRAT / QUELLE | where from? |
| AIR | FLÜSSIGKEITSLAUF | what liquid is already moving? |
| L | WEITERLEITEN | move the current item onward |
| AL | ZIELSTELLE | where to? |
| OL | FORTSETZEN | continue the same operation |
| OT | DANACH | advance to the following operation |

The union contains 85 exact cards and 146 events. Because many already combine
with OK, CHD, SH, CKH, OR, and the endpoint grid, adding this layer expands the
current compositional dictionary to 146 of 173 cards and 309 of 381 events.

## Important distinctions

- AR is not AIR: a source address is not the liquid running from it.
- L is not OL: forwarding an item is not merely continuing the same step.
- OL is not OT: continuation stays inside the operation; OT advances.
- AL remains the target even when the local picture makes that target a body
  location, vessel, basin, outlet, or work surface.
- AIR names the working liquid in motion without deciding whether it is water,
  wash liquor, or an extract.

These six values are deliberately short. `schedair`, for example, is simply
CHD+AIR: **move/transfer the running liquid**. `lchedar` is L+CHD+AR: **forward
and transfer from the source stock**. `qotal` is OT+AL: **then to the target**.
None needs a sentence-sized dictionary entry.

## Consequence

The emerging workshop grammar is now reusable across the fixed Herbal and Bio
pages:

> choose a source (AR), act on or move the item (OK/CHD/SH/P/LSH), optionally
> continue it (OL) or advance (OT), direct it onward (L) or into a target (AL),
> and leave it active (Y) or close the licensed step (DY).

AIR supplies the recurrent wet material when the operation concerns a liquid.
The pictures still decide which concrete source and target are intended.
