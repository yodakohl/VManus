# GDT496 method

## Question

When the action head is removed from each of the 27 GDT495 Tier-A families, do
all observed same-register clauses preserve the target object's portable and
owner-local remainder in the same order? Can the nine state-dependent defaults
therefore be phrased without falsely fixing the inherited noun?

## Inputs

- the 27 complete GDT495 Tier-A future cards;
- GDT495's 86 local non-T/R and nine opposite-T/R support cells;
- the 4,576 GDT416 observed owner-local imperative clauses.

## Method

1. Join every GDT495 support cell back to all exact GDT416 events by component
   recipe and register. The resulting card-specific inventory contains 95
   head cells and 242 events.
2. Locate `@ACTION` in the fixed formal frame. In each target trace and source
   event, remove only that aligned component.
3. Compare the remaining portable meanings, owner-local meanings and component
   order exactly. Retain source clauses, action readings, explicit arguments,
   inherited arguments, surfaces, pages and event IDs.
4. A self-contained target keeps its concrete GDT495 phrase. An
   active-argument target replaces the temporary owner-Y noun plus
   `[wie zuvor]` with `das zuvor Genannte`; its action and every visible fixed
   component remain unchanged.
5. Publish every event, every head-cell summary, all 27 target cards and a
   complete readable horizontal atlas.

## Decision rule and claim ceiling

`DIRECT_SELF_CONTAINED_REMAINDER` requires exact portable and owner-local
remainders for every family event and no inherited argument. A context-safe
class requires the same exact remainders but retains the active-argument
condition. Any mismatch becomes `REMAINDER_CONFLICT` and blocks the proposed
default.

The context-safe wording is an editorial realization of inheritance, not a
new root meaning. No source clause, component meaning, event, page, surface or
evidence status changes, and no occurrence or surface is predicted.
