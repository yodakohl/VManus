# V23 selection — shared graphic deck, register-local meanings

Date: 2026-08-22

Status: **creative exact-surface bridge audit; no new translation claim**.

## Attempt

The strongest creative shortcut would be that Astro reuses ordinary Herbal/Bio
cards. V23 therefore compares complete visible groups—not substrings—across the
fixed seven prose pages and three Astro pages.

There are 44 exact shared surface forms, covering 98 prose events and 89 Astro
events. This is enough overlap that a common graphic repertoire is plausible.
It does **not** produce a portable semantic dictionary: under the current total
working translation, zero of 44 forms has one exact default across all prose
and Astro occurrences.

## Selected architecture

The best explanation is now a **shared graphic/abbreviation deck with
register-local binding**:

```text
common hand-learned card shapes
  → Herbal/Bio construction assigns practical instruction value
  → Astro diagram slot assigns selector/catalogue/schedule value
```

This resembles a workshop reusing familiar shorthand shapes in tables, labels
and prose while letting the surrounding form determine the reading. It is
easier for several scribes to learn than two wholly unrelated alphabets, but it
does not require every repeated shape to be the same word.

The result also explains why importing PAGE_HOST, prose tuples or the V20 bridge
deck directly into Astro has repeatedly felt attractive yet produces
contradictions. Diagram ownership is part of the code.

## Creative survivors

Some local coincidences remain suggestive rather than selected:

- `okeey` can evoke warmth in prose and a warm bath in one f69 entry;
- `aiin` is a prose measure and occurs once in an Astro “usual measure” phrase;
- `sal` links pictured-place application in prose with “use the indicated
  remedy” in f67.

But each form also has incompatible Astro uses. They may be mnemonic echoes,
renderer pieces, common abbreviations with polysemy, or coincidence. None is
promoted to a cross-register word.

## Consequence for the working translation

V22's 776 concrete defaults remain unchanged. The improvement is architectural:
Astro meanings belong first to whole diagram slots and complete local entries,
not to surface words imported from prose. `V23_EXACT_SURFACE_HOMOGRAPHS.tsv`
publishes all 44 collisions so future creative readings must confront every
occurrence rather than select the attractive ones.

This does not disprove natural language upstream. It says only that the visible
card is not a globally stable word under the current theory. f84 and f84r
remained sealed.
