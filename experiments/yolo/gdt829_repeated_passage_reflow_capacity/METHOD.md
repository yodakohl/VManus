# GDT829 method

The fixed design is in `PREREGISTRATION.md` and `src/SPEC.json`.
`src/run.py` applies the selector-first guard, reconstructs bounded paragraphs
and literal source-group streams, writes and hashes the masked context census,
then releases layout alone and computes conservative comparison capacity.

`src/test_controls.py` checks the implementation on synthetic source rows.
`src/validate.py` independently reconstructs the scientific accounting; it does
not import the runner. No test establishes glyph identity or semantics.

Run `python3 experiments/yolo/gdt829_repeated_passage_reflow_capacity/src/run.py`
to generate artifacts; add `--check` for exact replay. The source atlas and
allowlist remain repository inputs. No full mixed table is directly parsed.

Primary l/m outcomes are omitted from result columns and never scored here.
Masking is procedural; literals in overlapping contexts may expose each other.
Alternative readings are separate sensitivity channels under one ZL scaffold.
