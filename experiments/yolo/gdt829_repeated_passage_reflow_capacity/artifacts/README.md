readings (not independent replications). Its complete 7.6 MB census is retained
so the negative recurrence claim can be audited rather than represented by
selected examples. The four recurrent/layout/pair/component tables are
header-only because no key recurs. MASKED_FREEZE.json binds selection bytes.
No target-outcome column or directional statistic is emitted; overlapping
literal flanks mean that masking is procedural, not cryptographic.
