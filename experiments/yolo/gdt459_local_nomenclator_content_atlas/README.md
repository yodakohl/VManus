# GDT459 — local nomenclator content atlas

Status: `MIXED_PORTABLE_ADDRESS_FORMULAS_AND_LEARNED_LOCAL_NOMENCLATOR`

GDT407 left 183 local address/label events unparsed. GDT459 separates them into
76 short portable or provisional address formulae and 107 learned whole-label
events. The latter are given only their visible owner class—plant, stellar
position, bath station, or drug/ingredient—not an invented individual name.

The release covers only six previously admitted pages and revises none of the
nineteen working core meanings. See `METHOD.md`, `REPORT.md`, and
`artifacts/README.md`.
