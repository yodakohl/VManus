# GDT741 working protocol

## Target

Replace GDT740's thirteen manual attachment overrides with the smallest useful
local rule system that does not dispatch on occurrence identity or locus.

## Planned pass

1. Materialize host, opposite-flank and middle-cell features from the fixed
   GDT739/GDT740 artifacts.
2. Apply boundary ownership, flank non-fusion, single-host carrier coverage,
   strict relay continuity and direct process support in a fixed order.
3. Compare the resulting roles and modes with all 103 binding contacts and the
   thirteen former manual decisions.
4. Re-render all 202 positions and the fixed twenty-passage audit.
5. Run a looser relay channel over the same contacts and publish every new
   collision without activating it.

## Useful success and honest failure

A useful pass must reproduce all thirteen functions without an ID/locus lookup,
surface every changed contact and preserve the zero-export ceiling. It remains
an in-sample compression if a rule has no repeated trigger. Any relaxed relay
that changes an open target remains a candidate, not an automatic repair.

## Required outputs

- feature and decision rows for all 103 binding contacts and 95 targets;
- one replay row for each of the thirteen former overrides;
- a trigger census for every rule;
- strict and relaxed radius-two candidates with collision status;
- all 202 renderer patches and twenty passage replays;
- an intentionally ineligible GDT388 packet, result JSON, independent validator
  and byte-identical builder replay.

## Non-exports

No new page, `f84`, `f84r`, global whole meaning, substring/component, head/body
meaning, sound, glyph value, historical expansion, literal patient, species,
unit, lexeme, language or plaintext clause may be exported.
