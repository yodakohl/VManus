## Chronology and adaptation

The outside-target deck and discovery exclusion were fixed before the first
score. The first implementation produced attractive raw X2/X3 distribution
tiers. Before accepting them, the same rule was applied leave-self-out to all
forty-six known reference wholes. That calibration recovered only 23 true
quality/stage labels while adding 42 false labels and missing 60. The packaged
decision rule was therefore adapted openly: raw ranks remain in the artifacts,
but they cannot confirm or reject a target role. Final working tiers use only
weak, baseline-adjusted immediate-context compatibility, and no tier is a
decoded word.

This is an exploratory throughput experiment, not a blinded confirmatory test.
The chronology is retained so that the failed attractive renderer is not
mistaken for the calibrated result.
