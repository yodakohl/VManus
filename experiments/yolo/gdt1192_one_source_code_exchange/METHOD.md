# A single public table exchange

Changing the owners of two existing codes changes all occurrences globally and preserves one-to-one code lookup. It changes source code lengths and adjacent spellings, not literal source segmentation or the meaning/recovery of its source words. The new inverse table is mandatory.

An exact histogram update filters all unordered pairs before expensive direct metrics. The complete criterion stays unchanged; filter arithmetic and limited complete-metric enumeration are reported separately.
