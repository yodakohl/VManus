# GDT1096 — finite recurrent domains

Prospective necessary-consequence follow-up to the unchanged GDT963 complete
content-code hypothesis. See METHOD.md and PREREGISTRATION.md. It is not a
new decoder or a reading of any Voynich word.

Run `python3 experiments/yolo/gdt1096_dioscorides_finite_recurrent_domains/src/run.py`,
then `python3 experiments/yolo/gdt1096_dioscorides_finite_recurrent_domains/src/validate.py`.
Controls only: append `--controls` to the validator command. No external package
or network is required. All parent bytes are checked against src/PREREG_LOCK.json.
