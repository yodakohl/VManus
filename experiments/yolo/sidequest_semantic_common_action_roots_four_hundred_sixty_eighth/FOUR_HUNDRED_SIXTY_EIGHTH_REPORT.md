# Pass 468 — gemeinsame Handlungen statt Wasser im Himmel

Die vollständige Astrozerlegung zeigt sieben noch zu enge Nasswörter. Sie
werden auf kurze gemeinsame Handlungen zurückgenommen:

- `R = SENKEN` — im Nasskontext abkühlen;
- `CHK = ANHEBEN` — im Nasskontext erwärmen;
- `CKHE = TRENNEN` — im Nasskontext seihen;
- `CHEO = ENTNAHME` — im Pflanzenkontext Auszug;
- `CH = ENTNEHMEN` — im Nasskontext abziehen;
- `CKH = DURCHGANG` — im Nasskontext Rohr- oder Seihdurchlass;
- `LS = HINAUSFÜHREN` — im Nasskontext abführen.

Damit kann dieselbe Kurzkarte eine Flüssigkeit im Becken oder einen Eintrag im
Himmelsdiagramm bearbeiten. Die konkrete Übersetzung bleibt lesbar: `R+AL`
heißt atomar „an der Stelle senken“ und im Bad „an der Stelle abkühlen“;
`SH+CKHE+DY` heißt atomar „halten, trennen, Schluss“ und im Rezept „seihen;
Schluss“. Das Wörterbuch wird dadurch kürzer und die Zusammensetzung stärker,
nicht unbestimmter.
