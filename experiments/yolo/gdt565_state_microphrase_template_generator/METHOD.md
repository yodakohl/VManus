# GDT565 method

## Question

Can all 716 GDT564 recipe-context readings and all 1,656 GDT563 event
microphrases be generated from a small reusable sentence kit, rather than
retained as learned long phrases? Does exact generation expose any editorial
inconsistency in the current working edition?

## Inputs

- GDT563's complete 1,656-row state-card microphrase edition;
- GDT561's 36-entry typed state-atom dictionary;
- GDT564's complete 402-recipe route table;
- GDT564's 415 observed variable-recipe selector cells.

No new page, image, transcription, surface or segmentation is used.

## Renderer kit

The generator contains 42 explicit cards:

- nine state frames, one for every observed OT/OL/DY sequence;
- nine action templates, each with objectless and argument-bearing forms;
- four argument phrases;
- fourteen distinct modifier fragments mapping all twenty non-action,
  non-argument and non-state atoms;
- six combinators for argument coordination, doubled Y, action chains,
  adjacent repetition, modifier order and final sentence assembly.

Every card has an observed usage count. All 42 must be used.

## Generation

For each source card, the GDT564-selected effective action and argument fill the
open semantic slots. Visible action atoms are retained in order. Immediately
adjacent identical actions alone may become “zweimal”; separated repetitions
remain separate units. Argument roots are rendered in order, with `Y|Y`
normalized to “die beiden Posten”.

All recipe atoms outside action, argument and state classes become modifier
fragments in their exact written order. The state frame then adds its prefix
and suffix, and one final combinator supplies colons, semicolons,
capitalization and punctuation.

## Template inventories

Each event receives two descriptive signatures:

- an outer skeleton recording prefix, base mode, modifier presence and suffix;
- a structural signature recording exact state sequence, base mode, action
  topology, argument topology and modifier-type sequence.

These signatures describe assembly shape; they are not new meanings. The 716
recipe-context cells are rebuilt from generated rather than learned phrases and
linked back to all 415 GDT564 variable cells.

## Named normalization

The source contains one renderer-history inconsistency. Four `Y|Y` action
phrases say “die beiden Posten”, while inherited-action event `G407-E1000`
still says “den Posten und den Posten”. The generator applies the same double-Y
rule everywhere and records this one German editorial change in a dedicated
artifact. Recipe `Y+D_ADDR+OL+Y`, both Y atoms, effective K, atom alignment and
root meanings remain unchanged.

## Decision rule and claim ceiling

Pass requires 1,655 byte-identical source replays, exactly the one named
double-argument normalization, zero unexpected drift, complete accounting of
all 716 cells, all 42 renderer cards used, and deterministic artifact replay.

This is an exploratory German realization grammar for the current working
dictionary. It demonstrates that the existing phrases are compositionally
expressible; it does not independently confirm any root meaning, language,
syntax, genre, object or plaintext. It licenses no new manuscript occurrence
or surface.
