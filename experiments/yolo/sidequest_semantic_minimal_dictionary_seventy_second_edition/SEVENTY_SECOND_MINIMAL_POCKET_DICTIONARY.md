# Kleinstes aktives Werkstattwörterbuch

## Produktive Stämme

- `AIIN` = **Sollwert**
- `AIN` = **Anteil**
- `IIN` = **Stufe**
- `AL` = **Ziel**
- `AR` = **Quelle**
- `AIR` = **Lauf**
- `OK` = **ansetzen**
- `OL` = **weiter**
- `OT` = **danach**
- `OR` = **Ansatz**
- `Y` = **dies**
- `E` = **kurz**
- `EE` = **länger**
- `EEE` = **vollständig**
- `CLOSE` = **Ende**
- `CHD` = **umsetzen**
- `CTH` = **bereit**
- `CKH` = **Durchlass**
- `CKHE` = **trennen**
- `CHK` = **wärmen**
- `SHED` = **absetzen**
- `SOLK` = **sammeln**
- `HO` = **Zutat**
- `CHEO` = **Auszug**
- `KCH` = **bearbeiten**
- `TY` = **Teil**
- `SH` = **halten**
- `CHEEY` = **Ergebnis**

## Gelernte Ganzkarten und Muster

- `cfhy` = **auswringen**
- `cphy|ocphy` = **nachseihen**
- `ches|chety|chty` = **teilen**
- `cho|sho|tshol` = **Zutat**
- `dchey` = **Wurzelteil**
- `dchol|schol` = **vorher**
- `lshedy|lsho|rshedy` = **waschen**
- `qokylddy` = **befestigen**
- `skar` = **ausgießen**
- `sotodan` = **anwenden**
- `dl` = **Zusatz**
- `talam` = **verwahren**
- `dain` = **Tuch|Portion**
- `ody` = **kühlen|markieren**
- `os` = **Gefäß|Feld**

Bildbesitzer, Prozessmakros, Merkregister und Astro-Namensräume sind
keine Wörter. Sie liefern Kontext oder Schreibablauf. Ein komplexer Satz darf
daher nie als Bedeutung eines einzelnen Stammes in dieses Wörterbuch zurück.
