# GDT689 — V62 erhält den Wortkern der `dy/y`-Schwestern

Status: `PASS_V62_36_HEAD_SISTERS_PLUS_1_RECIPE_NULL__25_RESULT_12_FIELD_0_TELIC__47_HEAD_PLUS_3_NULL_REVISIONS`

V62 ersetzt die alte Annahme „sichtbares `dy` hat überall dieselbe
Bedeutung“ durch einen kleineren gemischten Code. Von 60 gebundenen
`dy`-Oberflächen besitzen 36 ein bedeutetes nicht-`dy`-Gegenstück; ein
weiteres Paar ist nur parseridentisch. 25 Formen werden
als Resultatform des unveränderten Schwesterkerns gelesen; zwölf übernehmen
die bereits abgeschlossene Schwester ohne zusätzlichen gesprochenen
`dy`-Wert. Kein Paar benötigt eine produktive neue Handlungstelizität.

Dadurch werden 47 Schwesterstellen und drei Parser-Nullstellen auf 25 Zeilen
konkreter und konsistenter. Zum
Beispiel wird `olchdy` nicht mehr zum generischen Befehl „Trockenstoff
vollständig trocknen“, sondern zu „Holzdroge im Ansatz fertig getrocknet“.

Siehe `REPORT.md`, `METHOD.md`, den vollständigen Reader
`artifacts/GDT689_V62_DY_SISTER_READER.md` und die 50 exakten Änderungen in
`artifacts/V62_50_POSITION_REVISIONS.tsv`.
