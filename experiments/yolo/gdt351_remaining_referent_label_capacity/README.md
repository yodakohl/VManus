Source-only audit of the four GDT169 `ASSERTED_SAME` Herbal→pharmaceutical
relations that lacked a local label query.  It asks whether any can be upgraded
to a singularly owned target inscription without opening images or formal text.

```bash
python3 experiments/yolo/gdt351_remaining_referent_label_capacity/src/run.py
python3 experiments/yolo/gdt351_remaining_referent_label_capacity/src/validate.py
```

No f84 material is an input.
