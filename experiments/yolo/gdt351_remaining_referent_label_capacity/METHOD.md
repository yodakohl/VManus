# GDT351 method — remaining externally nominated referent-label capacity

## Question

Do any of the four GDT169 `ASSERTED_SAME` Herbal→pharmaceutical relations
without a published local query have a source-documented, singularly owned
pharmaceutical inscription that could support a new exact tuple transfer test?

This is a source-only capacity audit.  It opens no manuscript image and reads
no Voynich token, family, tuple, PAGE_HOST, or other formal identity.

Prepublication correction: the first local build parsed the two global human
tables before filtering and therefore transiently parsed f84 catalogue rows.
No such row was displayed, retained, used for selection, or scored.  The final
producer and validator use the repository `GuardedTSV` reader, which rejects
all `f84*` rows by raw page-field offsets before parsing any other field.  Exact
superseded local artifact hashes are retained in the result.

## Frozen panel

The panel is defined mechanically from `gdt169_external_referent_candidates.tsv`:
retain `HERBAL_TO_PHARMA`, `ASSERTED_SAME`, `local_query_locus=NONE`.  The four
rows are:

- f1v → f102r1, catalogue fragment 204;
- f32v → f102r2, catalogue fragment 206;
- f47v → f102r2, catalogue fragment 205;
- f48r → f89v2, catalogue fragment 61.

The catalogue fragment numbers come from the already published GDT151 relation
inventory.  Target-page label capacity is assessed only from the cached human
page catalogue and exact Stolfi locus comments.

## Eligibility

A relation is `ELIGIBLE_NEW_LOCAL_QUERY` only if the human source supplies one
inscription whose ownership of the nominated fragment is singular.  A page-level
count is not ownership.  `near`, `between`, or an assumed container/plant split
is not singular ownership.

No visual adjudication is allowed to repair an absent or ambiguous source join.
If all four rows fail, stop before images and formal scoring.

## Claim ceiling

This audit can establish only whether the current cached human sources contain
a new singular referent→inscription join.  It cannot establish a plant identity,
label meaning, word, language, plaintext, or translation.  f84 is excluded.
