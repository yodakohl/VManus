# GDT505 method

## Question

Does one short carrier-neutral German action handgrip survive every exact old
GDT416 carrier of the five ordered pairs used by GDT504's eleven pair cards?

## Inputs

- the complete 4,576-clause GDT416 edition;
- the complete GDT421 81-pair profile table;
- the fixed GDT413 46-component dictionary;
- all 46 GDT504 semantic-delta cards, from which the eleven pair-frame edits
  are selected.

No page, image, transcription, target phrase or component value is added.

## Method

1. Select every old clause whose exact explicit action-root sequence is one of
   `P+CH`, `S+CHD`, `CH+P`, `CH+CH` or `CH+SH`.
2. Locate the two actions in each ordered recipe. Publish all frame components
   before, between and after them, along with argument mode and exact clause.
3. Independently locate both German action markers in the clause and require
   the same order. Repeated `CH+CH` requires two old NEHMEN markers.
4. Collapse only the actions to one portable handgrip. Do not transfer any of
   the sixteen surrounding frame-atom families into that handgrip.
5. Aggregate pair, register, adjacency/separation, intervening patterns,
   arguments, pages, recipes, surfaces and clauses; cross-check GDT421 counts.
6. Join the five handgrips to all eleven GDT504 pair cards. A current repeated
   target may realize the second action with `zweimal`. Mark whether the pair
   is old in the target register or only in another register.

## Decision rule and claim ceiling

A handgrip is retained only if all old carrier clauses express both actions in
the expected order and roundtrip exactly. It asserts the portable action order,
not adjacency, a shared object word, or transfer of grade, argument, relation,
order-control or close slots. A target remains `COMPOSED_WORKING`; a
carrier-neutral phrase neither observes the target recipe nor predicts a
surface or occurrence.
