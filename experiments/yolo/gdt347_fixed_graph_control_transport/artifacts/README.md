# GDT347 artifacts

- `gdt347_design.json`: frozen split, coverage, null, and decision rules.
- `gdt347_frozen_graph.json`: one Voynich topology and its immutable weights.
- `gdt347_control_capacity.tsv`: pre-score coordinate and transition capacity.
- `gdt347_freeze_validation.json`: independent freeze validation.
- `gdt347_panel_scores.tsv`: native/matched aggregate gains and decisions.
- `gdt347_folio_scores.tsv`: held-folio scores with fixed graph weights.
- `gdt347_environment_scores.tsv`: event-exact section/register/hand transfer.
- `gdt347_edge_scores.tsv`: decision-inert frozen-edge decomposition.
- `gdt347_null.tsv`: 4,096 coupling-destruction worlds per panel.
- `gdt347_counterexamples.tsv`, compact result, and final validation.
