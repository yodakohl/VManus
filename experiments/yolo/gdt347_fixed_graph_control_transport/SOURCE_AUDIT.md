# GDT347 source and capacity audit

The Voynich training source is only GDT345's corrected, validated, f84-free
transition inventory: 8,268 edges on 91 physical folios. The topology source
is GDT346's published graph-edge table, not a new target search.

The control source is GDT278's already frozen native-order event inventory and
pre-score architecture manifest: 15 controls plus the Voynich integrity row.
The event table exposes the same parser coordinates needed here. Architecture
truth labels were frozen independently of GDT347 and no oracle field is scored.

Important pre-score limitations:

- ordinary, diplomatic, and all current synthetic controls have `dy_closure=0`
  throughout, whereas Voynich has 1,405 DY-closed events;
- the learned MAP/SAMPLED abbreviation outputs, Ste1 diplomatic/expanded
  sensitivities, and parts of the apothecary control have little or no parsed
  coordinate variation;
- ordinary controls use their own wrapper/frame/right values, so many frozen
  Voynich pair-potential cells will be neutral by construction;
- only incremental graph gain at explicitly reported overlapping support is
  comparable; missing overlap is not a failure;
- source folios within paired Nuremberg views and within A/B/B2 are correlated
  schedules, not independent corpora.

The native inventory's Voynich row reconstructs all 8,448 GDT327 events and
all 8,268 GDT345 adjacent transitions exactly when canonical `s` line-entry
and `q` post-DY renderer effects are removed. This is an integrity anchor only.

No source file used by GDT347 contains or permits an f84 row in the selected
panel. The scorer must use guarded row selection before retaining formal data.
