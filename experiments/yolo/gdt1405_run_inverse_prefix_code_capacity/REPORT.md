## Why enlarging the prefix table cannot rescue the eight fixed W

The ONLY source counterforms declared before new capacity results were the
already exposed1403 `cholols` and `dydydy`. Neither changes under run collapse.
When every unit of one of these words is forced to a singleton code, prefix
freedom forbids a longer code beginning with those units. It must therefore
read one source character per working unit, with the same equality pattern,
regardless of any additional codes elsewhere or total inventory size.

- `cholols`: ch,o,l,o,l,s; equality pattern0,1,2,1,2,3.
- `dydydy`: d,y,d,y,d,y; equality pattern0,1,0,1,0,1.

Neither pattern occurs in ANY of the eight pinned1403BIDIR envelopes. That
previous independent source-wordbook audit is a stated dependency, not newly
recomputed here. It already grants different perword letter keys and sourceword
directions. Thus the literal-character/prefix-code/wholegroup/run-inverse/W
conjunction fails even for arbitrarily large code tables where a present
counterform has all its singleton codes forced.

Both witnesses qualify in FULL in all3readers, and in LEAF2 IT/RF. In ZLLEAF2,
cholols is present but ch is NOTforced; dydydy is absent from the RAWrecurrent
panel. The predeclared bridge is therefore silent there. It is not a found key,
compatible source reading or proof that another counterexample is absent. No
post-result witness search was used to fill this cell. Readers are alternate
transcriptions of one manuscript, not three independent confirmations.

## Writer assumptions and remaining classes

The proposed rendering expands each e/i into a positive run. For collapse to be
an exact inverse the ENTIRE underlying encoded source WORD must be ee/ii-free,
including every codeword join. A table covering observed collapsed strings does
not supply that production law on a real source lexicon. We deliberately ignore
this extra duty for necessary bounds; this is generous to the candidate.

Prefix decoding is in the fixed native-unit direction. SourceBIDIR pattern
comparison enlarges the source envelope; it does not establish arbitrary reversal
of entire emitted block words. General freelyUD/suffix/dictionary-assisted codes,
contextual values, multiple drawings per letter, multi-character source units,
other vocabularies, changed working glyphs or word boundaries are different
classes. No one of them is selected or generally excluded by this result.
The old eight wordbooks are finite controls, not languages or actual originals.

Decision: close this two-layer prefix-code escape for the stated fixedW cases;
retain numeric sensitivity and the ZLLEAF2 unproved bridge. Do not enlarge a
codebook, pick an alphabet, delete y, optimize source words or start a decoder.
The exact formal tables are representations, not readings. Confirmed words:0.
