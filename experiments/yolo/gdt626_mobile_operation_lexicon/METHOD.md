# GDT626 method

## Question

Can a mobile word between the GDT625 part and quality carriers receive a
concrete operation meaning, or does its internal paradigm identify a more
useful compositional value system?

## Inputs and scope

The builder uses the canonical 179-page GDT624 allow-list. f1r is excluded;
f84 and f84r are rejected before payload materialization. Both the ZL3b token
table and the ZL3b/IT2a/RF1b line table are read only through `query-tsv` with
all 179 selector allow-values and explicit projected columns. The three
transcriptions are alternate readings of one manuscript, not independent
samples. No new manuscript image was opened.

The inherited working layer is fixed:

- `k/t` = hot/cold;
- `ch/sh` = dry/moist;
- `cth` = leaf or above-ground drug-material family;
- `chor/shor` = reproductive or other plant-part family.

These remain working meanings rather than confirmed plaintext lexemes.

## Paradigm extraction

Every surface matching `^(.*a)(i*)n$` is split at the final `a`. The number of
visible `i` minims before terminal `n` is recorded without semantic
normalization. The safe corpus itself limits this slot to zero through three
internal minims; a fourth internal `i` never occurs. The practical value reader
is therefore:

| written tail | historical final-j analogue | working value |
|---|---|---:|
| `-an` | `j` | I |
| `-ain` | `ij` | II |
| `-aiin` | `iij` | III |
| `-aiiin` | `iiij` | IV |

For each head the builder records all four cells, cross-reading-stable token
capacity, page and section distribution, and same-line co-occurrence of two or
more cells. It separately records section, hand, and line-edge profiles so the
strong inflectional or scribal-grade rival remains visible.

## Compositional readers

Quality-value compounds match an inherited terminal quality core
`k|t + ch|sh`, optional inherited `e/d` frame material, `a`, and the minim
value. Registered bare/o/qo direct-core cells are emitted as a complete
3×4×4 matrix; extended wrappers remain visible rather than being forced into
the registered grid.

Plant-part compounds match a known `cth`, `chor`, `shor`, `dair`, or `sair`
head followed by the same value tail. A quality head receives the concrete
default `degree I-IV`. A part head receives only `amount/dose/degree/class
I-IV`: no absolute unit and no literal number of pictured organs is invented.

The full `dan/dain/daiin/daiiin` family is retained occurrence by occurrence.
This resegments `daiin` as `d+III`; it does not identify the `d` head or exclude
an additional learned surface-specific linking use.

## Historical and visual comparison

The manual comparator file binds dated medical witnesses around the fifteenth
century. Real recipes use final-`j` Roman series and independently use Roman
values for dosage. Real materia-medica glossaries combine compact hot/cold and
dry/moist descriptions with degrees I-IV. They support a mechanism and a
working reading, not a glyph identity.

Manual judgments use only already opened Herbal images. They distinguish a
part-plus-value layout from literal counts such as “three leaves” or “three
drachms,” neither of which is licensed.

## Claim ceiling

GDT626 promotes a reproducible four-cell minim slot and an exploratory
I/II/III/IV reader. It promotes degree readings only on the inherited quality
heads and an unresolved value reading on part heads. It does not prove that
EVA `n` is Latin `j`, that every value is numerical, that `a` is a unit, that
the inherited quality orientation is correct, or that any complete sentence
has been translated.
