# GDT626 — four-cell minim-value lexicon

Status: `FOUR_CELL_MINIM_VALUE_READER__QUALITY_DEGREES_COMPOSE__DAIIN_RESEGMENTED`

The attempted search for a mobile operation word found something more useful:
the 5,176 safe-panel forms ending in `-an/-ain/-aiin/-aiiin` constitute a
bounded four-cell written paradigm. The current practical reader assigns these
tails values I/II/III/IV, following the exact medieval final-`j` recipe series
`j/ij/iij/iiij`.

This produces concrete, compositional readings:

| surface | segmentation | working reading |
|---|---|---|
| `qokchain` | `qo+k+ch+II` | hot-dry, degree II |
| `qokchaiin` | `qo+k+ch+III` | hot-dry, degree III |
| `qotchain` | `qo+t+ch+II` | cold-dry, degree II |
| `qotchaiin` | `qo+t+ch+III` | cold-dry, degree III |
| `cthan/cthain/cthaiin` | `cth+I/II/III` | leaf or above-ground drug material, value I/II/III |
| `daiin` | `d+III` | d-value III; locally an amount/degree marker, with `d` still open |

The value on quality heads defaults to a Galenic degree. On plant-part heads
it remains amount, dose, degree, or class until a unit is identified. `daiin`
is no longer rendered as an empty operation, `and`, or `item`.
