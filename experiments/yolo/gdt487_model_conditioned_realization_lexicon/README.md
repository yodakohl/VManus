# GDT487 — Modellgebundenes Realisierungslexikon

Status: `THIRTEEN_VALUE_REALIZATION_LEXICON__FOURTEEN_SINGLETON_CYCLES__TWO_ENDPOINT_ANCHORS`

GDT487 dreht die 29 Kontrastregeln aus GDT486 um. Für dreizehn feste
Arbeitswerte sammelt es sämtliche dort tatsächlich beobachteten deutschen
Formen getrennt nach Katalog-, Koordinaten- und Anweisungsmodell. Unbelegte
Zellen bleiben ausdrücklich `OPEN`; es werden keine Formen ergänzt.

Die vollständige lesbare Ausgabe steht in
`artifacts/GDT487_MODEL_CONDITIONED_REALIZATION_LEXICON.md`. Methode und
Ergebnis sind in `METHOD.md` und `REPORT.md` zusammengefasst.
