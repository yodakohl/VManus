# Sidequest Pass 902: kontextueller Allographenselektor

Die 16 mehrdeutigen Wurzelrezepte werden auf allen aktuellen Vorkommen mit einer kurzen Priorität aus Register, Kartenposition, Auftrag, Seite, Stufe und lokalem Mini-Deck ausgewählt. Damit erzeugt der Schreiber für jede der 437 Marken die beobachtete Oberfläche; die verbleibende Lernlast steht explizit pro Familie im Selektorhandbuch.
