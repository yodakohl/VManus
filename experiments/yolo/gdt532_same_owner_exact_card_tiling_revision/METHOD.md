# GDT532 method

## Question

Can any remaining non-top-one surface be reconstructed completely from exact
old cards, and can a current same-owner carrier decide a unique recipe even
when the finite compiler ranks it below its heuristic default?

## Inputs

- GDT407's 4,576 old running events and 693 old local groups;
- GDT516's 597 current contextualized events;
- GDT529's finite candidate recipes and ranks;
- GDT531's complete 159-form working edition and five-form residual queue.

No page beyond the already admitted thirty is used.

## Method

### Exact-card inventory

For every old running surface with one invariant recipe, retain that exact
surface-recipe card. If a surface is absent from old running prose, admit an
invariant old local card instead. Running cards have precedence over local
roles. This produces 1,885 exact cards; no arbitrary substring-to-atom mapping
is learned.

For each of GDT531's five residual forms, enumerate all segmentations into two
or more inventory cards. Concatenate the card recipes and retain a route only
if the complete result is already one of GDT529's finite candidates for that
surface. Sixteen routes survive:

| Surface | exact routes | distinct candidate recipes | outcome |
|---|---:|---:|---|
| `dairykodas` | 12 | 2 | ambiguous between ranks 1 and 2 |
| `dsholdaiir` | 4 | 1 | unique recipe, rank 6 |
| `aiicthy` | 0 | 0 | unresolved |
| `dalcheeeky` | 0 | 0 | unresolved |
| `qef` | 0 | 0 | unresolved |

Among equivalent routes for one recipe, prefer fewer cards, then the longest
available whole card. For `dsholdaiir` this selects:

```text
d       | shol  | daiir
D_ADDR  | SH+OL | DA+IIN+R
```

The route must also contain an old local card that has crossed into current
prose with the same recipe and recurs elsewhere in the target's current owner
block. `daiir` satisfies all three conditions: two old f70v local cards, two
current prose cards on f31r and f66r, and current `G515-E0408` at f66r.62 in
the same `F66R_PROSE_02/F66R_TEXT_BLOCK_02` as target `G515-E0366` at f66r.58.

The same block independently contains `sholdy=SH+OL+D_ADDR+Y` at f66r.60,
confirming that `SH+OL` remains a live package there.

## Decision rule and claim ceiling

Select a composition override only when the residual has exactly one tileable
candidate recipe, its preferred route is shorter than competing equivalent
tilings, and an old-local tile has both cross-role current reuse and a distinct
same-owner/same-block carrier. Only `dsholdaiir` passes.

This is intentionally not a score improvement. The previous working recipe was
GDT529 rank 2; the exact-card recipe is rank 6. Across the 159-form edition,
rank one stays 154, top two falls 158→157, and rank sum rises 171→175. Those
numbers measure agreement with the inherited provisional recipes. Here, exact
visible composition is taken as stronger semantic evidence than the heuristic
candidate order, and the cost is retained rather than hidden.

The selected packages read:

```text
d       = HIER
shol    = HALTEN · FORTSETZEN
daiir   = STUFE II · MARKIEREN
```

Thus the compact reading is “Hier halten und fortsetzen; Stufe II markieren.”
This remains an exploratory functional reconstruction, not confirmed plaintext
or a license to tile arbitrary strings freely.
