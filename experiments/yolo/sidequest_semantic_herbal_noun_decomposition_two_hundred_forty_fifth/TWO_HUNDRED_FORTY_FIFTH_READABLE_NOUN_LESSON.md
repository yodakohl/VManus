# Herbal-Nomenlektion

## Vollständig gebaute Nomenkarten

- `chodaly` = `CHO + AL + Y` → Zugabe am aktuellen Ziel
- `qotchor` = `OT + OR` → Folgeansatz
- `orain` = `OR + AIN` → Bereitungsanteil
- `ycheor` = `Y + CHEO + OR` → aktueller Auszugsansatz
- `cheoar` = `CHEO + AR` → Auszug aus der Quelle
- `chodaiin` = `CHO + AIIN` → Zugabemaß
- `chochor` = `CHO + OR` → Zugabeansatz
- `choy` = `CHO + Y` → aktuelle Zutat

## Bekannter Rahmen plus neuer Nomenkern

- `chair` = `CH + AIR` → laufendes Medium zugießen; lerne CH pouring core
- `oykchor` = `OYK + OR` → Gefäß für den Ansatz; lerne OYK preparation-vessel core
- `ykain` = `Y + K + AIN` → erste Portion; lerne K ordinal/index core
- `shoyty` = `SHO + YTY` → Zugabeteil; lerne YTY material-part core
- `otytchol` = `OT + YTY + OL` → Folgeteil; lerne YTY material-part core
- `kchoar` = `K + CHO + AR` → bearbeiteter Quellauszug; lerne KCHO processed-extract core
- `ykan` = `Y + K + AIN` → zweite Portion; lerne K ordinal/index core
- `ykaiin` = `Y + K + AIIN` → Sollportion; lerne K ordinal/index core

## Ganze Nomen

- `cho` → weitere Zutat
- `schoal` → Sudansatz
- `dchey` → Wurzel
- `tshol` → Kochgut
- `etyd` → kleiner Rest
- `sh` → Stängel
- `os` → Aufnahmegefäß
- `talam` → Verwahrort

Der sichtbare Bildbesitzer ersetzt den Pflanzennamen. Deshalb genügen dreizehn neue Inhaltskerne für Teil, Zutat, Gefäß, Ansatz, Rest und Ort; Menge, Folge, Quelle und Ziel kommen aus der gemeinsamen Grammatik.
