# Vier Passagen mit der gemeinsamen Kompositionssprache

Die linke Seite liest jede Meisterkarte aus kurzen Bausteinen; die flüssige Zeile setzt erst danach Besitzer und Werkstattgegenstand ein.

## H2-S002 · f10r · f10r.8

**Sichtbar:** `qotchor chor otol chol cholor chol daiin dar`

**Kartenweise:**

- `qotchor` → `OT+OR` → **FOLGEANSATZ** (aus gemeinsamen Atomen vorhergesagt)
- `chor` → `OR` → **ANSATZ** (gemeinsame Meisterkarte)
- `otol` → `OT+OL` → **DANACH FORTSETZEN** (gemeinsame Meisterkarte)
- `chol` → `OL` → **FORTSETZEN** (gemeinsame Meisterkarte)
- `cholor` → `OL+OR` → **FORTGESETZTER ANSATZ** (gemeinsame Meisterkarte)
- `chol` → `OL` → **FORTSETZEN** (gemeinsame Meisterkarte)
- `daiin` → `AIIN` → **VORGABEWERT** (gemeinsame Meisterkarte)
- `dar` → `AR` → **VOM AUSGANG** (gemeinsame Meisterkarte)

**Neue flüssige Lesung:** Nimm den Folgeansatz, führe Ansatz und Fortsetzungsansatz weiter, stelle den Vorgabewert ein und entnimm ihn vom Ausgang.

**Bisherige Lesung:** Führe den bemessenen Pflanzenansatz als Folgeansatz samt seinem Fortsetzungsposten weiter und nimm daraus das Sollmaß

## H5-S001 · f56r · f56r.5|f56r.7

**Sichtbar:** `chochor cho chodaly daiin sho kchol otchor choky dal`

**Kartenweise:**

- `chochor` → `HO+OR` → **EINGANGSANSATZ** (aus gemeinsamen Atomen vorhergesagt)
- `cho` → `HO` → **EINGANGSPOSTEN** (gemeinsame Meisterkarte)
- `chodaly` → `HO+AL+Y` → **EINGANGSPOSTEN ZUM ZIEL** (aus gemeinsamen Atomen vorhergesagt)
- `daiin` → `AIIN` → **VORGABEWERT** (gemeinsame Meisterkarte)
- `sho` → `HO` → **EINGANGSPOSTEN** (gemeinsame Meisterkarte)
- `kchol` → `KCH+OL` → **WEITER BEARBEITEN** (aus gemeinsamen Atomen vorhergesagt)
- `otchor` → `OT+OR` → **FOLGEANSATZ** (aus gemeinsamen Atomen vorhergesagt)
- `choky` → `OK+Y` → **AKTUELLEN POSTEN SETZEN** (gemeinsame Meisterkarte)
- `dal` → `AL` → **ZUM ZIEL** (gemeinsame Meisterkarte)

**Neue flüssige Lesung:** Setze einen Eingangsansatz an, bringe den Eingangsposten zum Ziel, nimm den Vorgabewert, bearbeite weiter, beginne den Folgeansatz und setze den aktuellen Posten am Ziel.

**Bisherige Lesung:** Bereite einen Zutatenansatz, gib die Zutat dorthin nach Sollmass, bearbeite die naechste Zutat weiter, beginne den Folgeansatz und setze den Posten dort an.

## B1-S002 · f81v · f81v.2|f81v.7

**Sichtbar:** `okaiin kair okal sar ol kain olkain al ol rol dl olor ol sheckhal daiin qokeedal daiin chckhy schedy`

**Kartenweise:**

- `okaiin` → `OK+AIIN` → **AUF VORGABEWERT SETZEN** (aus gemeinsamen Atomen vorhergesagt)
- `kair` → `LOCAL_WHOLE` → **BECKENWASSER** (lokale Ganzkarte)
- `okal` → `OK+AL` → **AM ZIEL SETZEN** (gemeinsame Meisterkarte)
- `sar` → `AR` → **VOM AUSGANG** (gemeinsame Meisterkarte)
- `ol` → `OL` → **FORTSETZEN** (gemeinsame Meisterkarte)
- `kain` → `AIN` → **ANTEIL** (aus gemeinsamen Atomen vorhergesagt)
- `olkain` → `OL+AIN` → **WEITERER ANTEIL** (aus gemeinsamen Atomen vorhergesagt)
- `al` → `AL` → **ZUM ZIEL** (gemeinsame Meisterkarte)
- `ol` → `OL` → **FORTSETZEN** (gemeinsame Meisterkarte)
- `rol` → `OL` → **FORTSETZEN** (aus gemeinsamen Atomen vorhergesagt)
- `dl` → `LOCAL_WHOLE` → **ZUSATZ** (lokale Ganzkarte)
- `olor` → `OL+OR` → **FORTGESETZTER ANSATZ** (gemeinsame Meisterkarte)
- `ol` → `OL` → **FORTSETZEN** (gemeinsame Meisterkarte)
- `sheckhal` → `LOCAL_WHOLE` → **KURZ ZUR ZIELSTELLE DURCHLEITEN** (lokale Ganzkarte)
- `daiin` → `AIIN` → **VORGABEWERT** (gemeinsame Meisterkarte)
- `qokeedal` → `LOCAL_WHOLE` → **DORT LÄNGER HALTEN** (lokale Ganzkarte)
- `daiin` → `AIIN` → **VORGABEWERT** (gemeinsame Meisterkarte)
- `chckhy` → `LOCAL_WHOLE` → **DURCHLEITEN** (lokale Ganzkarte)
- `schedy` → `CHD+CLOSE` → **ÜBERTRAGEN; SCHLUSS** (aus gemeinsamen Atomen vorhergesagt)

**Neue flüssige Lesung:** Setze den Vorgabewert, setze das Beckenwasser am Ziel an, nimm vom Ausgang, führe weiter, gib Anteil und weiteren Anteil zum Ziel, halte dort länger, übertrage und schließe.

**Bisherige Lesung:** Stelle das Sollmass ein, setze den Posten dort an, gib die weiteren Portionen und den Zusatz zu, fuehre den Ansatz weiter, leite kurz zur Zielstelle durch, stelle das Sollmass ein, halte dort laenger, leite durch, setze um und schliesse.

## B3-S032 · f83r · f83r.22

**Sichtbar:** `chedain chedy qotedaiin otaiin otedy`

**Kartenweise:**

- `chedain` → `CHD+AIN` → **ANTEIL ÜBERTRAGEN** (aus gemeinsamen Atomen vorhergesagt)
- `chedy` → `CHD+Y` → **AKTUELLEN POSTEN ÜBERTRAGEN** (gemeinsame Meisterkarte)
- `qotedaiin` → `OT+E+AIIN` → **KURZER FOLGEWERT** (aus gemeinsamen Atomen vorhergesagt)
- `otaiin` → `OT+AIIN` → **FOLGEWERT** (aus gemeinsamen Atomen vorhergesagt)
- `otedy` → `OT+E+CLOSE` → **KURZE FOLGE; SCHLUSS** (aus gemeinsamen Atomen vorhergesagt)

**Neue flüssige Lesung:** Übertrage einen Anteil und den aktuellen Posten, setze den kurzen Folgewert und den Folgewert, führe die kurze Folge aus und schließe.

**Bisherige Lesung:** Setze eine Portion um, stelle ein kurzes Folgemass und danach das Folgemass ein, fuehre die kurze Folge aus und schliesse.
