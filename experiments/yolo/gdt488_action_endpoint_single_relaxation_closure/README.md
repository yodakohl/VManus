# GDT488 — Einmal gelockerte Aktionsendpunkte

Status: `HALTEN_CYCLE_CLOSED__EINSTELLEN_REMAINS_CAPACITY_LIMITED`

GDT488 sucht für die beiden verbliebenen GDT487-Endpunkte nach einem zweiten
Kontrast, wobei jeweils nur eine GDT486-Bedingung gelockert wird. `HALTEN`
erhält einen vollständigen Alternativzyklus über `BAHN`; `EINSTELLEN` besitzt
in den vorhandenen 183 Events keinen zweiten lokalen Ersatzpartner.

Die vollständige lesbare Ausgabe steht in
`artifacts/GDT488_ACTION_ENDPOINT_SINGLE_RELAXATION_CLOSURE.md`. Methode und
Ergebnis sind in `METHOD.md` und `REPORT.md` zusammengefasst.
