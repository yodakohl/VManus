# Sidequest Pass 631: five freely composed branch orders

## Result

The current workshop deck can compose a new six-card order for each of the five
complete Herbal-to-Biological cases. All thirty visible forms and exact cards
already occur on the fixed ten pages. No complete order occurs in the source,
yet every order reads back to its intended instruction and the existing early
selector assigns all five to the intended case.

This is the strongest practical evidence so far that the working system is not
only a list of memorized manuscript lines. A learner can reuse old cards in new
orders while preserving a recognizable case branch.

|---|---|---|---|
| C1 | `qokaiin os lsho qokal shey shedy` | Set prescribed amount; choose the work compartment; run the washing step at the target; hold longer; settle and close. | `OS=ARBEITSFACH` |
| C2 | `cthy cthaiin qoctholy ches qokal qokeeedy` | Ready the item and prescribed amount; continue the prepared operation; take off briefly and divide; set at target; close at full grade. | `CTH=BEREIT` three times |
| C3 | `cfhy cphy qokaiin qokal shey shedy` | Wring out; pour in; set by prescribed amount at the target; hold longer; settle and close. | `CFH=AUSWRINGEN` |
| C4 | `qokaiin qokain ykan qokal qokylddy talam` | Dose prescribed amount, portion, and subsequent portion; set at target; fasten and close; store. | `AN=NACHPORTION` |
| C5 | `cho qokaiin kchoar chodaly daiiin shedy` | Take an ingredient; set prescribed amount; take another ingredient from stock to the target; set the second stage; settle and close. | `HO=ZUTAT` |

These are deliberately apprentice exercises, not newly claimed Voynich
sentences. Their value is that they force the dictionary and grammar to do
something generative.

## What was actually reused

- 30/30 steps use an already attested exact card.
- 30/30 use an already attested visible surface.
- Each selected surface maps to exactly one current exact card.
- 30/30 backward readings recover the intended card and command.
- 5/5 complete six-card sequences are absent from the 381 source events.
- 24/25 adjacent card pairs are also absent from the source; only the C2
  `CTH+AIIN -> CTH+OL+Y` transition is already attested.
- 5/5 cases are selected correctly from the first five cards.
- New words, cards, surfaces, pages, and Astro labels: zero.

The very high bigram novelty is useful here. The strips are not source phrases
with one token swapped. They are mostly new local joins made from the shared
module inventory.

## Working grammar implied by the exercise

The five strips can be taught with the same loose workshop order:

1. optionally announce the case-specific material, operation, or state;
2. establish amount/portion;
3. choose source, work compartment, or target;
4. perform or continue the operation;
5. hold, settle, fasten, or advance the stage;
6. close or store the result.

The order is not a rigid six-slot sentence. C1 and C3 delay their decisive
operation until after the amount in ordinary prose, but move it forward in the
exercise to advertise the branch. C5 begins with its ingredient marker. This
suggests that branch cues behave more like movable headings or construction
prompts than inflexible grammatical prefixes.

## Current interpretation

Keep the mixed model:

- a small productive command/component vocabulary;
- learned exact cards for common instructions and exceptional contents;
- a movable case cue within the early part of the instruction;
- a shared dose/address/operation/state/close skeleton;
- a small renderer manual plus sixteen residual memorized surface entries.

The next useful exercise is to move each branch cue through several licensed
early positions while holding the other five cards fixed. If the same case and
instruction remain readable, the cue is a true movable workshop selector. If
not, its position is part of the learned construction.
