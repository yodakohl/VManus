# GDT389 artifacts

- `gdt389_pre_image_freeze.json`: exact page universe, review order, outcomes,
  access rules, gates, and claim ceiling.
- `gdt389_pre_image_freeze_validation.json`: independent freeze validation.

- `gdt389_image_manifest.tsv` / `gdt389_image_mapping.json`: guarded official
  Yale page-to-canvas mapping.
- `gdt389_review_image_hashes.tsv`: hashes of the 50 directly reviewed
  allow-listed 1600-pixel images; no image bytes are committed.
- `gdt389_page_observations.tsv`: all 61 page-screen outcomes in frozen order.
- `gdt389_ambiguous_candidates.tsv`: the 14 connector-rich pages retained as
  unresolved rather than converted to negatives.
- `gdt389_eligible_edge_packet.tsv`: empty eligible edge packet.
- `gdt389_capacity_gates.tsv`: two acquisition-integrity passes and seven
  failed endpoint/capacity gates.
- `gdt389_access_log.json`: direct-review and sealed-access accounting.
- `gdt389_result.json` / `gdt389_validation.json`: compact result and
  independent integrity/accounting validation.
