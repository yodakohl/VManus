# Sidequest pass 677: reverse apprentice test

Twelve complete German workshop intentions, covering all eleven prose records,
were run through the manual in reverse:

> German intent → components → exact card lookup → copied surface → atomic
> readback → fluent instruction.

The selected traces contain 73 visible events. Every component, card, and
surface returns exactly because the apprentice uses the 173-card master table.
The examples include the f11r wring/fill chain, the f81v wash cycle, long Bio
passage/measure chains, and the B6 collect/cool/forward sequence.

Four deliberately new but readable recipes behave differently. Their German
meaning and component recipe can be stated, but no exact card is present in the
ten-page table. The apprentice must stop at lookup; no surface is invented.
This sharpens the working theory: semantic composition is productive, visible
card realization is exemplar-bound.
