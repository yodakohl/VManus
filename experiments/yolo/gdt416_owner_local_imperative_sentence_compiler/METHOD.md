# GDT416 method

## Question

Can the reversible register readings be converted into a complete, readable
imperative edition without adding sentence-sized word meanings?

## Inputs

GDT415 supplies all 4,576 event readings and 715 owner-bound statements.
GDT412 supplies the structural category and portable value of each core;
GDT413 supplies the complete control/local-sign inventory. No other page,
image, or transcription is admitted.

## Method

Each visible card is assigned one of eleven small clause templates. Explicit
actions and arguments retain source order. When a card omits an action or
argument, the last active value may be carried only inside the same physical
page and frozen visible owner; every such use is written to a separate audit.
Order, relation, grade, local sign, and close remain separate phrase parts.
The source recipe and portable back-projection are retained beside every
imperative clause.

## Decision rule and claim ceiling

The output is a fluent working paraphrase, not recovered syntax or plaintext.
Inherited material is an explicit workshop-state hypothesis. No imperative
word form is promoted to a Voynich lexeme.
