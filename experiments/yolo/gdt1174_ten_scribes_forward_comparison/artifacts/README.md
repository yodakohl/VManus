# Vollständige Konstruktionsartefakte

RESULT.json enthält alle Kennzahlen, Leser und Grenzen. SYSTEM_01.txt bis SYSTEM_10.txt enthalten alle künstlichen Ausgaben einschließlich Definitionen und Steuerwörtern. SOURCE_MESSAGES.json und EXAMPLES.json bewahren vollständige Nachrichten und Beispiele. VALIDATION.json bestätigt technische Nachrechnungen, keine Voynich-Bedeutung. REGISTRATION_LOCK.json bindet die vor der Zählung lokalen Regeln.
