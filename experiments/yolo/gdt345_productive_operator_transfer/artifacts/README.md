# GDT345 artifacts

- `gdt345_design.json`: frozen models, smoothing, splits, gate, and null.
- `gdt345_operator_inventory.tsv`: descriptive aggregate operator census.
- `gdt345_transition_inventory.tsv`: source/target-state and operator IDs.
- `gdt345_lofo_folds.tsv`: physical-folio held scores.
- `gdt345_transfer_folds.tsv`: section/register/hand held scores.
- `gdt345_model_scores.tsv`: aggregate LOFO comparison and gate fields.
- `gdt345_null.tsv`: fixed-prediction max-two null.
- `gdt345_counterexamples.tsv`: sparse, unstable, and access negatives.
- `gdt345_result.json`, `gdt345_validation.json`: compact result and audit.
