# Method

## Inputs

- GDT416's 4,576 imperative clauses, including exact component recipes,
  register, page, owner and inherited-context flags;
- GDT413's fixed 46-component working dictionary.

No transcription, image or page outside the existing 26-page edition is read.

## Procedure

1. Select the seven GDT417 recipes that occur in all five registers and are
   fully self-contained.
2. Enumerate every attested recipe at token edit distance one from each anchor.
3. Separately generate only role-preserving action, argument and grade
   substitutions, grade deletion/insertion, and final `Y→DY` closure.
4. Compare each attested neighbour inside the same page-owner where possible.
5. Preserve every unattested cell as a conditional future reading: if the
   visible composition appears later, its root-sum is fixed in advance.

The resulting German delta is not independent proof of a lexeme: it follows
from the current dictionary by construction. The nontrivial result is which
cells actually exist, recur across registers, and coexist under the same
owner, and which apparently legal operations are absent.
