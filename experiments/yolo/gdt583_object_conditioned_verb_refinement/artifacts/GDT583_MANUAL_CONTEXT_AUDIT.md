# GDT583 manual context audit

Three independent passes were reconciled before the rule deck was compiled:

1. a `T` pass inspected all 384 slots and separated register, grade-host and
   immediate action-direction readings;
2. a `CHD/S/SH` pass checked the complete governor hosts against GDT507 and
   GDT510–512, including remote inherited arguments;
3. a passage pass read all twenty complete GDT582 inspection statements and
   supplied the separate editorial reader channel.

The strongest common conclusion was that fine verbs are contextual
subreadings, not replacements for the portable root values. The `T` pass found
repeated `T→SH` and `SH→T` directions; the passage pass independently rejected
assigning cooling or drying from a grade/form marker alone. The combined deck
therefore admits direction only from immediate action order.

The two physical-object passes differed deliberately in boldness. One favored
local `S+AIIN=seihen`, dry `CHD=zerreiben` and bath-owner `SH=baden`; the passage
pass warned that none carries as a universal stem value. GDT583 retains the
useful verbs only below the fixed host conditions and phrases Biological `SH`
as “im Bad halten beziehungsweise baden,” not as portable `SH=baden`.
