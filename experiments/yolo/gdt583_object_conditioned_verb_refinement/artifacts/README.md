# GDT583 artifacts

- `gdt583_context_rule_deck.tsv` — the 29 ordered, executable context rules.
- `gdt583_target_occurrence_assignments.tsv` — all 1,921 target slots with
  direct/complete hosts, neighbors, rule and subreading.
- `gdt583_refined_event_edition.tsv` — the 1,623 affected running events.
- `gdt583_refined_local_card_edition.tsv` — the 158 affected local cards.
- `gdt583_affected_statement_edition.tsv` — all 591 affected statements.
- `gdt583_20_refined_passage_edition.tsv` — exact and editorial channels for
  the fixed twenty passages.
- `GDT583_REFINED_PASSAGES.md` — readable twenty-passage book.
- `gdt583_semantic_inventory.tsv` — placement of the concrete working senses.
- `gdt583_result.json` and `gdt583_validation.json` — compact counts, hashes
  and the independent 25-check rederivation.

The large occurrence/event/statement tables are retained because they are the
reproducible proof that every narrowed verb remains attached to its original
slot and governor and that no broad string replacement silently changes an
unrelated action.
