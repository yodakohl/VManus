# GDT1081 — native f69r wind ownership and orientation

Registered before new target pixels, 2026-09-28. Exploratory visual inspection,
not a lexical test or reserved confirmation. Historical public f69r scans and
four-class summaries were already seen by the project; this is not blind data.

## Decision note

GDT1067 proves that the existing 12-of-16 color geometry has eight exact
rotated/reflected source alignments, each paired with an equally exact
180-degree source/destination opposite. FXR001 also found no robust
outer-to-radial same-wedge formal match. IDEA649/661 require both an
independent orientation marker and a singular author-visible binding from
written item to wind direction. The truly unknown input is whether the
official native image itself contains a connector, arrow, labelled cardinal
mark or other noncolor asymmetry that earlier class summaries omitted.

If both independent orientation and singular ownership are visible, the next
research decision changes to a separately registered complete text test; no
wind word is assigned here. If either is absent or equivocal, retain the
GDT1067 stop and do not mine the exposed labels for another orientation.
Smallest adequate test: inspect the whole f69r panel once at native resolution,
enumerate all sixteen outer sectors, all twelve colored spokes, all
radial text loci and all possible cardinal/start cues; crop only this page if
needed. Time budget 70 minutes, including registration, source retrieval,
manual annotation, validation and publication. At the limit stop expansion.

## Frozen evidence and decision rule

Record for all 16 outer angular sectors whether a physical ink leader or
arrow makes a unique connection to one colored spoke or radial text item;
record all 12 spoke endpoints and all radial inscription components. Bare
angular closeness, color matching, equal counts and painted bands do not
qualify as connectors. Record all visible orientation candidates, including
cardinal letters/words in independently readable script, differentiated
sunrise/sunset icon, an unequivocal arrowhead or start marker. A painted
direction without an external named bearing is insufficient. Any damaged,
clipped or ambiguous locus is marked uncertain, never guessed.

`BOTH_GATES_VISIBLE` requires (1) an unambiguous authorial named bearing or
equivalent independently identified east/west event that breaks the
GDT1067 antipodal pair, and (2) unambiguous ink ownership for a written
outer or radial item to that bearing. Otherwise `NO_LEXICAL_REOPENING`.
Describe any weaker partial observations separately, without lowering gates.
Even BOTH_GATES_VISIBLE is only capacity: a later full-register test would
still have to resolve reader uncertainty, morphology, provenance, held-folio
capacity, and complete rival words. No p-value, dictionary update, language,
plaintext or translated wind name follows from this image alone.
