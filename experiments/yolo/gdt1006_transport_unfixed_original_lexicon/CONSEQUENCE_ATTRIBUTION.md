# Derive syntax versus world contribution from the same finite coverage

Declared before public registration and the first free-code run. No new target,
probe, model or selection is required. For each of the11projected words, compare
its values among all evaluated syntactic maps with its values among saved
coherent tuples. Keep these domains as witnessed-only if the residual syntax
space is not exhausted and independently confirmed.

Coverage proof: an exact map/parse block removes only a map that has been fully
evaluated, whose projected word tuple is therefore already observed. A positive
projection block removes only other maps sharing that same observed word tuple
and meaning variant. Neither operation can remove a previously unseen projected
word tuple. Final residual UNSAT therefore proves completeness of the observed
syntax projections as well as the retained coherent projections. In the initial
grammar the32meaning settings are unconstrained, so each observed syntactic
word tuple pairs with all32settings. This is a finite coverage theorem, not a
search-wide significance test or a semantic interpretation of the grammar.

A world-invariant role that is already syntax-invariant has no additional
identifying contribution from physical meaning. Any domain reduction supplies
only a conditional source-model consequence. Singleton dictionaries and parses
inside covered tuples remain unenumerated. No additional word confirmation.
