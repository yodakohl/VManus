# GDT499 method

## Question

Which of the 352 visibly composed GDT498 cells have the strongest complete-cell
support, which observed cells support them exactly, and which compositions form
the finite old-values-only frontier?

## Inputs

- the complete 495-cell GDT498 action/frame/register matrix;
- the compact GDT498 result, used only as a source-count drift guard.

No manuscript page or transcription is opened. The experiment works entirely
from the already published GDT498 inventory.

## Method

1. Retain the 143 exact observed cells and 352 `COMPOSED_WORKING` cells as
   separate source sets.
2. For every composition, collect all exact observed cells with the same frame
   and register but another action head. Also collect exact cells with the same
   frame and action head in another register.
3. Retain the four GDT498 support classes: at least two local heads, one local
   head, cross-register same-action support, or old component values only.
4. Rank first by support class, then by descending local head/event count,
   descending cross-register cell/event count, absence of repeated action
   roots, component count, recipe and register.
5. Publish every support relation with its source matrix cell, event IDs,
   pages, selected clause and all clause forms. Publish exact tier subsets,
   frame/action summaries, and a separate repeated-action queue.

## Decision rule and claim ceiling

The priority atlas may identify a productive working layer only when complete
observed neighbor cells exist. Component-value support alone remains the
weakest tier. Ranking never changes a cell from `COMPOSED_WORKING`, changes no
root value, and predicts neither manuscript spelling nor occurrence. The
witness tables are repeated support relations, not independent observations.
