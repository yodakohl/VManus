# GDT239 — f82r translation-shaped page dossier

## Purpose

Assemble one concrete nonsealed q13 page from already published layers rather
than assigning another isolated substring gloss.  f82r is selected because the
human catalogue supplies a complete 45-locus census, 13 exact graphical labels,
paired lateral structures, and one label explicitly on a component.

## Inputs and separation

The dossier joins only f82r rows from the source-bound human page/exact-locus
annotations, every available f82r row in the GDT229 selected-record field
lattice, the GDT233 q13 prefix
decomposition, and the seven GDT237 fold-stable prefixes.  Each file is streamed
through an f82r whitelist before payload retention.

GDT229 covers only eight of the 32 human-catalogued prose loci on this page;
that partial coverage is a primary output, not silently promoted to a full-page
parse. Human visible descriptions, source-native formal structures, provisional
document roles, and interpretations remain separate columns.  Proximity is not
ownership.  The source catalogue's three paragraphs and the parser's one
mechanical record key are both retained rather than silently equated.
