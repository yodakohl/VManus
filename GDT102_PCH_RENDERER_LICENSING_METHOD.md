# GDT102 — `PCH` host-edge renderer licensing

## Question

Within the postselected GDT101 `PCH` factor grid, does the PAGE_HOST tail
transferably constrain the following HPR2 renderer (`DY`, RIGHT_FAMILY, or no
renderer), and does it carry information beyond ordinary final-character
statistics?

No semantic or linguistic role is assigned.

## Panel and seal

Use the 181 non-f84r exact grid groups frozen in GDT101:

`{EMPTY,o,y} + pch + {EMPTY,e,ed,ey,d,y}`.

f84r is filtered before retention and is not opened, queried, joined, scored,
or targeted.

## Outcomes

- `COARSE`: `DY`, `RIGHT`, or `BARE`.
- `DETAIL`: `DY`, `BARE`, or the observed RIGHT_FAMILY value.

The classes are formal HPR2 render states, not meanings.

## Predictors tried

All four variants are logged:

1. register only;
2. six-level inspected PAGE_HOST tail;
3. final PAGE_HOST source character;
4. exact PAGE_HOST.

Each source group is scored with its entire physical folio removed. Counts use
Jeffreys smoothing. An unseen feature backs off to the target register's
training distribution. The primary comparison is tail versus final character;
the latter is the relevant low-capacity string baseline.

The same predictors are also trained on Herbal-B and applied to Recipe/Stars-B,
then in the reverse direction. This is a register-transfer diagnostic, not an
independent manuscript replication.

## Interpretation

A tail gain over register only supports renderer licensing. It supports a
factor layer beyond elementary string statistics only if it also beats the
final-character baseline. Exact-host transfer does not by itself imply
semantics. GDT003 remains the controlling composition/string comparison.

## Claim ceiling

Formal renderer licensing only; no word, morpheme, POS, sound, language,
plaintext, semantic role, gloss, meaning, or translation.
