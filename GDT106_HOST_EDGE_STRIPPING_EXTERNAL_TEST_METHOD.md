# GDT106 — host-edge stripping external-information test

## Question

GDT105 identifies the final PAGE_HOST character as a universal
renderer-licensing edge state. Does removing or separating that state increase
the archived external object/relation signal, as a clean
`CONTENT_ADDRESS + EDGE_STATE` decomposition would predict?

## Panel and folds

Use the exact GDT103/GDT068 panel: 332 annotated loci on 19 physical folios,
eight archived axes, K=5, shrinkage=4, and complete target-folio exclusion.
The archive is exposed and correlated; this is hypothesis generation.

f84r is rejected before analysis and remains unopened, unretained, unqueried,
unjoined, unscored, and untargeted.

## Representations tried

- raw source-group character trigrams;
- full PAGE_HOST character trigrams;
- PAGE_HOST minus final one character;
- PAGE_HOST minus final two characters;
- PAGE_HOST minus first character;
- PAGE_HOST interior minus first and final characters;
- final character only;
- stripped core plus final character as a separate typed token;
- stripped core plus final two characters as a separate typed token.

All tried variants are logged. Empty residuals are retained as empty strings,
not dropped.

## Interpretation

Improvement after edge removal supports an independently content-bearing core.
Failure means the archived signal depends on the joint host surface at this
resolution. It does not show that the edge itself has a meaning: the edge can
simultaneously license rendering and participate in address identity, or the
result can reflect string-neighbour geometry.

## Claim ceiling

Formal external-signal localization only; no word, morpheme, POS, sound,
language, plaintext, semantic role, gloss, meaning, or translation.
