# GDT066 — RIGHT_FAMILY context invariance conditional on PAGE_HOST

Status: **YOLO exploratory internal-proxy test**

GDT062 showed that RIGHT_FAMILY is predicted by PAGE_HOST and register.  GDT059
did not establish that RIGHT_FAMILY is content-neutral.  GDT066 asks a narrower
question: does one exact PAGE_HOST retain its surrounding page-host ecology
when RIGHT_FAMILY changes?

Use the f84r-free GDT062 inventory.  Aggregate one unit per page × PAGE_HOST ×
RIGHT_FAMILY × wrapper × O/OT frame, removing all occurrences of the target
host from its page context.  Compare exact-host, different-RIGHT_FAMILY pairs
on different physical folios within the same register, wrapper, and frame.
Match each against different-host units with the target RIGHT_FAMILY and the
same register, wrapper, frame, host-length bucket, and page-size bucket.  Drop
pairs without a real matched control.  Cap each host×register×wrapper×frame pair
type at the 200 SHA256-smallest pairs.  Same-RIGHT_FAMILY pairs are a sensitivity
comparison, not the primary null.

Balance the headline over host×register×wrapper×frame cells.  Report register
dependence and the postselected GDT063 `d`/`ok` rows separately.  A positive
result supports only renderer invariance of an internal host key.  It cannot
establish content, semantics, or lexical meaning.  No role, gloss, word,
morpheme, POS, sound, language, plaintext, meaning, or translation is assigned.
f84r remains sealed.
