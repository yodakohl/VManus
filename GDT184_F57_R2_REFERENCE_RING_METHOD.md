# GDT184 — f57 R2 semantic-capacity reassessment

GDT179 treated R2 as a possible four-element property table. GDT184 asks a
simpler question before assigning any value: does the all-reading-stable
variation have enough capacity to identify four semantic rows?

The input is frozen GDT179 only: four repeated periods of 17 signs; exactly one
all-reading-stable changing column; state `f,f,p,p`. GDT182's multiplicity
correction is also binding. No new manuscript source or image is opened and
f84r is not accessed.

Four unique row identities require at least log2(4)=2 bits. The stable R2
profile has two states and therefore one bit. Models are ranked by whether they
need four unique row identities and whether near-exact repetition is expected.
This is an abductive capacity comparison, not a significance test.

The reference/calibration model is deliberately broad. It does not imply an
alphabet, cipher wheel, substitution key, or scribal exercise without an
independent mapping or readable analogue.
