# GDT184 — f57 R2 is better read as a repeated reference sequence

## Result

R2 contains four physical repetitions of a 17-position sequence, but only one
column changes stably across all three readings: `f,f,p,p`. Sixteen columns
supply no stable period contrast. The stable row capacity is therefore one
bit (two profiles), while four unique element identities require two bits.

This fails the strong reading “four rows individually identify Fire, Air,
Water, and Earth.” It leaves a weaker one-property table logically possible,
but its sole bit is exactly aliased among hot/cold, upper/lower page half, and
Latin masculine/feminine in the exposed comparator.

The leading generative description is now:

> **A fourfold repeated 17-position reference or calibration sequence with one
> stable binary variant.**

That description explains the extraordinary copying directly and does not ask
one bit to identify four sectors. An ornamental/scribal repetition remains a
live alternative. A cipher key or alphabet is only weak speculation because no
rotation, mapping, strict sign inventory, or readable legend has been shown.
