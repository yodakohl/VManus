# GDT054 — O/OT positional transfer to unseen host families

This tests frozen HPR-2 prediction `HPR2_P03`. GDT014 discovered a later
`OT+host` tendency on AR/AL/OL ladders. Exclude those three discovery hosts
entirely. From the f84-free GDT016 strict prose inventory, identify every other
base H for which H, O+H, and OT+H all occur. Compare normalized physical-line
position within exact base-host × page strata.

Three predeclared contrasts are tested with 20,000 deterministic conditional
permutations: H→OT+H, H→O+H, and O+H→OT+H. Report leave-one-host-out minima and
register-specific effects. Bonferroni correction covers the three contrasts.

The key falsifier is not simply a later longer string: O and OT must show
opposing directions, and the OT direction must survive every held host. A
positive result establishes a reusable positional renderer only, not a
semantic, morphological, phonological, or lexical interpretation.
