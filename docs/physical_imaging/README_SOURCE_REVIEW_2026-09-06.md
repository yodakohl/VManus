# Known imaging README: documentation review

On6September root retrieved the already catalogued
[READ ME.pdf](https://drive.google.com/file/d/1nzKNlV2BqCEz3VvheAFZ_4IULFwLExng/view)
from the public Lazarus/RIT source folder, then extracted its textual layer.
No manuscript image, thumbnail, TIFF or pixel analysis was opened. Its linked
interpretive blog was not followed. This is technical source documentation,
not a search for public decipherment approaches.

The note, signed Lisa Fagin Davis and dated9September2024, describes four
image-product folders from the2014capture session. It directs readers to
image properties and pseudocolor filenames for capture conditions. Reporting
correspondence with Easton, it describes exposure calibration using a
Spectralon reference and a3×3median operation before pseudocolor rendering.
It supplies no explicit lamp-direction assignment for the three f17rMB365UV
capture numbers used by EBA001. The correspondence is reported in the public
note; it is not an independently inspected capture log or calibration record.

This supports a more specific metadata question. EBA001's published acquisition
script exports selected standardTIFFfields, rather than an exhaustive tag
inventory. Whether additional embedded descriptive metadata identify lighting
remains untested in this review. No raw-image recalibration or new visual
comparison is authorized merely by the README.
