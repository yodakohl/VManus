# GDT332 — joint-tuple portability atlas

GDT332 inventories the manuscript reach of the opaque joint tuple that GDT326
and GDT327 identify as the current operative formal symbol.  It does not test
neighbors, glyph similarity, PAGE_HOST substrings, or meanings.

For every exact `joint_tuple_id` in the f84-free GDT327 interlinear, record:
event count, physical-folio count, page count, section/register/Currier/hand
support, executable-lexicon state, and whether it crosses folios, registers,
sections, and hands.  The same summaries are computed for opaque PAGE_HOST and
coordinate IDs as transparent capacity comparators.

The main quantities are type counts and event-weighted coverage.  An identity
is `ALL_FIVE_REGISTERS` only when observed in HERBAL_A, HERBAL_B, OTHER_A,
OTHER_B, and STARS_RECIPE_B.  `REGISTER_PRIVATE` means exactly one register.
Alternate readings are not replications.

This is a descriptive codebook architecture audit.  Recurrence does not make a
tuple a word or establish stable semantics.  No f84 row is used.
