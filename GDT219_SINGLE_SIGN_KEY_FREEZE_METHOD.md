# GDT219 — f76r single-sign diagram-key freeze

## Rationale

GDT218 found that f76r is the only page outside the GDT217 panel with both
existing label loci and confirmed-prose paragraph starts.  It cannot test the
frozen two-family rule because all nine labels are one-family source groups.

This checkpoint does not shorten or rescue GDT217.  It opens a separate
mechanism test motivated by two independent observations:

- the readable Wellcome MS 49 Wound Man uses compact single numerals, and the
  *Fasciculus medicinae* uses compact initials, to point into prose;
- f76r independently has nine source-bound one-sign label loci.

The paragraph-side family payload remains unopened at freeze time.

## Frozen prediction

Treat the nine f76r label family identities as an unordered candidate key set.
For each of the two already registered confirmed-prose paragraph starts, select
only the first source-native family of the first group.

Primary endpoint: number of the two paragraph-initial families present in the
frozen label key set (`0`, `1`, or `2`).

This is set-level linkage only.  No label is paired with a particular
paragraph, and label order is not invented.

## Frozen null

Use the 42 paragraph-initial first-family observations already public in the
GDT217 discovery inventory.  Enumerate all unordered draws of two distinct
opening occurrences without replacement.  For each draw, count how many keys
fall in the frozen f76r label set.  The exact inclusive upper tail is the
primary diagnostic.

Call `SINGLE_SIGN_KEY_SET_PROVISIONAL_LEAD` only if:

- both f76r paragraph starts fall in the label set;
- the exact empirical tail is `p <= .05`;
- the two paragraph keys are distinct;
- every selected label and paragraph family is source-native and stable in the
  frozen family view.

Otherwise report `SINGLE_SIGN_KEY_SET_NOT_SUPPORTED`.

The discovery distribution is not register-matched because GDT217 contains no
other section-T page.  This limitation prevents confirmation even if the gate
passes.

## Chronology and claim ceiling

During the GDT218 capacity audit, the nine f76r raw one-sign label surfaces
were displayed.  Their label role and one-family length were therefore known.
No f76r paragraph family, token, or key was displayed or retained.  This freeze
materializes the label-side key set and null before opening either paragraph
key.

Success would license only an f76r set-level single-sign reference lead.  It
would not identify a number, letter, ordinal, paragraph pairing, word, sound,
language, plaintext, meaning, or translation.  No f84r source or artifact is
accessed.
