# GDT015 post-resolution transition method

Status: **YOLO exploratory sequence inference**

Using the GDT014-frozen pairs `AR/OTAR`, `AL/OTAL`, and `OL/OTOL`, this pass
tests whether an OT-framed group has a different immediate field context from
its bare core.  Outcomes are previous-group DY closure, next-group DY closure,
previous-group q state, and next-group q state.

Every comparison is conditioned on core, physical page, and normalized group-
position quartile.  The exact null fixes marked-form and outcome counts inside
each stratum and convolves the stratum hypergeometric distributions.  Twelve
core-specific tests and one pooled OT-versus-bare previous-DY test are reported
with 13-test correction.  The pooled test was discovered after inspecting the
three frozen core directions and is therefore exploratory, not preregistered.

All rows are strict, all-reading-agreeing, non-f84r `CONFIRMED_PROSE` groups.
The result can refine a record-state machine only.  It cannot establish a
morpheme, sentence boundary, language, plaintext, meaning, or translation.
