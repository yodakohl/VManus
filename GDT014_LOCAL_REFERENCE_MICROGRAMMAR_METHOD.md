# GDT014 local-reference microgrammar

Status: **YOLO exploratory generative refinement**

GDT013 froze `ARO`, `TAR`, `ED`, and `KAL` as visual-role leads before this
prose-context pass.  GDT014 asks whether the `AR` lead participates in a
larger formal ladder already suggested by GDT011:

```text
CORE       O + CORE       OT + CORE
AR         OAR            OTAR
AL         OAL            OTAL
OL         OOL            OTOL
```

All strict, all-reading-agreeing, non-f84r `CONFIRMED_PROSE` groups are used.
No visual outcome is fitted here.

For the predeclared contrasts `AR→OAR`, `AR→OTAR`, `OAR→OTAR`, `AL→OTAL`,
and `OL→OTOL`, normalized group position is compared within page.  A
deterministic 20,000-draw permutation fixes page and the two form counts.
Five-test Bonferroni values are reported.  Counts of recovered outer prefix,
terminal `DY`, line-entry/final state, section, Currier, and physical folio
are descriptive compatibility constraints.

The complete corpus inventory of bases for which `H`, `oH`, and `otH` all
occur is reported to show productivity, but prior GDT003 string-null results
remain binding: this is formal generation, not proof of linguistic morphology.

Claim ceiling: a result can refine a procedural/local-reference compiler and
provisional functions for O/OT/q/DY.  It cannot establish morphemes, POS,
sounds, language, plaintext, or translation.  f84r remains sealed.
