# GDT028 direct Q/L × right-edge factorial capacity

GDT028 tests the strongest literal consequence of the GDT027 factorization.
For every Currier-B group carrying QJB/QKB or LJB/LKB, it freezes the GDT016
`residual_host`, Q/L branch, and anonymous record state. It then asks whether
one residual host realizes both branches across two or more right-edge states.

Every host × branch × state cell is counted once for combinatorial capacity,
with occurrence and physical-folio support retained separately. All 2×2 state
pairs having at least two observed cells are exported. A 3-of-4 rectangle
creates one explicit missing-cell prediction; a 4-of-4 rectangle supports
factorial combination. This is a complete census, not a significance search.

The test uses only the frozen f84r-free GDT016 inventory. It assigns no
meaning, morpheme, sound, language, plaintext, or translation.
