# GDT251 — `okal*` renderer-cluster method

GDT250 generated a provisional whole-host figure-class hypothesis from exact
`okaly`. GDT251 expands the source-surface family mechanically to every f84-
free human-annotated nonprose group beginning `okal`, then joins the already
published GDT233 transferred label prefix and GDT235 object class.

The expansion is not a semantic confirmation test. Its purpose is to decide
whether the apparent class purity belongs to a content host or to the known
graphical-label renderer. Every variant and counterexample is retained. No new
visual annotation or source row is created. No f84 input was read, retained,
joined, or scored and no new f84 access occurred.
