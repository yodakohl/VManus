# GDT215 — q13 generative-theory synthesis

## Purpose

GDT215 selects the strongest current generative theory for the q13 biological/
balneological pages.  It is an abductive YOLO synthesis, not a confirmation
test and not a translation.  It compares three broad generators:

1. compressed or abbreviated natural language;
2. semantic or technical notation;
3. a hybrid of language, abbreviation, record notation, and a diagram-local
   reference register.

The third is required to win rather than leaving the three possibilities tied.
Its provisional content prior is therapeutic balneology with an unusually
schematic hydraulic or process rendering.  That prior is explicitly weaker
than the formal architecture.

## Fixed evidence boundary

This pass reads only already published GDT reports.  It performs no new
Voynich scoring, image inspection, transcription query, feature selection, or
holdout opening.  Each input contributes a frozen positive, negative, or
instrument-calibration constraint to `gdt215_theory_evidence_matrix.tsv`.

The synthesis preserves the active reset:

- confirmed Voynich words: zero;
- plaintext clauses: zero;
- licensed semantic states: zero;
- an exact label-to-prose PAGE_HOST key dictionary is not supported;
- a stable one-referent/one-host dictionary is not supported;
- the tested simple historical-language and cipher channels fail their
  matched anonymous controls.

## Selected generator

The leading theory is
`HYBRID_MEDICAL_RECORD_COMPILER_WITH_DIAGRAM_REFERENCE_REGISTER`.

Its formal production is:

```text
PAGE := PAGE_PROFILE VISUAL_SYSTEM GRAPHICAL_LABEL_REGISTER? RECORD+
RECORD := RECORD_OPEN? RECORD_BODY+
RECORD_BODY := ENTRY_STATE? FIELD (DY_CLASS FIELD)* B3_CLASS?
FIELD := WRAPPER? INNER_D? POSITION_FRAME? PAGE_HOST RIGHT_FAMILY?
```

`PAGE_HOST` is an opaque page-conditioned address or value component, not a
word or translated stem.  The other compiler layers specify record position,
rendering, and closure without being assigned linguistic categories.  The
graphical label register is allowed to carry component, state, case, or
reference values; the current annotations do not choose among those options.

The document-level interpretation is that q13 may combine:

- a visible setting or hydraulic/process model;
- short diagram-local reference strings in a distinct construction register;
- longer practical medical records whose identity, indication, procedure,
  caution, and outcome information is not visually recoverable field by field.

This architecture permits a language-bearing payload but does not require
every source group to be an ordinary lexical word.  It also permits technical
notation but does not reduce the entire manuscript to a diagram code.

## Comparison logic

Compressed natural language alone ranks third because authentic abbreviation
can generate part of the observed architecture, while the tested static
language decoders and stable global host dictionary do not explain the full
compiler, label/prose heterogeneity, or page-conditioned rebinding.

Technical notation alone remains live but ranks second because it naturally
explains opaque addresses and label registers, yet does not by itself explain
the long record-like prose or the readable medieval medical comparators.

The hybrid ranks first because it jointly accommodates the formal compiler,
page-conditioned inventory, distinct label register, long practical records,
failed exact key dictionary, and external medical/balneological/hydraulic
document precedents.  This is explanatory compression, not a fitted score.

## Falsifiability

Five predictions are registered.  Four were not used to select the theory;
one is only partly informed by the readable-image calibration.  A prediction
may weaken one layer without forcing a repair elsewhere.  The preferred next
test requires genuinely new, source-bound evidence: either a repeated
hydraulic/setting referent with singular text ownership and held-folio
replication, or a readable q13-like diagram preserving diplomatic labels and
explanatory prose.

The six counterexamples remain unresolved costs.  More internal host mining
is not an identifying test and is not the registered next route.

## Claim ceiling and seal

GDT215 may claim only that the hybrid is the best current evidence-bounded
generator of the observed document architecture.  It establishes no bath,
water, disease, procedure, person, component, operation, word, morpheme, POS,
sound, language, cipher key, plaintext, or translation.

No manuscript image or source transcription is accessed.  No f84 artifact is
an input, output, or query.
