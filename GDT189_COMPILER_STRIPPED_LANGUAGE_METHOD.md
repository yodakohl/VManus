# GDT189 — compiler-stripped injective language screen

## Question

GDT188 proves that a fixed character substitution cannot create the visible
Voynich algebra.  Does removing the already frozen HPR2 compiler make the
remaining string layer materially more compatible with a historical language?

This is a genuinely different falsifier from mapping the visible text.  It
tests three fixed derived representations of the same confirmed-prose lines:

1. `RAW_VISIBLE`: complete visible source groups;
2. `RESIDUAL_HOST`: the GDT016 host after the outer wrapper and DY closure are
   removed; and
3. `PAGE_HOST`: the frozen HPR2 content/address candidate after B3,
   right-family, carrier-D, and licensed O/OT rendering are removed.

The sole line containing a literal unknown transcription character is removed
from every representation.  All `f84*` rows are rejected from the page/locus
prefix before parsing or retention.

## Fixed model

- physical lines reset an order-2 model;
- adjacent derived hosts retain a fixed SPACE event;
- active source signs receive an injective assignment to 26 named letters;
- six already frozen GDT001 historical language packs are scored;
- three deterministic pair-swap descents are run for each
  representation/language; and
- every retained mapping is rescored exactly by the existing CPU scorer and is
  locally optimal over all pair swaps.

Candidate overhead is `3 + U(2) + log2(6) + log2(P(26,k))` bits, where `k` is
the active derived alphabet.  The matched control is a line-reset integrated
Dirichlet-1/2 order-2 KT code over the same `k` source identities plus SPACE,
paying the common model/order overhead but no named-letter key.  Restarts are
search attempts for one key, not transmitted alternatives.

## Decision

The compiler-stripped language route remains open only if PAGE_HOST has a
negative paid gap to its matched KT control, the winning language is common to
all three starts, and all three active-sign mappings are identical.  A mere
improvement relative to raw visible text is not sufficient.

This derived-layer comparison is not a complete reversible manuscript code.
It can reject or retain an injective language substrate; it cannot establish a
sound, word, language, plaintext, or translation.  f84r is not accessed.
