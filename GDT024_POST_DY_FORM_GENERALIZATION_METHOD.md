# GDT024 post-DY form-generalization audit

GDT024 tests whether the QJB and KAL/OKAL branches isolated by GDT023 extend
past their most frequent exact target forms and across manuscript registers.
It uses only the frozen 15,592-group GDT016 inventory, which contains no f84r
row.  No canonical transcription, image, or f84r payload is opened.

For QJB, KAL, and OKAL, exact target tokens are ranked by their raw number of
post-DY occurrences.  The page + current-state + normalized-position-quartile
conditional test is repeated after removing the top 1, 2, 4, 8, and 16 tokens.
A separate tail retains only exact tokens occurring at most five times in the
feature set.  These are post-hoc robustness diagnostics, not fresh discovery
p-values.

The same association is reported within section, Currier, and hand strata.
Values with zero feature capacity remain explicit.  Finally QJB is compared
only among DY_RESOLUTION groups and KAL/OKAL only among AL_STATE groups, so a
result cannot be attributed merely to the coarse anonymous state label.

Claim ceiling: productive recurrence of an anonymous formal subtype, or
dominance by an exact whole form, within a post-checkpoint transition.  No
diagram role, referent, morpheme, word, syntax, sound, language, plaintext,
meaning, or translation is assigned.
