# GDT218 — post-score terminal-key orientation specificity

## Purpose

GDT217 selected one externally motivated orientation before scoring:
two-family label terminal to two-family paragraph initial.  GDT218 is a
post-score adversarial diagnostic, not a new confirmation test.  It asks
whether that direction is merely one attractive member of the four possible
two-family edge comparisons.

## Fixed comparisons

Use the published GDT217 inventory, 23 pages, eleven folios, and exact 432
whole-folio worlds.  Compare exactly:

1. label terminal → paragraph-initial group initial (`LT_PI`, GDT217);
2. label initial → paragraph-initial group initial (`LI_PI`);
3. label terminal → paragraph-initial group terminal (`LT_PT`);
4. label initial → paragraph-initial group terminal (`LI_PT`).

Every edge is two source-native family symbols, truncated only when the whole
source group is shorter.  Report local tails and a four-orientation maxT tail.
The max-four result is a robustness diagnostic; it does not rewrite the fact
that `LT_PI` was externally specified before GDT217 scoring.

## Untouched capacity

Mechanically enumerate every non-f84 page outside the GDT187/GDT217 panel that
has at least one GDT012 label locus and one GDT016 confirmed-prose paragraph
start.  Inspect only counts and label family lengths before any paragraph key.
An untouched transfer page must have at least one label source group of family
length two or greater, because the frozen hypothesis is explicitly a
two-family key.

Do not shorten the rule to one family merely to admit a target.

## Claim ceiling

The result may localize an edge-orientation effect and report prospective
capacity.  It cannot establish an index, numeral, letter, label-paragraph
pairing, word, language, plaintext, meaning, or translation.  No f84r source
or artifact is accessed.
