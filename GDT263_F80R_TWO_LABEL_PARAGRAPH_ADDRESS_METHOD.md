# GDT263 — f80r two-label/paragraph address method

The corrected f80r inventory contains ten ordered graphical-label loci and five
physical paragraphs. GDT263 tests the simplest untried document mapping:
labels 1–2 → P1, 3–4 → P2, ..., 9–10 → P5. This is a page-layout hypothesis,
not a claim that the labels name figures or that the paragraphs are recipes.

For each label and reading, enumerate every distinct contiguous four-member
source-native window. Search its one-member neighborhood inside all f80r prose
groups. For the predicted paragraph, compute the exact line-level
hypergeometric enrichment tail and select the best window, paying a Bonferroni
factor equal to that label's number of windows. The page score is the sum of
negative log2 adjusted tails across all ten labels.

The primary sensitivity circularly shifts every fixed prose hit mask through
all 43 physical line positions while preserving order, local clustering, line
opportunity, paragraph sizes, label windows, and the proposed 2:1 mapping. The
inclusive rank of the real alignment among 43 shifts is reported separately
for each reading. Alternate readings are sensitivities, not samples.

This is exposed hypothesis generation. Label locus order is a catalogue/source
order and some visual descriptions are between figures; it is not guaranteed
to be an authorial one-to-one figure ordinal. Only f80r/f82r-only formal data
and the corrected f80r paragraph coordinate are used. No f84r row is read and
GDT257 remains disclosed.
