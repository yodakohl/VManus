# GDT203 — Othmer MS 2 readable-apparatus acquisition audit

## Purpose

Search for new, institutionally catalogued medieval technical diagrams that
could provide the readable ordered homolog required after GDT202.  This first
acquisition tests Othmer MS 2, not by visual resemblance or Voynich strings,
but by the holding institution's source description.

This is a post-target-exposure source audit.  It is not a blind statistical
test.  A source qualifies as an exact f77 homolog only if its authoritative
description supplies all of:

1. six ordered states or inscriptions;
2. five adjacent relations;
3. four visibly active outputs and one inactive/hold relation;
4. readable authorial labels that assign values to those states or relations.

A generic apparatus, recipe, four-element discussion, or readable label is
historical context but not a homolog.

No Voynich transcription, manuscript image, or f84r material is read.
