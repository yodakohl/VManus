# GDT055 — field decomposition of the O/OT positional renderer

GDT054 establishes O-early/OT-late transfer across hosts excluded from AR/AL/OL
discovery. This follow-up localizes that effect inside the HPR-2 record.

Use only complete physical lines from the f84-free GDT016 inventory. Rebuild
fields by closing at every DY-resolution group. Keep the same 49 held ladder
bases and continue to exclude AR, AL, and OL. For H→OT+H, H→O+H, and
O+H→OT+H, test four features within exact page × base strata:

- normalized field index;
- normalized position inside the field;
- field-start status; and
- immediately-after-DY status.

Use 10,000 deterministic conditional permutations per contrast/feature and a
12-test Bonferroni correction. This is exploratory functional localization,
not semantics.
